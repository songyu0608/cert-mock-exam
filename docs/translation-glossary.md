# 번역 용어집

강의 스크립트·슬라이드를 한국어로 옮길 때 따르는 용어 규칙이다. 새 번역과 번역 수정은 모두 이 표를 따른다.

- 원본: CCAR-F 슬라이드 섹션 1–11 한국어판에 적용한 용어 교체 목록(choi, 2026-11)
- 한 줄 원칙: 개발 현장에서 굳어진 외래어(서브에이전트, 리포지토리, 컨텍스트 등)를 쓰고, 직역한 한자어는 피한다.
- 표에 없는 용어는 기존 노트의 표기를 따른다. 새 규칙이 생기면 이 파일에 먼저 추가한 뒤 번역에 쓴다.

> [!warning] 기존 이론 노트와의 차이
> `exams/*/theory/` 아래 기존 이론 노트는 이 용어집 이전에 만들어져 피해야 할 표기(예: 확신도, 인계, 병합, 보정, 맥락, 선행 조건 게이트)가 남아 있다. 기존 노트를 일괄로 고칠지는 따로 정한다.
