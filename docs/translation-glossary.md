# 번역 용어집

강의 스크립트·슬라이드를 한국어로 옮길 때 참고하는 권장 용어다. 목표는 표 준수가 아니라 자연스러운 번역이다.

- 기준: Claude 자격증 시험과 한국 개발자들이 실제로 쓰는 표현. 어색한 직역(예: 보조 에이전트, 확신도)을 피한다.
- 표는 권장안이다. 문맥상 다른 표현이 더 자연스러우면 그쪽을 쓴다.
- 출처: CCAR-F 슬라이드 섹션 1–11 한국어판에 적용한 용어 교체 목록(choi, 2026-11)

> [!caution] 뜻이 여러 개인 원어
> 아래 항목은 특정 뜻일 때만 바꾼다. 일괄 치환하지 않는다.
>
> - 저장소: Git repository일 때만 리포지토리. storage(데이터 저장 공간)는 저장소 그대로
> - 병합: Git merge일 때만 머지. 결과·데이터를 합치는 뜻이면 병합·통합이 자연스러울 수 있음
> - 보정: model/confidence calibration일 때만 캘리브레이션. 일반적인 수정·조정은 보정 그대로
> - 본문: 문제 지문일 때만. 요청 본문(request body), 메일 본문 등은 본문 그대로
> - 발견, 계층: 메모의 문맥에 따라 번역이 갈린다

> [!warning] 기존 이론 노트와의 차이
> `exams/*/theory/` 아래 기존 이론 노트는 이 용어집 이전에 만들어져 피해야 할 표기(예: 확신도, 인계, 병합, 보정, 맥락, 선행 조건 게이트)가 남아 있다. 기존 노트를 일괄로 고칠지는 따로 정한다.
