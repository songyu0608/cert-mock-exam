- 최초 검토 기준 커밋: `d063796f2136beab154416a3343d1cfde7a4566c`
- 목표: 기존 기능·화면·저장 기록을 유지하면서 미사용 코드와 중복을 줄이고 구조를 단순화한다.

## 작업 원칙

- 코드 줄 수 감소보다 동작 유지와 가독성을 우선한다. 감소율 목표는 미리 정하지 않는다.
- 삭제는 사용하지 않는다는 근거를 확보한 뒤 수행한다.
- 동적 로딩, 빌드·배포 스크립트, 테스트 전용 참조, 동적으로 조합되는 CSS 클래스도 확인한다.
- 파일 분리는 전체 코드량 감소와 별도로 평가한다. 단순히 파일을 나누기 위한 분리는 하지 않는다.
- 문항 ID, 채점 규칙, 기존 기록 형식, 동기화 동작을 유지한다.
- 학습 자료, 예외 처리, 호환성 처리, 테스트는 길거나 직접 import되지 않는다는 이유로 삭제하지 않는다.
- 기능 추가, 디자인 변경, 프레임워크 교체, 데이터 형식 변경은 이번 범위에 포함하지 않는다.

## 사전 확인한 개선 후보

| 대상                                                           | 확인 내용                                                         | 검토 방향                                   |
| -------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------- |
| `src/pages/SessionPage.tsx`, `src/components/SplitSession.tsx` | 답변 갱신, 플래그 변경, 일시정지 전환, 응답 수 계산이 반복됨      | 공통 동작을 통합하고 화면별 표현은 유지     |
| `src/pages/ExamHome.tsx`                                       | 출제 설정, 문항 선택, 통계 계산, 기록 관리, 화면 출력이 모여 있음 | 반복 필터·집계 재사용과 출제 로직 분리      |
| `src/styles.css`                                               | 여러 화면의 스타일이 한 파일에 있음                               | 미사용·중복 규칙 조사 후 필요한 부분만 정리 |
| 의존성·스크립트·기타 파일                                      | 전체 참조 관계는 아직 조사하지 않음                               | 실행·빌드·배포·테스트의 사용 여부 확인      |

위 항목은 검토 후보이며, 삭제 가능한 코드나 파일을 확정한 목록이 아니다. 배포 사이트의 실제 화면 동작은 아직 검증하지 않았다. 로컬 기준 검사 결과는 [결과 문서](./1차-리팩토링-결과.md)에 기록했다.
