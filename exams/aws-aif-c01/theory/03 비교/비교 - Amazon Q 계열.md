# 비교 - Amazon Q 계열

> [!summary] 한 줄로
> **누가 쓰나**로 구분: 개발자 → Q Developer, 직원 → Q Business, 업무 사용자 전반 → Quick, 분석가·BI → QuickSight

| 서비스 | 사용자 | 하는 일 | 트리거 |
|---|---|---|---|
| [[Amazon Q Developer]] | **개발자** | 코드 제안, 보안 스캔, 참조 추적, AWS 질문 | IDE, CodeWhisperer |
| [[Amazon Q Business]] | **직원** | 사내 데이터 기반 질의응답, 권한 반영 | 사내 문서 도우미 |
| Amazon Q Apps | 직원 | 조직 데이터로 노코드 생성형 AI 앱 | "…하는 앱을 만들어 줘" |
| [[Amazon Quick]] | **업무 사용자 전반** | 채팅·리서치·BI·Flows·Automate·Apps 통합 | 에이전틱 AI 한곳에 |
| [[Amazon QuickSight]] | 분석가 | 대시보드, BI | 시각화, KPI |
| QuickSight Q | 업무 사용자 | 자연어로 데이터 질문 | "가장 많이 팔린 제품은?" |

## 비슷한 기능, 다른 서비스
| 기능 | 개발자용 | 업무 사용자용 |
|---|---|---|
| RAG | [[Bedrock 지식 기반]] | Q Business, Quick Index |
| 워크플로 | [[Bedrock Flows]] | Quick Flows / Automate |

| 코드 리뷰 | [[Amazon CodeGuru]] | - |
