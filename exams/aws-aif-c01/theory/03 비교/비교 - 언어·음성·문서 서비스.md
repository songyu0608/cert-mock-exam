# 비교 - 언어·음성·문서 서비스

> [!summary] 한 줄로
> **입력이 무엇이고 출력이 무엇인지**만 보면 풀린다.

| 서비스 | 입력 → 출력 | 대표 트리거 |
|---|---|---|
| [[Amazon Comprehend]] | 텍스트 → 감정·엔터티·PII·주제 | 리뷰 감정 분석, PII 편집 |
| [[Amazon Translate]] | 텍스트 → 다른 언어 텍스트 | 다국어 번역, 사용자 지정 용어 |
| [[Amazon Textract]] | **문서 이미지** → 텍스트·양식·표 | 스캔 문서, 영수증, 양식 |
| [[Amazon Transcribe]] | **음성** → 텍스트 | 통화 녹음 전사, 자막, 화자 식별 |
| [[Amazon Polly]] | 텍스트 → **음성** | 음성 안내, SSML |
| [[Amazon Lex]] | 대화 → 인텐트·슬롯 → 이행 | 챗봇·음성 봇 구축 |
| [[Amazon Rekognition]] | **이미지·동영상** → 객체·얼굴·장면·텍스트 | 얼굴 비교, 콘텐츠 조정 |
| [[Contact Lens for Amazon Connect]] | 콜센터 통화 → 감정·분류·테마 | 콜센터 통화 분석 |

## 헷갈리는 짝
| 짝 | 구분 |
|---|---|
| Transcribe vs Polly | 음성→텍스트 / 텍스트→음성 |
| Textract vs Comprehend | 문서에서 **글자 뽑기** / 글의 **의미 분석** |
| Rekognition vs Textract | 사진 속 사물·간판 / 양식·표 문서 |
| Lex vs Contact Lens | 챗봇 **만들기** / 통화 **분석** |
| Comprehend vs Translate | 언어 **감지** / 언어 **변환** |
| Comprehend vs Macie | 텍스트 속 PII / **S3 버킷** 속 PII |

## 조합 문제 (파이프라인)
- 다국어 고객 통화 분석: Transcribe → Translate → Comprehend
- 스캔 계약서의 감정·엔터티: Textract → Comprehend
- 텍스트 답변을 음성으로 주는 봇: Lex (+ Polly)

## 세부 기능 키워드
| 키워드 | 서비스 |
|---|---|
| 대상 감정, Comprehend Medical | Comprehend |
| 사용자 지정 용어(CSV·TMX) | Translate |
| 화자 식별, 채널 식별, 사용자 지정 어휘, 통화 분석, HIPAA | Transcribe |
| 어휘집, SSML, 음성 마크 | Polly |
| 인텐트, 슬롯, 자동 챗봇 디자이너 | Lex |
| Custom Labels, Kinesis Video Streams | Rekognition |
