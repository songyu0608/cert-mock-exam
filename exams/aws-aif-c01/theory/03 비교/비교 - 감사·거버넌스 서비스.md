# 비교 - 감사·거버넌스 서비스

> [!summary] 한 줄로
> **누구의 문서인가**(AWS / 내 환경 / 내 모델)와 **무엇을 기록하나**(API / 구성 / 프롬프트)로 구분한다.

| 서비스 | 무엇을 | 키워드 |
|---|---|---|
| [[AWS CloudTrail]] | **누가 어떤 API를** 호출했나 | API 호출 기록, 사용자 활동 감사 |
| [[AWS Config]] | 리소스 **구성과 그 변화** | 구성 이력, 규칙 준수 평가 |
| [[AWS Audit Manager]] | **내 환경의 감사 증거** 자동 수집 | 감사 준비 자동화 |
| [[AWS Artifact]] | **AWS의** 규정 준수 보고서(SOC, ISO, PCI) | 보고서 다운로드 |
| [[AWS Trusted Advisor]] | 모범 사례 점검·권고 | 비용·보안·한도 점검 |
| [[Amazon Inspector]] | 취약점 지속 스캔 | CVE, NVD 위험 점수 |
| [[Amazon CloudWatch]] | 지표·로그·경보 | 성능 모니터링 |
| Bedrock 모델 호출 로깅 | **프롬프트와 응답 내용** | CloudWatch Logs 또는 S3 |

## 헷갈리는 짝
| 짝 | 구분 |
|---|---|
| CloudTrail vs Config | API **활동** vs 리소스 **구성** |
| CloudTrail vs CloudWatch | 감사(누가) vs 성능(얼마나) |
| Artifact vs Audit Manager | AWS 보고서 vs 내 증거 |
| 모델 카드 vs AI 서비스 카드 | 내 모델 vs AWS 서비스 |
| CloudTrail vs 모델 호출 로깅 | API를 호출했다는 사실 vs 프롬프트·응답 내용 |
