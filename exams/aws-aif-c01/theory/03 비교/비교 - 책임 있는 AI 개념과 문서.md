# 비교 - 책임 있는 AI 개념과 문서

> [!summary] 한 줄로
> 투명성 = **어떻게**, 설명 가능성 = **왜**, 해석 가능성 = **내부까지**.

## 개념
| 개념 | 질문 | 구현·예 |
|---|---|---|
| **투명성** | 모델이 **어떻게** 결정하나 | 투명한 문서, 모델 카드, AI 서비스 카드 |
| **설명 가능성** | **왜** 이 결과가 나왔나 | SHAP, LIME, 반사실적 설명, PDP / Clarify |
| **해석 가능성** | 사람이 원인을 이해하는 정도 (**내부 가중치까지**) | 선형 회귀, 의사 결정 트리 |
| **제어 가능성** | 입력 데이터를 바꿔 모델을 얼마나 제어하나 | 데이터 증강, 훈련 제약 |
| **모델 안전성** | 사회·개인 정보·보안상 해를 끼치지 않나 | 가드레일. 투명성과 충돌 |
| **공정성** | 집단 간 부당한 차이가 없나 | Clarify 편향 지표 |
| **진실성·견고성** | 예상 못한 입력에도 올바른가 | 자동 평가(견고성) |

## 트레이드오프
- 해석·제어가 쉬울수록 성능은 낮은 경향: 선형 회귀 → 의사 결정 트리 → 딥 러닝
- 안전성 ↔ 투명성: 개인 정보를 숨기면 설명이 어려워짐
- 투명성이 지나치면 약점이 악용되기 쉬움

## 설명 가능성 기법
| 기법 | 설명 |
|---|---|
| **SHAP** | 특징별 기여도(섀플리 값 근사) |
| 섀플리 값 | 게임 이론 기반 기여도. 시계열은 비대칭 섀플리 값 |
| **PDP** | 특징 값이 바뀔 때 예측 변화 |
| LIME | 국소적으로 단순 모델로 근사해 설명 |
| 반사실적 설명 | 특징이 달랐다면 결과가 어떻게 바뀌었을까 |
