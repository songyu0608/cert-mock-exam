# Amazon Inspector

> [!summary] 한 줄 정의
> AWS 워크로드의 **소프트웨어 취약점과 의도치 않은 네트워크 노출**을 계속 스캔하는 서비스

## 시험 트리거
- "알려진 취약점(CVE) 스캔"
- "EC2·컨테이너·Lambda 취약점 평가"
- "열린 네트워크 경로 탐지"

## 주요 기능
- 알려진 CVE, 악용 가능한 코드, 약한 암호화, 열린 네트워크 경로를 지속 스캔
- NVD 기반 위험 점수
