# Bedrock 가드레일

> [!summary] 한 줄 정의
> FM의 **입력(프롬프트)과 출력(응답)을 모두** 필터링해 유해 콘텐츠, 금지 주제, 개인 식별 정보(PII)를 막는 안전장치

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 유해 콘텐츠·특정 주제 차단 | **가드레일** |
| 응답에서 PII 제거 또는 마스킹 | **가드레일(민감 정보 필터)** |
| 프롬프트 주입(탈옥) 방어 | **가드레일(프롬프트 공격 필터)** |
| 응답이 제공된 컨텍스트에 근거하는지 점검, 환각 감지 | **컨텍스트 근거 검사** |

## 주요 기능
- 콘텐츠 필터: 혐오, 모욕, 성적, 폭력, 부정행위, 프롬프트 공격 (강도 조절)
- 거부할 주제(주제 필터), 단어 필터(욕설 차단)
- 민감 정보 필터: PII 제거·마스킹, 정규식
- 차단 시 사용자에게 보낼 메시지 지정
- **컨텍스트 근거 검사**: 근거성(컨텍스트와 일치) + 관련성(질의와 관련)
- 에이전트와 지식 기반에도 적용 가능
