# SageMaker Experiments

> [!summary] 한 줄 정의
> ML 작업(실험)을 정리·기록하고 서로 비교·검색하는 기능

## 시험 트리거
- "여러 훈련 실험의 결과를 기록하고 비교"
- "모델 개선 전략 수립, 성능 트레이드오프 테스트"

## 주요 기능
- 실험 정리, 기록, 비교, 검색
- [[SageMaker Clarify]]와 함께 설명 가능성(SHAP)
- 불필요한 훈련 아티팩트 정리에도 활용

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[SageMaker Model Registry]] | 배포할 모델 버전 관리 |
| [[SageMaker Debugger]] | 훈련 중 문제 탐지 |
