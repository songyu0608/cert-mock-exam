# Amazon QuickSight

> [!summary] 한 줄 정의
> 서버리스 **BI(비즈니스 인텔리전스)** 서비스로 대시보드와 시각화를 만든다. QuickSight Q는 자연어로 데이터 질문에 답한다

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 대시보드, KPI, BI 시각화 | **QuickSight** |
| "올해 가장 많이 팔린 제품은?"처럼 자연어로 데이터 질문 | **QuickSight Q** |

## 주요 기능
- 데이터 원본: Redshift, Aurora·RDS, Athena, EC2의 DB, S3·온프레미스 파일(Excel, CSV), Salesforce 같은 SaaS, JDBC/ODBC
- 데이터 준비 단계에서 제한적 ETL
- QuickSight Q: 데이터셋에 연결된 **토픽** 설정 필요, 필드 이름을 NLP 친화적으로, 날짜 처리 정의
- 현재는 [[Amazon Quick]] 안의 Quick Sight로 제공

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon Quick]] | QuickSight가 진화한 업무용 에이전틱 AI |
| [[Amazon SageMaker]] Canvas | 노코드 ML 예측. QuickSight는 시각화·분석 |
