# AWS Security Hub

> [!summary] 한 줄 정의
> 여러 보안 서비스의 **결과를 한 대시보드에** 모으고 자동 플레이북을 실행하는 서비스

## 시험 트리거
- "모든 보안 결과를 한곳에서"
- "보안 상태 중앙 집중 관리"

## 주요 기능
- GuardDuty, Inspector, Macie 등의 결과 통합
- 자동 대응 플레이북
- 심층 방어 6층(위협 탐지·사고 대응)

## 헷갈리는 서비스

| [[AWS Trusted Advisor]] | 모범 사례 점검·권고 |
