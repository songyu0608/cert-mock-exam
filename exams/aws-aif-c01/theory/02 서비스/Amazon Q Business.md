# Amazon Q Business

> [!summary] 한 줄 정의
> **조직 데이터**(문서, 위키, 앱)를 바탕으로 직원 질문에 답하고 작업을 돕는 생성형 AI 업무 도우미. Q Apps로 노코드 앱도 만든다

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 사내 문서 기반으로 직원 질문에 답하는 도우미 | **Q Business** |
| 조직 데이터로 노코드 생성형 AI 앱을 만들고 공유 | **Q Apps** |
| 사용자가 원래 볼 수 있는 문서만 답변 | **Q Business** (권한 인식) |

## 주요 기능
**Q Business**
- 기업 데이터 원본에 연결해 RAG 방식으로 답변, 출처 인용
- 사용자 권한(ACL) 반영, 관리자 제어
- 플러그인으로 외부 앱 작업 실행

**Q Apps**
- "…하는 앱을 만들어 줘"라고 입력하면 생성 (사실상 시스템 프롬프트 지정)
- 입력·출력 카드로 레이아웃 구성 (파일 업로드 등)
- Q Apps 라이브러리에 게시, 복사해 수정

**요금(강의 기준)**
- Lite: 사용자당 월 $3, 채팅만
- Pro: 사용자당 월 $20, Q Apps·QuickSight의 Q·사용자 지정 플러그인 포함
- 인덱스 단위(문서 2만 개 또는 200MB)당 시간 과금 — 금방 커질 수 있음
