# Amazon Fraud Detector

> [!summary] 한 줄 정의
> 과거 사기 데이터로 모델을 만들어 **온라인 사기 위험**을 평가하는 서비스

## 시험 트리거
- "신규 계정 사기, 비회원 결제, 체험 악용, 온라인 결제 위험 평가"

## 주요 기능
- 과거 사기 데이터 업로드 → 템플릿 선택 → 모델 생성 → API로 제공

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon GuardDuty]] | AWS 계정·워크로드의 보안 **위협** 탐지. Fraud Detector는 비즈니스 거래 사기 |
