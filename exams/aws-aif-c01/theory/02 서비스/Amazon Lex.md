# Amazon Lex

> [!summary] 한 줄 정의
> 음성·텍스트 **대화형 챗봇**을 만드는 서비스. Alexa와 같은 기술 기반이며 인텐트 중심으로 설계한다

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 고객 문의 챗봇·음성 봇 구축 | **Lex** |
| 사용자가 원하는 행동 | **인텐트(의도)** |
| 의도를 수행하는 데 필요한 정보 (날짜, 객실 유형) | **슬롯** |
| 기존 대화 전사본으로 봇 설계 자동 생성 | **Lex 자동 챗봇 디자이너** |

## 주요 기능
- 구성: 발화 → 인텐트 → 슬롯 → 이행(Lambda 함수)
- 배포: AWS Mobile SDK, Facebook Messenger, Slack, Twilio
- 자동 챗봇 디자이너: 전사본에서 인텐트·슬롯 추출, Amazon Connect 전사본 연동
