# Bedrock 프롬프트 관리

> [!summary] 한 줄 정의
> 재사용할 프롬프트를 **저장·버전 관리**하고 변수로 입력을 받아 여러 앱이 공유하게 하는 기능

## 시험 트리거
- "프롬프트 템플릿을 저장해 재사용"
- "프롬프트 버전 관리"
- "변수(자리 표시자)로 사용자 입력 전달"

## 주요 기능
- 변수는 이중 중괄호: 예) `{{도시}}에서 보낼 {{일수}}일짜리 일정`
- 프롬프트 변형: 모델·추론 구성별 버전 비교
- 콘솔의 Prompt Builder로 실험
- 도구·캐싱을 프롬프트에 연결
- 배포한 프롬프트를 [[Bedrock Flows]] 안에서 사용

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Bedrock Flows]] | 프롬프트를 이어 붙인 워크플로 |
| [[Bedrock 가드레일]] | 입출력 안전 필터 |
