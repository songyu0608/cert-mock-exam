# AWS IAM

> [!summary] 한 줄 정의
> 누가(사용자·역할) 어떤 AWS 리소스에 어떤 작업을 할 수 있는지 **인증과 권한을 관리**하는 서비스

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 사용자·앱·서비스의 AWS 접근 권한 제어 | **IAM** |
| EC2나 SageMaker 같은 서비스에 임시 권한 부여 | **IAM 역할** |
| 권한이 지나친 계정·역할·리소스 찾기 | **IAM Access Analyzer** |
| 필요한 최소한의 권한만 부여 | **최소 권한 원칙** |

## 주요 기능
- IAM 사용자·사용자 그룹: 자체 자격 증명, 비교적 장기적
- IAM 역할: 보통 임시, 사람이 아닌 서비스에도 부여
- IAM 정책: 사용자나 역할에 붙이는 구체적인 권한
- Access Analyzer: 외부와 공유되거나 과도한 권한 탐지
- 심층 방어 2층(아이덴티티·접근 관리)과 7층(정책·절차) 담당
- 단기 자격 증명 사용 권장
