# Amazon Polly

> [!summary] 한 줄 정의
> **텍스트를 자연스러운 음성으로** 바꾸는 뉴럴 텍스트 음성 변환(TTS) 서비스

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 텍스트를 사람 같은 음성으로 | **Polly** |
| 특정 단어의 발음 지정 (약어 풀어 읽기) | **어휘집(Lexicon)** |
| 강조, 속삭임, 말하는 속도, 쉼 제어 | **SSML** |
| 입 모양 애니메이션과 동기화 | **음성 마크** |

## 주요 기능
- 다양한 음성과 언어
- 어휘집, SSML(음성 합성 마크업 언어), 음성 마크

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon Transcribe]] | 반대 방향: 음성 → 텍스트 |
| [[Amazon Lex]] | 대화형 봇 (음성 출력에 Polly 사용 가능) |
