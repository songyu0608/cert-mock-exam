# Amazon Rekognition

> [!summary] 한 줄 정의
> 이미지·동영상에서 **객체, 장면, 얼굴, 텍스트, 부적절한 콘텐츠**를 인식하는 컴퓨터 비전 서비스

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 사진 속 객체·장면·얼굴 인식 | **Rekognition** |
| 부적절한 이미지 자동 감지 | **Rekognition 콘텐츠 조정(모더레이션)** |
| 두 얼굴이 같은 사람인지 | **얼굴 비교** |
| 유명인 식별 | **유명인 인식** |
| 우리 회사만의 부품·로고를 적은 이미지로 인식 | **Rekognition Custom Labels** |
| 양식·표가 있는 문서에서 텍스트 추출 | [[Amazon Textract]] |

## 주요 기능
**기능**
- 객체·장면 탐지, 얼굴 분석·속성, 얼굴 비교, 자체 얼굴 컬렉션
- 유명인 인식, 이미지 속 텍스트(간판 등), 콘텐츠 조정
- 동영상: 타임라인 표시, 사람 동선 추적

**세부 사항**
- 이미지는 S3 또는 바이트로 (S3가 더 빠름)
- 얼굴 인식 품질: 조명, 각도, 눈 노출, 해상도
- 동영상은 Kinesis Video Streams (H.264, 초당 5~30프레임, 해상도 우선)
- Lambda로 업로드 시 자동 분석

**Custom Labels**
- 레이블 붙인 **소량의 이미지**로 훈련
- 예: 공장 부품 불량 유형, 선반의 자사 상품 로고
