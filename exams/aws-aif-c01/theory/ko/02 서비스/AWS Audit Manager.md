# AWS Audit Manager

> [!summary] 한 줄 정의
> 하이브리드·멀티 클라우드를 포함해 **감사 증거 수집을 자동화**하고 증거 무결성을 보장하는 서비스

## 시험 트리거
- "감사 증거 자동 수집"
- "규정 준수 감사 준비 자동화"

## 주요 기능
- 사전 구축 프레임워크(예: 생성형 AI 모범 사례)로 통제 평가
- 증거 무결성 보장
