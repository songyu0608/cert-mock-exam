# SageMaker 모델 카드

> [!summary] 한 줄 정의
> **내가 만든 모델**의 의도한 용도, 위험 등급, 훈련 세부 정보를 문서로 남기는 거버넌스 도구

## 시험 트리거
- "자사 모델의 용도·위험·훈련 정보를 문서화"
- "투명성 확보, 모델 거버넌스"
- 함께 나오는 **모델 대시보드**: "운영 중인 모든 모델의 동작을 한곳에서"

## 주요 기능
- 모델 카드: 의도한 용도, 위험 등급, 훈련 세부 정보
- 모델 대시보드: 운영 중 모든 모델의 동작 개요
- ML 거버넌스 3종: [[SageMaker Role Manager]], 모델 카드, 모델 대시보드
- 데이터 계보 도구로도 소개됨
