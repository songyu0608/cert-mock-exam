# Amazon Translate

> [!summary] 한 줄 정의
> 딥 러닝 기반 **기계 번역** 서비스

## 시험 트리거
- "웹사이트·문서를 여러 언어로 번역"
- "브랜드명·고유 명사는 번역하지 않거나 정해진 번역으로" → **사용자 지정 용어**

## 주요 기능
- 신경망 기계 번역
- **사용자 지정 용어**: CSV 또는 TMX 형식으로 등록
