# AWS PrivateLink

> [!summary] 한 줄 정의
> VPC에서 AWS 서비스로 **인터넷을 거치지 않고** 비공개로 연결하는 서비스

## 시험 트리거
- "퍼블릭 인터넷에 노출하지 않고 VPC에서 Bedrock 호출"
- "민감한 훈련 데이터를 비공개 네트워크로"
- "인터페이스 VPC 엔드포인트"

## 주요 기능
- 트래픽이 AWS 네트워크 안에만 머무름
- Bedrock 미세 조정 데이터 보호에 VPC와 함께 사용
- S3는 게이트웨이 VPC 엔드포인트로 특정 버킷만 접근 가능

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| Amazon VPC | 논리적으로 격리된 가상 네트워크 자체 |
| [[AWS KMS]] | 데이터 암호화 |
