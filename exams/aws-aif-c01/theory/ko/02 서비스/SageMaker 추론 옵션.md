# SageMaker 추론 옵션

> [!summary] 한 줄 정의
> 훈련한 모델을 서비스하는 4가지 방식(실시간, 서버리스, 비동기, 배치 변환)과 안전한 배포 기능

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 짧은 지연 시간, 즉시 응답 | **실시간 추론** |
| 간헐적 트래픽, 콜드 스타트 감수, 유휴 비용 없애기 | **서버리스 추론** |
| 큰 페이로드, 처리 수 분, 대기열 | **비동기 추론** |
| 대량 데이터를 한꺼번에, 엔드포인트 불필요 | **배치 변환** |

## 안전한 배포
- **배포 가드레일(블루/그린)**: 한 번에 전부 / **카나리**(소량 먼저) / **선형**(같은 간격 단계), 자동 롤백
- **섀도 테스트**: 새 모델을 운영 모델과 비교, 콘솔에서 승격 시점 결정
- A/B 테스트
- 추가 옵션: 추론 파이프라인, 다중 모델·다중 컨테이너 엔드포인트, 자동 확장, Inference Recommender(적정 크기)
