# Amazon GuardDuty

> [!summary] 한 줄 정의
> 계정과 워크로드에서 **수상하거나 무단인 행동을 감시**하는 지능형 위협 탐지 서비스

## 시험 트리거
- "비정상적인 API 호출, 악의적인 활동 탐지"
- "지속적인 위협 탐지"

## 주요 기능
- 심층 방어 6층(위협 탐지·사고 대응)
- 대응은 Lambda와 EventBridge로 자동화
