# Amazon Macie

> [!summary] 한 줄 정의
> ML로 **S3에 저장된 민감 데이터**(PII, PHI, 금융 정보)를 찾아내는 데이터 보안 서비스

## 시험 트리거
- "S3 버킷에서 PII 탐지"
- "훈련 데이터에 개인 정보가 있는지 확인"
- "민감 데이터 검색·분류"

## 주요 기능
- S3의 PII, 개인 건강 정보(PHI), 금융 정보 스캔
- DB 데이터는 S3 데이터 레이크로 내보내면 검사 가능

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon Comprehend]] | **텍스트** 내 PII 식별·편집 (NLP) |
| [[Bedrock 가드레일]] | FM 입출력의 PII 마스킹 |
| [[Amazon Inspector]] | 소프트웨어 **취약점** 스캔 |
