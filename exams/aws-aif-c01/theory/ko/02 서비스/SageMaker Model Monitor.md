# SageMaker Model Monitor

> [!summary] 한 줄 정의
> 운영 중인 모델의 품질과 데이터 드리프트를 **지속적으로 감시**하고 알림을 주는 기능

## 시험 트리거
- "운영 중 입력 데이터 분포가 훈련 때와 달라짐(데이터 드리프트)"
- "배포 후 모델 성능 저하를 감지하고 알림"
- "허용 정확도를 벗어날 때만 재훈련"

## 주요 기능
- 실시간 엔드포인트 또는 정기 배치 작업을 대상으로 감시
- 감시 유형(AWS 문서 기준, 보충): 데이터 품질, 모델 품질, 편향 드리프트, 특징 기여도 드리프트
- 적대적·악의적 활동 방어, 환경 간 스큐 점검에도 활용
- 재훈련 파이프라인([[SageMaker Pipelines]])과 연결
