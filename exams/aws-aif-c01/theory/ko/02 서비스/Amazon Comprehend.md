# Amazon Comprehend

> [!summary] 한 줄 정의
> 텍스트에서 **감정, 엔터티, 핵심 구, 언어, 주제, PII**를 뽑아내는 자연어 처리(NLP) 서비스

## 시험 트리거
| 문제 속 표현 | 정답 |
|---|---|
| 고객 리뷰·소셜 미디어의 감정 분석 | **Comprehend** |
| 텍스트에서 사람·장소·날짜(엔터티) 추출 | **Comprehend** |
| 문서에서 PII 식별·편집(가림) | **Comprehend** |
| 의료 기록에서 정보 추출 | **Comprehend Medical** |
| 문서 이미지에서 글자·표 추출 | [[Amazon Textract]] |

## 주요 기능
- 추출: 핵심 구, 엔터티, 감정, 언어, 구문, 주제(토픽 모델링), 이벤트
- 문서 분류, **대상 감정**(특정 엔터티에 대한 감정)
- PII 식별과 편집
- 내 데이터로 사용자 지정 훈련 (사용자 지정 분류·엔터티)
- 입력: 소셜 미디어, 이메일, 웹 페이지, 문서, 전사본

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon Textract]] | 문서 **이미지**에서 글자·양식·표를 뽑음. Comprehend는 뽑은 **글의 의미** 분석 |
| [[Amazon Translate]] | 번역. Comprehend는 언어 **감지** |
| [[Amazon Macie]] | **S3**의 민감 데이터 탐지. Comprehend는 텍스트 PII |
