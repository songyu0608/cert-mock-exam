# Amazon Textract

> [!summary] 한 줄 정의
> 스캔 문서에서 **텍스트, 양식(키-값), 표**까지 추출하는 ML 기반 OCR 서비스

## 시험 트리거
- "스캔한 문서·영수증·양식에서 데이터 추출"
- "표와 양식 필드 인식"
- "수작업 데이터 입력 자동화"

## 주요 기능
- 단순 OCR을 넘어 양식 필드와 표 구조까지 인식

## 헷갈리는 서비스
| 비교 대상 | 차이 |
|---|---|
| [[Amazon Comprehend]] | 추출한 **글의 의미**(감정·엔터티) 분석 |
| [[Amazon Rekognition]] | 사진 속 사물·얼굴·간판 글자 |
