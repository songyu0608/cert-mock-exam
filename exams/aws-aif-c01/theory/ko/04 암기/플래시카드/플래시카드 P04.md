# 플래시카드 P04

> [!info] 이론: [[P04 Amazon SageMaker]] · 카드 37장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

SageMaker 훈련 작업에 지정하는 4가지는?::훈련 데이터 S3 URL, 컴퓨팅 리소스, 결과 저장 S3 URL, 훈련 코드 ECR 경로

SageMaker 알고리즘이 흔히 쓰는 데이터 형식은?::RecordIO / Protobuf

데이터 전처리를 위한 SageMaker 처리 작업은?::SageMaker Processing (S3 → 처리 컨테이너 → S3)

ML용 시각적 IDE는?::SageMaker Studio

ML 실험을 기록·비교·검색하는 기능은?::SageMaker Experiments

알고리즘 선택·전처리·튜닝을 자동화하는 AutoML은?::SageMaker Autopilot

Autopilot이 지원하는 데이터 형식은?::테이블 형식의 CSV 또는 Parquet

Autopilot이 지원하는 문제 유형은?::이진 분류, 다중 클래스 분류, 회귀

Autopilot에서 추천 모델을 고르는 곳은?::모델 리더보드

Autopilot 자동 모드는 언제 HPO, 언제 앙상블?::100MB 초과면 HPO, 미만이면 앙상블

Autopilot 앙상블 모드가 쓰는 라이브러리는?::AutoGluon (스태킹 앙상블)

Autopilot의 설명 가능성은 어디서?::SageMaker Clarify 통합, SHAP

ML 경험 없는 비즈니스 분석가가 코드 없이 예측하려면?::SageMaker Canvas

Studio 안에서 300가지 이상 변환으로 데이터를 준비하는 도구는?::SageMaker Data Wrangler

Data Wrangler에서 준비한 데이터로 빠르게 모델을 훈련해 보는 기능은?::Quick Model

사전 훈련된 오픈 소스 모델 150개 이상을 클릭 한 번으로 쓰는 허브는?::SageMaker JumpStart

Feature Store의 온라인 스토어와 오프라인 스토어 차이는?::온라인은 저지연 실시간(PutRecord/GetRecord), 오프라인은 S3 배치(Athena 등)

Feature Store에서 특징을 묶는 단위는?::특징 그룹 (레코드 식별자, 특징 이름, 이벤트 시간)

감사와 규정 준수를 위해 ML 워크플로 이력을 남기는 기능은?::SageMaker ML Lineage Tracking

계보를 계정 간에 공유하려면?::AWS RAM과 연동

간헐적 트래픽, 콜드 스타트 감수 → 어떤 추론 옵션?::서버리스 추론

큰 페이로드, 수 분 처리 → 어떤 추론 옵션?::비동기 추론

데이터 세트 전체를 한꺼번에, 엔드포인트 불필요 → 어떤 추론 옵션?::배치 변환

일부 트래픽만 먼저 새 모델로 옮기는 배포는?::카나리

같은 간격 단계로 조금씩 옮기는 배포는?::선형

새 모델을 운영 모델과 비교하고 승격 시점을 직접 정하는 기능은?::섀도 테스트

엣지 장치 소프트웨어 에이전트로 Neo 모델을 쓰는 기능은?::SageMaker Edge Manager

희소한 클릭·추천 데이터용 알고리즘은?::Factorization Machines

표 형식 데이터의 강력한 기본 선택 알고리즘은?::XGBoost

번역·요약·음성→텍스트 알고리즘은?::Seq2Seq

1차원 시계열 예측 알고리즘은?::DeepAR

단어 임베딩(Word2vec)과 텍스트 분류 알고리즘은?::BlazingText

주제 모델링 알고리즘 두 가지는?::Neural Topic Model, LDA (비지도)

경계 상자로 객체를 찾는 이미지 알고리즘은?::객체 탐지

픽셀 단위로 분류하는 이미지 알고리즘은?::시맨틱 분할

이상 탐지 알고리즘은?::Random Cut Forest (RCF)

수상한 IP 로그인을 찾는 알고리즘은?::IP Insights
