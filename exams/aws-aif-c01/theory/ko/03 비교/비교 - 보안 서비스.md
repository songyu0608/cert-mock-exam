# 비교 - 보안 서비스

> [!summary] 한 줄로
> **데이터(암호화·탐지) / 접근(권한·인증) / 네트워크 / 위협 대응** 네 묶음으로 외운다.

| 묶음 | 서비스 | 한 줄 | 트리거 |
|---|---|---|---|
| 데이터 | [[AWS KMS]] | 암호화 키 관리 | 저장 시 암호화, 고객 관리형 키 |
| | [[Amazon Macie]] | S3 민감 데이터 탐지 | S3의 PII·PHI |
| | ACM | 인증서 | 전송 중 암호화(TLS) |
| 접근 | [[AWS IAM]] | AWS 리소스 권한 | 최소 권한, 역할 |
| | IAM Access Analyzer | 과도한 권한 탐지 | 외부 공유·과도 권한 |
| | [[SageMaker Role Manager]] | ML 페르소나 역할 | 데이터 과학자 역할 |
| | [[Amazon Cognito]] | 앱 최종 사용자 인증 | 로그인·가입 |
| 네트워크 | [[AWS PrivateLink]] | 인터넷 없이 비공개 연결 | VPC에서 Bedrock |
| | [[AWS WAF]] | 웹 요청 필터 | 봇, SQL 주입 |
| | [[AWS Shield]] | DDoS 방어 | DDoS |
| 위협 대응 | [[Amazon GuardDuty]] | 위협(이상 행동) 탐지 | 수상한 API 호출 |
| | [[Amazon Inspector]] | 취약점 스캔 | CVE, 열린 포트 |
| | [[Amazon Detective]] | 사고 원인 조사 | 포렌식 |
| | [[AWS Security Hub]] | 결과 통합 대시보드 | 한곳에서 보안 상태 |
| AI 전용 | [[Bedrock 가드레일]] | FM 입출력 필터 | 프롬프트 주입, PII 마스킹 |

## 헷갈리는 짝
| 짝 | 구분 |
|---|---|
| GuardDuty vs Inspector | **이상 행동** vs **취약점** |
| GuardDuty vs Detective | **탐지** vs **조사** |
| Macie vs Comprehend | **S3** 속 PII vs **텍스트** 속 PII |
| IAM vs Cognito | AWS 리소스 접근 vs 앱 사용자 로그인 |
| WAF vs Shield | 웹 요청 필터 vs DDoS |
| WAF vs 가드레일 | HTTP 요청 vs 프롬프트·응답 **내용** |

## 공동 책임 모델
- 고객: 데이터, IAM, 암호화 설정, 모델에 넣는 데이터 → **클라우드 안**
- AWS: 하드웨어, 데이터 센터, 네트워크 → **클라우드 자체**
