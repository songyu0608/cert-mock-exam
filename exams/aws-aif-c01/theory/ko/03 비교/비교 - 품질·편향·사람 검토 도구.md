# 비교 - 품질·편향·사람 검토 도구

> [!summary] 한 줄로
> **언제(훈련 전 / 운영 중)** 와 **누가(기계 / 사람)** 로 나눈다.

| 도구 | 시점 | 하는 일 | 주체 |
|---|---|---|---|
| [[SageMaker Ground Truth]] | 훈련 **전** | 훈련 데이터 **레이블링**, RLHF 순위 | 사람 |
| [[SageMaker Clarify]] | 훈련 전·후 | **편향 탐지**, **설명 가능성(SHAP)**, FM 평가 | 기계 |
| [[SageMaker Data Wrangler]] | 훈련 전 | 데이터 준비, **편향 바로잡기**(언더·오버샘플링, SMOTE) | 기계 |
| [[SageMaker Debugger]] | 훈련 **중** | 훈련 문제(기울기 소실 등) 탐지 | 기계 |
| [[SageMaker Model Monitor]] | **운영 중** | 데이터·모델 품질, 편향 드리프트, 특징 기여도 드리프트 | 기계 |
| [[Amazon Augmented AI]] | **운영 중** | 신뢰도 낮은 예측을 **사람이 검토** | 사람 |
| [[Bedrock 가드레일]] | 운영 중(실시간) | 유해 콘텐츠·PII 차단, 근거성 검사 | 기계 |
| Bedrock 모델 평가 | 모델 선택 시 | 자동 평가(정확도·유해성) / 인적 평가(브랜드 보이스) | 둘 다 |

## 문제 속 표현 → 정답
| 표현 | 정답 |
|---|---|
| 데이터 세트에 특정 성별이 적은지 확인 | Clarify |
| 어떤 특징이 예측에 가장 기여했나 | Clarify (SHAP) |
| 부족한 집단 데이터를 늘려 균형 | Data Wrangler |
| 배포 후 입력 분포가 바뀜(드리프트) 알림 | Model Monitor |
| 신뢰도 낮은 결과만 사람이 확인 | A2I |
| 이미지에 사람이 레이블을 붙임 | Ground Truth |
| 챗봇이 유해한 답을 못 하게 | 가드레일 |

> [!warning] 함정
> Clarify는 편향을 **보고**만 한다. 고치는 건 Data Wrangler. A2I는 **운영 중**, Ground Truth는 **훈련 데이터**.
