# 비교 - 배포 전략과 추론 옵션

> [!summary] 한 줄로
> **어떻게 서비스하나**(추론 옵션 4가지)와 **어떻게 새 모델로 바꾸나**(배포 전략)를 구분한다.

## SageMaker 추론 옵션 → [[SageMaker 추론 옵션]]
| 옵션 | 지연 시간 | 트래픽 | 페이로드·처리 시간 | 비용 특징 |
|---|---|---|---|---|
| **실시간** | 가장 짧음 | 꾸준함 | 작음 | 항상 켜진 엔드포인트 |
| **서버리스** | 콜드 스타트 있음 | **간헐적** | 작음 | 유휴 비용 없음 |
| **비동기** | 수 분까지 | 대기열 | **큼, 오래 걸림** | 대기열로 처리 |
| **배치 변환** | 해당 없음 | 없음(오프라인) | **대량 데이터 세트** | 엔드포인트 불필요 |

## 새 모델로 바꾸는 전략
| 전략 | 방식 |
|---|---|
| 블루/그린 한 번에 | 전부 옮기고 지켜본 뒤 기존 플릿 종료 |
| **카나리** | **일부 트래픽 먼저** |
| **선형** | **같은 간격 단계**로 조금씩 |
| A/B 테스트 | 두 모델에 트래픽을 나눠 비교 |
| **섀도 테스트** | 새 모델이 운영 트래픽 복사본을 받아 비교, **사용자에게는 응답 안 함**, 승격 시점 직접 결정 |
- 배포 가드레일은 **자동 롤백** 지원

## Bedrock 요금 방식 (추론)
| 방식 | 언제 |
|---|---|
| 온디맨드 | 약정 없이 쓴 만큼 |
| 배치 | 실시간 불필요, **50% 저렴**, 결과는 S3 |
| 프로비저닝된 처리량 | 처리량 보장, 1~6개월 약정, **사용자 지정 모델 호출** |
