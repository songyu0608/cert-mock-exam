# 사용법

## 1. 보관함 열기
1. 받은 zip 파일의 압축을 푼다 → `AIF-C01` 폴더가 나온다
2. Obsidian 실행 → **보관함 관리 → 폴더를 보관함으로 열기** → `AIF-C01` 폴더 선택
3. [[00 대시보드]]를 연다. 자주 쓰면 파일 메뉴(⋯)에서 **북마크**해 두면 편하다

> [!tip] 대시보드를 시작 화면으로
> 설정 → 핵심 플러그인에서 "시작 페이지"류 기능을 쓰거나, 커뮤니티 플러그인 **Homepage**를 설치해 `00 대시보드`를 지정할 수 있다 (선택 사항).

## 2. 폴더 구성
| 폴더 | 내용 | 언제 보나 |
|---|---|---|
| `00 대시보드` | 전체 목차 | 시작할 때 |
| `01 이론` | 파트별 해설 10개 | 강의와 함께 1회독 |
| `02 서비스` | 서비스 카드 65개 | 이론을 읽다가 링크로 |
| `03 비교` | 헷갈리는 서비스·개념 비교 10개 | 파트를 끝낸 뒤 |
| `04 암기` | 역색인, 분류표, 공식, 알고리즘 표, 플래시카드 | 반복 복습 |
| `05 참고` | 이 문서 | |

## 3. 노트 안의 표시
| 표시 | 뜻 |
|---|---|
| `[[링크]]` | 누르면 해당 노트로 이동. Ctrl/Cmd를 누른 채 올리면 미리 보기 |
| 💡 **tip** 상자 | 시험 포인트 |
| ⚠️ **warning** 상자 | 헷갈림 주의, 함정 |
| ❓ **question** 상자(접힘) | 셀프 체크. 눌러서 답 확인 |
| 노트 맨 위 속성 | 분류, 파트, 도메인, 중요도 |

- 서비스 카드의 **중요도**: 상(자주 출제) / 중 / 하(가끔)
- **덱: N번 슬라이드** = 슬라이드 해설 덱의 번호

## 4. 찾기
- **빠른 전환**(Ctrl/Cmd + O): 노트 이름이나 별칭으로 이동. 예) `A2I`, `RAG`, `CodeWhisperer`를 쳐도 해당 카드가 나온다 (aliases 설정)
- **검색**(Ctrl/Cmd + Shift + F): 본문 전체 검색
- **태그**: 왼쪽 태그 창에서 `분류/Bedrock`, `분류/보안`, `책임있는AI` 등으로 모아 보기
- **그래프 뷰**: 서비스끼리 어떻게 연결되는지 한눈에

## 5. 플래시카드 (Spaced Repetition 플러그인)
플러그인 없이도 `질문::답` 형식이라 그냥 읽을 수 있다. 플러그인을 쓰면 복습 시점을 자동으로 잡아 준다.

### PC 설치
1. 설정 → **커뮤니티 플러그인** → **제한 모드 끄기**
2. **찾아보기** → `Spaced Repetition` 검색 → 설치 → **활성화**
3. 오른쪽 사이드바의 카드 아이콘 또는 명령 팔레트(Ctrl/Cmd + P) → "Review flashcards"
4. 덱은 `flashcards/P01` ~ `flashcards/P10`으로 나뉜다. 답을 보고 **Hard / Good / Easy** 중 하나를 누른다

### 휴대폰 설치 (iOS·Android)
1. Obsidian 앱에서 보관함을 연 뒤 왼쪽 위 메뉴 → 설정(톱니)
2. 커뮤니티 플러그인 → 제한 모드 끄기 → 찾아보기 → Spaced Repetition 설치·활성화
3. 명령 팔레트 → "Review flashcards"

> [!warning] 알아 둘 점
> - 플러그인은 **기기마다** 설치한다 (Obsidian Sync 등으로 설정 폴더까지 동기화하면 함께 넘어간다)
> - 복습하면 카드 줄 끝에 `<!--SR:...-->` 같은 **복습 기록 주석**이 붙는다. 지우지 말 것
> - 두 기기에서 **동시에** 복습하면 동기화 충돌이 날 수 있다. 한쪽에서 끝낸 뒤 다른 기기를 연다

## 6. 동기화 (선택)
| 방법 | 특징 |
|---|---|
| Obsidian Sync | 유료, 가장 간단, 플러그인 설정까지 동기화 |
| iCloud Drive | iPhone + Mac이면 무료. 보관함을 iCloud의 Obsidian 폴더에 둔다 |
| Google Drive 등 | Android는 추가 앱(예: 동기화 도구)이 필요할 수 있다 |

## 7. 더 나아가기 (선택)
- **Bases**(Obsidian 1.9 이상 핵심 기능): `02 서비스` 폴더를 표로 만들어 `분류`·`중요도` 속성으로 필터·정렬할 수 있다. 새 베이스를 만들고 "폴더가 02 서비스인 파일" 필터를 걸면 된다
- **Dataview**(커뮤니티 플러그인): 쿼리로 목록을 자동 생성. 이 보관함은 Dataview 없이도 모든 표가 보이도록 정적 표로 만들었다
