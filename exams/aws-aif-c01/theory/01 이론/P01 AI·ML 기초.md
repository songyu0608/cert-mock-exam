# P01 AI·ML 기초

> [!abstract] 이 파트에서 배우는 것
> AI, 기계 학습, 딥 러닝, 생성형 AI의 관계 → 학습 방식 4가지 → 모델 평가와 과적합 → 신경망(CNN·RNN) → 트랜스포머와 생성 모델
> 관련 시험 도메인: **D1 AI 및 ML 기초(20%)**, **D2 생성형 AI 기초(24%)**

---

## 1. AI ⊃ 기계 학습 ⊃ 딥 러닝 ⊃ 생성형 AI

| 개념 | 정의 | 예 |
|---|---|---|
| **인공지능(AI)** | 인간의 학습·추론·판단 능력을 기계로 구현하는 가장 넓은 개념. 규칙 기반 시스템, 기계 학습, 로보틱스를 모두 포함 | 전문가 시스템 |
| **기계 학습(ML)** | 규칙을 일일이 프로그래밍하지 않고 **데이터로 알고리즘을 훈련**해 예측·결정을 내리는 AI의 하위 집합. 경험이 쌓일수록 성능 향상 | XGBoost, 의사 결정 트리, PCA |
| **딥 러닝(DL)** | 여러 층으로 쌓은 **심층 신경망**으로 대규모 데이터의 복잡한 패턴을 학습 | CNN, RNN |
| **생성형 AI** | 기존 데이터와 닮은 **새 콘텐츠**(텍스트, 이미지, 음악)를 만드는 분야. 트랜스포머와 LLM이 기반 | GPT, Claude |

### AI 분류 체계
- **전문가 시스템**: 사람이 정의한 if-then 규칙으로 판단. 데이터로 학습하지 않으므로 **ML이 아니다**
- **고전적 ML**: XGBoost, 의사 결정 트리, 회귀, 클러스터링
- **딥 러닝(신경망)**: CNN(컴퓨터 비전), RNN(시계열), MLP(다층 퍼셉트론)
- **생성형 AI**: GAN, 대규모 언어 모델(LLM), 확산 모델(이미지), 멀티모달 모델

> [!warning] 헷갈림 주의
> 규칙 기반 전문가 시스템은 AI이지만 기계 학습은 아니다. "데이터로 학습하는가?"가 ML을 가르는 기준이다.

## 2. 학습 방식

### 지도 학습 (Supervised Learning)
- **레이블(정답)이 있는 데이터**로 훈련한 뒤, 새 데이터의 레이블을 예측
- 레이블은 사람이 붙이거나 과거 데이터에서 얻는다 → 사람이 붙이는 작업은 [[SageMaker Ground Truth]]
- 예: 이미지 인식, 대출 연체 예측, 혈액 검사 결과로 건강 예측, 카드 거래 사기 판별
- **회귀도 지도 학습이다**
  - 선형 회귀: 과거 값으로 **수치** 예측 (직선. 곡선을 쓰면 다항 회귀)
  - 로지스틱 회귀: **참/거짓(이진 분류)** 예측

> [!tip] 시험 포인트
> "레이블이 지정된 데이터", "과거의 정답 데이터" → **지도 학습**

### 지도 학습 모델 평가
- **훈련 세트 / 테스트 세트 분할**(예: 80% / 20%): 훈련 세트로만 훈련하고 테스트 세트로 예측해 실제 값과 비교 (R² 등)
  - 두 세트 모두 다양한 변형과 이상치를 담을 만큼 커야 하고, 반드시 **무작위로** 나눈다
  - 한계: 표본이 작거나 두 세트가 우연히 비슷하면 과적합이 여전히 생길 수 있다
- **K-폴드 교차 검증**: 데이터를 무작위로 K개 폴드로 나누고, 한 폴드를 테스트용으로 남긴 채 나머지로 훈련 → 테스트 폴드를 바꿔 가며 반복 → **점수를 평균**. 과적합을 한층 더 막는다

### 비지도 · 자기 지도 · 강화 학습
| 방식 | 핵심 | 예 |
|---|---|---|
| **비지도 학습** | 레이블 없이 데이터 자체의 구조를 찾음 | **K-평균 클러스터링**: 중심점 K개 무작위 선택 → 가장 가까운 중심에 할당 → 중심 재계산 → 할당이 안 바뀔 때까지 반복 |
| **자기 지도 학습** | **데이터가 곧 레이블** | LLM(다음 단어 예측), 번역(번역문의 다음 단어), 멀티모달(설명으로 이미지 예측) |
| **강화 학습** | 시행착오, **보상과 벌점** | 팩맨: "상태 + 행동"의 가치(Q 값)를 예측해 가장 좋은 행동 선택 → [[AWS DeepRacer]] |

### 학습 방식별 대표 알고리즘
- 지도: 회귀, XGBoost, 신경망, 의사 결정 트리, K-최근접 이웃(KNN), 나이브 베이즈
- 비지도: K-평균, 오토인코더, 주성분 분석(PCA)
- 자기 지도: GPT, BERT, DALL-E

> [!tip] 시험 포인트
> - 레이블 없이 비슷한 것끼리 묶기 → **K-평균(비지도)**
> - 특징 수 줄이기(차원 축소) → **PCA(비지도)**
> - 대량 텍스트로 사전 훈련한 언어 모델 → **자기 지도 학습**

## 3. 모델 적합도: 과소적합과 과적합

| 상태 | 설명 | 편향·분산 |
|---|---|---|
| **과소적합** | 모델이 너무 단순해 패턴을 못 잡음 | **높은 편향** |
| 적절한 적합 | 처음 보는 데이터에도 잘 일반화 | 균형 |
| **과적합** | 훈련 데이터의 잡음까지 외워 새 데이터에서 성능 저하 | **높은 분산** |

- 과적합의 징후: **훈련 정확도는 높은데 테스트·평가 정확도는 낮다**
- **정규화(Regularization)**: 과적합을 막는 기법들을 통틀어 부르는 말
- 평가에는 훈련·검증·테스트 세트를 나눠 쓴다

### 편향(Bias)과 분산(Variance)
- 편향: 예측값 평균이 실제 정답에서 얼마나 떨어져 있나
- 분산: 예측값들이 얼마나 흩어져 있나
- **오류 = 편향² + 분산**. 복잡한 모델은 분산↑ 편향↓, 단순한 모델은 반대. 줄여야 할 것은 하나가 아니라 **전체 오류**

> [!warning] 헷갈림 주의
> 여기의 "편향"은 통계적 오차(과소적합)다. [[P09 책임 있는 AI]]의 "편향"(집단 간 불공정)과 이름만 같다.

## 5. 신경망

### 발전 과정
1. 뇌의 뉴런: 입력 신호가 충분하면 '발화'. 층으로 연결되면 학습 가능 (피질 기둥 ≈ GPU의 병렬 처리)
2. 1943년 인공 뉴런: 입력이 임계값을 넘으면 발화 → AND, OR, NOT
3. 1957년 **선형 임계 유닛(LTU)**: 입력 × 가중치의 합이 0 이상이면 1 (계단 함수)
4. **퍼셉트론**: LTU 한 층. 올바른 결과를 낸 가중치를 강화 ("함께 발화하는 세포는 함께 연결된다")
5. **다층 퍼셉트론(MLP)**: 은닉층 추가 = 심층 신경망(DNN)
6. 현대: 더 나은 활성화 함수, 출력에 **소프트맥스**, **경사 하강법**으로 훈련

### 신경망 튜닝 (하이퍼파라미터)
- **학습률**: 경사 하강법에서 한 번에 이동하는 간격. 대표적인 하이퍼파라미터
- **배치 크기**: 배치 하나에 쓰는 훈련 샘플 수

| 설정 | 결과 |
|---|---|
| 작은 배치 크기 | 지역 최솟값에 잘 **안** 갇힘 |
| 큰 배치 크기 | 잘못된 해에 수렴할 수 있음 |
| 큰 학습률 | 최적해를 **지나칠** 수 있음 |
| 작은 학습률 | 훈련 시간이 늘어남 |

### CNN (합성곱 신경망)
- 열로 정리되지 않는 데이터: 이미지 속 특징, 기계 번역, 문장 분류, 감정 분석
- **특징 위치 불변성**: 특징이 어디 있든 찾아냄 (사진 속 정지 표지판)
- 시각 피질에서 영감: 국소 수용 영역, 겹치며 전체를 덮음(합성곱), 선·각도 → 모양 → 사물

### RNN (순환 신경망)
- **시계열**(웹 로그, 센서, 주식, 자율 주행 궤적)과 **임의 길이 시퀀스**(번역, 이미지 캡션, 음악 생성)
- 출력을 다시 입력으로 되돌리는 **메모리 셀**
- 토폴로지: 시퀀스→시퀀스(주가), 시퀀스→벡터(문장→감정), 벡터→시퀀스(이미지→캡션), 인코더→디코더(번역)

> [!tip] 시험 포인트
> 이미지 → **CNN** · 시계열·시퀀스 → **RNN** · LLM → **트랜스포머**

## 6. 트랜스포머
1. RNN·LSTM: 피드백 루프로 시퀀스 처리
2. 인코더-디코더(둘 다 RNN): 가운데 벡터 하나가 **정보 병목**
3. 어텐션: 토큰마다 은닉 상태, 단어 관계 파악. 여전히 RNN이라 **병렬화 불가**
4. **트랜스포머**: RNN을 버리고 **셀프 어텐션** + 피드포워드 → **병렬 처리** → 훨씬 많은 데이터로 훈련
- 2017년 논문 "Attention Is All You Need". Claude, Titan 등 GPT 계열이 기반

### 핵심 용어 (자주 출제)
| 용어 | 뜻 |
|---|---|
| **토큰** | 단어나 단어 일부를 숫자로 표현한 단위 |
| **임베딩** | 토큰의 의미를 담은 벡터. 의미가 비슷하면 가깝다 → RAG의 기반 ([[Bedrock 지식 기반]]) |
| **온도** | 무작위성. 높으면 다양, **낮으면 일관** |
| **Top P** | 후보 토큰의 누적 확률 임계값. 높을수록 무작위 |
| **Top K** | 후보를 확률 상위 K개로 제한 |
| **컨텍스트 창** | 한 번에 처리할 수 있는 토큰 수 |
| **최대 토큰** | 입력·출력에 허용되는 전체 토큰 한도 |

> [!tip] 시험 포인트
> "응답을 더 일관되고 예측 가능하게" → **온도를 낮춘다**

## 7. 생성 모델
| 모델 | 원리 | 용도 |
|---|---|---|
| **오토인코더** | 인코더가 잠재 특징으로 압축, 디코더가 복원. 디코더만 떼어 합성 데이터 생성 | 차원 축소, 압축, 잡음 제거, 컬러화 |
| **VAE** | 잠재 벡터를 확률 분포(평균·분산)로 표현. GAN의 출발점 | 생성 |
| **GAN** | **생성자**가 가짜를 만들고 **판별자**가 가려내며 경쟁 | 딥페이크, 개인 정보를 뺀 합성 데이터, 이상 탐지 |
| **확산 모델** | 잡음을 더했다가 걷어내는 과정을 학습 → 순수한 잡음에서 이미지 생성 | Stable Diffusion |

## 파트 핵심 요약
> [!summary] 시험 직전 체크
> - 레이블 있음 → 지도 · 없음 → 비지도 · 데이터가 곧 레이블 → 자기 지도 · 보상/벌점 → 강화
> - 훈련 정확도↑ 테스트 정확도↓ → 과적합(높은 분산) · 너무 단순 → 과소적합(높은 편향)
> - 학습률 크면 지나침, 작으면 느림 · 작은 배치는 지역 최솟값에 덜 갇힘
> - 이미지 CNN · 시퀀스 RNN · LLM 트랜스포머(셀프 어텐션)
> - 온도↓ 일관 · 온도↑ 다양 · Top P↑ 후보 증가
