# P08 미세 조정과 평가 지표

> [!abstract] 이 파트에서 배우는 것
> 미세 조정이 바꾸는 것과 여러 형태 → RLHF → 미세 조정용 데이터 → FM 평가 4가지 → 텍스트 지표(ROUGE·BLEU·BERTScore) → 분류 지표(혼동 행렬, 재현율, 정밀도, F1, AUC) → 회귀 지표
> 관련 시험 도메인: **D3 파운데이션 모델 적용**
> 공식은 [[공식 모음]]에 따로 모아 두었다. 계산 문제가 나오니 손으로 한 번씩 풀어 볼 것.

---

## 1. 미세 조정은 무엇을 바꾸나
- FM의 초기 훈련이 끝난 지점에서 **훈련을 이어 감**
- 새 정보가 새 가중치나 새 층으로 **모델 자체의 일부**가 된다 → 프롬프트나 RAG와 다른 점
- 비용과 시간이 많이 들 수 있다

| 이점 | 뜻 |
|---|---|
| 구체성 | 원래 배우지 않은 내용 학습 |
| 정확도 | 이미 배운 분야를 더 깊게 |
| 편향 감소 | 더 다양한 데이터로 보완 |
| 효율 | 실행 시 복잡도가 낮음 |

## 2. 미세 조정의 여러 형태
| 형태 | 설명 |
|---|---|
| **지시 튜닝** | 프롬프트-원하는 출력 쌍으로 지시 처리법을 가르침 (요약, 단계별 안내). 특정 앱 챗봇·가상 비서 |
| **도메인 적응** | 특정 산업의 프롬프트와 정답 응답. 법률(계약서), 의료(증상), 기술(코드), 금융, 고객 지원 |
| **전이 학습** | 기존 모델 훈련을 특정 용도로 확장. LLM만이 아님 (ResNet에 자사 로고 인식). 일부 층 고정, 새 언어 토크나이저 |
| **지속적인 사전 훈련** | **레이블 없는** 텍스트. "지속적" = 뉴스·사내 보고서처럼 계속 새로 나오는 데이터 |

## 3. RLHF (인간 피드백 기반 강화 학습)
1. **지도 미세 조정**: 사람이 대화의 양쪽을 맡아 예시 대화 → **지도 정책**
2. **보상 모델**: 한 프롬프트에 출력 여러 개 → 사람이 **순위** → 보상 모델 훈련 (유해 출력에 벌점)
3. **정책 최적화**: 지도 정책을 보상 모델로 최적화 (**PPO**, 근접 정책 최적화), 반복

- 핵심: 사람의 피드백을 보상 함수에 넣어 **사람의 목표에 맞춤**. 생성형 AI에만 쓰는 것은 아님
- 이점: 성능 향상, 사용자 만족도, 복잡한 훈련 기준 반영
- AWS: [[SageMaker Ground Truth]]의 RLHF용 데이터 주석 도구 (응답 순위·분류)

> [!tip] 시험 포인트
> RLHF 데이터(응답 순위 매기기)를 사람이 만드는 AWS 서비스 → **Ground Truth**

## 4. 미세 조정용 데이터 준비
- **양보다 질**: 풀려는 문제에 구체적이고 관련 있는 데이터
  - 초기 사전 훈련: 다양하고 폭넓고 방대 / 미세 조정: 좁고 구체적이고 관련성 높음
- 큐레이션, **레이블 정확성**(레이블이 없으면 사실상 지속적인 사전 훈련), 거버넌스·규정 준수, **편향**(과대·과소 대표) 확인

## 5. 파운데이션 모델 평가 4가지
생성형 AI는 복잡하고 비결정적이라 측정이 어렵다.

| 방법 | 설명 | 주의 |
|---|---|---|
| **인적 평가** | 사용 경험, 맥락 관련성, 창의성, 예상 못한 문제 대응 | 비용·시간 |
| **벤치마크 데이터셋** | 전문가(SME)가 만든 질문·답 세트로 정확도, 속도, 확장성, 검색 맥락 관련성 | 데이터 품질만큼만 믿을 수 있음. 리더보드, 1차 지표 |
| **다른 모델을 심사관으로** | 신뢰하는 모델이 채점(관련성, 포괄성, 정확도) | "심사관은 누가 감시하나?", 같은 약점 공유 위험. 소형 모델 테스트에 적합 |
| **하이브리드** | 사람 + 벤치마크 비교 | 각 방식의 한계가 드러남 |

→ Bedrock 모델 평가(자동·인적)는 [[P09 책임 있는 AI]]에서

## 6. 텍스트 생성 지표
| 지표 | 용도 | 중심 | 원리 |
|---|---|---|---|
| **ROUGE** | **요약**·번역 | **재현율** | 정답과 겹치는 단위 수. ROUGE-N(n-gram), ROUGE-L(최장 공통 부분 수열, 흐름·순서) |
| **BLEU** | **기계 번역** | **정밀도** | 생성 단어·구가 정답 번역에 얼마나 있나. 짧은 번역에 **간결성 페널티**. 유창성·문법 평가엔 한계 |
| **BERTScore** | **의미 유사도** | - | 임베딩 벡터로 의미 비교. 동의어·바꿔 쓰기에 덜 민감 |

> [!example] ROUGE 계산
> 정답 "AWS AI 자격증" · 출력 "AWS ML 자격증"
> - ROUGE-1: 정답 단어 3개 중 AWS, 자격증 일치 → **2/3**
> - ROUGE-2: 정답의 두 단어 묶음(AWS AI, AI 자격증) 중 일치 0 → **0**

## 7. 분류 지표
### 혼동 행렬 (사기 탐지, 거래 200건)
| | 실제 사기 | 실제 정상 |
|---|---|---|
| 사기로 예측 | **TP 12** | **FP 18** |
| 정상으로 예측 | **FN 8** | **TN 162** |

| 지표 | 공식 | 예시 값 | 의미 |
|---|---|---|---|
| **재현율(Recall)** | TP / (TP+FN) | 12/20 = **60%** | 실제 양성 중 잡아낸 비율. 민감도, 참 양성률. **놓침이 치명적**일 때 |
| **정밀도(Precision)** | TP / (TP+FP) | 12/30 = **40%** | 양성 예측 중 진짜. **오경보가 치명적**일 때 |
| **특이도(Specificity)** | TN / (TN+FP) | 162/180 = **90%** | 참 음성률 |
| **F1 점수** | 2·P·R / (P+R) | 2·0.4·0.6/1.0 = **48%** | 정밀도·재현율의 조화 평균. 2TP/(2TP+FP+FN) |
| 정확도 | (TP+TN) / 전체 | 174/200 = **87%** | 불균형 데이터에선 함정 |

> [!warning] 정확도의 함정
> 87%로 좋아 보이지만 사기의 40%를 놓친다. **클래스가 불균형하면 정확도만 보면 안 된다.**

### ROC 곡선, AUC, P-R 곡선
- **ROC 곡선**: 여러 임계값에서 참 양성률(세로) vs 거짓 양성률(가로). 대각선 위면 무작위보다 낫고, 왼쪽 위로 휠수록 좋음
- **AUC**: 무작위 양성을 무작위 음성보다 높게 평가할 확률. **0.5 = 쓸모없음, 1.0 = 완벽**. 분류기 비교에 사용
- **P-R 곡선**: 정밀도-재현율. 면적이 클수록 좋음. 수많은 문서 중 극소수를 찾는 **정보 검색**에 ROC보다 적합

## 8. 회귀 지표와 지표 선택
| 지표 | 뜻 |
|---|---|
| **R²(결정 계수)** | 관측값과 예측값 상관 계수의 제곱. 1에 가까울수록 좋음 |
| **RMSE** | 오차 제곱 평균의 제곱근. **큰 오차에 민감** |
| **MAE** | 오차 절댓값의 평균 |

| 상황 | 볼 지표 |
|---|---|
| 놓치면 큰일 (사기, 질병 발견) | **재현율** |
| 오경보가 큰일 (약물 검사) | **정밀도** |
| 둘 다 중요 | **F1** |
| 분류기끼리 비교 | **AUC** |
| 텍스트 요약 | **ROUGE** |
| 기계 번역 | **BLEU** |
| 의미가 같은지 | **BERTScore** |
| 가격·수량 같은 수치 예측 | **RMSE · MAE · R²** |

> [!warning] 헷갈림 주의
> RMSE, MAE, R²는 **회귀** 지표다. 분류 지표(정밀도·재현율)와 섞어 낸 보기를 조심.

## 파트 핵심 요약
> [!summary] 시험 직전 체크
> - 프롬프트-응답 쌍 → 지시 튜닝 · 산업 데이터 → 도메인 적응 · 기존 모델 확장 → 전이 학습
> - RLHF: 지도 미세 조정 → 사람이 순위 매긴 보상 모델 → PPO · AWS: Ground Truth
> - FM 평가: 인적 · 벤치마크 · 심사 모델 · 하이브리드
> - 요약·재현율 → ROUGE · 번역·정밀도 → BLEU · 의미 → BERTScore
> - 재현율 TP/(TP+FN) · 정밀도 TP/(TP+FP) · 특이도 TN/(TN+FP) · F1 조화 평균
> - AUC 0.5 무작위, 1.0 완벽 · 수치 예측 → R², RMSE, MAE
