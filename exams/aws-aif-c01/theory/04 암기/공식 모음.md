# 공식 모음

> [!summary] 사용법
> 계산 문제가 나오는 공식만 모았다. 아래 **예제 혼동 행렬**로 직접 계산해 보고, 접힌 칸을 열어 답을 확인한다.

## 혼동 행렬
|  | 실제 양성 | 실제 음성 |
|---|---|---|
| **양성으로 예측** | TP (참 양성) | FP (거짓 양성, 오경보) |
| **음성으로 예측** | FN (거짓 음성, 놓침) | TN (참 음성) |

> [!tip] 외우는 요령
> 두 번째 글자(P/N)는 **예측**, 첫 글자(T/F)는 **맞았는지**. FN = "음성이라고 예측했는데 틀림" = **놓친 것**

## 분류 지표
| 지표 | 공식 | 다른 이름 | 중시할 때 |
|---|---|---|---|
| **재현율** | TP / (TP + FN) | 민감도, 참 양성률(TPR) | **놓치면 큰일** (사기, 질병) |
| **정밀도** | TP / (TP + FP) | 양성 예측도 | **오경보가 큰일** (약물 검사, 스팸 필터) |
| **특이도** | TN / (TN + FP) | 참 음성률 | 음성을 잘 걸러야 할 때 |
| **F1 점수** | 2 × P × R / (P + R) = 2TP / (2TP + FP + FN) | 조화 평균 | 둘 다 중요, 불균형 데이터 |
| **정확도** | (TP + TN) / 전체 | | 클래스가 **균형**일 때만 믿을 만함 |
| 거짓 양성률(FPR) | FP / (FP + TN) = 1 − 특이도 | | ROC 곡선의 가로축 |

## 곡선
| 곡선 | 축 | 해석 |
|---|---|---|
| **ROC** | 세로 TPR(재현율), 가로 FPR | 왼쪽 위로 휠수록 좋음, 대각선 = 무작위 |
| **AUC** | ROC 아래 면적 | **0.5 = 무작위**, **1.0 = 완벽** |
| **P-R 곡선** | 정밀도-재현율 | 극소수를 찾는 정보 검색에 ROC보다 적합 |

## 회귀 지표
| 지표 | 공식 | 특징 |
|---|---|---|
| **MAE** | 평균( \|실제 − 예측\| ) | 오차 크기 그대로 |
| **RMSE** | √ 평균( (실제 − 예측)² ) | **큰 오차에 민감** |
| **R²** | 상관 계수² (1에 가까울수록 좋음) | 설명력 |

## 텍스트 지표
| 지표 | 계산 | 용도 |
|---|---|---|
| **ROUGE-N** | 정답의 n-gram 중 출력에 있는 비율 (재현율) | 요약 |
| **ROUGE-L** | 최장 공통 부분 수열 | 요약(순서·흐름) |
| **BLEU** | 출력의 n-gram 중 정답에 있는 비율 (정밀도) + 간결성 페널티 | 번역 |
| **BERTScore** | 임베딩 코사인 유사도 | 의미 유사도 |

## 편향·분산
- **오류 = 편향² + 분산** (+ 줄일 수 없는 잡음)
- 높은 편향 = 과소적합 · 높은 분산 = 과적합

## 연습 문제
> [!example] 예제 혼동 행렬 (거래 200건 사기 탐지)
> TP 12 · FP 18 · FN 8 · TN 162

> [!question]- 재현율은?
> 12 / (12 + 8) = 12/20 = **60%**

> [!question]- 정밀도는?
> 12 / (12 + 18) = 12/30 = **40%**

> [!question]- 특이도는?
> 162 / (162 + 18) = 162/180 = **90%**

> [!question]- F1 점수는?
> 2 × 0.4 × 0.6 / (0.4 + 0.6) = 0.48 = **48%**

> [!question]- 정확도는? 그리고 무엇이 문제인가?
> (12 + 162) / 200 = **87%**. 높아 보이지만 실제 사기의 40%를 놓친다. 불균형 데이터에서 정확도만 보면 안 된다.

> [!example] 두 번째 연습 (질병 선별 검사 1,000명)
> TP 45 · FP 55 · FN 5 · TN 895

> [!question]- 재현율, 정밀도, F1은?
> 재현율 45/50 = **90%** · 정밀도 45/100 = **45%** · F1 = 2×0.45×0.9/1.35 = **60%**

> [!question]- 이 검사는 선별용으로 적절한가?
> 선별 검사는 **놓치지 않는 것(재현율)** 이 중요하므로 재현율 90%는 적절하다. 양성 판정자는 정밀 검사로 다시 확인한다.

> [!question]- ROUGE-1: 정답 "고객 만족도 조사 결과", 출력 "고객 조사 결과 요약"
> 정답 단어 4개(고객, 만족도, 조사, 결과) 중 출력에 있는 것 3개 → **3/4 = 0.75**
