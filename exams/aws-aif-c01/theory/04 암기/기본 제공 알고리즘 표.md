# 기본 제공 알고리즘 표

> [!summary] 사용법
> SageMaker 기본 제공 알고리즘을 **데이터 유형**별로 묶었다. 문제에서 "무엇을 하고 싶은가"를 찾아 오른쪽 열로 연결한다.

## 한눈에 고르기
| 하고 싶은 일 | 알고리즘 | 학습 방식 |
|---|---|---|
| 표 형식 데이터 분류·회귀 (강력한 기본값) | **XGBoost** | 지도 |
| 직선으로 회귀·분류 | **Linear Learner** | 지도 |
| 가까운 이웃으로 분류·회귀 | **KNN** | 지도 |
| 희소한 클릭·추천 데이터 | **Factorization Machines** | 지도 |
| 번역, 요약, 음성→텍스트 | **Seq2Seq** | 지도 |
| 시계열 예측 | **DeepAR** | 지도 |
| 텍스트 분류 / 단어 임베딩(Word2vec) | **BlazingText** | 분류는 지도 |
| 임의 객체의 임베딩, 유사 항목 | **Object2Vec** | - |
| 문서 주제 분류 (딥 러닝) | **Neural Topic Model** | 비지도 |
| 문서 주제 분류 (딥 러닝 아님) | **LDA** | 비지도 |
| 이미지에 무엇이 있나 | **이미지 분류** | 지도 |
| 이미지 속 객체 위치(경계 상자) | **객체 탐지** | 지도 |
| 픽셀 단위 분할 | **시맨틱 분할** | 지도 |
| 이상 탐지, 이상 점수 | **Random Cut Forest** | 비지도 |
| 수상한 IP 로그인 | **IP Insights** | 비지도 |
| 그룹 나누기 | **K-Means** | 비지도 |
| 특징 수 줄이기(차원 축소) | **PCA** | 비지도 |

## 헷갈리는 쌍
| 쌍 | 구분 |
|---|---|
| 이미지 분류 vs 객체 탐지 vs 시맨틱 분할 | 무엇이 / 어디에(상자) / 픽셀마다 |
| NTM vs LDA | 둘 다 주제 모델링, NTM은 딥 러닝·LDA는 아님, 둘 다 주제 **이름**은 못 붙임 |
| BlazingText vs Object2Vec | 단어 임베딩 / 단어 외 임의 객체 임베딩 |
| DeepAR vs Amazon Forecast | SageMaker 알고리즘 / 완전 관리형 서비스(DeepAR 포함) |
| RCF vs IP Insights | 일반 이상 탐지 / IP 사용 패턴 특화 |
| K-Means vs KNN | 비지도 군집 / 지도 분류·회귀 |
| Factorization Machines vs Amazon Personalize | 추천용 알고리즘 / 완전 관리형 추천 서비스 |

## Autopilot이 쓰는 알고리즘
Linear Learner · XGBoost · 딥 러닝(MLP) · 앙상블(AutoGluon)

## 셀프 체크
> [!question]- 자율 주행 카메라 영상에서 도로와 보행자를 픽셀 단위로 구분하려면?
> 시맨틱 분할

> [!question]- 웹사이트 클릭 로그처럼 대부분 비어 있는 사용자-상품 데이터로 추천하려면?
> Factorization Machines

> [!question]- 센서 데이터의 갑작스러운 급증을 찾으려면?
> Random Cut Forest

> [!question]- 여러 매장의 판매 시계열로 한 모델을 훈련해 수요를 예측하려면?
> DeepAR
