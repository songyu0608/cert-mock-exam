# 플래시카드 P01

> [!info] 이론: [[P01 AI·ML 기초]] · 카드 30장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

AI, ML, 딥 러닝, 생성형 AI의 포함 관계는?::AI ⊃ 기계 학습 ⊃ 딥 러닝 ⊃ 생성형 AI

if-then 규칙으로 판단하는 전문가 시스템은 기계 학습인가?::아니다. AI이지만 데이터로 학습하지 않으므로 ML이 아니다

레이블이 있는 데이터로 훈련하는 학습 방식은?::지도 학습

선형 회귀와 로지스틱 회귀의 차이는?::선형 회귀는 수치 예측, 로지스틱 회귀는 참/거짓(이진 분류) 예측. 둘 다 지도 학습

레이블 없이 데이터의 구조를 찾는 학습 방식은?::비지도 학습 (예: K-평균 클러스터링)

LLM이 다음 단어를 예측하며 사전 훈련하는 방식은?::자기 지도 학습 (데이터가 곧 레이블)

보상과 벌점으로 시행착오를 거쳐 배우는 방식은?::강화 학습

K-평균 클러스터링의 반복 과정은?::중심 K개 무작위 선택 → 가장 가까운 중심에 할당 → 중심 재계산 → 할당이 안 바뀔 때까지 반복

특징 수를 줄이는 비지도 알고리즘은?::PCA(주성분 분석)

K-폴드 교차 검증은 어떻게 하나?::데이터를 K개 폴드로 나눠 하나씩 테스트용으로 돌려 가며 훈련·평가하고 점수를 평균

훈련 정확도는 높고 테스트 정확도는 낮다. 무엇인가?::과적합 (높은 분산)

모델이 너무 단순해 훈련 데이터도 잘 못 맞춘다. 무엇인가?::과소적합 (높은 편향)

과적합을 막는 기법을 통틀어 부르는 말은?::정규화(Regularization)

편향과 분산으로 표현한 오류는?::오류 = 편향² + 분산

학습률이 너무 크면?::최적해를 지나칠 수 있다

학습률이 너무 작으면?::훈련 시간이 오래 걸린다

작은 배치 크기의 장점은?::지역 최솟값에 잘 갇히지 않는다

이미지 속 특징을 위치에 상관없이 찾는 신경망은?::CNN(합성곱 신경망), 특징 위치 불변성

시계열·시퀀스 데이터에 쓰는 신경망은?::RNN(순환 신경망), 메모리 셀

트랜스포머의 핵심 두 가지는?::셀프 어텐션과 병렬 처리

트랜스포머를 처음 제안한 2017년 논문은?::Attention Is All You Need

토큰이란?::단어나 단어 일부를 숫자로 표현한 단위

임베딩이란?::의미를 담은 벡터. 의미가 비슷하면 벡터 공간에서 가깝다

응답을 더 일관되고 예측 가능하게 하려면 온도를?::낮춘다

Top P를 높이면?::후보 토큰이 많아져 더 무작위적이 된다

컨텍스트 창이란?::LLM이 한 번에 처리할 수 있는 토큰 수

생성자와 판별자가 경쟁하는 생성 모델은?::GAN(생성형 적대 신경망)

잡음을 더했다 걷어내는 과정을 학습하는 이미지 생성 모델은?::확산 모델 (예: Stable Diffusion)

잠재 벡터를 확률 분포로 표현하는 오토인코더는?::VAE(변분 오토인코더)

다층 퍼셉트론(MLP)이란?::입력층과 출력층 사이에 은닉층을 넣은 신경망 = 심층 신경망
