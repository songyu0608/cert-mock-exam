# 플래시카드 P10

> [!info] 이론: [[P10 보안·거버넌스·규정 준수]] · 카드 34장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

보안, 거버넌스, 규정 준수의 차이는?::보안은 기밀성·무결성·가용성 보호, 거버넌스는 위험 관리, 규정 준수는 요구 사항 준수

공동 책임 모델에서 AWS의 책임은?::클라우드 자체의 보안 (하드웨어, 시설, 네트워크)

공동 책임 모델에서 고객의 책임은?::클라우드 안의 보안 (데이터, IAM, 암호화 설정, 패치)

심층 방어란?::여러 겹의 중복된 방어를 두는 전략 (7겹)

저장 데이터 암호화 키 관리 서비스는?::AWS KMS

전송 중 암호화 인증서 서비스는?::AWS Certificate Manager (ACM)

사람이 아닌 서비스에 임시 권한을 주는 IAM 아이덴티티는?::IAM 역할

과도한 권한을 가진 역할·리소스를 찾는 도구는?::IAM Access Analyzer

DDoS 방어 서비스는?::AWS Shield (Advanced)

웹 트래픽 필터링과 봇 제어 서비스는?::AWS WAF (Bot Control)

앱 최종 사용자 인증 서비스는?::Amazon Cognito

보안 결과를 한 대시보드로 모으는 서비스는?::AWS Security Hub

수상한 행동을 감시하는 위협 탐지 서비스는?::Amazon GuardDuty

S3의 PII·PHI를 찾는 서비스는?::Amazon Macie

소프트웨어 취약점과 네트워크 노출을 스캔하는 서비스는?::Amazon Inspector

보안 사고의 포렌식 조사를 돕는 서비스는?::Amazon Detective

데이터 계보 도구 세 가지는?::SageMaker ML Lineage Tracking, Glue Data Catalog, SageMaker 모델 카드

데이터 품질 확인 AWS 도구는?::Glue DataBrew, Glue Data Quality

개인 정보 보호 강화 기법 세 가지는?::마스킹·난독화, 암호화, 토큰화

AI 거버넌스 위원회의 구성원은?::법무, 개발자(SME), 규정 준수, 개인 정보 전문가 (교차 기능)

AWS가 ISO 27001 인증을 가지면 고객도 인증받은 것인가?::아니다. 고객이 물려받지 않는다

HIPAA, GDPR, PCI DSS는 각각?::의료 정보, EU 개인 정보, 카드 결제 정보

EU AI 법이 요구하는 것은?::투명성, 위험 평가, 사람의 감독

AI 규정 준수가 특히 어려운 이유는?::복잡성·불투명성, 동적 변화, 창발적 행동

리소스 구성 이력과 변경을 추적하는 서비스는?::AWS Config

누가 어떤 API를 호출했는지 기록하는 서비스는?::AWS CloudTrail

AWS의 SOC·ISO 보고서를 내려받는 곳은?::AWS Artifact

내 환경의 감사 증거 수집을 자동화하는 서비스는?::AWS Audit Manager

비용·성능·보안·서비스 한도 모범 사례를 점검하는 서비스는?::AWS Trusted Advisor

생성형 AI 보안 범위 지정 매트릭스의 5단계는?::소비자 앱, 기업용 앱, 사전 훈련 모델, 미세 조정 모델, 자체 훈련 모델

Bedrock으로 앱을 만드는 것은 범위 몇인가?::범위 3 (사전 훈련 모델)

고객 책임이 가장 큰 범위는?::범위 5 (자체 훈련 모델)

시험의 새 문제 유형 세 가지는?::순서 배열, 연결, 사례 연구

복수 응답·순서 배열·연결 문제의 부분 점수는?::없다
