# 플래시카드 P09

> [!info] 이론: [[P09 책임 있는 AI]] · 카드 30장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

책임 있는 AI의 8가지 차원은?::공정성, 설명 가능성, 개인 정보 보호·보안, 안전성, 제어 가능성, 진실성·견고성, 거버넌스, 투명성

편향 탐지와 설명 가능성 도구는?::SageMaker Clarify

Clarify가 편향을 찾은 뒤 데이터 균형을 맞추는 도구는?::SageMaker Data Wrangler

소수 클래스의 새 샘플을 최근접 이웃으로 인공 생성하는 기법은?::SMOTE

많은 쪽 데이터를 무작위로 줄이는 기법은?::무작위 언더샘플링

Clarify에서 비교하려는 인구 집단을 부르는 말은?::패싯(facet)

한 집단의 훈련 데이터가 적은지 보는 편향 지표는?::클래스 불균형(CI)

집단 간 긍정적 결과 비율 차이를 보는 지표는?::레이블 비율 차이(DPL)

각 특징의 예측 기여도를 계산하는 방법은?::SHAP (섀플리 값 근사)

특징 값이 바뀔 때 예측 변화를 보여 주는 그래프는?::부분 의존도 플롯(PDP)

시계열 설명 가능성에 쓰는 섀플리 값은?::비대칭 섀플리 값

"우리 브랜드 말투와 맞는지" 평가 방식은?::인적 평가

정확도·견고성·유해성 평가 방식은?::자동 평가

운영 중 모델 품질을 계속 감시하는 도구는?::SageMaker Model Monitor

사람 검토자 워크플로를 제공하는 서비스는?::Amazon Augmented AI (A2I)

내 모델의 용도·위험 등급·훈련 정보 문서는?::SageMaker 모델 카드

AWS AI 서비스의 사용 사례·한계 문서는?::AWS AI 서비스 카드

운영 중 모든 모델 동작을 한곳에서 보는 기능은?::SageMaker 모델 대시보드

SageMaker ML 거버넌스 3종은?::Role Manager, 모델 카드, 모델 대시보드

투명성과 설명 가능성의 차이는?::투명성은 어떻게(HOW), 설명 가능성은 왜(WHY)

내부 가중치까지 이해하는 수준의 개념은?::해석 가능성

입력 데이터를 바꿔 모델을 제어할 수 있는 정도는?::제어 가능성

투명성과 자주 충돌하는 개념은?::모델 안전성

해석 가능성과 성능의 트레이드오프 예시는?::선형 회귀·의사 결정 트리는 해석 쉬움, 딥 러닝은 성능 높고 불투명

"특징이 달랐다면 결과가 어떻게 바뀌었을까"로 설명하는 기법은?::반사실적 설명

책임 있는 모델 선택에서 성능 테스트 원칙은?::일반 벤치마크가 아니라 내 데이터로 테스트

대상이 좁은 모델의 데이터 큐레이션 원칙은?::그 집단 데이터만 남긴다 (너무 다양해도 문제)

데이터 드리프트 때문에 필요한 편향 관리는?::정기 감사

인간 중심 설계의 대표 예는?::RLHF

증폭된 의사 결정의 설계 원칙은?::명확성, 단순성, 사용성, 성찰성, 책임성
