# 플래시카드 P08

> [!info] 이론: [[P08 미세 조정과 평가 지표]] · 카드 32장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

미세 조정이 프롬프트·RAG와 다른 점은?::새 정보가 가중치로 모델 자체의 일부가 된다

프롬프트-원하는 출력 쌍으로 지시 처리법을 가르치는 미세 조정은?::지시 튜닝

특정 산업의 프롬프트와 정답 응답으로 훈련하는 것은?::도메인 적응

기존 모델의 훈련을 특정 용도로 확장(일부 층 고정 등)하는 것은?::전이 학습

RLHF 3단계는?::지도 미세 조정 → 사람이 순위 매긴 보상 모델 → PPO로 정책 최적화

RLHF에서 사람이 하는 일은?::여러 출력에 순위를 매긴다

RLHF용 데이터 주석 AWS 서비스는?::SageMaker Ground Truth

미세 조정 데이터의 원칙은?::양보다 질, 좁고 구체적이며 관련성 높은 데이터

레이블 없는 데이터로 하는 미세 조정은 사실상?::지속적인 사전 훈련

FM 평가 4가지 방법은?::인적 평가, 벤치마크 데이터셋, 다른 모델을 심사관으로, 하이브리드

다른 모델을 심사관으로 쓸 때의 문제는?::심사관은 누가 감시하나, 같은 약점 공유 위험

벤치마크 데이터셋의 한계는?::데이터 품질만큼만 믿을 수 있다

요약 평가, 재현율 중심 지표는?::ROUGE

기계 번역 평가, 정밀도 중심 지표는?::BLEU

임베딩으로 의미 유사도를 보는 지표는?::BERTScore

BLEU가 짧은 번역에 주는 것은?::간결성 페널티

ROUGE-L이 보는 것은?::최장 공통 부분 수열 (흐름과 순서)

재현율 공식은?::TP / (TP + FN)

정밀도 공식은?::TP / (TP + FP)

특이도 공식은?::TN / (TN + FP)

F1 점수 공식은?::2 × 정밀도 × 재현율 / (정밀도 + 재현율)

놓치면 큰일인 사기·질병 탐지에서 중시할 지표는?::재현율

오경보가 큰일인 약물 검사에서 중시할 지표는?::정밀도

정밀도와 재현율이 둘 다 중요할 때 지표는?::F1 점수

불균형 데이터에서 정확도만 보면 안 되는 이유는?::다수 클래스만 맞혀도 정확도가 높게 나온다

AUC 0.5와 1.0의 의미는?::0.5는 무작위(쓸모없음), 1.0은 완벽

ROC 곡선의 두 축은?::세로 참 양성률, 가로 거짓 양성률

극소수 관련 문서를 찾는 정보 검색에 ROC보다 적합한 곡선은?::P-R 곡선

수치 예측(회귀) 지표 세 가지는?::R², RMSE, MAE

큰 오차에 더 민감한 회귀 지표는?::RMSE

TP 12, FN 8이면 재현율은?::60%

TP 12, FP 18이면 정밀도는?::40%
