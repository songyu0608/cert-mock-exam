# 플래시카드 P07

> [!info] 이론: [[P07 고수준 AI 서비스]] · 카드 37장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

텍스트의 감정·엔터티·PII를 분석하는 서비스는?::Amazon Comprehend

특정 엔터티에 대한 감정을 뽑는 Comprehend 기능은?::대상 감정

의료 기록에서 정보를 뽑는 서비스는?::Amazon Comprehend Medical

번역 서비스와 사용자 지정 용어 형식은?::Amazon Translate, CSV 또는 TMX

텍스트를 음성으로 바꾸는 서비스는?::Amazon Polly

Polly에서 속삭임·말하는 속도·쉼을 제어하는 것은?::SSML

Polly에서 약어 발음을 지정하는 것은?::어휘집(Lexicon)

Polly에서 입 모양 애니메이션을 동기화하는 것은?::음성 마크

음성을 텍스트로 바꾸는 서비스는?::Amazon Transcribe

Transcribe에서 누가 말했는지 구분하는 기능은?::화자 식별

Transcribe에서 두 통화자를 따로 전사하는 기능은?::채널 식별

Transcribe의 인식률을 높이는 특수 단어 목록은?::사용자 지정 어휘

고객 통화의 감정·끼어들기·특정 문구를 탐지하는 Transcribe 기능은?::통화 분석(Call Analytics)

HIPAA 적격 의료 음성 인식은?::Amazon Transcribe Medical

이미지·동영상의 객체·얼굴·장면을 인식하는 서비스는?::Amazon Rekognition

부적절한 이미지를 자동으로 감지하는 Rekognition 기능은?::콘텐츠 조정(모더레이션)

자사 부품 불량을 적은 이미지로 인식하려면?::Rekognition Custom Labels

Rekognition이 동영상 스트림을 받는 서비스는?::Kinesis Video Streams

스캔 문서에서 양식·표까지 추출하는 서비스는?::Amazon Textract

시계열 수요 예측 서비스는?::Amazon Forecast

Forecast의 구성 단위 순서는?::데이터셋 그룹 → 예측기 → 예측

대화형 챗봇을 만드는 서비스는?::Amazon Lex

Lex에서 사용자가 원하는 행동은?::인텐트

Lex에서 인텐트 수행에 필요한 정보(날짜 등)는?::슬롯

Lex에서 실제 처리를 담당하는 것은?::이행(Lambda 함수)

기존 대화 전사본으로 봇 설계를 만드는 Lex 기능은?::자동 챗봇 디자이너

사용자별 추천 서비스는?::Amazon Personalize

편집자가 고른 목록을 사용자별로 재정렬하는 Personalize API는?::GetPersonalizedRanking

실시간 사용자 행동을 Personalize에 넣는 API는?::PutEvents

Personalize 스키마 형식은?::Avro

온라인 결제 사기 위험을 평가하는 서비스는?::Amazon Fraud Detector

ML 기반 자동 코드 리뷰 서비스는?::Amazon CodeGuru

콜센터 통화·채팅을 분석하는 서비스는?::Contact Lens for Amazon Connect

강화 학습 레이싱카는?::AWS DeepRacer

Textract vs Comprehend?::문서에서 글자·표 뽑기는 Textract, 글의 의미 분석은 Comprehend

Lex vs Contact Lens?::챗봇 구축은 Lex, 콜센터 통화 분석은 Contact Lens

Forecast vs Personalize?::수요·수치 예측은 Forecast, 사용자별 추천은 Personalize
