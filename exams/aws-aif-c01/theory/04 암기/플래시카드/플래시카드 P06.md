# 플래시카드 P06

> [!info] 이론: [[P06 Amazon Q와 Quick]] · 카드 26장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

CodeWhisperer의 현재 이름은?::Amazon Q Developer

IDE에서 코드 제안과 보안 스캔을 하는 서비스는?::Amazon Q Developer

오픈 소스와 비슷한 코드 제안에 출처를 알려 주는 기능은?::참조 추적기 (Q Developer)

Q Developer 개인 요금제의 데이터 주의점은?::Amazon이 데이터를 활용할 수 있다

조직 데이터 기반으로 직원 질문에 답하는 도우미는?::Amazon Q Business

조직 데이터로 노코드 생성형 AI 앱을 만드는 기능은?::Amazon Q Apps

Q Apps는 실제로 무엇에 가까운가?::사용자 지정 GPT (대부분 시스템 프롬프트 지정)

Q Business Lite와 Pro의 차이(강의 기준)?::Lite 월 $3 채팅만, Pro 월 $20 Q Apps·QuickSight Q·플러그인 포함

채팅·리서치·BI·자동화·노코드 앱을 한곳에서 쓰는 업무용 AI는?::Amazon Quick

Amazon Quick은 무엇에서 진화했나?::Amazon QuickSight

Quick의 5개 계층은?::채팅, 에이전트, 스페이스, 통합, 기능

Quick 채팅 에이전트의 세 요소는?::지침, 지식 소스, 도구

Quick의 답변 범위 원칙은?::호출한 사용자가 원래 볼 수 있는 범위로 제한

팀·도메인 범위의 공유 맥락을 주는 Quick 기능은?::스페이스

스페이스를 공유하면 안의 자산 권한도 생기나?::아니다

Quick이 가져올 수 있는 기존 인덱스는?::Q Business 인덱스, Bedrock 지식 기반

개인·팀의 짧은 반복 업무 자동화 Quick 기능은?::Quick Flows

전사 대량·장기 프로세스, 휴먼 인 더 루프 Quick 기능은?::Quick Automate (Enterprise 전용)

여러 출처를 깊이 조사해 인용 달린 보고서를 주는 기능은?::Quick Research

자연어로 노코드 웹 앱을 만드는 Quick 기능은?::Apps in Quick

Quick의 KMS 고객 관리형 키는 언제 설정해야 하나?::리소스를 만들기 전

Quick에서 대시보드 작성이 가능한 요금제는?::Enterprise

승인 안 된 도구에 기밀 데이터를 붙여 넣는 문제를 부르는 말은?::섀도 AI

서버리스 BI 대시보드 서비스는?::Amazon QuickSight

자연어로 데이터 질문에 답하는 QuickSight 기능은?::QuickSight Q

QuickSight Q를 쓰려면 설정할 것은?::데이터셋에 연결된 토픽, NLP 친화적 필드 이름
