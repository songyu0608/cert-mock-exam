# 플래시카드 P05

> [!info] 이론: [[P05 파운데이션 모델과 Bedrock]] · 카드 42장
> Spaced Repetition 플러그인이 있으면 오른쪽 사이드바 "Review"로 복습한다. 플러그인이 없으면 `::` 왼쪽이 질문, 오른쪽이 답이다.

파운데이션 모델(FM)이란?::방대한 데이터로 미리 훈련한 거대한 트랜스포머 모델

인프라 관리 없이 API로 여러 FM을 쓰는 서비스는?::Amazon Bedrock

FM을 직접 배포·관리(인프라 제어)하려면?::SageMaker JumpStart

Bedrock에서 모델을 쓰기 전 필요한 것은?::모델 액세스 요청

Bedrock 추론 API 이름 두 가지는?::Converse, InvokeModel (+ 스트리밍 버전)

지식 기반에서 검색과 생성을 한 번에 하는 API는?::RetrieveAndGenerate

모델 맞춤화 4가지를 비용 순으로?::프롬프트 엔지니어링 < RAG < 미세 조정 < 지속적인 사전 훈련

가중치를 바꾸지 않는 맞춤화 두 가지는?::프롬프트 엔지니어링, RAG

최신 정보를 재훈련 없이 자주 반영하려면?::RAG (Bedrock 지식 기반)

레이블 있는 프롬프트-응답 쌍으로 특정 작업을 개선하려면?::미세 조정

레이블 없는 사내 문서로 도메인에 적응시키려면?::지속적인 사전 훈련

미세 조정의 장기적 이점은?::긴 프롬프트가 필요 없어져 토큰 절약

Bedrock 미세 조정 데이터를 보호하는 네트워크 방법은?::VPC와 PrivateLink

RAG를 비유하면?::LLM에게 치르게 하는 오픈북 시험

RAG의 대표적 한계는?::검색 결과 관련성과 프롬프트 템플릿에 민감, 여전히 환각 가능

의미가 비슷한 문서를 찾는 검색 방식은?::시맨틱 검색 (임베딩 + K-최근접 이웃)

pgvector를 쓰는 AWS 벡터 저장소는?::RDS·Aurora PostgreSQL

Bedrock 지식 기반의 기본 벡터 저장소는?::Amazon OpenSearch Serverless

Bedrock 지식 기반 임베딩 모델 예는?::Amazon Titan, Cohere

문서를 조각으로 나누는 지식 기반 과정은?::청킹

에이전트가 지식 기반을 도구처럼 쓰는 방식은?::에이전틱 RAG

가드레일은 입력과 출력 중 무엇을 필터링하나?::둘 다

가드레일의 컨텍스트 근거 검사가 재는 두 가지는?::근거성(Grounding), 관련성(Relevance)

PII 마스킹, 거부할 주제, 욕설 차단을 하는 기능은?::Bedrock 가드레일

프롬프트 템플릿의 변수 표기법은?::이중 중괄호 {{변수}}

프롬프트와 모델을 노드로 연결하는 시각적 워크플로는?::Bedrock Flows

에이전트의 세 요소는?::메모리, 계획, 도구

Bedrock 에이전트가 도구를 정의하는 단위는?::작업 그룹(Action Group), 보통 Lambda

에이전트가 사용자 프롬프트에서 파라미터 값을 뽑는 근거는?::작업 그룹의 파라미터 설명

라우팅 패턴이란?::라우터 LLM이 전문 에이전트 하나만 골라 호출

평가자-최적화자 패턴이란?::한 LLM이 생성, 다른 LLM이 평가·피드백, 반복

단기 메모리와 장기 메모리의 차이는?::단기는 세션 안 대화 기록, 장기는 선호·사실·세션 요약 같은 추출 인사이트

프롬프트와 응답을 감사용으로 기록하는 기능과 저장 위치는?::모델 호출 로깅, CloudWatch Logs 또는 S3

이미지가 Titan으로 생성됐는지 확인하는 기능은?::워터마크 탐지

실시간 불필요한 대량 작업 비용 절감 요금 방식은?::배치 (온디맨드보다 50% 저렴)

사용자 지정(미세 조정) 모델 호출에 필요한 요금 방식은?::프로비저닝된 처리량

프로비저닝된 처리량의 약정 기간은?::1~6개월

인터넷 없이 VPC에서 Bedrock에 접근하려면?::AWS PrivateLink

에이전트를 대규모로 배포·운영하는 서버리스 서비스는?::Amazon Bedrock AgentCore

API·Lambda를 MCP 도구로 바꾸는 AgentCore 구성 요소는?::AgentCore Gateway

AgentCore 정책의 언어와 기본 동작은?::Cedar, 기본 거부

Amazon의 오픈 소스 Python 에이전트 SDK는?::Strands Agents
