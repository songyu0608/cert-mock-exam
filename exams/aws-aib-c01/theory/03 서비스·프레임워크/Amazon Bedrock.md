# Amazon Bedrock

> [!summary] 한 줄 정의
> 여러 회사의 파운데이션 모델을 API로 쓰는 관리형 생성형 AI 플랫폼. 가드레일, 지식 기반(RAG), 에이전트, 모델 사용자 지정을 제공한다.

**일본어** Amazon Bedrock　·　**영어** Amazon Bedrock

## 시험 트리거
- "자체 생성형 AI 앱을 빠르게 구축"
- "여러 모델을 비교·선택"
- "인프라 관리 없이 FM 사용"
- "RAG / 가드레일 / 에이전트"

## 핵심
| 시험에서 연결되는 기능 | 관련 개념 |
|---|---|
| 지식 기반 | [[검색 증강 생성(RAG)]] |
| 가드레일 | [[가드레일]] (유해 콘텐츠, 거부 주제, PII 마스킹, 근거성 검사) |
| 에이전트 | [[AI 에이전트]] |
| 모델 사용자 지정 | [[미세 조정]] |

**가격**: 사용량 기반(온디맨드), 배치 추론(온디맨드보다 저렴), 프로비저닝된 처리량(약정형) → [[AWS AI 가격 책정 구조]]

**데이터**: Bedrock에서는 프롬프트와 출력이 모델 학습에 쓰이거나 모델 제공업체와 공유되지 않는다(AWS 공식 설명). 그래도 데이터·액세스·사용 방법의 책임은 고객 → [[AWS 공동 책임 모델]]

**구축-구매-파트너에서 위치**: 구축(Build) 쪽이지만 관리형이라 SageMaker AI보다 빠르고 필요 역량이 적다.

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| [[Amazon SageMaker AI]] | 사용자 지정 **ML 모델**을 직접 구축·학습·배포. 더 유연하지만 역량 필요 |
| [[Amazon Quick]] | 개발 없이 **바로 쓰는** 업무용 AI 어시스턴트·BI |
