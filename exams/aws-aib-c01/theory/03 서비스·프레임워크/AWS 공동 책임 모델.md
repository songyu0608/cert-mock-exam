# AWS 공동 책임 모델

> [!summary] 한 줄 정의
> AWS는 클라우드"의" 보안(물리 인프라, 하드웨어, 네트워크, 관리형 서비스 기반)을, 고객은 클라우드 "내" 보안(데이터, 액세스, 가드레일 설정, 출력 사용, 규정 준수)을 책임진다.

**일본어** AWS 責任共有モデル　·　**영어** AWS Shared Responsibility Model

## 시험 트리거
- "관리형 서비스를 쓰면 보안은 AWS 책임?" → 오답
- "데이터 분류·액세스 관리는 누구 책임?" → 고객

## 핵심
| AWS 책임 (OF the cloud) | 고객 책임 (IN the cloud) |
|---|---|
| 데이터 센터 등 물리 인프라 | 데이터 분류·암호화·보존 |
| 하드웨어, 네트워크 | 액세스 관리(누가 쓸 수 있나) |
| 관리형 서비스 기반(Bedrock에서 FM을 운영하는 인프라 등) | 가드레일과 프롬프트 설정 |
| | 출력의 사용 방법, 사람의 감시 |
| | 규정 준수와 책임 있는 AI 실천 |

- 직접 만들수록 고객 책임이 넓어진다 → [[생성형 AI 보안 범위 지정 매트릭스]]

> [!note] 용어
> 한국어 공식: 공동 책임 모델 / 일본어 공식: 責任共有モデル
