# 기술 및 인프라 요구 사항

> [!summary] 한 줄 정의
> AI를 받치는 기반: 확장 가능한 컴퓨팅·스토리지, 데이터 통합, 시스템 연동, 보안·ID 관리, 운영·모니터링 기반, 비용 관리. 비즈니스 담당자는 구축 방법이 아니라 요구 충족 여부를 평가한다.

**일본어** テクノロジーとインフラの要件　·　**영어** Technology and infrastructure requirements

## 시험 트리거
- "AI 이니셔티브를 지원하는 기술 요구 사항 평가"

## 핵심
| 요구 사항 | 내용 |
|---|---|
| 확장 가능한 기반 | 수요에 따라 늘릴 수 있는 컴퓨팅·스토리지 |
| 데이터 통합 | 흩어진 데이터를 모으는 파이프라인 |
| 시스템 연동 | 기존 업무 시스템과 API 연동 |
| 보안과 ID 관리 | 인증, 권한, 암호화, 네트워크 보호 |
| 운영·모니터링 기반 | 모델·앱 모니터링, 배포 체계 |
| 비용 관리 | 사용량·비용 시각화·최적화 |
