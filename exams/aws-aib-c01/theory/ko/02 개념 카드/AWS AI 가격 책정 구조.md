# AWS AI 가격 책정 구조

> [!summary] 한 줄 정의
> 사용량 기반(쓴 만큼), 인스턴스 기반(가동 시간), 사용자 기반(사용자 수 × 월정액), 약정·예약형(미리 약정해 할인). 범위 내 서비스 목록에 명시된 개념.

**일본어** AWS の AI サービスの料金体系　·　**영어** AWS AI service pricing structures

## 시험 트리거
- "사용량이 불확실·변동, 파일럿" → 사용량 기반
- "사용자가 명확한 업무 앱" → 사용자 기반
- "대량·안정 사용" → 약정형

## 핵심
| 구조 | 방식 | 예 | 적합 |
|---|---|---|---|
| 사용량 기반 | 토큰·요청 수만큼 | [[Amazon Bedrock]] 온디맨드 | 불확실·변동, 파일럿 |
| 인스턴스 기반 | 컴퓨팅 가동 시간 | [[Amazon SageMaker AI]] 학습·추론 | 사용자 지정 모델, 안정 부하 |
| 사용자 기반(시트 기반) | 사용자 수 × 월정액 | [[Amazon Quick]] 사용자 구독 | 사용자가 명확한 업무 앱 |
| 약정·예약형 | 일정량 약정으로 할인 | Bedrock 프로비저닝된 처리량, [[절감형 플랜]] | 대량·안정 사용 |

- Bedrock은 온디맨드 외에 **배치 추론**(온디맨드보다 저렴)과 **프로비저닝된 처리량**을 고를 수 있다(덱 노트 기준).
- 공식 범위 목록의 예시는 "사용량 기반, 인스턴스 기반, 사용자 기반" 3가지. 약정형은 덱이 덧붙인 정리.

> [!important] 시험 포인트
> 초기(사용량 예측 어려움)에는 사용량 기반 → 사용이 안정·대규모화되면 약정형으로 최적화.
