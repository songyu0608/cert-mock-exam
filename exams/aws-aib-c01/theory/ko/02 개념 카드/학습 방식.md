# 학습 방식

> [!summary] 한 줄 정의
> 과거 데이터로 모델을 학습시키는 3가지 방식. 레이블 있음 = 지도, 레이블 없음 = 비지도, 보상으로 시행착오 = 강화.

**일본어** 教師あり学習／教師なし学習／強化学習　·　**영어** Supervised / Unsupervised / Reinforcement learning

## 시험 트리거
- "과거 사기 표시로 사기 탐지" → 지도 학습
- "고객 세분화, 이상 탐지" → 비지도 학습
- "재고·가격 최적화, 보상 최대화" → 강화 학습

## 핵심
| 방식 | 데이터 | 비즈니스 예시 |
|---|---|---|
| 지도 학습 | 정답 레이블이 있는 과거 데이터 | 사기 탐지, 수요 예측 |
| 비지도 학습 | 레이블 없는 데이터에서 패턴·그룹 발견 | 고객 세분화, 이상 탐지 |
| 강화 학습 | 시행착오로 보상 최대화 | 재고·가격 최적화, 로봇 제어 |

> [!important] 시험 포인트
> 과거 데이터는 과거의 상황과 **편향**을 그대로 학습한다. 시장이 바뀌면 정확도가 떨어지고([[모델 드리프트]]), 과거의 불공정한 판단도 재현될 수 있다([[바이어스 드리프트]]).
