# 미세 조정

> [!summary] 한 줄 정의
> 자사 데이터로 기존 모델을 추가 학습해 문체·형식·특정 전문 작업의 동작을 조정하는 기법. RAG보다 비용·기간이 크다.

**일본어** ファインチューニング　·　**영어** Fine-tuning

## 시험 트리거
- "일관된 문체·형식"
- "특정 전문 작업의 정확도"
- "브랜드 톤을 항상 유지"

## 핵심
**모델 적응 기법 스펙트럼** (오른쪽일수록 비용·기간·데이터·전문성 ↑)

[[프롬프트 엔지니어링]] → [[검색 증강 생성(RAG)|RAG]] → **미세 조정** → 지속 사전 학습·자체 모델

| | RAG | 미세 조정 |
|---|---|---|
| 해결 과제 | 지식 부족, 최신·사내 정보 | 동작 방식, 문체, 전문 작업 |
| 데이터 업데이트 | 지식 기반만 교체 | 업데이트마다 재학습 |
| 근거 제시 | 가능 | 불가 |
| 비용·기간 | 낮고 짧음 | 높고 김 |
| AWS 예 | Bedrock 지식 기반 | Bedrock 모델 사용자 지정, SageMaker AI |

> [!important] 시험 포인트
> "최소한의 비용과 노력으로 요구 사항을 충족하는 기법"이 정답이 되기 쉽다. 처음부터 자체 모델 구축을 고르지 않는다.
