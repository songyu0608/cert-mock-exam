# 바이어스 드리프트

> [!summary] 한 줄 정의
> 운영 중 데이터 분포가 바뀌어 특정 그룹에 대한 결과의 편향이 생기거나 커지는 것. 도입 시 공정했어도 지속적으로 모니터링해야 한다.

**일본어** バイアスドリフト　·　**영어** Bias drift

## 시험 트리거
- "도입 시엔 공정했는데 시간이 지나며 특정 그룹에 불리해졌다"
- "편향은 어느 단계에서 생기나" → 여러 단계

## 핵심
**편향이 생기는 수명 주기 단계**

| 단계 | 원인 |
|---|---|
| 데이터 수집 | 대표성 부족, 과거 차별 반영 |
| 레이블 지정 | 작업자 주관, 판단 편차 |
| 모델 설계 | 특성·최적화 목표 선택 |
| 평가 | 치우친 테스트 데이터 |
| 운영 | 사용자층·환경 변화 → **바이어스 드리프트** |

- 모니터링 예: Amazon SageMaker Clarify(덱 언급. 시험 범위 서비스 목록에는 없음).
