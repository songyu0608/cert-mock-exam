# 정형·비정형 데이터

> [!summary] 한 줄 정의
> 정형 = 행과 열(스키마 있음), 반정형 = 태그·키 구조(JSON, 로그), 비정형 = 정해진 형식 없음(이메일, PDF, 이미지, 음성).

**일본어** 構造化データ／半構造化データ／非構造化データ　·　**영어** Structured / Semi-structured / Unstructured data

## 시험 트리거
- "매출표, CRM, 거래 내역" → 정형
- "JSON, XML, 로그" → 반정형
- "계약서 PDF, 통화 녹음, 채팅 기록" → 비정형

## 핵심
| 유형 | 예 | 주요 용도 |
|---|---|---|
| 정형 | 매출표, CRM, 거래 내역, 센서 수치 | 예측, 분류, 수요 예측(기존 ML) |
| 반정형 | JSON, XML, 로그 파일 | 시스템 연동, 로그 분석 |
| 비정형 | 이메일, 계약서 PDF, 이미지, 음성, 동영상, 채팅 기록 | 생성형 AI, NLP, 이미지 인식, 문서 추출 |

- 기업 데이터의 상당 부분은 비정형이다. 생성형 AI의 가치는 이를 업무에 활용하게 해 준다는 점.
