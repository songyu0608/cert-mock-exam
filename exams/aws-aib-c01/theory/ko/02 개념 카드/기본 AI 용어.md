# 기본 AI 용어

> [!summary] 한 줄 정의
> 알고리즘(학습 절차) → 학습(Training)으로 모델을 만들고 → 추론(Inference)으로 새 데이터에 적용해 → 예측(Prediction)을 얻는다.

**일본어** アルゴリズム／モデル／トレーニング／推論／予測　·　**영어** Algorithm / Model / Training / Inference / Prediction

## 시험 트리거
- "학습된 모델을 새 데이터에 적용" → 추론
- "사용량에 비례해 계속 드는 비용" → 추론 비용

## 핵심
| 용어 | 의미 | 비즈니스 예시 |
|---|---|---|
| 알고리즘 | 데이터로부터 학습하기 위한 절차·계산 방법 | 의사 결정 트리, 신경망 |
| 모델 | 학습 결과로 만들어진, 패턴을 표현한 것 | 고객 이탈 예측 모델 |
| 학습(교육) | 과거 데이터로 모델이 패턴을 익히는 과정 | 최근 3년 고객 데이터로 학습 |
| 추론 | 학습된 모델을 새 데이터에 적용 | 신규 고객 이탈 확률 산출 |
| 예측 | 추론으로 얻은 출력 | "이탈 확률 82%" |

> [!note] 용어 표기
> 공식 한국어 안내서는 Training을 기술 1.1.1에서 **교육**, 1.1.5에서 **학습**으로 쓴다. 같은 뜻이다. 일본어는 トレーニング.

**비용 관점**: 학습은 일회성 투자, 추론은 사용량에 비례해 계속 발생한다. → [[총소유비용(TCO)]]
