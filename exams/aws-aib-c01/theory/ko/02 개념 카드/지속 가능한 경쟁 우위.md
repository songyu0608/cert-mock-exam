# 지속 가능한 경쟁 우위

> [!summary] 한 줄 정의
> 파운데이션 모델은 누구나 쓸 수 있다. 지속 가능한 우위의 원천은 고유 데이터 × 업무 프로세스 통합 × 조직 역량 × 고객 신뢰.

**일본어** 持続可能な競争優位性　·　**영어** Sustainable competitive advantage

## 시험 트리거
- "경쟁사가 따라 하기 어렵게 하려면?"
- "데이터 플라이휠"

## 핵심
**데이터 플라이휠**: 더 나은 AI 경험 → 사용자 증가 → 데이터 축적 → 모델·서비스 개선 → (반복). 이 순환이 돌수록 후발 기업이 따라오기 어렵다.

| 모방하기 어려운 원천 | 모방하기 쉬운 것 |
|---|---|
| 고유 데이터 | 범용 파운데이션 모델을 그대로 사용 |
| 업무 프로세스에 깊이 통합 | 누구나 살 수 있는 SaaS 도입 |
| 조직 역량(인재·문화) | |
| 고객과의 신뢰 | |

## 오답 함정
> [!warning] "최신 파운데이션 모델을 쓰는 것"이 우위의 원천이라는 선택지
