# 데이터 사일로

> [!summary] 한 줄 정의
> 부서마다 데이터가 분단된 상태. 전체 그림이 안 보이고 모델이 일부 데이터만 쓰며 통합 비용이 크다. 데이터 준비 상태는 품질·접근성·사일로 영향으로 평가한다.

**일본어** データサイロ／データ準備状況　·　**영어** Data silos / data readiness

## 시험 트리거
- "부서마다 데이터가 나뉘어 AI에 활용할 수 없다"

## 핵심
| 데이터 준비 상태 평가 | 내용 |
|---|---|
| 데이터 품질 | 정확성·완전성·일관성, 레이블 유무와 신뢰성 → [[데이터 품질]] |
| 접근성 | 필요한 사람·시스템이 **안전하게** 액세스할 수 있나 |
| 데이터 사일로 | 부서별 분단 → 전체 그림 부재, 일부 데이터만 사용, 통합 비용 증가 |

**정답 방향**: 전사 [[데이터 전략과 데이터 소유권|데이터 전략]], 데이터 공유 체계, 데이터 통합 기반
