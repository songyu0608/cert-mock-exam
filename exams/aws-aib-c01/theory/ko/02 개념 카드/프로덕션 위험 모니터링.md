# 프로덕션 위험 모니터링

> [!summary] 한 줄 정의
> 프로덕션 AI는 성능·드리프트·안전·사용량·비용·피드백을 모니터링하고, 임계값 알림·인시던트 대응·정기 검토·롤백/중지 절차를 갖춰야 한다.

**일본어** 本番環境のリスク管理とモニタリング　·　**영어** Risk controls and monitoring in production

## 시험 트리거
- "문제가 생기면 감지하고 멈추고 고칠 수 있어야"
- "프로덕션 전환 후 무엇을 갖춰야 하나"

## 핵심
| 무엇을 모니터링 | 어떤 메커니즘 |
|---|---|
| 성능: 정확도, 답변 품질 | 임계값과 알림 |
| 드리프트: 데이터·개념·편향 | 인시던트 대응 절차와 책임자 |
| 안전: 유해 출력, 가드레일 작동 | 정기 검토 |
| 사용 현황과 비용 | 롤백·중지 절차 |
| 사용자 피드백 | |
