# 문제 중심 AI 전략

> [!summary] 한 줄 정의
> AI 전략은 기술이 아니라 비즈니스 문제에서 출발한다. 비즈니스 목표 → 과제·기회 → AI 기능 연결 → 측정 가능한 KPI 순서.

**일본어** 課題起点の AI 戦略　·　**영어** Problem-first AI strategy

## 시험 트리거
- "생성형 AI로 뭔가 할 수 없을까" → 기술 중심(오답 쪽)
- "문의 처리 시간을 줄이고 싶다" → 문제 중심(정답 쪽)
- "AI 기능을 특정 비즈니스 성과에 연결"

## 핵심
| | 기술 중심(피함) | 문제 중심(권장) |
|---|---|---|
| 출발점 | "최신 모델을 도입하자" | "이탈률을 낮추고 싶다" |
| 결과 | 목적이 모호, 성과 측정 불가, PoC에서 멈춤 | 목표에서 거꾸로 AI 활용 방법을 정함 |

**비즈니스 기능별 대표 사용 사례** (공식 기술 2.1.1의 예시 기능)

| 기능 | 사용 사례 | 성과 |
|---|---|---|
| 고객 운영 | 자동 응답, 상담원 지원, 통화 요약 | 처리 시간 단축, 고객 만족도 |
| 영업 및 마케팅 | 개인화, 리드 평가, 콘텐츠 생성 | 성약률·매출 |
| 연구 및 개발 | 문헌 조사, 설계안 탐색 | 개발 기간 단축 |
| 소프트웨어 개발 | 코드 생성, 테스트 작성, 레거시 전환 | 개발 생산성 |
| 백오피스(참고) | 문서 추출, 경비 처리, 사내 검색 | 처리 비용·오류 감소 |

**AI 기능 → 성과 → KPI 연결 예**

| AI 기능 | 활용 | KPI 예 |
|---|---|---|
| 요약 | 통화 기록 자동 요약 | 평균 처리 시간(AHT) |
| 예측 | 수요 예측 발주 | 결품률, 재고 회전율 |
| 분류·추출 | 청구서 자동 처리 | 건당 처리 비용 |
| 생성 | 상품 설명문 작성 | 작성 리드 타임 |
| 개인화 | 개인별 추천 | 전환율, 객단가 |

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - "먼저 기술(모델)을 고른다" "최신 모델 도입"
> - "업무 효율화" 같은 모호한 목표 → 측정 가능한 KPI까지 구체화해야 함
