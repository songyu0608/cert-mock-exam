# AI 성숙도 모델

> [!summary] 한 줄 정의
> 기업이 AI 여정의 어느 단계에 있는지 평가하는 모델. 덱 예: 인식·탐색 → 실험 → 운영 → 엔터프라이즈 규모 배포 → 혁신. 성숙도에 맞는 시책을 고른다.

**일본어** AI 成熟度モデル　·　**영어** AI maturity model

## 시험 트리거
- "실험 단계 조직이 다음에 할 일" → 퀵 윈으로 가치 입증
- "단계를 건너뛰지 않는 진행 경로"

## 핵심
| 단계 | 상태 | 우선할 투자 | 다음 단계 조건 |
|---|---|---|---|
| 1 인식·탐색 | 개인·일부 부서가 산발적 시도 | 활용 능력 교육, 사용 사례 발굴, 경영진 합의 | 작은 PoC로 가치 입증 |
| 2 실험 | 부서 단위 PoC·파일럿 | 데이터 기반, 기본 거버넌스 규칙, 성공 기준 | 파일럿을 프로덕션으로 |
| 3 운영 | 일부가 프로덕션에서 가치 입증 | 운영·모니터링, 변화 관리, 재사용 구조 | CoE로 다른 부서 확산 |
| 4 엔터프라이즈 규모 배포 | 표준화, CoE, 전사 확산 | 공통 플랫폼, 전사 인력 육성, 표준화 | 비즈니스 모델 혁신 |
| 5 혁신 | AI가 사업·비즈니스 모델의 중심 | | |

- 공식 안내서 예시 단계는 "실험, 엔터프라이즈 규모 배포" 두 개뿐. **단계 이름은 모델마다 다르다**.
