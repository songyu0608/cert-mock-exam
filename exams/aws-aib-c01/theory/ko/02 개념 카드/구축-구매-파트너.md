# 구축-구매-파트너

> [!summary] 한 줄 정의
> 구축(자체 개발)·구매(기성 SaaS·제품)·파트너(SI·컨설팅·ISV 협업) 중 예산·일정·기능·공급업체 제안·규정 준수 요구 사항·사내 역량으로 고른다.

**일본어** ビルド・バイ・パートナー　·　**영어** Build / Buy / Partner

## 시험 트리거
- "핵심 차별화, 고유 데이터" → 구축
- "범용 업무, 빠른 도입, 역량 부족" → 구매
- "역량은 부족하지만 빨리 하고 역량도 키우고 싶다" → 파트너

## 핵심
| | 구축 Build | 구매 Buy | 파트너 Partner |
|---|---|---|---|
| 예 | Bedrock·SageMaker AI로 자체 개발 | Amazon Quick, Marketplace 제품 | SI·컨설팅·ISV |
| 적합 | 경쟁 우위의 원천, 고유 데이터 | 범용 업무, 빠른 도입 | 전문성 부족 + 속도 + 내재화 |
| 주의 | 기간·비용·인력, 운영 책임 | 차별화 어려움, 사용자 지정 제한, 공급업체 의존 | 의존 위험, 지식 이전 계획, 계약·데이터 관리 |

**판단 요소** (공식 기술 2.1.2: 예산, 일정, 기능, 공급업체 제안, 규정 준수 요구 사항)

| 요소 | 구축 쪽 | 구매·파트너 쪽 |
|---|---|---|
| 예산 | 초기 투자 감당 가능 | 초기 투자 축소 |
| 일정 | 시간 여유 | 빠른 성과 필요 |
| 기능 | 고유성·차별화 필요 | 범용으로 충분 |
| 공급업체 제안 | 요구를 충족하는 제품 없음 | 성숙한 제품 있음 |
| 규정 준수 | 데이터 위치·관리를 완전 통제 | 공급업체가 인증·통제 보유 |
| 사내 역량 | AI 인력·운영 체계 있음 | 부족(→ 파트너) |

**AWS 선택지 스펙트럼**: [[Amazon Quick]] → [[AWS Marketplace]] → [[Amazon Bedrock]] → [[Amazon SageMaker AI]] (왼쪽 = 도입 속도 ↑, 오른쪽 = 유연성·필요 역량 ↑)
