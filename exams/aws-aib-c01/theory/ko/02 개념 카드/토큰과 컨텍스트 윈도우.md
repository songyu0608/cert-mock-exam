# 토큰과 컨텍스트 윈도우

> [!summary] 한 줄 정의
> 토큰 = 모델이 텍스트를 처리하는 단위(요금 기준이 되는 경우가 많음). 컨텍스트 윈도우 = 한 번에 다룰 수 있는 최대 토큰 수(입력+출력).

**일본어** トークン／コンテキストウィンドウ　·　**영어** Token / Context window

## 시험 트리거
- "긴 문서에서 답이 불완전하다 / 앞부분 정보가 반영되지 않는다"
- "비용·응답 시간이 늘었다"

## 핵심
- 요금은 입력·출력 **토큰 수**로 정해지는 경우가 많다. 한국어·일본어는 영어보다 토큰 수가 늘기 쉽다.
- 윈도우를 넘으면 잘리거나 앞부분 정보가 반영되기 어려워진다.
- 영향을 주는 상황: 긴 문서 일괄 입력, 긴 대화 기록, 대량의 검색 결과

**대처**: 요약·분할(청크화), [[검색 증강 생성(RAG)|RAG]]로 관련 부분만 전달, 적절한 모델 선택
