# 시험 개요와 출제 범위

> [!info] 기준
> AWS 공식 시험 안내서(한국어·일본어) 기준. 이 시험은 베타로 시작했으니 응시 전에 최신 안내서를 다시 확인한다.

## 형식
| 항목 | 내용 |
|---|---|
| 시험 시간 | 130분 |
| 합격 점수 | 700점 (100~1,000 변환 점수) |
| 문항 유형 | 선다형(정답 1, 오답 3), 복수 응답형(5개 이상 중 정답 2개 이상, 모두 맞혀야 점수) |
| 미응답 | 오답 처리. 추측에 불이익 없음 → **반드시 답을 고른다** |
| 판정 | 보상 점수 모델: 섹션별 합격선 없이 총점 |
| 문항 수 | 공식 안내서 본문에서 확인하지 못함(미기재로 보임) |

일본어 표기: 択一選択問題 / 複数選択問題 / 未解答は不正解

## 대상 응시자
- 조직·고객을 위해 AI 이니셔티브를 평가·주도·확장하는 비즈니스 전문가(제품·프로그램 관리자, 영업, 사업부 관리자, 컨설턴트, 마케터, 비즈니스 분석가)
- AI 도입 또는 도입 팀과 협업한 경험 6개월 권장

**범위 밖**: 모델·알고리즘 개발·코딩, 데이터 엔지니어링·특성 추출·하이퍼파라미터 튜닝, 파이프라인 구축, AWS 서비스 구성·배포·관리, 수학·통계 분석, 프로덕션 기술 운영

> [!important] 시험 포인트
> 선택지에 기술 절차가 나와도 "비즈니스 판단으로 가장 적절한가"로 고른다.

## AI Practitioner(AIF-C01)와의 차이
| 관점 | AIF-C01 | AIB-C01 |
|---|---|---|
| 초점 | AI·ML·생성형 AI 기초와 AWS AI 서비스 | AI 투자·거버넌스·도입 추진의 비즈니스 판단 |
| AWS 서비스 | 기능과 용도를 폭넓게 | 전략 수준만(Bedrock, SageMaker AI, Quick 등) |
| 전형적 질문 | "어떤 서비스를 써야 하나" | "다음에 무엇을 해야 하나" "무엇을 우선하나" |
| 카테고리 | Foundational | Business |

AIF에서 배운 기초는 도메인 1에 그대로 쓰인다. 점수 차이는 도메인 2~4의 절충 판단에서 난다.
