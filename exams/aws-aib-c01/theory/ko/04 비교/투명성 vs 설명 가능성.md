# 투명성 vs 설명 가능성

| | 투명성 Transparency | 설명 가능성 Explainability |
|---|---|---|
| 질문 | AI를 **쓰고 있나**, 무엇을 할 수 있고 한계는? | 이 **결과는 왜** 나왔나? |
| 대응 | AI 사용 명시, 능력·한계 공개 | 판단에 영향 준 요인 제시 |
| 시나리오 | "AI가 쓴 글임을 몰랐다" | "심사 결과의 이유를 알려 달라" |
| 일본어 | 透明性 | 説明可能性 |
