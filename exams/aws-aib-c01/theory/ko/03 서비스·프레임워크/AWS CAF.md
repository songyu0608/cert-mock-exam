# AWS CAF

> [!summary] 한 줄 정의
> 조직 전반에서 AI(클라우드) 도입을 계획하고 확장하기 위한 AWS 프레임워크. 비즈니스·인력·거버넌스·플랫폼·보안·운영의 6가지 관점으로 준비 상태를 평가하고 로드맵을 만든다.

**일본어** AWS クラウド導入フレームワーク（AWS CAF）　·　**영어** AWS Cloud Adoption Framework (AWS CAF)

## 시험 트리거
- "준비 상태 평가" "로드맵 작성" "6가지 관점"
- "조직 전반에서 AI 이니셔티브를 계획·확장"

## 핵심
| 관점 | 초점 | 쪽 |
|---|---|---|
| 비즈니스 | AI 투자를 사업 전략·가치 창출에 연결 | 비즈니스 |
| 인력 People | 역량, 문화, 조직 변화, 리더십 | 비즈니스 |
| 거버넌스 | 위험 관리, 책임 있는 AI, 포트폴리오 관리 | 비즈니스 |
| 플랫폼 | AI 인프라와 아키텍처 | 기술 |
| 보안 | 데이터·모델 보호, 규정 준수 | 기술 |
| 운영 | 운영, 모니터링, 지속적 개선 | 기술 |

- **CAF-AI**(AWS CAF for AI)는 CAF를 AI용으로 확장한 것. 혁신 여정 = Envision → Align → Launch → Scale. → [[반복적 변환 접근 방식]]
