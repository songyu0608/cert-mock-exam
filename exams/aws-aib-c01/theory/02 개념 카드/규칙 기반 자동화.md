# 규칙 기반 자동화

> [!summary] 한 줄 정의
> 판단 로직을 if-then으로 명확히 쓸 수 있고 항상 같은 결과(결정론적)가 필요하면 AI가 아니라 규칙 기반 자동화를 쓴다.

**일본어** ルールベースのオートメーション　·　**영어** Rule-based automation

## 시험 트리거
- "규칙으로 명확하게 정의할 수 있다"
- "항상 같은 결과가 필요 / 규정상 결정론적"
- "청구 금액 계산, 승인 흐름"

## 핵심
| 관점 | 규칙 기반 자동화 | AI 솔루션 |
|---|---|---|
| 판단 로직 | 명확(if-then) | 복잡·명문화 어려움 |
| 입력 | 정형·정해진 형식 | 비정형·편차 큼 |
| 결과 요건 | 항상 같은 결과 | 확률적 출력 허용 |
| 환경 변화 | 규칙이 안정적 | 학습으로 적응 필요 |
| 예 | 청구 금액 계산, 승인 흐름, 정형 분류 | 사기 탐지, 수요 예측, 문서 요약 |

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| [[AI 에이전트]] | 예상 못 한 상황에서 다음 행동을 스스로 고른다 |
| [[AI가 적합하지 않은 경우]] | 규칙으로 해결 가능 = AI가 맞지 않는 대표 사례 |
