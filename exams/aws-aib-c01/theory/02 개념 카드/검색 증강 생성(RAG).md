# 검색 증강 생성(RAG)

> [!summary] 한 줄 정의
> 사내·외부 지식을 검색해 답변의 근거로 넣는 기법. 모델을 재학습하지 않고 최신·고유 정보로 답하고 출처를 보여줄 수 있다.

**일본어** 検索拡張生成（RAG）　·　**영어** Retrieval-Augmented Generation (RAG)

## 시험 트리거
- "자주 바뀌는 사내 정보로 답하고 싶다"
- "출처를 보여주고 싶다"
- "사실과 다른 답(할루시네이션)을 줄이고 싶다"

## 핵심
- 데이터가 바뀌면 **지식 기반만 교체**하면 된다(재학습 불필요).
- 출처 제시로 [[할루시네이션]] 감소.
- 비용·기간이 [[미세 조정]]보다 낮고 짧다.
- AWS 예: [[Amazon Bedrock]] 지식 기반.
- 거버넌스 포인트: 검색 결과도 **사용자 권한 안의 문서로 한정**해야 한다(권한을 반영한 검색). → [[액세스 제어와 데이터 보안]]

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| [[미세 조정]] | 문체·형식·전문 작업 **동작**을 바꿈. 출처 제시 불가, 업데이트마다 재학습 |
| [[AI 에이전트]] | 답변을 넘어 **행동**까지 |

## 오답 함정
> [!warning] 자주 바뀌는 정보에 미세 조정을 고르는 선택지 → 업데이트마다 재학습이 필요해 부적합
