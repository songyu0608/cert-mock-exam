# 실험에서 프로덕션으로

> [!summary] 한 줄 정의
> "PoC는 성공했는데 프로덕션으로 못 간다"의 원인은 대개 거버넌스·운영 요구 사항 미충족. 전환 계획에 데이터·거버넌스·보안·운영·규모·책임 체계를 포함한다.

**일본어** 実験段階から本番環境対応レベルへ　·　**영어** From experimentation to production

## 시험 트리거
- "PoC가 프로덕션으로 가지 못한다"
- "파일럿의 늪"

## 핵심
| 관점 | 실험(PoC·파일럿) | 프로덕션 수준 |
|---|---|---|
| 데이터 | 샘플, 수작업 준비 | 자동화 파이프라인, 품질 관리 |
| 거버넌스 | 제한적 | 승인 게이트, 위험 평가, 문서화, 감사 |
| 보안 | 격리된 환경 | 프로덕션 인증·권한·암호화 |
| 운영 | 수동, 최선의 노력 | 모니터링, SLA, 인시던트 대응 |
| 규모 | 소수 사용자 | 전체 부하, 비용 관리 |
| 책임 체계 | 프로젝트 팀 | 업무 소유자·운영 팀에 인계 |
