# 데이터 전략과 데이터 소유권

> [!summary] 한 줄 정의
> 데이터 전략(무엇을 왜 모으나), 데이터 소유권(품질·액세스 승인 책임자), 데이터 공유 프레임워크(규칙·카탈로그·승인·계약)가 AI의 기반이다.

**일본어** データ戦略・データ所有権・データ共有フレームワーク　·　**영어** Data strategy / ownership / sharing framework

## 시험 트리거
- "데이터 품질 문제가 계속된다" → 소유자 부재
- "부서 간·거래처와 데이터를 공유하는 규칙"

## 핵심
| 요소 | 내용 |
|---|---|
| 데이터 전략 | 어떤 데이터를 무엇을 위해 어떻게 모아 쓸지 비즈니스 목표와 연동 |
| 데이터 소유권 | 데이터 소유자(스튜어드)가 품질과 액세스 승인을 책임 |
| 데이터 공유 프레임워크 | 부서 간·거래처 공유 규칙, 카탈로그, 승인 절차, 계약 |
| 데이터 거버넌스 | 분류, 개인정보 보호, 보존 기간, 데이터 계보(리니지) |

> [!important] 시험 포인트
> 품질 문제가 반복되면 근본 대책은 **소유권과 책임 명확화**.
