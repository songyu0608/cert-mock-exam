# 모델 드리프트

> [!summary] 한 줄 정의
> 환경 변화로 도입 후 모델 성능이 떨어지는 현상. 지속적 모니터링 → 감지 → 원인 분석 → 재학습·업데이트 → 재평가로 대응한다.

**일본어** モデルドリフト　·　**영어** Model drift

## 시험 트리거
- "도입 후 시간이 지나며 정확도가 떨어진다"
- "새 고객층·계절 요인·신상품"
- "사기 수법이 바뀌었다"

## 핵심
| 종류 | 무엇이 바뀌나 | 예 |
|---|---|---|
| 데이터 드리프트 | **입력 데이터 분포** | 새 고객층, 계절 요인, 신상품 |
| 개념 드리프트 | **입력과 정답의 관계** | 사기 수법·시장 구조 변화 |

**징후**: 정확도·KPI 하락, 사용자 불만, 사람에게 넘어가는 에스컬레이션 증가

**대응 사이클**: 모니터링 → 감지 → 원인 분석 → 재학습·업데이트 → 재평가

> [!important] 시험 포인트
> AI는 도입하면 끝이 아니다. 모니터링·재학습 체계와 **비용**을 처음부터 계획에 넣는다.
