# AI 에이전트

> [!summary] 한 줄 정의
> 목표를 받아 계획 → 도구 실행 → 결과 평가 → 다음 행동을 자율적으로 반복하는 AI. 답만 하는 챗봇·RAG와 달리 시스템을 실제로 조작한다.

**일본어** AI エージェント　·　**영어** AI agent

## 시험 트리거
- "이전 결과에 따라 다음 행동을 고른다"
- "여러 시스템에서 처리 실행(환불·재발송·에스컬레이션)"
- "스스로 계획하고 도구를 호출"

## 핵심
**핵심 기능 4가지** (공식 기술 1.2.2 예시)

| 기능 | 내용 | 일본어 |
|---|---|---|
| 자율성 Autonomy | 목표만 주면 스스로 절차를 계획·진행 | 自律性 |
| 도구 사용 Tool use | API·DB·업무 시스템 호출(예: MCP) | ツールの使用 |
| 에이전트 간 통신 | 전문 에이전트끼리 협력·위임(예: A2A 프로토콜) | エージェント間のコミュニケーション |
| 오케스트레이션 전략 | 여러 에이전트·단계 조정(감독자형, 순차형, 병렬형) | オーケストレーション戦略 |

- MCP(Model Context Protocol) = 에이전트와 도구를 잇는 프로토콜, A2A(Agent-to-Agent) = 에이전트 간 협업 프로토콜.
- 자율성이 높을수록 **최소 권한, 사람의 승인 지점, 작업 로그(감사)** 가 더 중요해진다. → [[사람의 감시]], [[액세스 제어와 데이터 보안]]
- AWS에서는 [[Amazon Bedrock]]의 에이전트 기능으로 만들 수 있다(전략 수준만 알면 됨).
