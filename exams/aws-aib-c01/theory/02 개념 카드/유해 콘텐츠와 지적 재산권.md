# 유해 콘텐츠와 지적 재산권

> [!summary] 한 줄 정의
> 유해 콘텐츠(차별·폭력·허위, 프롬프트 인젝션·탈옥)와 IP 위험(학습 데이터 권리, 유사 생성물, 기밀 유출, 권리 귀속)을 관리한다.

**일본어** 有害なコンテンツと知的財産（IP）　·　**영어** Harmful content and intellectual property risk

## 시험 트리거
- "생성물이 기존 저작물과 비슷하다"
- "프롬프트 인젝션으로 정책 밖 답변"

## 핵심
| | 위험 | 대책 |
|---|---|---|
| 유해 콘텐츠 | 차별적·폭력적·부적절 출력, 허위 정보, 프롬프트 인젝션·탈옥 | [[가드레일]]·콘텐츠 필터, 레드 팀 테스트, 사용 정책, 사람의 검토 |
| 지적 재산권 | 학습 데이터 권리, 기존 저작물과 유사한 생성물, 기밀 유출, 생성물 권리 귀속 | 권리가 명확한 데이터·모델 선정, 공급업체 IP 보상 확인, 사내 가이드라인, 기밀 입력 제한 |
