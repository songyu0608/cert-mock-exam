# RACI

> [!summary] 한 줄 정의
> R = 실행 책임, A = 최종 책임(반드시 1명), C = 협의, I = 보고. 책임 소재를 명확히 하는 표준 도구.

**일본어** RACI　·　**영어** RACI (Responsible, Accountable, Consulted, Informed)

## 시험 트리거
- "책임자가 불명확하다"
- "명확한 책임 표준을 지정"

## 핵심
| 기호 | 의미 |
|---|---|
| R Responsible | 실행 책임 |
| A Accountable | 최종 책임 (**한 명**) |
| C Consulted | 협의 |
| I Informed | 보고 |

- RACI는 덱이 쓴 대표 도구이고, 공식 안내서 문구는 "명확한 책임 소재/책임 표준"이다(RACI라는 단어 자체는 안내서에 없음).
