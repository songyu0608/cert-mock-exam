# 전사적 스케일링 요소

> [!summary] 한 줄 정의
> 전사 확장 시 비즈니스 연속성·성능·비용·조직과 사람·거버넌스·규제·의존 관계를 다면적으로 평가한다.

**일본어** 全社的なスケーリングで評価する要素　·　**영어** Factors for enterprise-wide scaling

## 시험 트리거
- "전사로 확대할 때 비즈니스 연속성과 성능을 보장"

## 핵심
| 요소 | 확인할 것 |
|---|---|
| 비즈니스 연속성 | 대체 수단, 단계적 배포, 롤백 절차 |
| 성능 | 사용자가 늘어도 응답 시간·정확도 유지 |
| 비용 | 사용량 증가에 따른 비용·한도 관리 |
| 조직과 사람 | 지원 체계, 교육, 변화 관리 |
| 거버넌스·규제 | 지역별 규제, 데이터 저장 위치 |
| 의존 관계 | 공급업체, 모델 업데이트·지원 종료 대비 |
