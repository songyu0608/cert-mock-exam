# 데이터 품질

> [!summary] 한 줄 정의
> "Garbage in, garbage out". 데이터 품질은 정확성·완전성·일관성·적시성·대표성의 5관점으로 평가한다.

**일본어** データ品質　·　**영어** Data quality

## 시험 트리거
- "정확도가 안 나온다 / 결과가 치우친다"
- "모델을 바꾸기 전에 무엇을?" → 데이터 품질 점검

## 핵심
| 관점 | 의미 | 일본어 |
|---|---|---|
| 정확성 Accuracy | 값에 오류가 없다 | 正確性 |
| 완전성 Completeness | 누락·빠진 값이 없다 | 完全性 |
| 일관성 Consistency | 시스템 간 정의·형식이 같다 | 一貫性 |
| 적시성 Timeliness | 최신 상태 유지 | 適時性 |
| 대표성 Representativeness | 대상 모집단을 치우침 없이 나타냄 | 代表性 |

- 대표성이 낮으면 [[책임 있는 AI 차원|공정성]] 문제(편향)로 이어진다.
- 품질 문제가 반복되면 근본 원인은 대개 **책임자 부재** → [[데이터 전략과 데이터 소유권]].

## 헷갈리는 개념
