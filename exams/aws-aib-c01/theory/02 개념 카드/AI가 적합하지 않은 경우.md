# AI가 적합하지 않은 경우

> [!summary] 한 줄 정의
> 규칙으로 해결되거나, 데이터가 없거나, 오류가 허용되지 않고 사람 확인도 둘 수 없거나, 비용 대비 효과가 없거나, 근본 원인이 따로 있거나, 규제·윤리상 허용되지 않으면 AI를 쓰지 않는다.

**일본어** AI が適切なソリューションではない場合　·　**영어** When AI is not the right solution

## 시험 트리거
- "AI를 쓰지 않는다"가 정답인 문제도 나온다
- "처리 건수가 적다" "원인이 프로세스·조직에 있다"

## 핵심
| 경우 | 설명 |
|---|---|
| 규칙으로 해결 | 명확한 로직이면 [[규칙 기반 자동화]]로 충분 |
| 데이터 부족·저품질 | 학습·근거로 쓸 데이터가 없음 |
| 오류 불허 | 완벽한 정확성·설명이 필수인데 사람 확인도 둘 수 없음 |
| 비용 대비 효과 없음 | 처리 건수가 적거나 비용 > 효과 |
| 근본 원인이 따로 | 문제 원인이 프로세스나 조직 |
| 규제·윤리상 불허 | 법규나 사회적으로 AI 사용이 인정되지 않음 |
