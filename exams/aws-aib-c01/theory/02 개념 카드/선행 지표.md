# 선행 지표

> [!summary] 한 줄 정의
> AI 프로젝트 성공을 미리 예측하는 지표(사용자 채택률, 사용 빈도, AI 제안 채택률, 만족도, 작업 완료율, 경영진 관여도). ROI 같은 후행 지표보다 일찍 보인다.

**일본어** 先行指標　·　**영어** Leading indicators

## 시험 트리거
- "파일럿을 계속·확대할지 판단하고 싶다"
- "ROI가 아직 확정되지 않았다"

## 핵심
| 선행 지표 (일찍 보임) | 후행 지표 (결과로 보임) |
|---|---|
| 사용자 채택률·사용 빈도 | ROI |
| AI 제안이 채택된 비율 | 비용 절감액 |
| 사용자 만족도·피드백 | 매출 증가 |
| 작업 완료율 | 고객 유지율 |
| 경영진의 관여도 | |

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| 후행 지표 | ROI·비용 절감액처럼 결과가 나와야 보임 |
