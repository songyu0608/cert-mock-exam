# 사람의 감시

> [!summary] 한 줄 정의
> 영향이 크거나 되돌릴 수 없거나 규정상 요구되거나 AI 확신도가 낮을 때 사람의 감시를 둔다. HITL = 승인 후 실행, HOTL = 모니터링하다 필요 시 개입.

**일본어** 人による監視　·　**영어** Human oversight (HITL / HOTL)

## 시험 트리거
- "대출·채용·의료·법적 판단"
- "지급·계약·삭제처럼 되돌릴 수 없다"
- "확신도가 낮거나 전례가 없다"

## 핵심
| 사람의 감시 필요 | 자동화하기 쉬움 |
|---|---|
| 영향이 큰 판단(대출, 채용, 의료, 법적 판단) | 위험이 낮고 되돌릴 수 있음 |
| 되돌릴 수 없는 행동(지급, 계약, 삭제) | 대량·정형 처리 |
| 규정상 사람 판단 요구 | 오류 영향이 작음 |
| AI 확신도 낮음, 전례 없음 | 사후 확인 가능 |

**에스컬레이션 기준(예)**: 확신도 낮음, 불만·감정적인 고객, 고액 거래, 규제 대상 → 사람에게 넘긴다.

공식 기술 3.1.4의 보호 장치 예시: **할루시네이션 감지, 가드레일, 에스컬레이션 기준**.
