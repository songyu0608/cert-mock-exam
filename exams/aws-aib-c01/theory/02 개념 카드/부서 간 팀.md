# 부서 간 팀

> [!summary] 한 줄 정의
> 비즈니스 리더·기술 전문가·법률·규정 준수(·보안·인사)를 대표하는 팀을 구성하고 명확한 책임 표준(RACI 등)을 지정한다. 기술 팀만의 프로젝트는 오답이 되기 쉽다.

**일본어** 部門横断チーム　·　**영어** Cross-functional team

## 시험 트리거
- "AI 이니셔티브 팀을 어떻게 구성하나"

## 핵심
| 구성원 | 역할 |
|---|---|
| 비즈니스 리더 | 과제 정의와 성과 |
| 기술 전문가 | 데이터, 모델, 시스템 |
| 법률 | 계약, 지적 재산권, 규제 |
| 규정 준수·위험 | 통제, 감사 |
| 보안 | 데이터 보호 |
| 인사 | 인력 육성, 직무 변화 |

공식 예시는 비즈니스 리더, 기술 전문가, 법률, 규정 준수 4개. 책임 표준은 [[RACI]].
