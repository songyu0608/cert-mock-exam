# 총소유비용(TCO)

> [!summary] 한 줄 정의
> AI 비용은 이용료만이 아니다. 데이터 준비·개발·통합·모델 사용자 지정·운영·모니터링·인력·변화 관리·거버넌스까지 포함한 전체 비용.

**일본어** 総所有コスト（TCO）　·　**영어** Total cost of ownership (TCO)

## 시험 트리거
- "예상보다 비용이 크게 나왔다"
- "비용 계획에 무엇을 포함하나"

## 핵심
| 비용 요소 | 내용 |
|---|---|
| 추론·이용료 | 토큰 수, 요청 수, 인스턴스 가동 시간. 사용량에 비례 |
| 데이터 준비 | 수집, 정제, 레이블 지정, 지식 기반 정비 |
| 개발·통합 | 기존 시스템·업무 흐름과 연동 |
| 모델 사용자 지정 | 미세 조정, 추가 학습 |
| 운영·모니터링 | 모니터링, 재학습, 가드레일 유지 |
| 인력·변화 | 교육, 변화 관리, 지원 체계 |
| 거버넌스 | 위험 평가, 감사, 규정 준수 대응 |
