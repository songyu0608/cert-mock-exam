# AI 솔루션 범주

> [!summary] 한 줄 정의
> 추천 엔진, 자연어 처리, 컴퓨터 비전, 문서 추출, 예측 분석, 고객 운영을 위한 AI·생성형 AI. 입력 데이터 종류와 원하는 출력으로 고른다.

**일본어** 主な AI ソリューションのカテゴリー　·　**영어** Common AI solution categories

## 시험 트리거
- "구매 이력으로 상품 추천" → 추천 엔진
- "감정 분석, 번역, 개체명" → NLP
- "검품, 본인 확인" → 컴퓨터 비전
- "청구서에서 항목 추출" → 문서 추출
- "이탈·수요 예측, 신용 평가" → 예측 분석

## 핵심
| 범주 | 하는 일 |
|---|---|
| 추천 엔진 | 구매·열람 이력으로 상품·콘텐츠 추천 |
| 자연어 처리(NLP) | 감정 분석, 분류, 번역, 개체명 추출 |
| 컴퓨터 비전 | 이미지·동영상 인식(검품, 본인 확인, 재고 확인) |
| 문서 추출 | 청구서·신청서 항목 추출로 처리 자동화 |
| 예측 분석 | 수요·이탈 예측, 사기 탐지, 신용 평가 |
| 고객 운영을 위한 AI·생성형 AI | 채팅 어시스턴트, 요약, 콘텐츠 생성, 콘택트 센터 지원 |

- 대상 응시자는 이 범주들을 **인식**하면 되고 구축 경험은 필요 없다(시험 안내서 대상 응시자 설명).
