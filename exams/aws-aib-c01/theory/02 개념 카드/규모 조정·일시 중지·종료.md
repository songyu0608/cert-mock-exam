# 규모 조정·일시 중지·종료

> [!summary] 한 줄 정의
> 사전에 정한 성공 기준(KPI)으로 이니셔티브를 확대·보류·중단한다. 매몰 비용에 얽매이지 않는다.

**일본어** スケーリング・一時停止・終了　·　**영어** Scale / Pause / Stop

## 시험 트리거
- "KPI 달성 + 채택 + 운영 체계" → 규모 조정
- "가치는 있지만 전제 조건 미비" → 일시 중지
- "가치 없음 / 전략과 불일치 / 비용 > 이점" → 종료

## 핵심
| 판단 | 조건 | 행동 |
|---|---|---|
| 규모 조정 Scale | KPI 달성, 사용자 채택, 운영·거버넌스 체계 | 투자 확대, 다른 부서로 확산 |
| 일시 중지 Pause | 가치는 기대되나 전제 미비(데이터 품질, 규제 불확실성, 역량 부족) | 과제 해결까지 보류 |
| 종료 Stop | 가치 없음, 전략 불일치, 비용 > 이점 | 중단하고 자원 재배분 |

## 오답 함정
> [!warning] "지금까지 많이 투자했으니 계속" → 매몰 비용 오류
