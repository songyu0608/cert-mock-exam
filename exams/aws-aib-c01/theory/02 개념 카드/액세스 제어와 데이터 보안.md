# 액세스 제어와 데이터 보안

> [!summary] 한 줄 정의
> 최소 권한, 데이터 분류, 암호화, 개인정보 보호, 권한을 반영한 검색, 감사 로그로 AI 시스템의 접근과 데이터를 보호한다.

**일본어** アクセス制御とデータセキュリティ　·　**영어** Access control and data security

## 시험 트리거
- "AI가 원래 볼 수 없어야 할 사내 문서 내용을 답했다" → 권한을 반영한 검색
- "프롬프트에 기밀 정보 입력"

## 핵심
| 조치 | 내용 |
|---|---|
| 최소 권한 | 필요한 사람·시스템에 필요한 범위만 |
| 데이터 분류 | 민감도별 취급 규칙 |
| 암호화 | 저장 중·전송 중 |
| 개인정보 보호 | 마스킹·익명화, 프롬프트에 기밀 입력 제한 |
| 권한을 반영한 검색 | RAG 검색 결과도 사용자 권한 안의 문서로 한정 |
| 감사 로그 | 누가 언제 무엇에 액세스했는지 기록 |
