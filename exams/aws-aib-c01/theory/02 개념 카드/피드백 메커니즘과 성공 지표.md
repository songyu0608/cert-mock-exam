# 피드백 메커니즘과 성공 지표

> [!summary] 한 줄 정의
> 장기 가치를 추적하려면 사용자 피드백·채택 지표·비즈니스 성과·품질 지표를 계속 측정하고 정기 검토로 개선 사이클을 돌린다.

**일본어** 継続的なフィードバックと成功メトリクス　·　**영어** Continuous feedback and success metrics

## 시험 트리거
- "AI 이니셔티브의 장기적 가치를 추적"

## 핵심
| 요소 | 예 |
|---|---|
| 사용자 피드백 | 평가 버튼, 설문, 인터뷰 |
| 사용·채택 지표 | 활성 사용자 수, 사용 빈도 |
| 비즈니스 성과 지표 | KPI·ROI 추이 |
| 품질 지표 | 정확도, 에스컬레이션 비율, 할루시네이션 발생률 |
| 정기 검토 | 분기마다 포트폴리오 재검토 |
| 개선 사이클 | 측정 → 학습 → 개선 반복 |

- 측정 결과는 [[규모 조정·일시 중지·종료]] 판단에 쓴다.
