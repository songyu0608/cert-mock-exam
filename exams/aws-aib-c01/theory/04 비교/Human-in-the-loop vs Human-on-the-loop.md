# Human-in-the-loop vs Human-on-the-loop

| | Human-in-the-loop | Human-on-the-loop |
|---|---|---|
| 방식 | 사람이 **승인한 뒤** 실행 | AI가 실행, 사람이 **모니터링하다 필요 시 개입** |
| 맞는 위험 | 높음(대출, 채용, 의료, 지급) | 중간(표본 검사, 예외 처리) |
| 일본어 | 人による監視 (덱 용어집은 Human-in-the-loop에 대응) | |
