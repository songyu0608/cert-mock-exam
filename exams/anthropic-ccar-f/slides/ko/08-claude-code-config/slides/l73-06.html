glob 패턴

glob은 파일 유형으로 일치시킨다

*              any part of a file name
**             any folder, at any depth
**/*.test.tsx  any file ending in .test.tsx

chat/Cart.test.tsx        matches
chat/Header.test.tsx      matches
new-folder/Order.test.tsx matches too

패턴은 위치가 아니라 파일 유형으로 파일을 찾습니다.

원문 제목: Globs match files by type (GLOB PATTERNS). 의미: * = 파일 이름의 아무 부분, ** = 깊이와 관계없이 아무 폴더, **/*.test.tsx = .test.tsx로 끝나는 모든 파일. chat/Cart.test.tsx, chat/Header.test.tsx 일치, new-folder/Order.test.tsx도 일치. 캡션: The pattern matches files by type, not by location.
