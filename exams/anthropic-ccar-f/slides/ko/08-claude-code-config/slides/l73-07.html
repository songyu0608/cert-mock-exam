glob 패턴

패턴 하나로 한 폴더를 다룰 수도 있다

# testing rule
paths:
  - "**/*.test.tsx"

# deployment rule
paths:
  - "terraform/**/*"

한 패턴은 파일 유형을, 다른 패턴은 한 폴더와 그 아래 전부를 다룹니다.

원문 제목: A pattern can cover one folder (GLOB PATTERNS). 코드(영문 유지) 의미: 테스트 규칙 paths "**/*.test.tsx", 배포 규칙 paths "terraform/**/*". 캡션: One pattern covers a type of file, the other one folder and everything under it.
