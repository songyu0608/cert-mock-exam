argument-hint

힌트가 무엇을 넣을지 보여 준다

● ● ●

스킬 호출

DEMO

/map-flow <the flow to map, such as refund or escalation, or a PR number>

힌트는 입력을 검사하지 않습니다. 필요한 입력을 분명히 보여 줄 뿐입니다.

원문 제목: The hint shows what to provide (ARGUMENT-HINT). 예시 화면(Skill call, DEMO): 입력창에 "/map-flow <그릴 흐름: 환불이나 에스컬레이션 같은 것, 또는 PR 번호>"가 표시됨. 캡션: The hint does not check the input - it only makes the required input clear.
