첫째, 프로젝트 파일

팀 서버는 .mcp.json에 둔다

{
  "mcpServers": {
    "shopassist": {
      "command": "shopassist-mcp"
    },
    "github": {
      "command": "npx",
      "args": ["-y", "github-mcp-server"]
    }
  }
}

서버마다 이름과 명령이 있습니다. 파일을 커밋하면 풀하는 모두가 같은 서버를 받습니다.

원문 제목: Team servers live in .mcp.json (FIRST, THE PROJECT FILE). JSON(영문 유지) 의미: mcpServers 아래 shopassist(명령 shopassist-mcp), github(명령 npx, 인수 -y github-mcp-server). 캡션: Each server has a name and a command. Commit the file, and everyone who pulls gets the same servers.
