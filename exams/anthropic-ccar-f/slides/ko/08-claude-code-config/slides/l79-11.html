Grep

파일 안의 텍스트

Glob

이름 패턴으로 파일 찾기

Read

파일 전체를 로드

Write

파일을 만들거나 교체

원문 제목: Six tools, six clear jobs (RECAP). Grep: Text in files / Glob: Files by name pattern / Read: Loads a whole file / Write: Creates or replaces a file / Edit: One spot, unique anchor / Bash: Runs commands, like tests.
