allowed-tools

map-flow는 읽기 전용 도구를 받는다

Read

파일을 엶

Grep

파일 안을 검색

Glob

이름으로 파일을 찾음

시험 기준으로, map-flow는 파일을 고치거나 명령을 실행할 수 없습니다.

원문 제목: Map flow gets read-only tools (ALLOWED-TOOLS). Read: Opens a file / Grep: Searches inside files / Glob: Finds files by name. 하단: In exam terms, map flow cannot edit a file or run a command.
