Edit가 실패할 때

반복된 줄이 Edit를 깨뜨린다

def refund_item(amount):
    total = round(amount, 2)
    return total

def refund_order(amount):
    total = round(amount, 2)
    return total

Edit(old_text="total = round(amount, 2)")
Error: anchor found 2 times - not unique

같은 줄이 두 함수에 있어서, Edit는 어느 쪽을 뜻하는지 알 수 없습니다.

원문 제목: A repeated line breaks Edit (WHEN EDIT FAILS). 코드(영문 유지) 의미: refund_item과 refund_order 두 함수에 같은 줄 "total = round(amount, 2)"가 있음. Edit 결과 오류: 기준점이 2번 발견됨 - 고유하지 않음. 캡션: The same line sits in two functions, so Edit cannot tell which one is meant.
