paths 필드

frontmatter에 paths 필드를 더한다

---
paths:
  - "**/*.test.ts"
  - "**/*.test.tsx"
---

# Testing rules
- Name each test after the behaviour it checks.
- Mock external calls, never the network.

헤더는 파일 맨 위, 대시 세 개로 된 두 줄 사이에 둡니다.

원문 제목: Frontmatter adds a paths field (THE PATHS FIELD). 코드(영문 유지) 의미: paths에 **/*.test.ts, **/*.test.tsx 지정. 본문 "테스트 규칙: 각 테스트에 그것이 확인하는 동작의 이름을 붙인다 / 외부 호출은 목(mock)으로 처리하고, 실제 네트워크는 쓰지 않는다". 캡션: The header sits at the top of the file, between two lines of three dashes.
