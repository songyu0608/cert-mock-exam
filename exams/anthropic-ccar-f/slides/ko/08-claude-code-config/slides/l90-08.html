거부된 파일 건너뛰기

나머지를 완료로 보고하면 어떤 핸들러가 빠졌는지 가려집니다.

필요한 것: 아무것도 깨뜨리지 않는 빠짐없는 변경, 그리고 효과가 있었다는 증거.

원문 제목: Rewriting and skipping both fail (SECOND DECISION). Rewrite with Write: Write replaces the whole file; anything not copied is lost. / Skip refused files: Reporting the rest as done hides which handlers are missing. 하단: Need: a complete change that breaks nothing, and proof that it worked.
