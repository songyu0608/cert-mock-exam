둘째: 테스트 먼저

코드보다 테스트를 먼저 쓴다

def test_examples():
    assert convert(OLD_1) == NEW_1
    assert convert(OLD_2) == NEW_2

def test_edge_cases():
    assert convert(ZERO_AMOUNT)["amount_cents"] == 0
    assert convert(UNKNOWN_STATUS)["status"] == "unknown"

def test_ten_thousand_records():
    with max_seconds(5):
        convert_all(SAMPLE_10K)

테스트 스위트가 기대 동작, 엣지 케이스, 성능을 다룹니다. 그다음 Claude Code가 스크립트를 씁니다.

원문 제목: Write the tests before the code (SECOND: TESTS FIRST). 코드(영문 유지) 의미: test_examples - 예시 변환이 기대값과 같음 / test_edge_cases - 금액 0이면 amount_cents 0, 모르는 상태는 "unknown" / test_ten_thousand_records - 레코드 1만 개를 5초 안에 변환. 캡션: A test suite covers expected behavior, edge cases and performance - then Claude Code writes the script.
