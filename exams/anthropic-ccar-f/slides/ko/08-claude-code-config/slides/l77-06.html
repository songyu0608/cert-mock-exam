둘째, 비밀

토큰이 아니라 이름을 커밋한다

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "github-mcp-server"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}

파일에는 변수 이름만 있으므로 커밋해도 안전합니다.

원문 제목: Commit the name, not the token (SECOND, THE SECRET). JSON(영문 유지) 의미: github 서버의 env에 GITHUB_TOKEN: "${GITHUB_TOKEN}" - 실제 값이 아니라 환경 변수 이름을 참조. 캡션: The file holds only the variable's name, so it is safe to commit.
