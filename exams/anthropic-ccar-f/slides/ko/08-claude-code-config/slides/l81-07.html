노이즈가 많은 탐색에는 Explore를 쓴다

Explore 사용

긴 작업의 노이즈가 많은 탐색. 예: 모듈 지도 그리기, 흐름 추적.

Explore 생략

이미 아는 파일 하나의 작은 변경. 메인 대화가 그냥 읽으면 됩니다.

원문 제목: Use Explore for noisy discovery (WHEN TO USE IT). Use Explore: Noisy discovery in a long task, like mapping a module or tracing a flow. / Skip Explore: A small change in one known file. The main conversation can simply read it.
