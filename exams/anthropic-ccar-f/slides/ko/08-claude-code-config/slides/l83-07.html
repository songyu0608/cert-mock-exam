문제 다섯 개 중 두 개가 연결돼 있다

def lookup_order(order_id, customer_id):
    key = order_id
    if key in cache:
        return cache[key]
    order = order_service.get(order_id)
    check_owner(order, customer_id)
    cache[key] = order
    return order

def on_refund(order_id):
    cache.pop(order_id, None)

리뷰에서 문제 다섯 개가 나왔고, 그중 두 개는 같은 캐시 키를 공유합니다.

원문 제목: Two of five problems are linked (HABIT TWO: PROBLEMS PER MESSAGE). 코드(영문 유지) 의미: lookup_order는 order_id만 캐시 키로 씀. 캐시에 있으면 소유자 확인(check_owner) 없이 바로 반환. on_refund는 order_id 키로 캐시를 지움. 캡션: A review finds five problems - two of them share one cache key.
