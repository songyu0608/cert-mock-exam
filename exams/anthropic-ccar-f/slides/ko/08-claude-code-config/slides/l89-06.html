대기 중인 환불이 이제 지급된 것처럼 보인다

def to_ledger(record):
    # the old library returned None while a refund is pending
    settled = record.settled_date or date.today()
    return {
        "status": record.status,
        "settled_date": settled,
    }

예시용 버그: 빈 날짜가 채워져서 대기 중인 환불이 지급된 것처럼 보입니다. 대략 50건 중 1건입니다.

원문 제목: Pending refunds now look paid (SECOND DECISION). 코드(영문 유지) 의미: 옛 라이브러리는 환불이 대기 중일 때 None을 돌려줬음. 새 코드는 settled_date가 없으면 오늘 날짜로 채우므로, 대기 중 환불에 정산일이 생겨 지급된 것처럼 보임. 캡션: An illustrative bug: the empty date is filled in, so pending refunds look paid - about one record in fifty.
