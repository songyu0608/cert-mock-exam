최선의 수

토큰이 아니라 파일을 커밋한다

{
  "mcpServers": {
    "jira": {
      "command": "npx",
      "args": ["-y", "community-jira-server"],
      "env": {
        "JIRA_TOKEN": "${JIRA_API_TOKEN}"
      }
    }
  }
}

공유되는 .mcp.json: 파일에는 변수 이름만 들어 있습니다. 개발자는 각자 한 번만 값을 설정합니다.

원문 제목: Commit the file, not the token (THE BEST MOVE). 코드(영문 유지) 의미: .mcp.json에 jira 서버를 npx로 community-jira-server를 실행하도록 등록. JIRA_TOKEN에는 실제 토큰 대신 ${JIRA_API_TOKEN} 환경 변수 참조만 넣음. 패키지 이름 community-jira-server는 원문의 예시입니다. 캡션: A shared .mcp.json: the file holds only the variable's name. Each developer sets it once.
