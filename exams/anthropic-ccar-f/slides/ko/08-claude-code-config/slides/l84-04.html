첫째: 이름으로 이어 가기

ID가 아니라 이름으로 이어 간다

# Friday: give the session a name
/rename refund analysis

# Monday: resume it by name
claude --resume "refund analysis"

# Newer versions also accept the ID
claude --resume <session-id>

시험에서 정답은 세션 이름과 함께 쓰는 resume 플래그입니다.

원문 제목: Resume by name, not by ID (FIRST: RESUME BY NAME). 코드(영문 유지) 의미: 금요일에 /rename으로 세션 이름을 "refund analysis"로 붙임. 월요일에 claude --resume "refund analysis"로 이름을 지정해 이어 감. 새 버전은 세션 ID도 받음. 명령 동작은 원문 그대로이며 확인하지 않았습니다. 캡션: On the exam, the answer is the resume flag with the session name.
