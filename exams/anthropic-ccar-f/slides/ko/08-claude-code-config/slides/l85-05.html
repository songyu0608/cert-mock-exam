어떻게 포크하나

resume에 플래그를 더하면 포크가 된다

# Agent SDK (Python): resume by ID and fork
options = ClaudeAgentOptions(
    resume=session_id,
    fork_session=True,
)

원래 세션은 그대로 남고, 포크는 새 세션 ID를 받습니다.

원문 제목: Resume plus a flag makes a fork (HOW TO FORK). 코드(영문 유지) 의미: Agent SDK(Python)에서 resume에 세션 ID를 넣고 fork_session=True를 주면 그 세션을 이어 가는 대신 포크합니다. 캡션: The original session stays as it was; the fork gets a new session ID.
