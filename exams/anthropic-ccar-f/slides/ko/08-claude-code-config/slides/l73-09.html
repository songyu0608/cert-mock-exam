규칙을 그 범위에 맞춘다

디렉터리 하나

그 디렉터리에 CLAUDE.md를 둡니다. 예: 환불 폴더 자체의 규칙.

한 파일 유형, 여러 폴더

rules 폴더에 경로별 규칙을 둡니다. 예: 모든 테스트 파일.

규칙은 컨텍스트이지 강제가 아닙니다. 반드시 통과해야 하는 테스트는 여전히 CI에서 실행됩니다.

원문 제목: Match the rule to its scope (HOW TO CHOOSE). One directory: Use a CLAUDE.md in that directory, like the refund folder's own rules. / One type of file, many folders: Use a path-scoped rule in the rules folder, like all test files. 하단: Rules are context, not enforcement - a test that must pass still runs in CI.
