최선의 수

정확한 사례 하나는 의심의 여지를 남기지 않는다

# input: a pending refund record
case_input = {
    "status": "pending",
    "settled_date": None,
}
# expected output: the same record, unchanged
case_expected = {
    "status": "pending",
    "settled_date": None,
}

이런 예시는 두 가지로 읽힐 수 없습니다.

원문 제목: One exact case leaves no doubt (THE BEST MOVE). 코드(영문 유지) 의미: 입력은 대기 중(pending)이고 settled_date가 None인 환불 레코드. 기대 출력은 같은 레코드 그대로(바뀌지 않음). 캡션: An example like this cannot be read two ways.
