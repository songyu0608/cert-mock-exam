원문 제목: Linked problems go in one message (LINKED PROBLEMS). 코드(영문 유지) 의미: 1라운드에서 키만 (order_id, customer_id)로 고침. on_refund는 여전히 옛 키(order_id)로 지우므로 환불 후 캐시가 지워지지 않음. 캡션: One detailed message, or the second round repairs what the first one broke.
