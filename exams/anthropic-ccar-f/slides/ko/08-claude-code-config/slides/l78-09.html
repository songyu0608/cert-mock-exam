작고 명확한 수정은 바로 실행한다

def check_delivery_date(delivery_date, today):
    if delivery_date is None:
        return None

    if delivery_date > today:
        raise ValueError("Delivery date is in the future")

    return delivery_date

명확하고 범위가 정해진 변경: 계획을 세워 봐야 스택 트레이스가 말하는 내용을 되풀이할 뿐입니다.

원문 제목: A small, clear fix goes direct (DIRECT EXECUTION). 코드(영문 유지) 의미: check_delivery_date - 배송일이 None이면 None 반환(충돌 수정), 배송일이 오늘보다 뒤면 "배송일이 미래임" 오류, 그 외에는 배송일 반환. 캡션: A clear, scoped change: a plan would only repeat what the stack trace says.
