해결책

결정을 가르는 기준을 명시한다

Customer: "Can a jacket delivered 5 weeks ago be returned?"
→ plain question: explain the 30-day window

Customer: "Please accept the return anyway."
→ request for an exception: hand off to a human

기준이 명확하면 메시지 종류마다 해석이 하나만 남습니다.

원문 제목: State the criterion that decides (THE FIX). 프롬프트 예시(영문 유지) 의미: 고객 “5주 전에 배송된 재킷을 반품할 수 있나요?” → 단순 질문: 30일 기간을 설명한다. / 고객 “그래도 반품을 받아 주세요.” → 예외 요청: 사람에게 넘긴다. 캡션: A clear criterion leaves one reading for each kind of message.
