둘째: EFFORT

effort를 낮추면 비용이 줄어든다

# A plain 'it has shipped' answer: lower effort
reply = client.messages.create(
    model=CHAT_MODEL,
    max_tokens=1024,
    output_config={"effort": "low"},
    messages=messages,
)

effort가 높으면 더 신중하게 일합니다. 낮으면 더 빠르고, 더 짧고, 도구 호출이 줄어듭니다.

원문 제목: Lower the effort to spend less (SECOND: THE EFFORT). 코드(영문 유지) 주석 의미: “발송되었습니다” 같은 단순한 답에는 낮은 effort. 캡션: Higher effort: more careful work. Lower effort: faster, shorter, fewer tool calls.
