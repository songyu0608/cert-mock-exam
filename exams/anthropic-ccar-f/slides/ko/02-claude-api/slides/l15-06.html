단계마다 맞는 모델

모델 ID는 한 곳에서 한 번만 정한다

# Easy, runs after every chat: Haiku
SUMMARY_MODEL = "claude-haiku-5-5"

# Needs judgment: Sonnet
CHAT_MODEL = "claude-sonnet-5-5"

reply = client.messages.create(
    model=CHAT_MODEL,
    max_tokens=1024,
    messages=messages,
)

단계마다 모델을 고르는 한 가지 방법입니다. 새 모델이 나오면 한 줄만 바꾸면 됩니다.

원문 제목: Set each model ID once (RIGHT MODEL PER STEP). 코드(영문 유지) 주석 의미: 쉬운 일, 채팅마다 실행되므로 Haiku / 판단이 필요하므로 Sonnet. 캡션: One way to choose a model per step: a new model changes one line.
