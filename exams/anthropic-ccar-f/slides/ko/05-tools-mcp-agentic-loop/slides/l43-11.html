실패의 종류와 재시도 여부를 밝힌다

isError: true

MCP가 실패한 호출에 표시

오류 범주

transient, validation, business, permission

isRetryable

같은 호출이 성공할 수 있을 때만 true

설명

무엇이 잘못됐고 무엇을 고칠지

에이전트에게 어떤 종류의 실패인지, 다시 시도하면 도움이 되는지 알려 주세요.

원문 제목: Name the failure and the retry (WHAT TO REMEMBER). isError: true: MCP marks a failed call / Error category: Transient, validation, business, permission / isRetryable: True only if the same call may work / Description: What went wrong and what to fix. 하단: Tell the agent what kind of failure happened and whether trying again can help.
