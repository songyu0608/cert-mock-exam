while True:
    response = client.messages.create(
        model=MODEL, max_tokens=1024, tools=TOOLS, messages=messages,
    )
    if response.stop_reason == "tool_use":
        results = run_tools(response)
        messages += [as_assistant(response), as_user(results)]
    elif response.stop_reason == "end_turn":
        show(response)
        break

원문 제목: Four steps, repeat until end_turn (THE LOOP IN CODE). 코드(영문 유지) 의미: 무한 반복 안에서 Claude에 요청을 보낸다. stop_reason이 "tool_use"이면 도구를 실행하고, Claude의 응답 전체와 도구 결과를 메시지 기록에 추가한 뒤 다시 돈다. "end_turn"이면 답변을 보여 주고 루프를 빠져나온다. 캡션: Send, read the stop reason, run, add, repeat.
