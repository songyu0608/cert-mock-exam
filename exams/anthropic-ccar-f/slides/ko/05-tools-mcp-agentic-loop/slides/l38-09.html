매 라운드마다 대화 기록 전체를 다시 보낸다

messages = [{"role": "user", "content": "My jacket arrived damaged..."}]

response = client.messages.create(
    model=MODEL, max_tokens=1024, tools=TOOLS, messages=messages,
)

# stop_reason is "tool_use": add two messages
messages.append({"role": "assistant", "content": response.content})
messages.append({"role": "user", "content": tool_results})

API는 아무것도 기억하지 않으므로, 모든 호출이 대화 전체를 담아 보냅니다.

원문 제목: Every round resends the history (SECOND, THE HISTORY). 코드(영문 유지) 의미: 사용자 메시지 "My jacket arrived damaged..."(재킷이 파손되어 도착했어요)로 기록을 시작해 요청을 보낸다. 주석 "stop_reason is tool_use: add two messages"는 "stop_reason이 tool_use이면 메시지 두 개를 추가한다"는 뜻으로, Claude의 응답 전체(assistant)와 도구 결과(user)를 차례로 추가한다. 캡션: The API remembers nothing, so every call carries the whole conversation.
