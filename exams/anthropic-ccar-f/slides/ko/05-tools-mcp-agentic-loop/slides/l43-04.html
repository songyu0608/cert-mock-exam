플래그 먼저, 그다음 범주

isError는 실패했다는 사실만 말한다

{
  "isError": true,
  "errorCategory": "business",
  "message": "Operation failed"
}

isError는 MCP의 일부이고, errorCategory는 도구와 에이전트 사이에 우리가 정한 약속입니다.

원문 제목: isError says only that it failed (FIRST THE FLAG, THEN THE CATEGORY). JSON(영문 유지) 의미: 오류 여부 true, 오류 범주 "business"(업무 규칙), 메시지 "Operation failed"(작업 실패). 메시지만으로는 무엇을 해야 할지 알 수 없습니다. 캡션: isError is part of MCP; errorCategory is our own contract between tools and agent.
