내용 전체를 ID와 함께 보관한다

messages.append({"role": "assistant", "content": response.content})
messages.append({
    "role": "user",
    "content": [{
        "type": "tool_result",
        "tool_use_id": "toolu_01",
        "content": '{"customer_id": "CUS-1001"}',
    }],
})

응답은 통째로 저장하고, 각 결과에는 해당 요청의 ID를 붙입니다.

원문 제목: Keep the full content, with IDs (A DETAIL THAT BREAKS LOOPS). 코드(영문 유지) 의미: Claude의 응답 content를 잘라내지 않고 그대로 assistant 메시지로 추가한다. 이어지는 user 메시지에는 tool_result 블록을 넣고, tool_use_id "toolu_01"로 어떤 요청에 대한 결과인지 연결한다. 결과 내용은 {"customer_id": "CUS-1001"}. 캡션: Save the full response; each result carries the ID of its request.
