오류 범주

일시적 문제인가, 잘못된 입력인가

transient (일시적)

타임아웃이나 잠깐의 서비스 중단. 주문 서비스가 제때 응답하지 않았다.

validation (검증)

입력이 잘못됐다. Alex가 주문 번호를 한 자리 빼고 입력했다.

원문 제목: Temporary problem or wrong input (THE ERROR CATEGORY). Transient: A timeout or a service down for a moment. The order service did not answer in time. / Validation: The input was wrong. Alex typed his order number with a digit missing.
