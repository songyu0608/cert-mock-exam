시험 범위 밖

시험은 다섯 가지 중 두 가지만 다룬다

end_turn

Claude가 끝냈다

tool_use

도구를 실행하고 계속

max_tokens

한도에서 잘림

pause_turn

일시 정지, 그대로 다시 보냄

refusal

Claude가 거절함

원문 제목: The exam names two of five (BEYOND THE EXAM). end_turn: Claude has finished / tool_use: Run the tool, continue / max_tokens: Cut off at the limit / pause_turn: Paused, send it back / refusal: Claude declined. 시험에서 다루는 것은 end_turn과 tool_use 두 가지입니다.
