재시도 플래그

성공할 수 있을 때만 재시도한다

타임아웃

isRetryable: true
같은 호출이 나중에 성공할 수 있다

업무 규칙 오류

isRetryable: false
내일이 되어도 기한 밖이다

검증 오류

isRetryable: false
같은 잘못된 번호는 또 실패한다

isRetryable은 같은 호출을 그대로 다시 했을 때 성공할 수 있는 경우에만 true입니다.

원문 제목: Retry only when it may succeed (THE RETRY FLAG). Timeout: isRetryable: true - the same call may work later / Business error: isRetryable: false - still outside the window tomorrow / Validation error: isRetryable: false - the same wrong number fails again. 하단: isRetryable is true only when the same call, unchanged, may succeed later.
