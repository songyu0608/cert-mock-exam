보내고, stop_reason을 읽고, 실행하고, 추가하고, 반복한다.

Claude는 도구를 요청하고, 애플리케이션이 실행한다

tool_use: 실행하고, 응답 전체와 결과를 추가해 다시 호출

end_turn: 작업 완료

여러 도구를 한 번에: 사용자 메시지 하나, tool_use_id로 짝지음

Claude는 알게 된 내용을 바탕으로 다음 도구를 고른다

원문 제목: The loop: send, read, run, add (RECAP). The agentic loop: Send, read the stop reason, run, add, repeat. / Claude asks for tools, your application runs them / tool_use: run, add the full response and results, call again / end_turn: the task is done / Several tools at once: one user message, matched by tool use ID / Claude picks each next tool from what it has learned.
