코드로 만드는 보장

숫자는 요약 밖에 둔다

case_facts:
  - issue: jacket
    amount: 89.00
    refund_id: REF-4417
    status: refunded
    refund_to: card
  - issue: lamp
    refund: refused
    reason: outside return window
    customer_told: true

요약은 이야기를 담고, 케이스 정보 블록은 숫자를 담습니다.

원문 제목: Keep numbers outside the summary (A GUARANTEE IN CODE). 코드(영문 유지) 의미: case_facts - 재킷(금액 89.00, 환불 ID REF-4417, 상태 환불 완료, 환불 수단 카드), 램프(환불 거절, 사유 반품 기한 밖, 고객에게 안내함). 캡션: The summary keeps the story, and the case-facts block keeps the numbers.
