escalate_to_human의 입력

핸드오프에는 사실 네 가지를 담는다

// escalate_to_human - tool input
{
  "customer_id": "CUS-1001",
  "root_cause": "Arrived broken, photo shows damage, order in return window",
  "refund_amount": 620.00,
  "recommended_action": "Approve full refund - above the automatic limit"
}

이 네 필드가 있으면 담당자가 바로 처리할 수 있습니다.

원문 제목: The handoff carries four facts (INPUT OF ESCALATE_TO_HUMAN). JSON(영문 유지) 의미: 고객 ID CUS-1001, 근본 원인 "파손된 채 도착, 사진으로 파손 확인, 반품 기한 내 주문", 환불 금액 620.00, 권장 조치 "전액 환불 승인 - 자동 처리 한도 초과". 캡션: With these four fields, the person can act at once.
