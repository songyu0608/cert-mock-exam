KEEP = ["status", "items", "amount", "delivered_on", "return_window"]

def post_tool_use(result):
    result = plain_words(result)
    return {k: result[k] for k in KEEP}

PostToolUse 훅의 스케치입니다. 줄여도 모든 값은 그대로이고, 이번 결정에 쓰지 않는 것만 버립니다.

원문 제목: Trimming drops fields, not values (TRIMMING IN PRACTICE). 코드(영문 유지) 의미: 남길 필드(status, items, amount, delivered_on, return_window)를 정하고, post_tool_use에서 결과를 평이한 표현으로 바꾼 뒤 그 필드만 돌려준다. 캡션: A sketch of a PostToolUse hook: trimming leaves every value unchanged and only drops what this decision does not use.
