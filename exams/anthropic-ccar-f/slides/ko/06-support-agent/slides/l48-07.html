둘째, 도구

작업에 필요한 도구만 허용한다

// TypeScript
const options = { allowedTools: [
  "mcp__store__get_customer", "mcp__store__lookup_order",
  "mcp__store__process_refund", "mcp__store__escalate_to_human",
] };

# Python
options = ClaudeAgentOptions(allowed_tools=[
  "mcp__store__get_customer", "mcp__store__lookup_order",
  "mcp__store__process_refund", "mcp__store__escalate_to_human",
])

지원 에이전트에는 도구 네 개만 줍니다. 환불 대화에 셸은 필요 없고, 도구가 적을수록 Claude가 고르기 쉽습니다.

원문 제목: Allow only the tools the job needs (SECOND, THE TOOLS). 코드(영문 유지) 의미: TypeScript와 Python에서 각각 허용 도구 목록에 스토어 MCP 서버의 도구 네 개(get_customer, lookup_order, process_refund, escalate_to_human)만 넣는다. 도구 이름은 mcp__서버이름__도구이름 형식이다. 캡션: A support agent gets four tools - no shell in a refund conversation, and fewer tools make Claude's choice easier.
