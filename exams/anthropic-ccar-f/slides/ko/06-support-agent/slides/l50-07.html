훅 설정

이 훅은 도구 하나만 지킨다

async def check_refund(input_data, tool_use_id, context):
    if input_data["tool_input"]["amount"] > 500:
        return {"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "permissionDecision": "deny",
            "permissionDecisionReason": "Over $500: escalate to a person"}}
    return {}

hooks = {"PreToolUse": [HookMatcher(
    matcher="mcp__store__process_refund", hooks=[check_refund])]}

훅을 도구 하나에만 붙이는 한 가지 방법입니다. 백엔드도 이런 환불은 거부합니다.

원문 제목: The hook guards one tool only (THE HOOK CONFIGURATION). 코드(영문 유지) 의미: check_refund 함수는 도구 입력의 amount가 500을 넘으면 PreToolUse 결과로 permissionDecision "deny"(거부)와 이유 "Over $500: escalate to a person"($500 초과: 사람에게 에스컬레이션)을 반환하고, 아니면 빈 객체를 반환한다. HookMatcher의 matcher로 mcp__store__process_refund 도구에만 이 훅을 연결한다. 캡션: One way to attach a hook to a single tool. The backend also refuses such a refund.
