설명에 인접 도구를 적는다

process_refund:
  Sends money to the customer.
  Never a status check.
  Runs only when the customer asked for a
  refund and the order qualifies.
  For order questions, use lookup_order.
lookup_order:
  Returns status, items, amounts, return window.
  Use for any question about whether an order
  can still be returned or refunded.
  To send a refund, use process_refund.

각 설명은 도구가 하는 일과, 언제 대신 인접 도구를 써야 하는지를 말합니다.

원문 제목: Descriptions name the neighbor (SECOND DECISION). 설명(영문 유지) 의미: process_refund - 고객에게 돈을 보낸다. 상태 확인용이 절대 아니다. 고객이 환불을 요청했고 주문이 조건을 충족할 때만 실행한다. 주문 질문에는 lookup_order를 쓴다. / lookup_order - 상태, 품목, 금액, 반품 기한을 돌려준다. 주문을 아직 반품하거나 환불할 수 있는지에 관한 모든 질문에 쓴다. 환불을 보내려면 process_refund를 쓴다. 캡션: Each description says what the tool does and when to use its neighbor instead.
