Five domains: Each domain's share of the exam questions. 27% Agentic Architecture and Orchestration / 18% Tool Design and MCP Integration / 20% Claude Code Configuration and Workflows / 20% Prompt Engineering and Structured Output / 15% Context Management and Reliability. 도메인 명칭은 공식 가이드 한국어판(ccarf-guide-ko.md) 표기를 따름.
