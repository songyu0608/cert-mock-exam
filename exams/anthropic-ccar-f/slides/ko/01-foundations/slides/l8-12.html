ShopAssist

Agent SDK로 만든 온라인 스토어용 고객 지원 에이전트.

도구 네 가지: get_customer, lookup_order, process_refund, escalate_to_human

반드시 할 일 목록: 판단이 필요한 일이며, Claude가 내린다

절대 하지 말 일 목록: 우리 코드의 검사

목표: 첫 문의 해결률 80%. 따라서 너무 자주 에스컬레이션하면 실패다

원문 제목: ShopAssist in five points (RECAP). ShopAssist: A support agent for an online store, built with the Agent SDK. / Four tools: get customer, lookup order, process refund, escalate to human / Must-do list: judgment, and Claude makes those calls / Must-never list: checks in our code / Target: 80 % first-contact resolution, so escalating too often is a failure.
