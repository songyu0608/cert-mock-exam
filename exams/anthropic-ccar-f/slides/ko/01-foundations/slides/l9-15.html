주된 긴장 관계

형식은 맞지만 데이터는 틀리다

{
  "invoice_id": "INV-2041",
  "vendor": "Northwind Supplies",
  "items": [120.00, 80.00],
  "total": 250.00,
  "po_number": null
}

레코드는 스키마와 일치하면서도 틀릴 수 있습니다. (120.00 + 80.00 = 200.00이지만 total은 250.00)

원문 제목: Valid shape, wrong data (THE MAIN TENSION). JSON 레코드(영문 유지). 캡션: A record can match the schema and still be wrong. 괄호 안의 합계 설명은 번역 시 덧붙인 것(원문 슬라이드에는 없음).
