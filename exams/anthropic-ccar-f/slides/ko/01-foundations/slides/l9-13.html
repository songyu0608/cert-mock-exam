파이프라인에서 실행

키보드 앞에는 아무도 없다

# A CI step that runs on every pull request
claude -p "Review this diff. Report only real bugs, with file and line." \
  --output-format json > review.json

# The next step reads the result with a script
jq -r '.result' review.json

질문에 답해 줄 사람이 없는 상태에서 리뷰를 실행하는 한 가지 방법입니다.

원문 제목: Nobody at the keyboard (RUNNING IN A PIPELINE). 코드(영문 유지) 의미: 모든 풀 리퀘스트마다 실행되는 CI 단계. claude -p로 "이 diff를 리뷰하라. 실제 버그만 파일과 줄과 함께 보고하라"를 실행하고 JSON으로 review.json에 저장. 다음 단계는 스크립트(jq)로 결과를 읽음. 캡션: One way to run a review with no one there to answer questions.
