# /review - a custom slash command for the team

Review the staged changes.
- Check them against the conventions in CLAUDE.md
- Flag missing tests for new functions
- List findings by file and line, most severe first

Focus: $ARGUMENTS

공유 지침은 CLAUDE.md에 두고, 팀원 누구나 실행할 수 있는 단축 명령을 만듭니다.

원문 제목: Shared instructions and shortcuts (CONFIGURATION AND WORKFLOW). 라벨: the same shortcut for everyone. 코드(영문 유지) 의미: /review는 팀용 커스텀 슬래시 커맨드. 스테이징된 변경을 리뷰하라. CLAUDE.md의 컨벤션과 대조하고, 새 함수에 테스트가 없으면 표시하고, 지적 사항을 파일과 줄 단위로 심각한 것부터 나열하라. Focus: $ARGUMENTS. 캡션: Shared instructions in CLAUDE.md, then a shortcut every teammate can run.
