AGENT SDK가 더해 주는 것

SDK가 루프를 대신 실행한다

Agent SDK

일반 API를 쓰면 루프를 직접 작성해야 합니다. SDK는 내 코드를 위해 루프를 실행해 줍니다.

내장 도구: 파일 읽기, 명령 실행

서브에이전트: 한 에이전트를 돕는 보조 에이전트

훅: 도구 호출 전이나 후에 실행되는 내 코드

세션: 대화를 나중에 이어서 진행

MCP 서버: 다른 시스템을 연결

원문 제목: The SDK runs the loop for you (WHAT THE AGENT SDK ADDS). Agent SDK: With the plain API you write the loop yourself. The SDK runs it for your code. / Built-in tools: read files, run commands / Subagents: helper agents for one agent / Hooks: your code before or after a tool call / Sessions: continue a conversation later / MCP servers: connect other systems.
