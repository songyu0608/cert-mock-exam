프롬프트: 기준

보고할 것과 건너뛸 것을 이름으로 댄다

REVIEW_PROMPT = """
Report: bugs, security problems.
Skip: minor style, local patterns.
Severity (definition + example each):
- critical: query built from user input
- minor: unused import
"""

DISABLED = ["naming"]  # noisy, fix first

모호한 "조심하라"는 Claude가 한계를 추측하게 만듭니다. 명시적 기준이 추측을 없앱니다.

원문 제목: Name what to report and skip (PROMPTS: CRITERIA). 프롬프트(영문 유지) 의미: 보고: 버그, 보안 문제. 건너뛰기: 사소한 스타일, 국지적 패턴. 심각도(각각 정의와 예시): critical은 사용자 입력으로 만든 쿼리, minor는 쓰이지 않는 import. DISABLED: naming 범주는 시끄러우니 먼저 고칠 것. 캡션: Vague caution makes Claude guess the limit. Explicit criteria remove the guess.
