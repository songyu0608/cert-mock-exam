구조화된 오류 컨텍스트

필드 네 개가 쓸모 있는 보고를 만든다

{
  "failure_type": "timeout, supplier archive, after 2 retries",
  "query": "supplier reports about lamp defects, last 2 years",
  "partial_results": [
    "2 of 5 supplier reports loaded",
    "support tickets about loose wiring read"
  ],
  "alternatives": ["retry the archive later", "web search: published reports"]
}

코디네이터가 선택할 수 있도록 실패를 보고하는 한 가지 방법입니다.

원문 제목: Four fields make a useful report (STRUCTURED ERROR CONTEXT). JSON(영문 유지) 의미: failure_type - 시간 초과, 공급업체 아카이브, 재시도 2회 후 / query - 최근 2년 램프 결함 관련 공급업체 보고서 / partial_results - 공급업체 보고서 5건 중 2건 로드, 느슨한 배선 관련 지원 티켓 읽음 / alternatives - 나중에 아카이브 재시도, 웹 검색: 공개 보고서. 캡션: One way to report a failure so the coordinator can choose.
