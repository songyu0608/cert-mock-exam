최선의 조치

요청만 하지 말고, 도구를 제한한다

search_agent = AgentDefinition(
    description="Finds articles on one area",
    prompt="Search the web for the assigned area.",
    tools=["WebSearch"],
)

synthesis = AgentDefinition(
    description="Combines findings into a report",
    prompt="Combine the findings you are given.",
    tools=[],
)

프롬프트 한 줄은 대부분의 경우 안내하는 데 그치고, 도구 목록은 제한합니다.

원문 제목: Restrict tools, don't just ask (THE BEST MOVE). 코드(영문 유지) 의미: search_agent - 설명 "한 영역의 기사를 찾는다", 프롬프트 "배정된 영역을 웹에서 검색하라", 도구 WebSearch만. synthesis - 설명 "조사 결과를 보고서로 합친다", 프롬프트 "받은 조사 결과를 합쳐라", 도구 없음([]). 캡션: A prompt line guides most of the time; a tool list restricts.
