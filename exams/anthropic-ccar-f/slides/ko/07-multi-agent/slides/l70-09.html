최선의 조치는 문서 분석에서 시작

두 값을 남기고, 충돌을 표시한다

{
  "figure": "packages nobody maintains, last year",
  "conflict": true,
  "values": [
    { "value": "18%", "source": "industry survey",
      "method": "owners asked about their own packages" },
    { "value": "31%", "source": "university study",
      "method": "how often each package's code changed" }
  ]
}

예시 레코드 하나: 두 값, 충돌 표시, 각 출처와 그 방법.

원문 제목: Keep both values, flag conflict (THE BEST MOVE STARTS IN DOCUMENT ANALYSIS). JSON(영문 유지) 의미: 수치 "작년 아무도 관리하지 않는 패키지", 충돌 true, 값 - ① 18%, 출처: 업계 설문, 방법: 소유자에게 자기 패키지에 대해 물음 ② 31%, 출처: 대학 연구, 방법: 각 패키지 코드가 얼마나 자주 바뀌었는지. 캡션: One illustrative record: both values, the conflict flag, each source and its method.
