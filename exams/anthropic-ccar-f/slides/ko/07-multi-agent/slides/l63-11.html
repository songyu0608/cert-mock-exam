핵심 포인트

정리: 도구 범위를 역할에 맞춘다

역할마다 도구 4~5개

시스템의 모든 도구가 아님

도구는 적게

너무 많으면 선택이 덜 안정적

역할 안에 머물기

남는 도구는 오용된다

원문 제목: Recap: scope tools to the role (MAIN POINTS). 4-5 tools per role: Not every tool in the system / Fewer tools: Too many make selection less reliable / Stay in role: Spare tools get misused.
