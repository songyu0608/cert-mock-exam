제약이 있는 도구

좁은 도구는 호출마다 확인한다

ALLOWED_HOSTS = {"reports.supplier.example", "reviews.example"}

def load_document(url: str) -> str:
    host = urlparse(url).hostname
    if host not in ALLOWED_HOSTS:
        # the check lives inside the tool
        raise ValueError("Not a real document address")
    return download(url)

무엇이든 할 수 있는 도구보다, 올바른 일만 할 수 있는 도구를 택합니다.

원문 제목: A narrow tool checks every call (A CONSTRAINED TOOL). 코드(영문 유지) 의미: 허용 호스트 목록을 두고, load_document는 URL의 호스트가 목록에 없으면 "실제 문서 주소가 아님" 오류를 낸다(확인은 도구 안에 있음). 통과하면 내려받는다. 캡션: Prefer a tool that can only do the right thing over a tool that can do anything.
