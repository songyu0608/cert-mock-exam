허용 도구

코디네이터에게는 Task 허용이 필요하다

# Exam: "Task". Current SDK releases: "Agent".
MODEL = "claude-sonnet-5-5"

coordinator = ClaudeAgentOptions(
    model=MODEL,
    system_prompt="You coordinate research on lamp returns.",
    allowed_tools=["Task"],
)

allowed_tools에 Task가 없으면, 코디네이터는 계획은 세워도 서브에이전트를 시작할 수 없습니다.

원문 제목: The coordinator needs Task allowed (ALLOWED TOOLS). 코드(영문 유지) 의미: 주석 - 시험에서는 "Task", 현재 SDK 릴리스에서는 "Agent". 코디네이터 옵션: 모델, 시스템 프롬프트 "램프 반품에 관한 리서치를 조율한다", 허용 도구 Task. 캡션: Without Task in allowed_tools, the coordinator can plan but cannot start a subagent. (코드 속 모델명과 API 이름은 원문 그대로이며 검증하지 않음)
