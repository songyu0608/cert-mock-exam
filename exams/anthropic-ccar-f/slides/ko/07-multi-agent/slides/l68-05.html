첫째, 분석

레코드는 두 값을 모두 담는다

{
  "claim": "lamp defect rate, last year",
  "conflict": true,
  "values": [
    { "value": "2 in 100", "source": "supplier report",
      "period": "last year", "method": "factory test" },
    { "value": "6 in 100", "source": "support tickets",
      "period": "last year", "method": "customer returns" }
  ]
}

충돌을 기록하는 한 가지 방법입니다. 이 레코드는 종합 단계로 바로 가지 않고 코디네이터에게 갑니다.

원문 제목: The record keeps both values (FIRST, THE ANALYSIS). JSON(영문 유지) 의미: 주장 "작년 램프 결함률", 충돌 true, 값 - ① 100개 중 2개, 출처: 공급업체 보고서, 기간: 작년, 방법: 공장 테스트 ② 100개 중 6개, 출처: 지원 티켓, 기간: 작년, 방법: 고객 반품. 캡션: One way to record a conflict - and it goes to the coordinator, not straight to synthesis.
