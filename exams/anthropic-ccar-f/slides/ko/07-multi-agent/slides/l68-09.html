둘째, 날짜

모든 조사 결과에는 날짜가 필요하다

{
  "properties": {
    "value": { "type": "string" },
    "source": { ... },
    "published": { ... },
    "collected": { ... }
  },
  "required": ["value", "source", "published", "collected"]
}

두 날짜가 없으면, 서로 다른 해의 숫자가 의견 불일치처럼 보입니다.

원문 제목: Every finding needs a date (SECOND, THE DATES). JSON 스키마(영문 유지) 의미: 속성 value(문자열), source, published(발행일), collected(수집일). 네 항목 모두 필수(required). 캡션: Without both dates, numbers from different years look like a disagreement.
