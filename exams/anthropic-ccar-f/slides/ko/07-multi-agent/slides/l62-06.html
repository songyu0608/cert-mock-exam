둘째: 에이전트 정의

서브에이전트마다 정의가 있다

agents = {
    "document-analysis": AgentDefinition(
        description="Reads the store's tickets and supplier reports. "
                    "Use it for facts from the store's own files.",
        prompt="Read the support tickets and supplier reports. "
               "Give every finding its source and its date.",
        tools=["Read", "Grep"],
    ),
}

description, prompt, tools: 에이전트 정의 하나를 이루는 세 부분입니다.

원문 제목: Each helper has a definition (SECOND: AGENT DEFINITIONS). 코드(영문 유지) 의미: document-analysis 에이전트 정의. description - 스토어의 티켓과 공급업체 보고서를 읽는다. 스토어 자체 파일의 사실이 필요할 때 쓴다. prompt - 지원 티켓과 공급업체 보고서를 읽어라. 모든 조사 결과에 출처와 날짜를 붙여라. tools - Read, Grep. 캡션: Description, prompt and tools: three parts of one agent definition.
