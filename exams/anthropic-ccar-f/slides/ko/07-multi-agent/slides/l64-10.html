상류에서 시작

상류 에이전트가 메타데이터를 붙여야 한다

FINDING_SCHEMA = {
    "type": "object",
    "properties": {
        "claim": {"type": "string"},
        "evidence": {"type": "string"},
        "source": {"type": "string"},
        "date": {"type": "string"},
        "method": {"type": "string"},
    },
    "required": ["claim", "evidence", "source", "date", "method"],
}

상류의 모든 조사 결과가 메타데이터를 갖게 하는 한 가지 방법: 메타데이터가 없는 조사 결과는 불완전합니다.

원문 제목: Upstream agents must add metadata (START UPSTREAM). 코드(영문 유지) 의미: 조사 결과 스키마 - claim, evidence, source, date, method를 모두 문자열 필드로 두고 다섯 개 모두 필수로 지정한다. 캡션: One way to make every upstream finding carry its metadata: a finding without them is incomplete.
