def find_orders(email):
    try:
        orders = search_orders(email)
    except TimeoutError:
        # the order service timed out
        return []

    return orders

결과는 같지만 의미는 다릅니다: 일치하는 항목이 없는 것은 정상이고, 타임아웃은 실패입니다.

원문 제목: Two lookalikes, one boundary (THIRD JOB: CONTRASTING PAIRS). 코드(영문 유지): 주문 서비스 타임아웃 시 빈 목록을 반환. 캡션: Same result, different meaning: no match is normal, a timeout is a failure.
