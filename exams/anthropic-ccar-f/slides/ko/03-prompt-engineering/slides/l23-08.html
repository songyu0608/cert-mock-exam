가장 좋은 첫 해결책

각 등급을 실제 코드로 정의한다

severity:
  critical:
    means: money or customer data at risk
    example: refund = msg["amount"]
  major:
    means: wrong result, no money at risk
    example: total = price * qty  # tax missing
  minor:
    means: style or naming only
    example: tmp2 = items

일관된 심각도: 정의된 등급, 그리고 실제 코드로 보여 준 각 등급.

원문 제목: Define each level with real code (THE BEST FIRST FIX). 코드(영문 유지) 의미: critical = 돈이나 고객 데이터가 위험함, 예: 메시지의 금액을 그대로 환불 / major = 결과가 틀리지만 돈은 위험하지 않음, 예: 세금이 빠진 합계 / minor = 스타일이나 이름 짓기만, 예: tmp2 = items. 캡션: Consistent severity: defined levels, and each level shown with real code.
