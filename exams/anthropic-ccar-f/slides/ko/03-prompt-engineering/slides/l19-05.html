차단 검사는 풀 리퀘스트를 머지하기 전에 통과해야 합니다.

원문 제목: A blocking check locks the merge (SECOND - BLOCKING CHECKS). Pull request → CI checks: Run required checks / CI checks → Pull request: Required test failed / Pull request → Developer: Merge locked / Developer → Pull request: Fix + new commit / Pull request → CI checks: Checks run again. 캡션: A blocking check must pass before the pull request can be merged.
