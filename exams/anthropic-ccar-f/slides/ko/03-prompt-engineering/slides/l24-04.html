결정 1: 가장 좋은 방법

더 많은 설명보다 예시

Example 1
location: line 42, apply_discount()
issue: the discount is applied after tax
severity: high
fix: apply the discount before tax

Example 2
location: line 7, load_cart()
issue: an empty cart raises an error
severity: medium
fix: return an empty cart object

규칙: 자세한 지침에도 형식이 들쭉날쭉하면, 설명을 멈추고 보여 주세요.

원문 제목: Examples beat more description (DECISION 1: THE BEST MOVE). 예시(영문 유지) 의미: 예시 1 - 위치: 42번 줄 apply_discount() / 문제: 할인이 세금 뒤에 적용됨 / 심각도: high / 수정: 세금 전에 할인 적용. 예시 2 - 위치: 7번 줄 load_cart() / 문제: 빈 장바구니에서 오류 발생 / 심각도: medium / 수정: 빈 장바구니 객체 반환. 캡션: Rule: when detailed instructions still give an uneven format, stop describing it and show it.
