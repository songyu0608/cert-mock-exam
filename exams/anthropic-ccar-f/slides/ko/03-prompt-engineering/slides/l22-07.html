해결책

예시는 거친 표현도 읽어 낸다

# Example 1
report = "The chat froze for about half a minute."
result = {"delay_seconds": 30, "approximate": True}

# Example 2
report = "The chat was really slow."
result = {"delay_seconds": None}

거친 표현은 값이 되거나 - 정직하게 값 없음이 된다.

원문 제목: Examples read rough wording (THE FIX). 예시(영문 유지) 의미: 예시 1: "채팅이 30초쯤 멈췄다" → 지연 30초, 대략값 표시 / 예시 2: "채팅이 정말 느렸다" → 지연 값 없음(None). 캡션: Rough wording becomes a value - or an honest no value.
