결정 2 - 지어낸 값

필드를 비워 두게 한다

# Example 3: invoice without a PO number
Invoice: Nordic Lamps, 3 lamps, total 410.00
Answer: {
  "supplier": "Nordic Lamps",
  "po_number": null,
  "category": "equipment",
  "total": 410.00
}

원본이 비어 있으면, 필드도 비어 있습니다.

원문 제목: Let the field stay empty (DECISION 2 - INVENTED VALUES). 예시(영문 유지) 의미: 예시 3 - PO 번호가 없는 청구서. 청구서: Nordic Lamps, 램프 3개, 합계 410.00 / 답: supplier "Nordic Lamps", po_number null(값 없음), category "equipment", total 410.00. 캡션: When the source is empty, the field stays empty.
