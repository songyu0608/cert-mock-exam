값의 타입

모든 값에는 타입이 있다

{
  "reason": "broken button",
  "price": 89.9,
  "refund_requested": true,
  "problems": ["broken button", "missing belt"]
}

따옴표 안의 텍스트, 따옴표 없는 숫자, true 또는 false, 그리고 대괄호 안의 목록.

원문 제목: Every value has a type (VALUE TYPES). JSON(영문 유지) 의미: reason = 문자열, price = 숫자 89.9, refund_requested = true/false(불리언), problems = 목록(배열) ["단추 고장", "벨트 누락"]. 캡션: Text in quotes, a number without quotes, true or false, and a list in square brackets.
