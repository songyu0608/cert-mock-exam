시험 vs 코드

시험의 정답과 현재 코드

시험에서는

any 또는 강제 도구로 답한다.

현재 코드에서는

strict 도구와 그 도구를 지정하는 지침을 auto와 함께 쓰거나, structured outputs를 쓴다.

요청마다: Claude가 말해도 되는가, 아무 도구나 호출해야 하는가, 아니면 이 도구인가?

원문 제목: Exam answer versus current code (EXAM VERSUS CODE). On the exam: Answer any or a forced tool. / In current code: Auto with a strict tool and an instruction that names it, or structured outputs. 하단: Per request: may Claude talk, call some tool, or this one?
