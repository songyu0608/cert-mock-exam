재시도가 통하는 곳

재시도는 형식을 고칠 뿐, 없는 것은 못 고친다

재시도가 성공

형식 문제, 구조 오류, 틀린 필드에 들어간 값.

재시도가 실패

정보가 없을 때. 예를 들어 아무도 제공하지 않은 문서에만 있는 값.

원문 제목: Retry fixes format, not absence (WHERE A RETRY WORKS). A retry succeeds: On format problems, structural errors and values in the wrong field. / A retry fails: When the information is absent - for example, a value that lives only in a document nobody provided.
