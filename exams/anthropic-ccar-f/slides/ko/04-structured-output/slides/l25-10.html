Claude에게 도구를 설명한다

Claude는 도구 설명을 읽는다

{
  "name": "lookup_order",
  "description": "Find an order by its number. Use it for order questions.",
  "input_schema": {
    "type": "object",
    "properties": {
      "order_number": {"type": "string"}
    },
    "required": ["order_number"]
  }
}

도구는 세 부분으로 이루어집니다: 이름, 설명, 입력 스키마.

원문 제목: Claude reads a tool description (A TOOL IS DESCRIBED TO CLAUDE). 도구 정의(영문 유지) 의미: 이름 lookup_order / 설명 "주문 번호로 주문을 찾는다. 주문 관련 질문에 사용한다." / 입력 스키마: order_number(문자열, 필수). 캡션: A tool has three parts: a name, a description, and an input schema.
