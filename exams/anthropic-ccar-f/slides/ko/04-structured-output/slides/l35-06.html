결정 1 - 의미

모양이 유효해도 틀릴 수 있다

record = {
    "items": [120, 150, 140],
    "stated_total": 420,       # printed on the invoice
    "calculated_total": 410,   # sum of the items
}

if record["stated_total"] ≠ record["calculated_total"]:
    hold_for_review(record)

스키마는 모양을 보장하고, 의미는 코드가 검사합니다.

원문 제목: Valid shape can still be wrong (DECISION 1 - MEANING). 코드(영문 유지) 의미: 품목 120, 150, 140 / 청구서에 인쇄된 합계 420 / 품목의 합 410. 두 합계가 다르면 기록을 검토 대기로 보류. 캡션: The schema guarantees the shape, and your code checks the meaning.
