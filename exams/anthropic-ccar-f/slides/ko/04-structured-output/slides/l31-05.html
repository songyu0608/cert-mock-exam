필드 둘, 비교 하나

두 합계가 차이를 드러낸다

extraction = {
    "stated_total": 110.00,      # printed on the document
    "calculated_total": 100.00,  # sum of the line items
}

# our code compares the two
if extraction["stated_total"] ≠ extraction["calculated_total"]:
    flag_for_review(extraction)  # flagged, not saved

두 값 모두 스키마를 통과합니다 - 비교해야만 오류가 보입니다.

원문 제목: Two totals expose the gap (TWO FIELDS, ONE COMPARISON). 코드(영문 유지) 의미: stated_total = 문서에 인쇄된 합계 110.00 / calculated_total = 품목 금액의 합 100.00 / 코드가 둘을 비교해 다르면 검토 대상으로 표시하고 저장하지 않음. 캡션: Both values pass the schema - only the comparison shows the error.
