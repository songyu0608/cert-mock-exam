충돌 필드

플래그가 조용한 추측을 막는다

extraction = {
    "conflict_detected": True,
    "conflict_note": "Form: refund. Comment: replacement",
}

if extraction["conflict_detected"]:
    # no refund is started
    ask_customer(extraction["conflict_note"])

플래그가 환불을 멈추고, 결정은 고객이 합니다.

원문 제목: A flag stops a silent guess (THE CONFLICT FIELDS). 코드(영문 유지) 의미: conflict_detected = True / conflict_note = "양식: 환불. 의견: 교환" / 충돌이 감지되면 환불을 시작하지 않고 conflict_note로 고객에게 물어봄. 캡션: The flag stops the refund, and the customer decides.
