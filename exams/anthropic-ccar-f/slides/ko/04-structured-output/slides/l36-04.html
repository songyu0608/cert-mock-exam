시험의 정답

모르는 유형에는 any, 첫 단계에는 강제

# The exam's form of tool_choice (fragment)
# 1. Unknown document type: Claude must call a tool
tool_choice = {"type": "any"}

# 2. Metadata must run first: force that one tool
tool_choice = {"type": "tool", "name": "extract_metadata"}

# 3. Follow-up requests, enrichment
tool_choice = {"type": "auto"}

모르는 유형에는 도구 호출을 필수로, 첫 추출은 강제하고, 그다음 auto로 돌아갑니다.

원문 제목: Any for unknown, forced for first (THE EXAM'S ANSWER). 코드(영문 유지) 의미: 시험 형식의 tool_choice(일부). 1. 문서 유형을 모름: 반드시 도구를 호출 → any / 2. 메타데이터를 먼저 실행: 그 도구 하나를 강제 / 3. 후속 요청, 보강 → auto. 캡션: Required tool call for unknown types; force the first extraction, then go back to auto.
