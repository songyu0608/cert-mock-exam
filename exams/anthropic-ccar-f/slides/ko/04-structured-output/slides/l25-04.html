Alex의 요청을 JSON으로

JSON은 이름이 붙은 필드와 값이다

{
  "customer": "Alex",
  "item": "jacket",
  "reason": "broken button",
  "refund_requested": true
}

중괄호는 객체를 나타냅니다: 각각 이름과 값을 가진 필드의 묶음입니다.

원문 제목: JSON is named fields with values (ALEX'S REQUEST AS JSON). JSON(영문 유지) 의미: 고객 Alex, 품목 재킷, 사유 단추 고장, 환불 요청 true. 캡션: Braces mark an object: a group of fields, each with a name and a value.
