둘째, 스키마

스키마는 데이터의 규칙을 정한다

{
  "type": "object",
  "properties": {
    "reason": {"type": "string"},
    "refund_requested": {"type": "boolean"},
    "comment": {"type": "string"}
  },
  "required": ["reason", "refund_requested"]
}

스키마에는 고객 데이터가 없습니다 - 모든 요청이 갖춰야 할 모양만 있습니다.

원문 제목: A schema sets the rules for data (SECOND, THE SCHEMA). 스키마(영문 유지) 의미: 객체 타입이며 reason(문자열), refund_requested(불리언), comment(문자열) 필드를 가짐. reason과 refund_requested는 필수. 캡션: The schema holds no customer data - only the shape every request must have.
