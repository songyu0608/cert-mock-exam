결정 1 - 파싱

도구 스키마가 파싱을 보장한다

tool = {
    "name": "record_invoice",
    "strict": True,
    "input_schema": {
        "type": "object",
        "properties": {"supplier": {"type": "string"},
                      "total": {"type": "number"}},
        "required": ["supplier", "total"],
        "additionalProperties": False,
    },
}

strict 도구 사용: Claude가 청구서 스키마를 채웁니다. structured outputs도 같은 보장을 줍니다.

원문 제목: A tool schema guarantees parsing (DECISION 1 - PARSING). 코드(영문 유지) 의미: strict를 켠 record_invoice 도구. supplier(문자열)와 total(숫자)이 필수이고, 그 밖의 필드는 허용하지 않음(additionalProperties: False). 캡션: Strict tool use: Claude fills the invoice schema. Structured outputs give the same guarantee.
