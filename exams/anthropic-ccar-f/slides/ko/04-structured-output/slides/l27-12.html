요청마다 선택은 하나

요청 단위

각 요청이 자신의 도구 선택을 정한다.

auto - 텍스트 또는 도구 호출

any - 도구 호출, 도구는 Claude가 고름

강제 - 지정된 도구를 먼저

원문 제목: One choice for every request (RECAP). Per request: Each request sets its own tool choice. / auto - text or a tool call / any - a tool call, Claude picks / forced - one named tool first.
