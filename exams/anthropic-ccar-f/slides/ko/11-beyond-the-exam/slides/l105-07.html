프롬프트가 아니라 훅을 고친다

STATUS_WORDS = {
    1: "requested",
    2: "pending",
    3: "refunded",
}

def to_word(code):
    if code not in STATUS_WORDS:
        raise ValueError(f"unknown status {code}")
    return STATUS_WORDS[code]

프롬프트를 바꿔서는 이것을 고칠 수 없습니다. 증상을 숨길 뿐일 수 있습니다.

원문 제목: Fix the hook, not the prompt (THE FIRST WRONG STEP). 코드(영문 유지) 의미: 상태 코드 1·2·3을 requested·pending·refunded로 매핑하고, 표에 없는 코드는 기본값으로 넘기지 않고 오류("unknown status")를 냄. 캡션: A prompt change could not repair this - it might only hide the symptom.
