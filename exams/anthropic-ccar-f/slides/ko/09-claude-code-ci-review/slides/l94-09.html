핵심 정리

-p, JSON, 스키마를 쓴다

-p가 없으면 멈춤

대화형 모드는 사람을 기다림

-p / --print

프롬프트를 실행하고, 출력하고, 종료

output-format json

스크립트가 읽는 JSON 답

--json-schema

내 스키마를 따르는 JSON

원문 제목: Use -p, JSON and a schema (MAIN POINTS). No -p: it hangs: Interactive mode waits for a person / -p / --print: Runs the prompt, prints, exits / Output format json: The answer as JSON a script reads / --json-schema: JSON that follows your schema. 플래그 이름(--output-format json, --json-schema)은 원문 그대로이며 확인하지 않았습니다.
