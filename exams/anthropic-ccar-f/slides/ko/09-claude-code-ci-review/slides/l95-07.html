프로젝트 파일 안

모든 실행이 같은 파일을 읽는다

# Testing standards
- Framework: pytest; test files in a tests folder
# Valuable tests
- Check behavior that moves money or changes a decision:
  $500 limit, 30-day return window, no delivery date
- Skip trivial tests, such as returning a stored field
# Fixtures
- fake payment service
- sample customer with two orders
# Review criteria
- Report bugs and security problems; skip minor style

표준은 더 긴 테스트 프롬프트가 아니라 커밋된 파일 하나에 둡니다.

원문 제목: Every run reads the same file (INSIDE THE PROJECT FILE). 내용(영문 유지) 의미: 앞 슬라이드의 테스트 표준과 가치 있는 테스트에 더해, 픽스처(가짜 결제 서비스, 주문이 두 개인 샘플 고객)와 리뷰 기준(버그와 보안 문제를 보고하고 사소한 스타일은 건너뜀). 캡션: The standards live in one committed file, not in a longer test prompt.
