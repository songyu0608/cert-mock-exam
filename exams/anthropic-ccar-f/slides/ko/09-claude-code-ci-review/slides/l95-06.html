# Testing standards
- Framework: pytest; test files in a tests folder
# Valuable tests
- Check behavior that moves money or changes a decision:
  $500 limit, 30-day return window, no delivery date
- Skip trivial tests, such as returning a stored field

CI 작업을 위한 테스트 표준과 리뷰 기준을 쓰는 한 가지 방법.

원문 제목: One file carries four kinds (INSIDE THE PROJECT FILE). 내용(영문 유지) 의미: 테스트 표준 - 프레임워크는 pytest, 테스트 파일은 tests 폴더에 / 가치 있는 테스트 - 돈이 오가거나 결정을 바꾸는 동작을 확인($500 한도, 30일 반품 기간, 배송일 없음) / 저장된 필드를 반환하는 것 같은 사소한 테스트는 건너뜀. 캡션: One way to write testing standards and review criteria for a CI job.
