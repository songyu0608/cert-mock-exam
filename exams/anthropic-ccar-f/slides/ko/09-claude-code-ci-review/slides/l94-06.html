스키마를 따르는 JSON 출력

{ "type": "object",
  "required": ["findings"],
  "properties": { "findings": { "type": "array", "items": {
    "type": "object",
    "properties": {
      "file": {"type": "string"},  "line": {"type": "integer"},
      "severity": {"type": "string"},  "category": {"type": "string"},
      "message": {"type": "string"},  "fix": {"type": "string"}
    } } } } }

스크립트가 파싱할 수 있는 지적 사항을 얻는 한 가지 방법: 내 스키마에 맞는 JSON.

원문 제목: JSON output that follows a schema (TWO MORE FLAGS). 스키마(영문 유지) 의미: findings 배열이 필수이고, 각 항목은 file(문자열), line(정수), severity, category, message, fix(문자열)를 가짐. 캡션: One way to get findings a script can parse: JSON that matches your schema.
