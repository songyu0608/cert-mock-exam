개발자가 엶

Claude Code

리뷰하고 테스트를 제안

결정 1: 작업이 어떻게 실행되나. 결정 2: 실행마다 어떤 컨텍스트를 받나.

원문 제목: Two decisions shape every CI run (EXAM CHECKPOINT: CLAUDE CODE IN CI). Pull request (Opened by a developer) → CI job (Runs on every pull request) → Claude Code (Reviews and suggests tests). 하단: Decision 1: how the job runs. Decision 2: what context each run gets.
