부분 환불

자기 리뷰가 실제 버그를 놓쳤다

LIMIT = 500

def partial_refund(order, amount):
    if amount > LIMIT:
        raise ValueError("over limit")
    order.refund(amount)

partial_refund(order, 300)
partial_refund(order, 300)

한도는 주문 합계가 아니라 환불 한 건마다 확인됩니다. 600이 돌려지는데 아무도 보지 못합니다.

원문 제목: The self-review missed a real bug (PARTIAL REFUNDS). 코드(영문 유지) 의미: 한도 500. partial_refund는 이번 환불 금액만 한도와 비교하므로 300을 두 번 환불하면 둘 다 통과해 합계 600이 환불됨. 캡션: The limit is checked on each refund, not on the order total: 600 goes back and no person sees it.
