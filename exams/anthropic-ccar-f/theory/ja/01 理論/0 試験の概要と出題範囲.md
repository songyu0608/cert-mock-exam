# 0 試験の概要と出題範囲

Claude Certified Architect – Foundations（CCAR-F）は、Claude Code、Claude Agent SDK、Claude API、MCPで本番アプリケーションを構築する際の**トレードオフの判断**を問う。用語の暗記よりもシナリオの中での判断が中心。

## 試験情報（公式ガイドv1.0、2026年7月）
| 項目 | 内容 |
|---|---|
| 試験コード | CCAR-F |
| 問題数 | 60 |
| 形式 | 多肢選択式および複数選択式。選ぶ数は問題ごとに明記 |
| 構成 | 6つのシナリオから無作為に4つ |
| 時間 | 120分 |
| 合格点 | スケールスコア720（100-1,000） |
| 受験料 | 125ドル |
| 有効期間 | 取得日から12か月。期間内に無料の監督なし評価で更新 |
| 結果 | 合否＋スケールスコア、分野別の正答率 |
| 受験方法 | Pearson VUE（オンライン監督またはテストセンター） |
| 言語 | 英語、日本語（日本語の公式ガイドあり） |
| 再受験 | 不合格後14日、30日、90日の待機。12か月で最大4回 |
| 予約の変更 | 24時間前まで。24時間以内の変更は受験料の返金なし |

## 学習のポイント
- 正解はたいてい**根本原因を最小の労力で直すもの**。過剰な設計（分類器の学習、ルーティング層、大きなモデルへの切り替え）は誤答になりやすい。
- 「必ず守るべきルール」はプロンプトではなく**コード（フック・前提条件）**で強制する。
- ファイルパス・フラグ・フロントマターの名前（.claude/commands/、-p、context: forkなど）を正確に覚える。存在しない機能をもっともらしく混ぜた誤答が出る。
- 出題範囲外のトピックも確認する → [[出題範囲外のトピック]]
- 試験の言語（英語・日本語）は公式ガイドではなく外部記事（Sight-R）で確認した情報。予約画面で再確認する。
