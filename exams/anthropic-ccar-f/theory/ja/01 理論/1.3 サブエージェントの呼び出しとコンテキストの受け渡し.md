# タスク 1.3　サブエージェントの呼び出し、コンテキストの受け渡し、生成を設定する

**English** Configure subagent invocation, context passing, and spawning

分野 1　エージェントアーキテクチャとオーケストレーション (27%)

サブエージェントをどう生成し、何を渡すべきかを問う。

> [!tip] 判断の要点
> - allowedToolsに"Task"がないと生成できない
> - サブエージェントは親のコンテキストを継承しない → 結果をすべてプロンプトに明示
> - 並列化は1つの応答で複数のTask、プロンプトは手順ではなく目標と品質基準

## 必要な知識（Knowledge of）

1. サブエージェントを生成する仕組みとしてのTaskツール、およびコーディネーターがサブエージェントを呼び出すにはallowedToolsに"Task"を含める必要があるという要件
2. サブエージェントのコンテキストはプロンプトで明示的に提供する必要があること（サブエージェントは親のコンテキストを自動的に継承せず、呼び出し間でメモリを共有しない）
3. 各サブエージェントタイプの説明、システムプロンプト、ツール制限を含むAgentDefinitionの設定
4. 共通の分析ベースラインから異なるアプローチを探るための、フォークベースのセッション管理

> [!quote]- English 公式ガイド原文
> 1. The Task tool as the mechanism for spawning subagents, and the requirement that allowedTools must include "Task" for a coordinator to invoke subagents
> 2. That subagent context must be explicitly provided in the prompt—subagents do not automatically inherit parent context or share memory between invocations
> 3. The AgentDefinition configuration including descriptions, system prompts, and tool restrictions for each subagent type
> 4. Fork-based session management for exploring divergent approaches from a shared analysis baseline

## 必要なスキル（Skills in）

1. 先行するエージェントの調査結果全体をサブエージェントのプロンプトに直接含める（例：ウェブ検索結果とドキュメント分析の出力を統合サブエージェントに渡す）
2. エージェント間でコンテキストを渡す際に、情報源の帰属を保持するため、構造化データ形式を使用してコンテンツとメタデータ（ソースURL、ドキュメント名、ページ番号）を分離する
3. 別々のターンに分けるのではなく、コーディネーターの単一の応答で複数のTaskツール呼び出しを出力することで、サブエージェントを並列に生成する
4. サブエージェントが適応できるように、段階的な手順の指示ではなく、リサーチの目標と品質基準を指定するコーディネータープロンプトを設計する

> [!quote]- English 公式ガイド原文
> 1. Including complete findings from prior agents directly in the subagent's prompt (e.g., passing web search results and document analysis outputs to the synthesis subagent)
> 2. Using structured data formats to separate content from metadata (source URLs, document names, page numbers) when passing context between agents to preserve attribution
> 3. Spawning parallel subagents by emitting multiple Task tool calls in a single coordinator response rather than across separate turns
> 4. Designing coordinator prompts that specify research goals and quality criteria rather than step-by-step procedural instructions, to enable subagent adaptability
