# タスク 3.3　規約を条件付きで読み込むためにパス固有のルールを適用する

**English** Apply path-specific rules for conditional convention loading

分野 3　Claude Codeの設定とワークフロー (20%)

ファイルパスに応じて規約を条件付きで適用する方法を問う。

> [!tip] 判断の要点
> - .claude/rules/のファイルのYAMLフロントマターpathsにglob
> - 一致するファイルの編集時だけ読み込み → トークン節約
> - 散らばったファイル（テストなど）にはサブディレクトリのCLAUDE.mdよりパス固有のルール

## 必要な知識（Knowledge of）

1. 条件付きでルールを有効化するためのglobパターンを含むpathsフィールドをYAMLフロントマターに持つ.claude/rules/ファイル
2. パススコープのルールが、一致するファイルを編集するときにのみ読み込まれ、無関係なコンテキストとトークン使用量を削減する仕組み
3. 複数のディレクトリにまたがる規約（例：コードベース全体に散在するテストファイル）において、ディレクトリレベルのCLAUDE.mdファイルよりもglobパターンのルールが優れている点

> [!quote]- English 公式ガイド原文
> 1. .claude/rules/ files with YAML frontmatter paths fields containing glob patterns for conditional rule activation
> 2. How path-scoped rules load only when editing matching files, reducing irrelevant context and token usage
> 3. The advantage of glob-pattern rules over directory-level CLAUDE.md files for conventions that span multiple directories (e.g., test files spread throughout a codebase)

## 必要なスキル（Skills in）

1. YAMLフロントマターでパスのスコープを指定した.claude/rules/ファイルを作成し（例：paths:["terraform/**/*"]）、一致するファイルを編集するときにのみルールが読み込まれるようにする
2. パス固有のルールでglobパターンを使用し、ディレクトリの場所に関係なくファイルの種類ごとに規約を適用する（例：すべてのテストファイルに**/*.test.tsx）
3. コードベース全体に散在するファイルに規約を適用する必要がある場合に、サブディレクトリのCLAUDE.mdファイルではなくパス固有のルールを選択する

> [!quote]- English 公式ガイド原文
> 1. Creating .claude/rules/ files with YAML frontmatter path scoping (e.g., paths: ["terraform/**/*"]) so rules load only when editing matching files
> 2. Using glob patterns in path-specific rules to apply conventions to files by type regardless of directory location (e.g., **/*.test.tsx for all test files)
> 3. Choosing path-specific rules over subdirectory CLAUDE.md files when conventions must apply to files spread across the codebase
