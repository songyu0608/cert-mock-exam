# タスク 5.4　大規模なコードベースの探索においてコンテキストを効果的に管理する

**English** Manage context effectively in large codebase exploration

分野 5　コンテキスト管理と信頼性 (15%)

長い探索セッションでのコンテキストの劣化を防ぐ方法を問う。

> [!tip] 判断の要点
> - スクラッチパッドファイル、サブエージェントへの委任、フェーズの要約の注入
> - クラッシュからの復旧はマニフェスト
> - /compactでコンテキストを減らす

## 必要な知識（Knowledge of）

1. 長時間のセッションにおけるコンテキストの劣化：モデルが一貫しない回答を返し始め、以前に発見した具体的なクラスではなく「典型的なパターン」に言及するようになること
2. コンテキストの境界を越えて主要な発見事項を保持するためのスクラッチパッドファイルの役割
3. メインエージェントが高レベルの理解を調整する一方で、冗長な探索出力を分離するためのサブエージェントへの委任
4. クラッシュからの復旧のための構造化された状態の永続化：各エージェントが既知の場所に状態をエクスポートし、コーディネーターが再開時にマニフェストを読み込むこと

> [!quote]- English 公式ガイド原文
> 1. Context degradation in extended sessions: models start giving inconsistent answers and referencing "typical patterns" rather than specific classes discovered earlier
> 2. The role of scratchpad files for persisting key findings across context boundaries
> 3. Subagent delegation for isolating verbose exploration output while the main agent coordinates high-level understanding
> 4. Structured state persistence for crash recovery: each agent exports state to a known location, and the coordinator loads a manifest on resume

## 必要なスキル（Skills in）

1. メインエージェントが高レベルの調整を維持する一方で、特定の問い（例：「すべてのテストファイルを見つける」、「返金フローの依存関係をたどる」）を調査するサブエージェントを起動する
2. エージェントに主要な発見事項を記録するスクラッチパッドファイルを維持させ、以降の質問でそれを参照させて、コンテキストの劣化に対抗する
3. 次のフェーズのサブエージェントを起動する前に、ある探索フェーズの主要な発見事項を要約し、その要約を初期コンテキストに注入する
4. コーディネーターが再開時に読み込んでエージェントのプロンプトに注入する、構造化されたエージェント状態のエクスポート（マニフェスト）を用いて、クラッシュからの復旧を設計する
5. 長時間の探索セッション中に冗長な調査出力でコンテキストが埋まった場合に、/compactを使用してコンテキスト使用量を削減する

> [!quote]- English 公式ガイド原文
> 1. Spawning subagents to investigate specific questions (e.g., "find all test files," "trace refund flow dependencies") while the main agent preserves high-level coordination
> 2. Having agents maintain scratchpad files recording key findings, referencing them for subsequent questions to counteract context degradation
> 3. Summarizing key findings from one exploration phase before spawning sub-agents for the next phase, injecting summaries into initial context
> 4. Designing crash recovery using structured agent state exports (manifests) that the coordinator loads on resume and injects into agent prompts
> 5. Using /compact to reduce context usage during extended exploration sessions when context fills with verbose discovery output
