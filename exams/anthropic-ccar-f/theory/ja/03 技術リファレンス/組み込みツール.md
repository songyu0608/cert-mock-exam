# 組み込みツール

> [!summary] 一行定義
> Claude Code・Agent SDKの組み込みツールRead、Write、Edit、Bash、Grep、Globの用途と選択基準。

**English** Built-in tools

## 出題のきっかけ
- 「すべての呼び出し元を探せ」
- 「**/*.test.tsxのファイルを探す」
- 「Editが失敗した」

## 要点

| ツール | 用途 | 例 |
|---|---|---|
| Grep | ファイルの**内容**を検索 | 関数の呼び出し元、エラーメッセージ、import文 |
| Glob | ファイルの**パス・名前**のパターン | **/*.test.tsx |
| Read / Write | ファイル全体の読み書き | |
| Edit | 一意なテキストを基準に部分修正 | |
| Bash | コマンド実行 | |

- Editが**一意な基準テキストを見つけられない**ときは、Readで全体を読みWriteで書く。
