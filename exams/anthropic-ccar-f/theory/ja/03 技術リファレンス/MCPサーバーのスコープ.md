# MCPサーバーのスコープ

> [!summary] 一行定義
> チーム共有のMCPサーバーはプロジェクトスコープの.mcp.json、個人用・実験用はユーザースコープの~/.claude.json。認証情報は環境変数の展開で。

**English** MCP server scoping

## 出題のきっかけ
- 「チーム全員が同じMCPサーバーを使えるように」
- 「トークンをコミットせずに」
- 「自分の実験用サーバー」

## 要点

| スコープ | ファイル | 用途 |
|---|---|---|
| プロジェクト | .mcp.json | チーム共有、バージョン管理で共有 |
| ユーザー | ~/.claude.json | 個人用・実験用 |

- シークレットは**${GITHUB_TOKEN}**のような環境変数の展開で → シークレットをコミットしない。
- 設定されたすべてのサーバーのツールは**接続時に検出**され、**同時に**利用できる。
