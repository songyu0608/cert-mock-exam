# CLAUDE.mdの階層

> [!summary] 一行定義
> Claude Codeに指示を与えるCLAUDE.mdには、ユーザー・プロジェクト・ディレクトリの3つのレベルがある。

**English** CLAUDE.md hierarchy

## 出題のきっかけ
- 「新しいメンバーにだけ指示が適用されない」
- 「チームの標準を全員に適用」

## 要点

| レベル | 場所 | 共有 |
|---|---|---|
| ユーザー | ~/.claude/CLAUDE.md | **本人のみ**（バージョン管理されない） |
| プロジェクト | .claude/CLAUDE.md またはルートのCLAUDE.md | チームで共有 |
| ディレクトリ | サブディレクトリのCLAUDE.md | そのディレクトリでの作業時 |

- 「新メンバーが指示を受け取れない」→ 指示が**ユーザーレベル**にある場合が多い。プロジェクトレベルに移す。
- 読み込まれたメモリファイルの確認は**/memory**。
- CIでもCLAUDE.mdがプロジェクトのコンテキスト（テスト標準、フィクスチャ、レビュー基準）を伝える。
