# Agent SDKのフック

> [!summary] 一行定義
> ツール呼び出しの前後をインターセプトするコード。結果の正規化（PostToolUse）とポリシー違反の呼び出しのブロックに使い、決定論的な保証を与える。

**English** Agent SDK hooks

## 出題のきっかけ
- 「MCPツールごとに日付の形式が違う」
- 「500ドルを超える返金は絶対に不可」

## 要点
- **PostToolUse**：モデルが処理する前にツールの結果を変換。例：Unixタイムスタンプ・ISO 8601・数値のステータスコードを統一。
- **送信前の呼び出しのインターセプト**：ポリシー違反（例：500ドル超の返金）をブロックし、人間へのエスカレーションなど別のワークフローに回す。
- フック＝決定論的な保証、プロンプトの指示＝確率的な遵守。保証が必要ならフック。
