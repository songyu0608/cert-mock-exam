# MCPリソース

> [!summary] 一行定義
> Issueのサマリー、ドキュメント階層、DBスキーマなどのコンテンツカタログをエージェントに公開し、探索的なツール呼び出しを減らすMCPの仕組み。

**English** MCP resources

## 出題のきっかけ
- 「何があるかを知るためにエージェントがツールを呼び続ける」

## 要点
- リソース＝参照できる**コンテンツカタログ**、ツール＝**アクション**。
- リソースとして公開すれば、探索的な呼び出しなしで利用可能なデータがわかる。
