# Message Batches API

> [!summary] 一行定義
> 大量のリクエストを非同期で処理するAPI。50%のコスト削減、最大24時間の処理、レイテンシSLAなし。

**English** Message Batches API

## 出題のきっかけ
- 「コスト削減」
- 「夜間・週次の大量処理」

## 要点
- **50%のコスト削減／最大24時間／レイテンシSLAなし**。
- **custom_id**でリクエストとレスポンスを対応付ける（結果の順序の問題はこれで解決）。
- 1つのリクエスト内で**マルチターンのツール呼び出しはできない**（リクエストの途中でツールを実行して結果を返せない）。
- 完了の確認はポーリング。
