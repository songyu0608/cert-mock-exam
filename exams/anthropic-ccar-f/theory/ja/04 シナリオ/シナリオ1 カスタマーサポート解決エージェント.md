# シナリオ1 カスタマーサポート解決エージェント

**English** Scenario 1: Customer Support Resolution Agent

> [!abstract] シナリオ（公式ガイド原文）
> あなたは、Claude Agent SDKを使用してカスタマーサポート解決エージェントを構築しています。このエージェントは、返品、請求に関する異議、アカウントの問題など、曖昧さの大きいリクエストを処理します。カスタムのModel Context Protocol（MCP）ツール（get_customer、lookup_order、process_refund、escalate_to_human）を通じて、バックエンドシステムにアクセスできます。目標は、エスカレーションすべきタイミングを見極めながら、初回対応での解決率80%以上を達成することです。

主な分野: 1 エージェントアーキテクチャとオーケストレーション, 2 ツール設計とMCP統合, 5 コンテキスト管理と信頼性

## このシナリオでよく問われる判断
- 本人確認前の返金をブロック → [[プログラムによる強制]]
- ツールの取り違え → [[ツールの説明]]
- 上限超えの返金ブロック・データ正規化 → [[Agent SDKのフック]]
- いつ引き継ぐか → [[エスカレーションのトリガー]]、[[構造化されたハンドオフサマリー]]
- 長い会話の金額・日付 → [[ケースファクトブロック]]、[[ツール出力の絞り込み]]
- 複数の問題を含むリクエスト → [[複数の懸案を含むリクエストの分解]]
