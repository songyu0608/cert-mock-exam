# シナリオ5 継続的インテグレーションのためのClaude Code

**English** Scenario 5: Claude Code for Continuous Integration

> [!abstract] シナリオ（公式ガイド原文）
> あなたは、Claude Codeを継続的インテグレーション／継続的デプロイ（CI/CD）パイプラインに統合しています。このシステムは、自動コードレビューを実行し、テストケースを生成し、プルリクエストに対するフィードバックを提供します。実行可能なフィードバックを提供し、誤検知を最小限に抑えるプロンプトを設計する必要があります。

主な分野: 3 Claude Codeの設定とワークフロー, 4 プロンプトエンジニアリングと構造化出力

## このシナリオでよく問われる判断
- ジョブが止まる → [[-pフラグ]]
- 構造化された結果 → [[--output-format jsonと--json-schema]]
- 重複コメント → [[CIレビューの重複防止]]
- 誤検知 → [[明示的なレビュー基準]]、[[誤検知と開発者の信頼]]
- 大きなPR → [[マルチパスレビュー]]、[[独立したレビューインスタンス]]
- コスト → [[バッチ処理の適否]]
