# リトライが効くエラーと効かないエラー

| エラー | リトライ | 対応 |
|---|---|---|
| 一時的（タイムアウト、サービス利用不可） | 効く | ローカルでリトライ → 解決しなければ構造化エラーとして伝播 |
| 形式の不一致・出力構造のエラー（抽出） | 効く | 元の文書＋失敗した抽出＋具体的な検証エラーで再リクエスト |
| 検証（不正な入力） | 入力の修正が必要 | 入力を直す |
| ビジネス（ポリシー違反） | **効かない**（isRetryable: false） | 顧客に説明、エスカレーション |
| 権限 | 効かない | 権限の問題を報告 |
| ソースに情報がない（抽出） | **効かない** | nullを許容、人間によるレビュー |
