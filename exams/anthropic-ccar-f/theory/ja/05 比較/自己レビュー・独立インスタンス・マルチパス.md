# 自己レビュー・独立インスタンス・マルチパス

| 方法 | 効果 | 備考 |
|---|---|---|
| 同じセッションでの自己レビュー（拡張思考を含む） | 低い | 生成時のコンテキストが残り、自分の判断を疑わない |
| [[独立したレビューインスタンス]] | 高い | 生成者の推論コンテキストがない |
| [[マルチパスレビュー]] | 大きなPRに効果的 | ファイル単位＋統合パスで注意の分散を解消 |
| 同じレビューを3回実行して多数決 | 誤答 | 断続的にしか検出されない本物のバグを逃す |
| コンテキストの大きいモデル | 誤答 | 注意の質の問題はそのまま |
