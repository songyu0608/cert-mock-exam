# プロンプトチェーンと動的な分解

| | [[プロンプトチェーン]] | [[動的で適応的な分解]] |
|---|---|---|
| ステップ | 事前に固定 | 発見に応じて生成 |
| 向いているタスク | 予測可能な多面的レビュー | オープンエンドな調査 |
| 例 | ファイル単位の分析 → 統合パス | レガシーコードへの包括的なテスト追加 |
| リスク | 想定外の状況に弱い | 範囲が広がりやすい → 優先順位付きの計画で管理 |

> [!question]- 「レガシーコードベース全体にテストを追加せよ」
> 動的な分解。構造の把握 → 影響の大きい領域 → 優先順位付きの計画 → 依存関係が見えたら調整。
