# バッチAPIと同期API

| | [[Message Batches API]] | 同期（リアルタイム）API |
|---|---|---|
| コスト | **50%削減** | 通常料金 |
| 処理時間 | 最大24時間、SLAなし | 即時 |
| マルチターンのツール呼び出し | **不可** | 可能 |
| 向いている処理 | 夜間レポート、週次監査、夜間のテスト生成 | マージ前チェックのように待つ処理 |
| 対応付け | custom_id | - |

> [!question]- マージ前チェックと夜間レポートを両方バッチにする提案
> 夜間レポートだけバッチ。マージ前チェックは同期のまま。
