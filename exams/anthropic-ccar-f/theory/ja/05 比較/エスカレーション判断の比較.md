# エスカレーション判断の比較

| 状況 | 行動 |
|---|---|
| 顧客が**明示的に人間の担当者を要求** | **すぐに**引き継ぐ（先に調査しない） |
| 不満はあるが問題は対応範囲内 | 共感＋解決の提案。再度要求されたら引き継ぐ |
| ポリシーが**曖昧または記載がない**（例：競合他社の価格に合わせる） | 引き継ぐ |
| 意味のある進展が見込めない | 引き継ぐ |
| 単に複雑なだけ | 基準に従って判断（複雑さだけでは引き継がない） |
| 検索結果で**複数の顧客が一致** | 追加の識別情報を求める |
| 感情スコアが高い／自己申告の確信度が低い | 基準にならない |
