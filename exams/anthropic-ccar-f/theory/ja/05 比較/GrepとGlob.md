# GrepとGlob

| ツール | 探す対象 | 例 |
|---|---|---|
| Grep | ファイルの**内容** | 関数の呼び出し元、エラーメッセージ、import文 |
| Glob | ファイルの**パス・名前** | **/*.test.tsx |
| Read＋Write | ファイル全体 | Editが一意なテキストを見つけられないときの代替 |
| Edit | 一意なテキストを基準にした部分修正 | |
