# パス固有のルールとサブディレクトリのCLAUDE.md

| 方法 | 適用の基準 | 散らばったファイル（テストなど） | 自動適用 |
|---|---|---|---|
| [[パス固有のルールと.claude rules]]（paths glob） | ファイルパスのパターン | **適している** | はい |
| サブディレクトリのCLAUDE.md | ディレクトリ | 難しい | はい（そのディレクトリ） |
| ルートのCLAUDE.mdにすべて | Claudeの推測 | 不安定 | 推測に依存 |
| スキル | 呼び出し | - | いいえ（呼び出しが必要） |
| @import | パッケージごとのCLAUDE.mdに取り込み | - | 取り込んだ場所で |
