# tool_useによる構造化出力

> [!summary] 一行定義
> JSONスキーマを入力パラメーターとして定義した抽出ツールを呼ばせると、スキーマに準拠した出力を最も確実に得られる（構文エラーを排除）。

**English** Structured output via tool_use

## 出題のきっかけ
- 「JSONがときどき壊れる」
- 「抽出結果を下流システムに渡す」

## 要点
- 抽出ツールのinput_schema＝欲しい出力スキーマ → tool_useブロックからデータを取り出す。
- **構文エラーはなくなるが、意味的なエラーは残る。**→ [[構文エラーと意味的エラー]]
- ツールを必ず呼ばせるには[[tool_choice]]を"any"または強制選択に。
- ソースの形式がばらばらなら、厳密なスキーマと合わせて**形式の正規化ルール**をプロンプトに含める。
