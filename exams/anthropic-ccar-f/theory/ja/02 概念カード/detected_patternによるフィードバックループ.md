# detected_patternによるフィードバックループ

> [!summary] 一行定義
> 構造化されたレビュー結果ごとに、どのコード構造が指摘を引き起こしたかを記録し、開発者が却下した指摘のパターンを体系的に分析する。

**English** detected_pattern feedback loop

## 出題のきっかけ
- 「どの指摘がよく却下されるか知りたい」

## 要点
- 結果スキーマにdetected_patternフィールドを追加 → 却下と合わせて集計 → 誤検知パターンを把握 → 基準や例を改善。
