# ツールの分割と名前変更

> [!summary] 一行定義
> 機能が重複するツールは名前と説明を変え、汎用的なツールは入出力の契約が決まった目的別のツールに分割する。

**English** Splitting and renaming tools

## 出題のきっかけ
- 「analyze_contentとanalyze_documentがほぼ同じ」
- 「汎用ツール1つが何でもする」

## 要点
- 名前変更の例：analyze_content → **extract_web_results**（ウェブ専用の説明）。
- 分割の例：analyze_document → **extract_data_points / summarize_content / verify_claim_against_source**。
- 汎用ツールを制約付きのツールに置き換える例：fetch_url → 文書URLを検証する**load_document**。
