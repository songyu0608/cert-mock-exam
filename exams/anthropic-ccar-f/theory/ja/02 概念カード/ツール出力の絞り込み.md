# ツール出力の絞り込み

> [!summary] 一行定義
> ツールの結果は関連性に比べてトークンを多く消費する（例：注文照会ごとに40以上のフィールド、必要なのは5つ）。コンテキストに蓄積する前に関連フィールドだけを残す。

**English** Trimming verbose tool output

## 出題のきっかけ
- 「注文照会の結果が長すぎる」
- 「下流エージェントのコンテキスト予算が小さい」

## 要点
- 蓄積する**前に**絞り込む（例：返品に関係するフィールドだけ残す）。
- 上流のエージェントには、冗長な内容や推論の過程ではなく**構造化データ（重要な事実、引用、関連度スコア）**を返させる。
- サブエージェントの出力には日付・情報源の場所・方法論の文脈などのメタデータを含めさせる。
