# 46. 훅으로 환불을 검사하고 주문 결과를 정리하기

지난 노트에서는 고객의 신원이 확인될 때까지 주문 조회와 환불 처리를 막았습니다. 이제 신원이 확인된 고객이 고장 난 커피 머신 사진을 보내 왔다고 해 보세요. 주문도 찾았고 파손도 확인했습니다. 그런데 전액을 환불하려고 보니 금액이 620달러입니다. 스토어가 자동으로 처리할 수 있는 한도는 500달러입니다. 돈이 나가기 전에 어디에서 멈춰야 할까요?

## 환불을 실행하기 전에 금액 확인하기

**훅(hook)**은 에이전트 루프가 정해진 지점에 도달할 때 SDK가 호출하는 코드입니다. `PreToolUse` 훅은 Claude가 도구 호출을 요청한 뒤, 실제 도구가 실행되기 전에 도구 이름과 입력을 받습니다. 여기서 입력을 바꾸거나, 호출을 허용하거나, 이유를 알려 주고 차단할 수 있습니다. 시험에서 말하는 **도구 호출 가로채기(tool call interception)**가 이 과정입니다.

커피 머신 사례에서는 환불 도구 `process_refund`에만 금액 검사 훅을 연결합니다. Claude가 620달러 전액을 환불해 달라고 요청하면 훅이 금액을 읽습니다. 500달러를 초과했으므로 환불 호출을 차단합니다. 이 시점에는 아직 돈이 움직이지 않았습니다. 훅은 차단한 이유도 Claude에 돌려줍니다.

> 500달러를 초과하는 환불은 상담원의 승인이 필요합니다. 이 건을 상담원에게 넘기세요.

이유를 읽은 Claude가 이번에는 `escalate_to_human`을 요청합니다. 훅이 한 일은 환불을 멈추고 다음에 할 수 있는 일을 알려 준 데까지입니다. 상담원 연결 도구를 고른 쪽은 Claude입니다. 고객 확인이나 주문 조회에는 이 금액 검사 훅을 적용하지 않습니다. 스토어 백엔드에서도 같은 한도를 검사해 500달러를 초과하는 자동 환불을 거절합니다.

시스템 프롬프트에도 한도를 적어 두면 Claude가 처음부터 상담원 연결을 고를 수 있습니다. 그래도 실수로 환불 도구를 요청했을 때 한도를 지키게 하는 것은 호출마다 실행되는 코드입니다. 프롬프트 규칙은 대부분 지켜지지만 매번 지켜지지는 않고, 돈이 걸린 일에는 그것으로 부족합니다. 준수가 보장돼야 하는 비즈니스 규칙은 프롬프트 규칙이 아니라 훅에 둡니다.

## 도구가 반환한 날짜와 상태를 같은 형식으로 읽기

이번에는 반품 기한이 남았는지 묻는 고객을 떠올려 보세요. 스토어는 배송 후 30일까지 반품을 받습니다. 주문 서비스는 배송 시각을 1970년 1월 1일 UTC부터 지난 초 단위의 숫자(Unix timestamp)로 반환합니다. 배송 서비스는 같은 종류의 시각을 연·월·일과 시간이 적힌 ISO 8601 문자열로 돌려줍니다. 주문 상태도 주문 서비스에서는 숫자 `4`로 표시합니다. 이 서비스의 상태 코드표를 보지 않은 사람은 `4`만으로 배송이 끝났는지 알 수 없습니다.

이때 쓰는 것이 **실행 후 훅**인 `PostToolUse`입니다. MCP 도구가 성공적으로 실행된 뒤, Claude가 결과를 읽기 전에 반환값을 정리합니다. 같은 배송 시각이 결과에 어떻게 나타나는지 간단한 예를 들어 보겠습니다. 날짜는 UTC를 기준으로 표시합니다.

| 서비스가 반환한 값 | Claude가 읽는 값 |
| --- | --- |
| 주문 서비스의 배송 시각 `1767225600` | 배송일 `2026-01-01` |
| 배송 서비스의 배송 시각 `2026-01-01T00:00:00Z` | 배송일 `2026-01-01` |
| 주문 서비스의 상태 코드 `4` | 배송 상태 `delivered`(배송 완료) |

이제 Claude는 배송 시각을 직접 환산하거나 숫자 코드의 뜻을 추측할 필요 없이 반품 기한을 판단할 수 있습니다. 프롬프트에 변환 방법을 적어 주면 매 상담에서 Claude가 다시 계산해야 하고, 가끔은 틀립니다. 실행 후 훅에 변환을 두면 어느 서비스에서 읽었든 같은 기준으로 정리된 결과를 받습니다.

훅을 어디에 둘지 헷갈릴 때는 **언제까지 개입해야 하는지** 생각해 보세요. 고액 환불은 돈이 나가기 전에 멈춰야 합니다. 배송 날짜는 값을 받아 온 뒤, Claude가 읽기 전에 정리해야 합니다. 다음 노트에서는 620달러 환불을 넘겨받은 상담원이 무엇을 알아야 바로 일할 수 있는지 살펴보겠습니다.
