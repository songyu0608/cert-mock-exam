# 9. Udemy 실습 환경 사용법

다음 노트부터는 직접 코드를 실행해 봅니다. Udemy에서는 영상을 보면서 같은 단계를 따라 할 수 있습니다. 이때 브라우저로 여는 코딩 실습 환경을 ‘랩(lab)’이라고 부릅니다.

## 실습을 열기 전에

원본 영상 제작 당시 안내에 따르면 랩은 Udemy Personal Plan, Udemy Pro, Udemy Business 학습자가 이용할 수 있었고, 요금제에 따라 제공 여부가 달랐습니다. 지원 범위는 바뀔 수 있습니다. Udemy 화면에 랩이 보이지 않아도 영상과 과제 목록은 볼 수 있고, 실습 코드는 자신의 컴퓨터에서도 실행할 수 있습니다. 이 랩은 데스크톱용이므로 노트북이나 데스크톱 컴퓨터에서 열어 주세요.

브라우저 랩의 장점은 준비가 간단하다는 것입니다. 컴퓨터에 Python이나 라이브러리를 설치할 필요 없이, 랩을 열면 실습 코드가 준비되어 있습니다. 화면을 둘로 나눠 한쪽에는 영상, 다른 쪽에는 랩을 띄워 보세요. 강사가 한 단계를 보여 주면 탭을 오가지 않고 바로 옆에서 같은 단계를 따라 할 수 있습니다.

## 노트북을 열고 셀 실행하기

랩을 열면 **Jupyter 노트북** 환경이 시작됩니다. 준비하는 데 보통 몇 분이 걸리고, 5분이 넘어갈 때도 있습니다. Jupyter 웹사이트에서도 같은 도구를 무료로 써 볼 수 있습니다. Udemy 랩에는 해당 실습의 코드가 미리 들어 있고 개인 API 키를 입력할 필요가 없습니다.

준비가 끝나면 왼쪽 파일 목록에서 **`notebook.ipynb`**를 여세요. 이 파일이 코드를 작성하고 실행할 작업 공간입니다. 노트북 안의 안내문을 읽으면 무엇을 어떤 순서로 해야 하는지 알 수 있습니다. 특정 단계에서 어떻게 입력하는지 보고 싶을 때 영상을 함께 보세요.

노트북은 **셀(cell)**이라는 단위로 나뉩니다. 첫 번째 셀을 클릭한 다음 화면 위쪽의 실행 버튼(▶)을 눌러 보세요. 선택한 셀만 실행됩니다. 첫 실습도 이렇게 위에서부터 셀을 하나씩 실행하며 진행합니다.

## 점 세 개가 있는 칸 채우기

몇 개의 셀을 실행하다 보면 직접 채울 부분이 나옵니다. 코드의 뼈대는 이미 작성되어 있고, 값을 넣을 자리만 점 세 개(`...`)로 표시되어 있습니다. 각 빈칸 옆의 안내를 읽어 보세요.

강사는 먼저 점 세 개를 남겨 둔 채 실습 셀을 실행합니다. 이때 오류가 뜨는 것은 예상한 결과입니다. 이 셀에서는 아직 채워야 할 값이 남았다는 뜻입니다. 안내에 맞게 빈칸을 채운 뒤 **같은 셀을 다시 실행**해 보세요. 이번에는 정상적으로 동작합니다. 실제 API 키를 사용했을 때의 실행 모습은 원본 영상에서 볼 수 있습니다.

앞으로 실습을 열 때도 같은 순서로 진행하면 됩니다. 노트북의 안내를 읽고, 셀을 차례로 실행하고, 직접 작성하라고 표시된 부분을 채워 보세요.
