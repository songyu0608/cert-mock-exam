# 출제 범위 밖 주제

공식 가이드 17장이 "시험에 나오지 않는다"고 명시한 주제. 선택지에 이런 내용이 나오면 정답 근거가 되기 어렵다.

- Claude 모델 미세 조정이나 사용자 지정 모델 학습
- Claude API 인증, 결제, 계정 관리
- 특정 프로그래밍 언어·프레임워크의 상세 구현(도구·스키마 구성에 필요한 수준 이상)
- MCP 서버의 배포·호스팅(인프라, 네트워킹, 컨테이너 오케스트레이션)
- Claude의 내부 아키텍처, 학습 과정, 모델 가중치
- Constitutional AI, RLHF, 안전성 학습 방법론
- 임베딩 모델이나 벡터 데이터베이스 구현 세부 사항
- 컴퓨터 사용(브라우저 자동화, 데스크톱 상호 작용)
- 비전·이미지 분석 기능
- 스트리밍 API 구현이나 서버 전송 이벤트(SSE)
- 속도 제한, 할당량, API 요금 계산
- OAuth, API 키 교체, 인증 프로토콜 세부 사항
- 특정 클라우드 제공업체 구성(AWS, GCP, Azure)
- 성능 벤치마킹이나 모델 비교 지표
- 프롬프트 캐싱 구현 세부 사항(존재를 아는 수준 이상)
- 토큰 계산 알고리즘이나 토큰화 세부 사항
