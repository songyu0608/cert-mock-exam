# 플래시카드 도메인 2　도구 설계와 MCP 통합

#flashcards/ccar-f/d2

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
LLM이 도구를 고를 때 주로 의존하는 것은?::도구 설명
도구 설명에 넣어야 할 4가지는?::입력 형식, 예시 쿼리, 엣지 케이스, 비슷한 도구와의 경계
범용 analyze_document를 가이드는 어떻게 나누라고 예시했나?::extract_data_points, summarize_content, verify_claim_against_source
가이드가 구분하는 오류 4종은?::일시적, 유효성 검사, 비즈니스, 권한
헛된 재시도를 막기 위해 오류 응답에 넣는 불리언은?::isRetryable (비즈니스 위반은 retriable: false)
검색이 타임아웃됐을 때 빈 결과를 성공으로 반환하면 왜 안 되나?::접근 실패를 숨겨 코디네이터가 재시도·대안을 판단할 수 없다
종합 에이전트의 검증 왕복을 줄이면서 신뢰성을 유지하는 방법은?::단순 사실 확인용 범위 좁은 verify_fact 도구를 주고, 복잡한 검증은 코디네이터를 거치게 함
Jira 통합에 맞춤 MCP 서버를 새로 만드는 것이 가이드 기준으로 맞나?::아니다. 표준 통합은 커뮤니티 서버를 쓴다
낯선 코드베이스 이해의 권장 순서는?::Grep으로 진입점 찾기 → Read로 import를 따라가며 추적
모델이 반드시 어떤 도구든 호출하게 하는 tool_choice 값은?::"any"
extract_metadata를 가장 먼저 실행시키려면?::tool_choice: {"type": "tool", "name": "extract_metadata"}
MCP 도구가 실패를 에이전트에 알리는 플래그는?::isError
팀 공용 MCP 서버 구성 파일은?::프로젝트 범위 .mcp.json
.mcp.json에서 토큰을 커밋하지 않는 방법은?::${GITHUB_TOKEN} 같은 환경 변수 확장
데이터베이스 스키마 목록을 탐색 호출 없이 에이전트에 보여 주려면?::MCP 리소스로 노출
함수의 모든 호출자를 찾을 때 쓰는 도구는?::Grep
이름 패턴으로 파일을 찾을 때 쓰는 도구는?::Glob
Edit이 고유한 텍스트를 찾지 못하면?::Read로 전체를 읽고 Write로 다시 쓴다

## 상황 → 판단
상황: 비슷한 두 도구를 자주 헷갈림(첫 단계) → 정답 방향은?::도구 설명 보강
상황: 설명이 거의 같은 두 도구 → 정답 방향은?::이름 변경 + 설명 수정
상황: 범용 analyze_document가 모든 일 → 정답 방향은?::목적별 도구로 분할
상황: 잘 쓴 도구 설명이 무시됨 → 정답 방향은?::시스템 프롬프트의 키워드 지시 점검
상황: "Operation failed"만 반환 → 정답 방향은?::errorCategory·isRetryable·설명
상황: 정책 위반 오류 → 정답 방향은?::retriable: false + 고객용 설명
상황: 검색 결과 0건 → 정답 방향은?::유효한 빈 결과(성공). 접근 실패와 구분
상황: 도구 18개를 가진 에이전트의 선택 오류 → 정답 방향은?::역할에 필요한 도구만
상황: 종합 에이전트의 잦은 단순 검증 → 정답 방향은?::범위 좁은 verify_fact
상황: 반드시 도구를 호출하게 → 정답 방향은?::tool_choice: "any"
상황: 특정 도구를 먼저 → 정답 방향은?::tool_choice 강제 선택
상황: 팀 공용 MCP 서버 → 정답 방향은?::.mcp.json + ${ENV}
상황: 개인·실험용 MCP 서버 → 정답 방향은?::~/.claude.json
상황: 에이전트가 MCP 도구 대신 Grep을 씀 → 정답 방향은?::MCP 도구 설명을 자세히
상황: Jira 연동 → 정답 방향은?::커뮤니티 MCP 서버
상황: 무엇이 있는지 알려고 탐색 호출 반복 → 정답 방향은?::MCP 리소스로 카탈로그 노출
상황: 모든 호출자 찾기 → 정답 방향은?::Grep
상황: **/*.test.tsx 파일 찾기 → 정답 방향은?::Glob
상황: Edit이 고유 텍스트를 못 찾음 → 정답 방향은?::Read + Write
