# 사용자 지정 슬래시 명령

> [!summary] 한 줄 정의
> 프로젝트 범위 명령은 .claude/commands/(버전 관리로 공유), 개인 명령은 ~/.claude/commands/.

**English** Custom slash commands

## 시험 트리거
- "모든 개발자가 저장소를 받으면 /review를 쓸 수 있게"

## 핵심
- 팀 공용 → **.claude/commands/** (clone·pull하면 자동으로 사용 가능).
- 개인 → ~/.claude/commands/.
- CLAUDE.md는 지시·컨텍스트용이지 명령 정의용이 아니다.
- `.claude/config.json`의 commands 배열 같은 구성 방식은 없다(가이드 샘플 문제 해설).
