# 내장 도구

> [!summary] 한 줄 정의
> Claude Code·Agent SDK의 내장 도구 Read, Write, Edit, Bash, Grep, Glob의 용도와 선택 기준.

**English** Built-in tools

## 시험 트리거
- "모든 호출자를 찾아라"
- "**/*.test.tsx 파일 찾기"
- "Edit이 실패했다"

## 핵심

| 도구 | 용도 | 예 |
|---|---|---|
| Grep | 파일 **내용** 검색 | 함수 호출자, 오류 메시지, import 문 |
| Glob | 파일 **경로·이름** 패턴 | **/*.test.tsx |
| Read / Write | 파일 전체 읽기·쓰기 | |
| Edit | 고유한 텍스트를 찾아 부분 수정 | |
| Bash | 명령 실행 | |

- Edit이 **고유한 기준 텍스트를 못 찾으면** Read로 전체를 읽고 Write로 쓴다.
