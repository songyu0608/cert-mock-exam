# 경로별 규칙과 .claude rules

> [!summary] 한 줄 정의
> .claude/rules/에 주제별 규칙 파일을 두고, YAML frontmatter의 paths glob으로 일치하는 파일을 편집할 때만 로드한다.

**English** .claude/rules and path-specific rules

## 시험 트리거
- "테스트 파일이 코드베이스 곳곳에 있다"
- "Terraform 파일을 편집할 때만 적용"
- "CLAUDE.md가 너무 크다"

## 핵심
- 예: `paths: ["terraform/**/*"]`, `**/*.test.tsx`.
- 일치하는 파일 편집 시에만 로드 → 불필요한 컨텍스트·토큰 감소.
- 여러 디렉터리에 흩어진 파일에 같은 규칙 → **하위 디렉터리 CLAUDE.md보다 경로별 규칙**.
- 큰 CLAUDE.md를 testing.md, api-conventions.md, deployment.md처럼 주제별로 나눈다.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - "하위 디렉터리마다 CLAUDE.md" → 흩어진 테스트 파일을 다루기 어려움
> - "루트 CLAUDE.md에 제목별로 모두 넣고 추론에 맡김" → 명시적 매칭이 아님
