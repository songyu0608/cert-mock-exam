# MCP 서버 범위

> [!summary] 한 줄 정의
> 팀 공용 MCP 서버는 프로젝트 범위 .mcp.json, 개인·실험용은 사용자 범위 ~/.claude.json. 자격 증명은 환경 변수 확장으로.

**English** MCP server scoping

## 시험 트리거
- "팀 전원이 같은 MCP 서버를 쓰게"
- "토큰을 커밋하지 않고"
- "내 실험용 서버"

## 핵심

| 범위 | 파일 | 용도 |
|---|---|---|
| 프로젝트 | .mcp.json | 팀 공용, 버전 관리로 공유 |
| 사용자 | ~/.claude.json | 개인·실험용 |

- 비밀은 **${GITHUB_TOKEN}** 같은 환경 변수 확장으로 → 비밀을 커밋하지 않음.
- 구성된 모든 서버의 도구는 **연결 시점에 발견**되어 **동시에** 사용 가능.
