# Message Batches API

> [!summary] 한 줄 정의
> 대량 요청을 비동기로 처리하는 API. 비용 50% 절감, 최대 24시간 처리, 지연 SLA 없음.

**English** Message Batches API

## 시험 트리거
- "비용 절감"
- "야간·주간 대량 처리"

## 핵심
- **50% 비용 절감 / 최대 24시간 / 지연 SLA 없음**.
- **custom_id**로 요청과 응답을 짝짓는다(결과 순서 문제는 이것으로 해결).
- 한 요청 안에서 **여러 턴의 도구 호출 불가**(요청 도중 도구를 실행하고 결과를 돌려줄 수 없음).
- 완료 확인은 폴링.
