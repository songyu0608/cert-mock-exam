# Agent SDK 훅

> [!summary] 한 줄 정의
> 도구 호출 전후를 가로채는 코드. 결과 정규화(PostToolUse)와 정책 위반 호출 차단에 쓰며, 결정론적 보장을 준다.

**English** Agent SDK hooks

## 시험 트리거
- "MCP 도구마다 날짜 형식이 다르다"
- "500달러 넘는 환불은 절대 안 된다"

## 핵심
- **PostToolUse**: 모델이 처리하기 전에 도구 결과를 변환. 예: Unix 타임스탬프·ISO 8601·숫자 상태 코드를 통일.
- **나가는 호출 가로채기**: 정책 위반(예: 500달러 초과 환불)을 차단하고 사람 에스컬레이션 등 대체 흐름으로.
- 훅 = 결정론적 보장, 프롬프트 지시 = 확률적 준수. 보장이 필요하면 훅.
