# MCP 리소스

> [!summary] 한 줄 정의
> 이슈 요약, 문서 계층, DB 스키마 같은 콘텐츠 카탈로그를 에이전트에 노출해 탐색성 도구 호출을 줄이는 MCP 수단.

**English** MCP resources

## 시험 트리거
- "에이전트가 무엇이 있는지 알려고 도구를 계속 호출한다"

## 핵심
- 리소스 = 볼 수 있는 **콘텐츠 카탈로그**, 도구 = **행동**.
- 리소스로 노출하면 탐색 호출 없이 사용 가능한 데이터를 안다.
