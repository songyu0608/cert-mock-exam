# 0 시험 개요와 출제 범위

Claude Certified Architect – Foundations(CCAR-F)는 Claude Code, Claude Agent SDK, Claude API, MCP로 실제 운영 애플리케이션을 만들 때 **트레이드오프를 판단**하는 능력을 본다. 개념 암기보다 시나리오 속 판단이 중심이다.

## 시험 정보 (공식 가이드 v1.0, 2026년 7월)
| 항목 | 내용 |
|---|---|
| 시험 코드 | CCAR-F |
| 문항 수 | 60 |
| 형식 | 선다형 및 복수 응답형. 문항마다 고를 개수를 명시 |
| 구성 | 시나리오 6개 중 무작위 4개 |
| 시간 | 120분 |
| 합격 점수 | 스케일 점수 720 (100~1,000) |
| 응시료 | 125달러 |
| 유효 기간 | 취득일부터 12개월. 기한 내 무료 비감독 평가로 갱신 |
| 결과 | 합격/불합격 + 스케일 점수, 도메인별 정답률 |
| 응시 | Pearson VUE (온라인 감독 또는 테스트 센터) |
| 언어 | 영어, 일본어 (일본어 공식 가이드 있음) |
| 재응시 | 불합격 후 14일, 30일, 90일 대기. 12개월에 최대 4회 |
| 예약 변경 | 24시간 전까지. 이후 변경은 응시료 소멸 |

## 공부 포인트
- 정답은 대개 **근본 원인을 가장 적은 노력으로 고치는 것**이다. 과잉 설계(분류 모델 학습, 라우팅 레이어, 큰 모델 교체)는 오답이 되기 쉽다.
- "반드시 지켜야 하는 규칙"은 프롬프트가 아니라 **코드(훅·선행 조건)**로 강제한다.
- 파일 경로·플래그·frontmatter 이름(.claude/commands/, -p, context: fork 등)을 정확히 외운다. 없는 기능을 그럴듯하게 섞은 오답이 나온다.
- 시험 범위 밖 주제도 확인한다 → [[출제 범위 밖 주제]]
- "언어: 영어, 일본어"는 공식 가이드가 아니라 외부 기사(Sight-R)에서 확인한 정보다. 예약 화면에서 다시 확인한다.
