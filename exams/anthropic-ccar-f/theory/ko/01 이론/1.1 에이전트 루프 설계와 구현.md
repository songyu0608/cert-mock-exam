# 태스크 1.1　자율적 작업 수행을 위한 에이전트 루프를 설계하고 구현한다

**English** Design and implement agentic loops for autonomous task execution  
**日本語** 自律的なタスク実行のためのエージェントループを設計し実装する

도메인 1　에이전트 아키텍처와 오케스트레이션 (27%)

Claude가 도구를 쓰며 스스로 작업을 이어 가는 루프를 어떻게 돌리고 언제 멈추는지 묻는다.

> [!tip] 핵심 판단
> - 계속·종료는 **stop_reason**("tool_use" / "end_turn")으로만 판단
> - 도구 결과는 대화 기록에 붙여 다음 요청으로
> - 자연어 신호·반복 상한·텍스트 유무로 종료하면 오답

## 알아야 할 지식 (Knowledge of)

1. 에이전트 루프의 수명 주기: Claude에 요청 전송, stop_reason 확인("tool_use" 대 "end_turn"), 요청된 도구 실행, 다음 반복을 위해 결과 반환
2. 도구 결과가 대화 기록에 추가되어 모델이 다음 행동을 추론할 수 있게 되는 방식
3. 모델 주도 의사 결정(Claude가 컨텍스트를 바탕으로 다음에 호출할 도구를 추론)과 미리 구성된 의사 결정 트리·도구 순서의 차이

> [!quote]- English 공식 가이드 원문
> 1. The agentic loop lifecycle: sending requests to Claude, inspecting stop_reason ("tool_use" vs "end_turn"), executing requested tools, and returning results for the next iteration
> 2. How tool results are appended to conversation history so the model can reason about the next action
> 3. The distinction between model-driven decision-making (Claude reasons about which tool to call next based on context) and pre-configured decision trees or tool sequences

> [!quote]- 日本語 公式ガイド
> 1. エージェントループのライフサイクル：Claudeへのリクエスト送信、stop_reasonの確認（"tool_use"か"end_turn"か）、要求されたツールの実行、次の反復に向けた結果の返却
> 2. モデルが次のアクションについて推論できるように、ツールの結果が会話履歴に追加される仕組み
> 3. モデル主導の意思決定（Claudeがコンテキストに基づいて次に呼び出すツールを推論する）と、事前に設定された決定木やツールシーケンスとの違い

## 할 수 있어야 할 기술 (Skills in)

1. stop_reason이 "tool_use"이면 계속하고 "end_turn"이면 종료하는 에이전트 루프 제어 흐름 구현
2. 반복 사이에 도구 결과를 대화 컨텍스트에 추가해 모델이 새 정보를 추론에 반영하게 하기
3. 자연어 신호를 파싱해 루프 종료를 판단하기, 임의의 반복 횟수 상한을 주된 종료 수단으로 쓰기, 어시스턴트 텍스트 유무를 완료 신호로 보기 같은 안티패턴 피하기

> [!quote]- English 공식 가이드 원문
> 1. Implementing agentic loop control flow that continues when stop_reason is "tool_use" and terminates when stop_reason is "end_turn"
> 2. Adding tool results to conversation context between iterations so the model can incorporate new information into its reasoning
> 3. Avoiding anti-patterns such as parsing natural language signals to determine loop termination, setting arbitrary iteration caps as the primary stopping mechanism, or checking for assistant text content as a completion indicator

> [!quote]- 日本語 公式ガイド
> 1. stop_reasonが"tool_use"の場合は継続し、"end_turn"の場合は終了する、エージェントループの制御フローを実装する
> 2. モデルが新しい情報を推論に取り込めるように、反復の間にツールの結果を会話コンテキストに追加する
> 3. ループ終了の判定に自然言語のシグナルを解析する、主要な停止メカニズムとして根拠のない（恣意的な）反復回数上限を設定する、完了の指標としてアシスタントのテキストコンテンツの有無を確認する、といったアンチパターンを避ける
