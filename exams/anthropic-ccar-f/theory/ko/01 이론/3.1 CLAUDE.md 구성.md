# 태스크 3.1　알맞은 계층, 범위, 모듈 구성으로 CLAUDE.md 파일을 구성한다

**English** Configure CLAUDE.md files with appropriate hierarchy, scoping, and modular organization  
**日本語** 適切な階層、スコープ設定、モジュール構成でCLAUDE.mdファイルを設定する

도메인 3　Claude Code 구성과 워크플로 (20%)

CLAUDE.md 계층과 모듈화를 다룬다.

> [!tip] 핵심 판단
> - 사용자(~/.claude/CLAUDE.md)는 본인만, 프로젝트 수준은 팀 공유
> - @import와 .claude/rules/로 모듈화
> - 로드된 파일 확인은 /memory

## 알아야 할 지식 (Knowledge of)

1. CLAUDE.md 구성 계층: 사용자 수준(~/.claude/CLAUDE.md), 프로젝트 수준(.claude/CLAUDE.md 또는 루트 CLAUDE.md), 디렉터리 수준(하위 디렉터리의 CLAUDE.md)
2. 사용자 수준 설정은 그 사용자에게만 적용된다는 점: ~/.claude/CLAUDE.md의 지시는 버전 관리로 팀원과 공유되지 않는다
3. CLAUDE.md를 모듈식으로 유지하기 위해 외부 파일을 참조하는 @import 구문(예: 패키지마다 관련 표준 파일만 가져오기)
4. 하나로 뭉친 CLAUDE.md 대신 주제별 규칙 파일을 정리하는 .claude/rules/ 디렉터리

> [!quote]- English 공식 가이드 원문
> 1. The CLAUDE.md configuration hierarchy: user-level (~/.claude/CLAUDE.md), project-level (.claude/CLAUDE.md or root CLAUDE.md), and directory-level (subdirectory CLAUDE.md files)
> 2. That user-level settings apply only to that user—instructions in ~/.claude/CLAUDE.md are not shared with teammates via version control
> 3. The @import syntax for referencing external files to keep CLAUDE.md modular (e.g., importing specific standards files relevant to each package)
> 4. .claude/rules/ directory for organizing topic-specific rule files as an alternative to a monolithic CLAUDE.md

> [!quote]- 日本語 公式ガイド
> 1. CLAUDE.mdの設定階層：ユーザーレベル（~/.claude/CLAUDE.md）、プロジェクトレベル（.claude/CLAUDE.mdまたはルートのCLAUDE.md）、ディレクトリレベル（サブディレクトリのCLAUDE.mdファイル）
> 2. ユーザーレベルの設定はそのユーザーにのみ適用されること（~/.claude/CLAUDE.md内の指示は、バージョン管理を通じてチームメイトと共有されない）
> 3. 外部ファイルを参照してCLAUDE.mdをモジュール化しておくための@import構文（例：各パッケージに関連する特定の標準ファイルをインポートする）
> 4. 単一の巨大なCLAUDE.mdの代替として、トピック別のルールファイルを整理するための.claude/rules/ディレクトリ

## 할 수 있어야 할 기술 (Skills in)

1. 구성 계층 문제 진단(예: 지시가 프로젝트 수준이 아니라 사용자 수준에 있어 새 팀원이 받지 못하는 경우)
2. 관리자의 도메인 지식에 따라 각 패키지의 CLAUDE.md에 관련 표준 파일만 @import로 포함하기
3. 큰 CLAUDE.md를 .claude/rules/의 주제별 파일로 나누기(예: testing.md, api-conventions.md, deployment.md)
4. /memory 명령으로 어떤 메모리 파일이 로드됐는지 확인하고 세션마다 동작이 다른 원인 진단하기

> [!quote]- English 공식 가이드 원문
> 1. Diagnosing configuration hierarchy issues (e.g., a new team member not receiving instructions because they're in user-level rather than project-level configuration)
> 2. Using @import to selectively include relevant standards files in each package's CLAUDE.md based on maintainer domain knowledge
> 3. Splitting large CLAUDE.md files into focused topic-specific files in .claude/rules/ (e.g., testing.md, api-conventions.md, deployment.md)
> 4. Using the /memory command to verify which memory files are loaded and diagnose inconsistent behavior across sessions

> [!quote]- 日本語 公式ガイド
> 1. 設定階層の問題を診断する（例：指示がプロジェクトレベルではなくユーザーレベルの設定にあるために、新しいチームメンバーに指示が届いていない）
> 2. @importを使用し、メンテナーのドメイン知識に基づいて、関連する標準ファイルを各パッケージのCLAUDE.mdに選択的に取り込む
> 3. 大きなCLAUDE.mdファイルを、.claude/rules/内の焦点を絞ったトピック別ファイルに分割する（例：testing.md、api-conventions.md、deployment.md）コマンドを使用して、どのメモリファイルが読み込まれているかを確認し、セッション間で一
> 4. /memory貫しない動作を診断する
