# 공식 태스크 30개 체크리스트

공식 가이드의 태스크 30개(지식 문구 113개, 기술 문구 127개). 각 태스크 노트의 지식·기술 문구를 설명할 수 있으면 체크한다.

- [ ] **1.1** 자율적 작업 수행을 위한 에이전트 루프를 설계하고 구현한다  
　Design and implement agentic loops for autonomous task execution  
　自律的なタスク実行のためのエージェントループを設計し実装する

- [ ] **1.2** 코디네이터-서브에이전트 패턴으로 멀티 에이전트 시스템을 오케스트레이션한다  
　Orchestrate multi-agent systems with coordinator-subagent patterns  
　コーディネーター・サブエージェントパターンでマルチエージェントシステムをオーケストレーションする  
　→ [[1.2 코디네이터-서브에이전트 오케스트레이션]] · [[허브 앤 스포크 오케스트레이션]] · [[작업 분해 범위]] · [[반복 개선 루프]]

　Configure subagent invocation, context passing, and spawning  
　サブエージェントの呼び出し、コンテキストの受け渡し、生成を設定する  
　→ [[1.3 서브에이전트 호출과 컨텍스트 전달]] · [[서브에이전트 컨텍스트 전달]] · [[병렬 서브에이전트 생성]] · [[주장-출처 대응]] · [[Task 도구와 allowedTools]]

　Apply Agent SDK hooks for tool call interception and data normalization  
　ツール呼び出しのインターセプトとデータ正規化のためにAgent SDKのフックを適用する  
　→ [[1.5 Agent SDK 훅]] · [[프로그래밍 방식 강제]] · [[Agent SDK 훅]]
- [ ] **1.6** 복잡한 워크플로를 위한 작업 분해 전략을 설계한다  
　Design task decomposition strategies for complex workflows  
　複雑なワークフローのためのタスク分解戦略を設計する  
　→ [[1.6 작업 분해 전략]] · [[작업 분해 범위]] · [[프롬프트 체이닝]] · [[동적 적응형 분해]] · [[다중 패스 리뷰]]
- [ ] **1.7** 세션 상태, 재개, 포크를 관리한다
