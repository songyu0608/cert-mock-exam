# 서브에이전트 컨텍스트 전달

> [!summary] 한 줄 정의
> 서브에이전트는 부모 컨텍스트를 자동 상속하지 않으므로, 필요한 정보를 프롬프트에 명시적으로 넣어 넘긴다.

**English** Subagent context passing

## 시험 트리거
- "종합 에이전트가 앞 단계 결과를 모른다"
- "출처가 사라진다"

## 핵심
- 서브에이전트는 **부모 대화 기록을 상속하지 않고**, 호출 간 메모리도 공유하지 않는다.
- 이전 에이전트의 결과 **전체**를 서브에이전트 프롬프트에 직접 넣는다(예: 웹 검색 결과 + 문서 분석 결과 → 종합 에이전트).
- 콘텐츠와 메타데이터(출처 URL, 문서 이름, 페이지 번호)를 **구조화된 형식으로 분리**해 넘겨야 출처가 보존된다. → [[주장-출처 대응]]
- 코디네이터 프롬프트는 단계별 절차가 아니라 **연구 목표와 품질 기준**을 지정해 서브에이전트가 상황에 맞게 움직이게 한다.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - "서브에이전트는 코디네이터 대화를 자동으로 볼 수 있다" → 틀림
> - "공유 메모리에 넣어 두면 된다" → 가이드 기준 명시적 프롬프트 전달

## 셀프 체크
> [!question]- 서브에이전트가 코디네이터의 대화 기록을 자동으로 상속하나?
> 아니다. 필요한 내용을 프롬프트에 명시적으로 넣어야 한다

> [!question]- 에이전트 간에 출처를 보존하며 결과를 넘기려면?
> 콘텐츠와 메타데이터를 구조화된 형식으로 분리해 전달
