# 병렬 서브에이전트 생성

> [!summary] 한 줄 정의
> 코디네이터가 **한 응답 안에서 Task 도구 호출을 여러 개** 내보내 서브에이전트를 동시에 실행하는 방법.

**English** Parallel subagent spawning

## 시험 트리거
- "서브에이전트를 순차로 부르니 느리다"
- "지연 시간 단축"

## 핵심
- 여러 턴에 나눠 호출하면 순차 실행이 된다.
- 한 응답에 여러 Task 호출 → 병렬 실행 → 지연 시간 감소.
- 병렬화하려면 작업 범위가 겹치지 않게 나뉘어 있어야 한다. → [[허브 앤 스포크 오케스트레이션]]
