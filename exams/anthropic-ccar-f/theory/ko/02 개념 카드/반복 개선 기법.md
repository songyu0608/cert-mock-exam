# 반복 개선 기법

> [!summary] 한 줄 정의
> Claude Code 결과를 점진적으로 개선하는 4가지 기법: 구체적 입출력 예시, 테스트 주도 반복, 인터뷰 패턴, 얽힌 문제는 한 번에·독립 문제는 순차로.

**English** Iterative refinement techniques

## 시험 트리거
- "설명을 해도 결과가 매번 다르다"
- "엣지 케이스에서 틀린다"
- "낯선 도메인"

## 핵심
- **입출력 예시 2~3개**: 산문 설명이 일관되게 해석되지 않을 때 가장 효과적.
- **테스트 주도 반복**: 기대 동작·엣지 케이스·성능 요구를 담은 테스트를 먼저 쓰고, 실패를 공유하며 반복.
- **인터뷰 패턴**: 구현 전에 Claude가 질문하게 해 캐시 무효화 전략·실패 모드 같은 고려 사항을 드러냄.
- **얽힌 문제**는 한 번의 자세한 메시지로, **독립 문제**는 하나씩 순차로.
- 엣지 케이스(예: 마이그레이션 스크립트의 null)는 예시 입력과 기대 출력을 담은 테스트 케이스로 고친다.
