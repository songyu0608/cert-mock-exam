# 도구 배분과 최소 권한

> [!summary] 한 줄 정의
> 에이전트마다 역할에 필요한 도구만 준다. 도구가 많을수록(예: 4~5개가 아닌 18개) 선택 신뢰성이 떨어지고 전문 밖 도구를 오용한다.

**English** Tool distribution and scoped access

## 시험 트리거
- "종합 에이전트가 웹 검색을 시도한다"
- "도구 18개"
- "검증 때문에 왕복이 많다"

## 핵심
- 도구 수가 많으면 결정 복잡도가 올라가 선택이 불안정.
- 전문 밖 도구는 오용된다(예: 종합 에이전트의 웹 검색).
- **고빈도 요구에만** 범위를 좁힌 교차 역할 도구를 준다. 예: 종합 에이전트에 **verify_fact**(단순 사실 확인 85%), 복잡한 검증(15%)은 코디네이터를 거쳐 검색 에이전트로.
- "모든 웹 검색 도구를 종합 에이전트에" → 과잉 권한, 관심사 분리 위반.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 종합 에이전트에 검색 도구 전체를 주는 선택지 → 과잉 권한
> - 검증 요청을 모아 마지막에 일괄 처리 → 앞선 사실에 의존하는 단계가 막힘
> - "검색 에이전트가 미리 넉넉히 캐시" → 무엇이 필요할지 예측 불가
