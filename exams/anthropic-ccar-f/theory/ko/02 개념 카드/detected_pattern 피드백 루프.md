# detected_pattern 피드백 루프

> [!summary] 한 줄 정의
> 구조화된 리뷰 결과마다 어떤 코드 구조가 지적을 일으켰는지 기록해, 개발자가 기각한 지적의 패턴을 체계적으로 분석한다.

**English** detected_pattern feedback loop

## 시험 트리거
- "어떤 지적이 자주 기각되는지 알고 싶다"

## 핵심
- 결과 스키마에 detected_pattern 필드 추가 → 기각과 함께 집계 → 거짓 양성 패턴 파악 → 기준·예시 개선.
