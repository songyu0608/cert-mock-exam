# 접근 실패 vs 유효한 빈 결과

> [!summary] 한 줄 정의
> 타임아웃 같은 접근 실패는 재시도 판단이 필요하고, 일치 항목이 없는 성공한 쿼리는 정상 결과다. 둘을 섞으면 복구가 틀어진다.

**English** Access failure vs valid empty result

## 시험 트리거
- "검색 결과가 0건"
- "타임아웃을 빈 결과로 처리했다"

## 핵심
- 접근 실패 → 오류로 보고(재시도 여부 판단 대상).
- 유효한 빈 결과 → **성공**으로 보고(일치 없음).
- 타임아웃을 잡아 빈 결과를 성공으로 돌려주면 **오류 은폐**가 된다. → [[오류 전파 안티패턴]]

## 오답 함정
> [!warning] "타임아웃을 잡아 빈 결과 + 성공으로 반환" → 오류를 숨겨 복구 불가
