# 에이전트 루프

> [!summary] 한 줄 정의
> Claude에 요청 → stop_reason 확인 → 요청된 도구 실행 → 결과를 대화에 추가 → 다시 요청을 반복하는 자율 실행 구조.

**English** Agentic loop

## 시험 트리거
- "에이전트가 언제 멈춰야 하나"
- "도구 결과를 어떻게 다음 판단에 반영하나"

## 핵심
- 계속 조건은 stop_reason == "tool_use", 종료 조건은 stop_reason == "end_turn". → [[stop_reason]]
- 도구 결과는 **대화 기록에 추가**해서 다음 요청에 보낸다. 그래야 모델이 새 정보를 근거로 다음 행동을 고른다.
- 다음에 어떤 도구를 쓸지는 **모델이 컨텍스트를 보고 판단**한다(모델 주도). 미리 정한 의사 결정 트리·고정 도구 순서와 다르다.
- 순서가 반드시 지켜져야 하는 업무 규칙은 루프 안의 판단에 맡기지 않고 [[프로그래밍 방식 강제]]로 막는다.

## 오답 함정
> [!warning] "최대 반복 횟수 N회"를 **주된** 종료 수단으로 쓰는 선택지 → 안전장치일 수는 있어도 주 종료 조건은 stop_reason
