# tool_use 구조화된 출력

> [!summary] 한 줄 정의
> JSON 스키마를 입력 매개변수로 정의한 추출 도구를 호출하게 하면, 스키마를 준수하는 출력을 가장 확실하게 얻는다(구문 오류 제거).

**English** Structured output via tool_use

## 시험 트리거
- "JSON이 가끔 깨진다"
- "추출 결과를 시스템에 넘겨야 한다"

## 핵심
- 추출 도구의 input_schema = 원하는 출력 스키마 → tool_use 블록에서 데이터를 꺼낸다.
- **구문 오류는 사라지지만 의미 오류는 남는다.** → [[구문 오류 vs 의미 오류]]
- 도구를 반드시 호출하게 하려면 [[tool_choice]]를 "any" 또는 강제 선택으로.
- 원문 형식이 들쭉날쭉하면 엄격한 스키마와 함께 **형식 정규화 규칙**을 프롬프트에 넣는다.
