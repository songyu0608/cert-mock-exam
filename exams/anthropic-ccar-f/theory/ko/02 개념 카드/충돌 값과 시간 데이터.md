# 충돌 값과 시간 데이터

> [!summary] 한 줄 정의
> 신뢰할 만한 출처끼리 통계가 다르면 하나를 고르지 말고 출처를 밝혀 둘 다 남긴다. 발행일·수집일을 요구해 시점 차이를 모순으로 오해하지 않게 한다.

**English** Conflicting values and temporal data

## 시험 트리거
- "두 보고서의 수치가 다르다"
- "2023년 자료와 2025년 자료가 충돌"

## 핵심
- 충돌 → **두 값 모두 + 출처 주석**, 조정 방법은 **코디네이터가 결정**한 뒤 종합으로.
- 임의 선택 금지.
- 구조화된 출력에 **발행일·데이터 수집일**을 넣어 시점 차이를 구분.
