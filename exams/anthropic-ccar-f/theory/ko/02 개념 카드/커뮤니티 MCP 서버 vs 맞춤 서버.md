# 커뮤니티 MCP 서버 vs 맞춤 서버

> [!summary] 한 줄 정의
> Jira 같은 표준 통합은 기존 커뮤니티 MCP 서버를 쓰고, 맞춤 서버는 팀 고유 워크플로에만 만든다.

**English** Community vs custom MCP servers

## 시험 트리거
- "Jira 연동을 직접 만들까"

## 핵심
- 표준 통합 → 커뮤니티 서버.
- 팀 고유 워크플로 → 맞춤 서버.
