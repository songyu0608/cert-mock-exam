# 배치 API vs 동기 API

| | [[Message Batches API]] | 동기(실시간) API |
|---|---|---|
| 비용 | **50% 절감** | 정가 |
| 처리 시간 | 최대 24시간, SLA 없음 | 즉시 |
| 다중 턴 도구 호출 | **불가** | 가능 |
| 맞는 작업 | 야간 보고서, 주간 감사, 야간 테스트 생성 | 병합 전 검사처럼 기다리는 작업 |
| 짝짓기 | custom_id | - |

> [!question]- 병합 전 검사와 야간 보고서를 모두 배치로 바꾸자는 제안
> 야간 보고서만 배치. 병합 전 검사는 동기 유지.
