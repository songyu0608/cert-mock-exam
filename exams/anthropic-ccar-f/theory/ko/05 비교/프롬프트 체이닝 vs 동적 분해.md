# 프롬프트 체이닝 vs 동적 분해

| | [[프롬프트 체이닝]] | [[동적 적응형 분해]] |
|---|---|---|
| 단계 | 미리 고정 | 발견에 따라 생성 |
| 맞는 작업 | 예측 가능한 다면 리뷰 | 열린 조사 |
| 예 | 파일별 분석 → 통합 패스 | 레거시 코드에 포괄적 테스트 추가 |
| 위험 | 예상 밖 상황에 약함 | 범위가 퍼질 수 있음 → 우선순위 계획으로 관리 |

> [!question]- "레거시 코드베이스 전체에 테스트를 추가하라"
> 동적 분해. 구조 파악 → 고영향 영역 → 우선순위 계획 → 의존성이 드러나면 조정.
