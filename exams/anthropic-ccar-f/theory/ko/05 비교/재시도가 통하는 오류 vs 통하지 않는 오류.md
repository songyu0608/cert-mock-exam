# 재시도가 통하는 오류 vs 통하지 않는 오류

| 오류 | 재시도 | 대응 |
|---|---|---|
| 일시적(타임아웃, 서비스 불가) | 통함 | 로컬 재시도 → 해결 안 되면 구조화 오류로 전파 |
| 형식 불일치·출력 구조 오류(추출) | 통함 | 원문 + 실패 결과 + 구체적 검증 오류로 재요청 |
| 유효성 검사(잘못된 입력) | 입력을 고쳐야 함 | 입력 수정 |
| 비즈니스(정책 위반) | **안 통함** (retriable: false) | 고객에게 설명, 에스컬레이션 |
| 권한 | 안 통함 | 권한 문제 보고 |
| 원문에 정보 없음(추출) | **안 통함** | null 허용, 사람 검토 |
