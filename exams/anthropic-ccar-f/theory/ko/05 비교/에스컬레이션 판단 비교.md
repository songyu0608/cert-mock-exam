# 에스컬레이션 판단 비교

| 상황 | 행동 |
|---|---|
| 고객이 **명시적으로 상담원 요구** | **즉시** 넘김(조사 먼저 하지 않음) |
| 불만은 있지만 문제가 능력 범위 안 | 공감 + 해결 제안. 다시 요구하면 넘김 |
| 정책이 **모호하거나 언급 없음**(예: 경쟁사 가격 맞춤) | 넘김 |
| 의미 있는 진척 불가 | 넘김 |
| 단지 복잡함 | 기준에 따라 판단(복잡도만으로 넘기지 않음) |
| 조회 결과 **여러 명 일치** | 추가 식별 정보 요청 |
| 감정 점수 높음 / 자체 확신도 낮음 | 기준이 아님 |
