# 자체 리뷰 vs 독립 인스턴스 vs 다중 패스

| 방식 | 효과 | 비고 |
|---|---|---|
| 같은 세션 자체 리뷰(확장 사고 포함) | 낮음 | 생성 맥락이 남아 자기 결정을 의심하지 않음 |
| [[독립 리뷰 인스턴스]] | 높음 | 생성자 추론 맥락 없음 |
| [[다중 패스 리뷰]] | 큰 PR에 효과 | 파일별 + 통합 패스로 주의 분산 해소 |
| 같은 리뷰 3회 후 다수결 | 오답 | 간헐적으로 잡히는 진짜 버그를 놓침 |
| 더 큰 컨텍스트 모델 | 오답 | 주의 품질 문제는 그대로 |
