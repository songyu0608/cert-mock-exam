# 세션 재개 vs 포크 vs 새 세션

| 방법 | 쓰는 때 |
|---|---|
| --resume <session-name> | 이전 컨텍스트가 **대부분 유효**. 바뀐 파일은 구체적으로 알림 |
| fork_session | 같은 분석 기준점에서 **두 접근법 비교** |
| 요약 주입 + 새 세션 | 이전 도구 결과가 **오래됨** |
