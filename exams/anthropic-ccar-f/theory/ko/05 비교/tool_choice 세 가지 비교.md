# tool_choice 세 가지 비교

| 설정 | 도구 호출 | 어떤 도구 | 쓰는 때 |
|---|---|---|---|
| "auto" | 모델 판단(텍스트만 낼 수 있음) | 모델 | 일반 대화형 에이전트 |
| "any" | **반드시** | 모델 | 구조화 출력 보장, 스키마가 여러 개이고 문서 유형을 모를 때 |
| {"type": "tool", "name": "X"} | **반드시** | **X 고정** | 특정 단계 먼저(예: extract_metadata) |

자세히: [[tool_choice]]

> [!question]- 추출 스키마가 송장·영수증·계약서 3종이고 들어오는 문서 유형을 모른다. 반드시 구조화 출력을 받으려면?
> tool_choice: "any". 도구 호출은 강제하고 어떤 스키마인지는 모델이 고른다.
