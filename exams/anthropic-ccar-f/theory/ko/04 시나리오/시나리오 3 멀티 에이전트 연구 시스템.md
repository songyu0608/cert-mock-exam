# 시나리오 3 멀티 에이전트 연구 시스템

**English** Scenario 3: Multi-Agent Research System

> [!abstract] 시나리오 (공식 가이드 번역)
> Claude Agent SDK로 멀티 에이전트 연구 시스템을 만든다. 코디네이터 에이전트가 전문 서브에이전트에 위임한다. 하나는 웹을 검색하고, 하나는 문서를 분석하고, 하나는 결과를 종합하고, 하나는 보고서를 만든다. 시스템은 주제를 조사해 인용이 달린 포괄적인 보고서를 만든다.

주요 도메인: 1 에이전트 아키텍처와 오케스트레이션, 2 도구 설계와 MCP 통합, 5 컨텍스트 관리와 신뢰성

## 이 시나리오에서 자주 나오는 판단
- 구조 → [[허브 앤 스포크 오케스트레이션]]

- 컨텍스트 넘기기 → [[서브에이전트 컨텍스트 전달]], [[병렬 서브에이전트 생성]]
- 실패 처리 → [[구조화된 오류 컨텍스트]], [[오류 전파 안티패턴]]
- 도구 범위 → [[도구 배분과 최소 권한]]
- 출처 → [[주장-출처 대응]], [[충돌 값과 시간 데이터]]
