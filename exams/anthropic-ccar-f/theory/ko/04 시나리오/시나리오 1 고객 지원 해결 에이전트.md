# 시나리오 1 고객 지원 해결 에이전트

**English** Scenario 1: Customer Support Resolution Agent

> [!abstract] 시나리오 (공식 가이드 번역)
> Claude Agent SDK로 고객 지원 해결 에이전트를 만든다. 반품, 결제 분쟁, 계정 문제 같은 모호성이 큰 요청을 처리한다. 사용자 지정 MCP 도구(get_customer, lookup_order, process_refund, escalate_to_human)로 백엔드에 접근한다. 목표는 언제 에스컬레이션할지 알면서 첫 접촉 해결률 80% 이상을 달성하는 것이다.

주요 도메인: 1 에이전트 아키텍처와 오케스트레이션, 2 도구 설계와 MCP 통합, 5 컨텍스트 관리와 신뢰성
