# 116. If I Started Over: Learn, Build, Then Certify

If you were starting your career again right now, knowing everything you know today, what would you learn first? When you need to start? You mentioned that we don't need to do it with prompt engineering, but where do we need to start?

Yeah, so it's a great question. First of all, I would not spend too much time, like me, jumping between random YouTube tutorials and long courses. Instead of it, I would use a certification exam guide as a roadmap, and then I will study that roadmap, like study those topics. And right after that, I will build something real, like some practical product. And then, after that, if I have practical experience and basic knowledge, go ahead, try to pass an exam, try to build something in production.

Let's talk about long-term career. What will separate AI professionals who remain valuable over the next five years from those whose skills become obsolete?

I would say, as I said, the basic knowledge. So if you try to learn something vendor-specific, like cloud-specific, domain-specific, so models will change, right? And we don't know which model will be popular in a couple of years. But if you learn some basic things, like context management, reliability, evaluation, I believe it will be relevant even in many years. So this is my approach. Do not waste your time on some vendor-specific things.

Yeah, and definitely you're about the practical approach. So you built your cloud-certified architect foundation scores around the shop-assist AI projects. Why did you choose a real application instead of simply teaching the exam topics one by one?

As for me, it's the best way to understand how the knowledge can be applied. And the pure theory is harder to remember. And when you see where you can apply that knowledge in practice, this is the best way to learn it. This is how I do that over time. And this is what I recommend to do for other people.
