# 9. How to Use the Course Labs

Starting from the next lesson, this course uses labs. A lab is a coding exercise that runs inside the course, in your browser.

First, a note about access. Right now, labs are not available on every plan. As far as we know, they work for Udemy Personal Plan, Udemy Pro and Udemy Business Learners. Udemy may change this later. So if you do not see the lab in your course, that can be normal. It is not an error on your side. You will still have the video and the task list. And the lab code also runs on your own computer. So you do not lose the exercise.

Labs also work on desktop only for now. They do not work on a phone or a tablet. So please use a laptop or computer.

Now, why we use them. You do not need to install anything. No Python, no libraries, no setup on your machine. You open the lab and everything is ready.

This means you can watch the video and write the code at the same time. You see a step, then you do the same step yourself, right away. That is the whole idea.

I recommend using split screen. Put the video on one side and the lab on the other side. Then you can look at my code and write your own code without switching tabs.

Let me show you how this looks.

When you open a lab, it needs time to start. This is normal. It usually takes a few minutes. Sometimes it can be a little slow. Just give it a moment, it will start. If it takes more than 5 minutes, don't worry. Sometimes it can take a little longer.

What opens is a Jupyter notebook environment. It is the same tool you can try for free on the Jupyter website. But here the code for the lesson is already loaded and you do not need an API key. Everything works without a key.

When the lab is ready, look at the file list on the left. Open the file called notebook.ipynb. This is your working file. Read the text inside it. It explains what to do step by step. Follow those instructions and look at the video anytime you want to see what I am doing.

The notebook is split into sections called cells. You run each cell separately. Click on a cell, then press the play button at the top.

Let me do this with our first lab. I press play and the cell runs. I keep going cell by cell.

Now I reach a cell where I have to add something myself. You do not write this from scratch. The code is already here. Look at it. Some values are replaced by three dots. Those are the blanks and next to each one a command tells you what to put there.

Before I fill them in, watch this. I run the cell as it is. With the dots still in place. And I get an error. This is correct. This is not a problem. The error simply says that some blanks are still empty.

Now I fill them in. The command next to each blank tells me the value. And if I want to see this code working with a real API key, I can look at the lesson video. I run the cell again and it works.

That is everything. Open the lab. Read the notebook. Run the cells. And write the code where the notebook asks for it.
