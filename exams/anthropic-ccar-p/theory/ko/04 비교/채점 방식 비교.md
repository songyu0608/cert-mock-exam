# 채점 방식 비교

| | 코드 기반 | LLM 기반 | 사람 |
|---|---|---|---|
| 속도·확장성 | 가장 빠름, 매우 확장적 | 빠르고 확장적 | 느리고 비쌈 |
| 판단 | 규칙적 판단만(뉘앙스 부족) | 복잡한 판단 가능 | 가장 유연, 고품질 |
| 공식 권장 | 가능하면 우선 | 신뢰성 테스트 후 확장 | 가능하면 피함 |
| 예 | 정확 일치, 문자열 포함 | 루브릭 채점, 0.0~1.0 + 합격/불합격 | 엣지 케이스 발견 |

**판별 순서**: ① 정답이 명확한가? → 코드 ② 자유 서술·복잡 판단? → LLM(루브릭, 추론 후 점수) ③ 자동화가 놓치는 것을 찾을 때 → 사람
