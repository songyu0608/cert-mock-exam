## 개념 확인
조직 전체에서 특정 도구·명령을 막는 곳(공식 문서)은?::관리형 설정의 permissions.deny
기술적 강제와 행동 지침은 각각 어디에 두나?::강제는 설정(settings), 지침은 CLAUDE.md
Claude Code를 비대화형으로 실행하는 플래그는?::-p(--print)
편집 후 포매터를 자동 실행하는 훅 이벤트는?::PostToolUse(Edit|Write 매처)
GitHub·Slack·Sentry·Grafana·Splunk MCP 도구 정의가 차지하는 토큰(공식 문서 예)은?::약 55k 토큰
팀과 공유되는 CLAUDE.md 위치는?::./CLAUDE.md 또는 ./.claude/CLAUDE.md(소스 관리)
CLAUDE.md 권장 길이는?::파일당 200줄 미만
Claude Code 설정 우선순위(높은 순)는?::관리형 > 명령줄 > 로컬 프로젝트 > 공유 프로젝트 > 사용자
팀이 소스 관리로 공유하는 설정 파일은?::.claude/settings.json
PreToolUse 훅이 도구 실행을 막는 종료 코드는?::2
여러 PreToolUse 훅의 결정이 다를 때는?::가장 제한적인 결정(deny > defer > ask > allow)
CI에서 매번 같은 결과를 내려고 자동 탐색을 끄는 플래그는?::--bare
비용 정보가 포함되는 출력 형식은?::--output-format json(total_cost_usd)
팀과 공유되는 MCP 범위와 파일은?::프로젝트 범위, 프로젝트 루트의 .mcp.json
MCP 범위의 기본값은?::로컬

## 상황 → 판단
상황: 조직 전체에서 명령 금지 → 정답 방향은?::관리형 설정 permissions.deny
상황: 팀 공유 지침 → 정답 방향은?::./CLAUDE.md(소스 관리)
상황: 팀 공유 MCP 서버 → 정답 방향은?::프로젝트 범위 .mcp.json
상황: 편집 후 항상 포매터 → 정답 방향은?::PostToolUse 훅
상황: 보호 파일 편집 차단 → 정답 방향은?::PreToolUse 훅(종료 코드 2)
상황: CI에서 Claude Code 실행 → 정답 방향은?::claude -p(필요 시 --bare)
