# 오답 선택지 패턴

샘플 문제 해설과 공식 문서에서 뽑은, 그럴듯하지만 틀리기 쉬운 선택지 유형. 샘플 표시가 없는 행은 공식 문서 근거의 정리(해석)다.

| 오답이 되기 쉬운 선택지 | 맞는 쪽 | 노트 |

| 남용을 나중에 감사하도록 로깅 추가 | 필요 없는 도구 제거(샘플 1) | [[기능 비대화와 최소 권한]] |
| 모든 도구를 두고 확인 프롬프트만 추가 | 불필요 권한 제거가 먼저(샘플 1) | [[탐지 통제 vs 예방 통제]] |
| 더 큰 모델로 교체해 보안 해결 | 모델 크기는 인가 범위와 무관(샘플 1) | [[기능 비대화와 최소 권한]] |
