# 도메인 7　개발자 생산성과 운영 지원

**English** Domain 7: Developer Productivity & Operational Enablement  
**日本語** 分野7：開発者の生産性と運用支援

도메인 7 (7%) · 목표 3개

개발팀이 Claude Code 같은 도구를 잘 쓰게 만드는 도메인이다(7%). 범위별 설정과 자동화 방식을 구분하는 것이 핵심이다.

## 목표 7.1

**팀을 위한 Claude 도구와 환경(예: Claude Code)을 구성한다**

> [!quote]- 공식 원문 (English / 日本語)
> Configure Claude tools and environments for teams (e.g., Claude Code)
>
> チーム向けにClaudeのツールと環境（Claude Codeなど）を構成する

CLAUDE.md(지침)·settings(강제)·MCP 범위·인증을 범위별로 나눠 배포하고, 조직 정책은 관리형 설정으로 강제한다.

관련 카드: [[팀용 Claude Code 구성]] · [[CLAUDE.md 범위]] · [[Claude Code 설정 우선순위]] · [[Claude Code MCP 범위]]

## 목표 7.2

**AI 보조 도구로 개발자 워크플로를 개선한다**

> [!quote]- 공식 원문 (English / 日本語)
> Improve developer workflows using AI-assisted tooling
>
> AI支援ツールを使用して開発者のワークフローを改善する

-p로 CI·스크립트 자동화, 훅으로 결정적 동작(포맷·차단), 스킬로 반복 절차 재사용.

관련 카드: [[AI 보조 개발 워크플로]] · [[Claude Code 훅]] · [[헤드리스 모드(-p)]]

## 목표 7.3

**디버깅과 운영 문제 해결을 지원한다**

> [!quote]- 공식 원문 (English / 日本語)
> Support debugging and operational issue resolution
>
> デバッグと運用上の問題解決を支援する

관측 도구를 MCP로 연결해 원인 분석을 돕고, 운영 변경은 최소 권한과 확인으로 통제한다.

관련 카드: [[디버깅과 운영 문제 해결 지원]]

## 요약
- 강제는 설정·훅, 지침은 CLAUDE.md
- 설정: 관리형 > 명령줄 > 로컬 > 공유 프로젝트 > 사용자
- 팀 공유: ./CLAUDE.md, .claude/settings.json, .mcp.json

## 이 도메인의 카드
- [[팀용 Claude Code 구성]] — 팀 공유 지침(CLAUDE.md), 설정·권한(settings), MCP 서버, 인증을 범위별로 나눠 배포하고, 조직 정책은 관리형 설정으로 강제한다.
- [[AI 보조 개발 워크플로]] — Claude Code를 대화형 작업뿐 아니라 CI·스크립트(-p), 훅(자동 포맷·차단), 스킬·서브에이전트로 팀의 반복 작업에 연결한다.
- [[디버깅과 운영 문제 해결 지원]] — 로그·트레이스·모니터링 도구를 Claude에 연결해 원인 분석을 돕게 하고, 운영 환경에 대한 변경은 권한과 확인으로 통제한다.
- [[CLAUDE.md 범위]] — Claude Code가 매 세션 읽는 지침 파일. 관리형·사용자·프로젝트·로컬 범위로 나뉘고, 팀 공유 지침은 프로젝트 CLAUDE.md에 둔다.
- [[Claude Code 설정 우선순위]] — Claude Code 설정은 관리형 > 명령줄 > 로컬 프로젝트 > 공유 프로젝트 > 사용자 순으로 적용된다. 권한 목록은 범위를 넘어 합쳐진다.
- [[Claude Code 훅]] — Claude Code 수명주기의 특정 시점(도구 실행 전후, 알림 등)에 셸 명령을 자동 실행하는 기능. 지침이 아니라 결정적으로 실행된다.
- [[헤드리스 모드(-p)]] — claude -p로 Claude Code를 비대화형으로 실행해 CI·스크립트에서 쓰는 방식.
- [[Claude Code MCP 범위]] — Claude Code의 MCP 서버는 로컬·프로젝트·사용자 3개 범위에 설정하고, 팀 공유는 프로젝트 범위(.mcp.json)로 한다.
