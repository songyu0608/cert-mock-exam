# 0 시험 개요와 출제 범위

Claude Certified Architect – Professional(CCAR-P)은 Anthropic의 Claude 플랫폼으로 운영 수준의 AI 솔루션을 설계·구축·제공할 수 있는지를 검증한다. 모델·아키텍처·API 패턴 선택, 프롬프트·컨텍스트 엔지니어링, 엔터프라이즈 통합, 평가·보안·규제·거버넌스를 설계에 반영하는 아키텍트 역할이 대상이다.

## 시험 정보 (시험 가이드 v1.0, 2026년 7월 발효)
| 항목 | 내용 |
|---|---|
| 시험 코드 | CCAR-P |
| 문항 수 | 63 |
| 형식 | 단일 선택형과 복수 응답형. 문항마다 고를 개수를 명시 |
| 시간 | 120분 |
| 합격 점수 | 환산 점수 720 (100~1,000) |
| 응시료 | 175달러(USD). 결제 화면에 파트너 등급 할인 반영 |
| 유효 기간 | 취득일부터 12개월 |
| 결과 | 합격/불합격 + 환산 점수, 도메인별 정답률(합격 판정에는 쓰지 않음) |
| 채점 | 준거 참조(criterion-referenced): 다른 수험자가 아니라 고정 기준과 비교 |
| 응시 | Pearson VUE 감독 시험(온라인 감독 또는 테스트 센터) |
| 예약 변경·취소 | 예약 24시간 전까지. 24시간 이내 변경은 응시료 소멸 |
| 재응시 | 불합격 후 14일 / 30일 / 90일 대기. 같은 시험은 연속 12개월에 최대 4회. 매 회 응시료 |
| 결시·지각 | 응시료 소멸, 재등록 필요 |
| 갱신 | 기한 내 변경 사항 확인 + Partner Academy의 무료 비감독 평가. 만료되면 정가로 시험 전체 재응시 |
| 이의 신청 | 결정 통지일 또는 시험일로부터 14일 이내(Pearson VUE 지원 경유) |
| 선수 조건 | 없음. 권장 경력: 시스템 아키텍처 3년 이상, 운영 환경 Claude(또는 유사 LLM) 6개월 이상 |
| 시험 언어 | 가이드에 명시 없음. 외부 기사는 영어·일본어라고 전함(미확인) |
| 시나리오·범위 밖 목록 | 가이드에 없음 |

## 공부 포인트
- 가이드는 도메인별 목표 문구만 제시하고, 지식 목록·범위 서비스·범위 밖 주제는 제시하지 않는다. 목표 번호(1.1 등)는 이 볼트가 붙였다.
- 샘플 3문항의 해설이 판단 기준을 보여 준다: **필요 없는 권한은 제거**(로깅·확인은 탐지·보완 통제), **정적 내용 앞 + 캐싱**, **문서 갱신 뒤 오답은 검색/인덱싱부터**.
- 가이드 7장은 Claude API, 모델, 프롬프트 엔지니어링, MCP, Skills 공식 문서를 보라고 권한다. 카드의 보충 내용은 이 공식 문서에서 가져왔고 각 카드에 근거 링크를 달았다.
- 모델 이름·가격·기본값 같은 제품 정보는 빠르게 바뀐다. 카드에 "변동 정보"로 표시했다.
