# 출처와 주의 사항

## 사용한 자료 (2026-11-07 확인)
- **Claude Certified Architect – Professional Exam Guide** v1.0 (2026년 7월 발효, 영어). Anthropic 배포 PDF.
- **Claude Certified Architect – Professional 試験ガイド** v1.0 (일본어). 사용자가 제공한 PDF.
- 보충 내용의 근거(카드마다 링크): Anthropic 공식 글(Building effective agents, Multi-agent research system, Effective context engineering, Writing tools for agents, Advanced tool use, Code execution with MCP, Contextual retrieval), Claude 플랫폼 문서(평가, 할루시네이션, 탈옥·인젝션, 지연, 프롬프트 모범 사례, 모델 선택, 컨텍스트 윈도우, 배치, Skills, 도구 검색, 인용, MCP 커넥터, 데이터 보존), Claude Code 문서(memory, settings, authentication, MCP, hooks, headless), 공공 부문 FAQ(FedRAMP).
- 프롬프트 캐싱 수치(중단점 4개, TTL, 배율)는 Anthropic의 claude-api 스킬 참조 문서로 확인했다. 캐싱 문서 페이지를 직접 받지는 않았다.

## 가이드에서 확인한 사실
- 시험 정보, 도메인 7개와 비중(17/13/19/16/14/14/7%), 도메인별 목표 문구(6/5/8/6/5/5/3 = 38개), 샘플 3문항과 해설, 응시 정책.
- 목표 문구의 한국어는 영어 원문을 이 볼트가 번역한 것이다. 공식 한국어 가이드는 없다. 각 이론 노트에 영어·일본어 원문을 접어 두었다.

## 가이드에 없음
- 목표 번호(1.1 등): 가이드는 글머리 목록만 제시한다. 번호는 이 볼트가 붙였다.
- 지식 목록, 범위 서비스, 시나리오, 범위 밖 주제 목록.
- 시험 언어: 외부 기사(szymonpaluch, Anthropic FAQ 인용)가 영어·일본어라고 전하지만 가이드에는 없다. 예약 화면에서 확인한다.

## 해석과 변동 정보
- 카드의 "시험 트리거", "오답 함정", 비교표, 판단 패턴은 가이드 목표 문구·샘플 해설과 공식 문서를 바탕으로 **정리한 해석**이다. 가이드가 이 세부까지 출제한다는 보장은 없다.
- 카드 본문에서 〔해석〕 표시가 붙은 줄은 공식 문서에 직접 근거가 없는 일반 아키텍처 정리다. 특히 도메인 6(이해관계자·라이프사이클)과 A2A(에이전트 간), GDPR 세부는 공식 근거를 찾지 못했다.
- 모델 이름, effort 기본값, 캐시 배율, 컨텍스트 크기, FedRAMP 경로, 베타 기능 여부는 **변동 정보**다(2026-11 문서 기준).
- 가이드는 "예고 없이 바뀔 수 있다"고 명시한다. 응시 전 최신판을 확인한다.
