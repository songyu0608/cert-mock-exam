# 코드 실행과 MCP

> [!summary] 한 줄 정의
> MCP 도구를 코드 API(파일)로 노출하고, 에이전트가 파일 시스템을 탐색해 필요한 도구 정의만 읽고 코드로 호출하는 방식.

**日本語** コード実行とMCP　·　**English** Code execution with MCP

## 시험 트리거
- "연결한 MCP 도구가 너무 많다"
- "민감한 데이터가 모델을 거치지 않게 하고 싶다"

## 핵심
- 에이전트가 ./servers/ 디렉터리를 탐색해 필요한 도구 파일만 읽는다. 공식 글 예: 150,000→2,000토큰(98.7% 절감).
- 개인정보 보호: MCP 클라이언트가 PII를 토큰화해 실제 값이 모델을 거치지 않고 시스템 사이를 이동하게 할 수 있다.
- 저장한 함수에 SKILL.md를 붙이면 재사용 스킬이 된다.
- 대가: 에이전트가 만든 코드를 실행하려면 샌드박스·자원 제한·모니터링이 필요해 운영 부담과 보안 고려가 늘어난다.
