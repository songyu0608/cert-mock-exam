# 도구 검색 도구

> [!summary] 한 줄 정의
> 수백~수천 개 도구 정의를 미리 다 싣지 않고, Claude가 필요한 도구만 검색해 불러오게 하는 기능.

**日本語** ツール検索ツール　·　**English** Tool search tool

## 시험 트리거
- "MCP 서버 여러 개의 도구 정의만 수만 토큰"
- "도구가 많아 잘못된 도구를 고른다"

## 핵심
- GitHub·Slack·Sentry·Grafana·Splunk 같은 구성은 작업 전에 도구 정의만 약 55k 토큰. 도구 검색은 보통 85% 이상 줄이고 요청마다 필요한 3~5개만 로드한다.
- 도구가 30~50개를 넘으면 도구 선택 정확도가 떨어진다. 도구 검색은 수천 개에서도 정확도를 유지한다.
- defer_loading: true로 처음에 로드하지 않을 도구를 표시한다. 도구 검색 도구 자체 등 최소 1개는 지연 로드하지 않는다.
- 공식 발표 글의 내부 평가: 대규모 도구 라이브러리 MCP 평가에서 정확도 향상(예: Opus 4 49%→74%).
- 〔해석〕 검색 단계가 하나 늘어나므로 도구가 적으면 그냥 모두 로드하는 편이 단순하다.
