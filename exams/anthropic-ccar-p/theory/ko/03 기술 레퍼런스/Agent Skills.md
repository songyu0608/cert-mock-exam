# Agent Skills

> [!summary] 한 줄 정의
> 지시·메타데이터·스크립트·리소스를 폴더로 묶어 Claude가 필요할 때만 불러 쓰는 모듈형 기능. 점진적 공개로 컨텍스트를 아낀다.

**日本語** スキル　·　**English** Agent Skills

## 시험 트리거
- "팀 절차를 재사용 가능한 부품으로"
- "모든 지침을 시스템 프롬프트에 넣으면 너무 길다"
- "외부에서 받은 스킬을 설치"

## 핵심
- 1단계 메타데이터(name·description): 항상 로드, 스킬당 약 100토큰.
- 2단계 SKILL.md 본문: 요청이 description과 맞을 때 로드, 5k 토큰 미만.
- 3단계 리소스·코드: 필요할 때만. 스크립트는 bash로 실행되고 출력만 컨텍스트에 들어간다.
- description에는 무엇을 하는지와 언제 써야 하는지를 모두 적어야 한다(트리거 기준).
- 신뢰할 수 있는 출처(직접 만들었거나 Anthropic 제공)의 스킬만 쓰고, 외부 스킬은 감사한다. 악성 스킬은 의도하지 않은 도구 사용·데이터 유출을 일으킬 수 있다.
