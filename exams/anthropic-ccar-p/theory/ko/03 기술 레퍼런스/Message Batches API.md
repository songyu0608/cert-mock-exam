# Message Batches API

> [!summary] 한 줄 정의
> 즉시 응답이 필요 없는 대량 요청을 비동기로 처리하고 모든 토큰을 50% 할인받는 API.

**日本語** Message Batches API　·　**English** Message Batches API

## 시험 트리거
- "야간에 문서 수만 건을 분류"
- "결과를 바로 받을 필요가 없다"
- "평가셋을 대량으로 돌린다"

## 핵심
- 모든 사용량(입력·출력·특수 토큰)이 표준 가격 대비 50% 할인. 프롬프트 캐싱 할인과 중첩된다.
- 대부분 1시간 안에 끝나지만, 24시간 안에 끝나지 않으면 만료된다(만료된 요청은 과금되지 않음). 24시간은 SLA가 아니다.
- 한 배치는 요청 100,000건 또는 256MB 중 먼저 닿는 쪽까지. 결과는 생성 후 29일간 받을 수 있다.
- 배치는 5분을 넘길 수 있으므로 캐싱을 쓰면 1시간 캐시 TTL을 고려한다.
- 서버 도구(웹 검색, 코드 실행, MCP 커넥터, 도구 검색 등)는 배치에서도 동작한다. 〔해석〕 사용자 정의 도구는 결과를 돌려줄 때마다 새 요청이 필요해 실시간 도구 루프에는 맞지 않는다.
