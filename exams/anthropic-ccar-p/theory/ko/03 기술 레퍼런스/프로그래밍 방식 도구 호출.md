# 프로그래밍 방식 도구 호출

> [!summary] 한 줄 정의
> Claude가 도구를 하나씩 호출해 결과를 컨텍스트로 받는 대신, 코드 실행 환경에서 코드로 여러 도구를 조율하고 최종 결과만 받는 방식.

**日本語** プログラムによるツール呼び出し　·　**English** Programmatic tool calling

## 시험 트리거
- "도구 결과의 중간 데이터가 너무 크다"
- "여러 도구를 반복·조건 처리해야 한다"

## 핵심
- 중간 결과가 Claude의 컨텍스트에 들어오지 않아 토큰이 준다. 복잡한 조사 과제에서 평균 43,588→27,297토큰(37% 감소).
- 도구를 병렬로 실행할 수 있고, 반복·조건 같은 로직을 코드로 처리한다.
- 코드 실행 환경이 필요하다 → [[코드 실행과 MCP]].

> [!warning] 프로그래밍 방식 도구 호출이 도구 정의 토큰을 줄인다는 선택지 → 줄이는 것은 중간 결과(도구 출력) 토큰
