# 문제 분해 기법

> [!summary] 한 줄 정의
> 복잡한 문제를 LLM이 다루기 쉬운 하위 작업으로 나누는 방법. 고정 분해(체이닝·섹셔닝)와 동적 분해(오케스트레이터·에이전트)를 구분한다.

**日本語** 分解の手法　·　**English** Decomposition techniques

## 시험 트리거
- "한 번의 프롬프트로는 품질이 안정되지 않는다"
- "각 단계 결과를 검증해야 한다"
- "하위 작업을 미리 알 수 없다"

## 핵심
- 고정 분해: 단계가 미리 정해짐 → [[프롬프트 체이닝]](순차), [[병렬화(섹셔닝·투표)]](병렬).
- 동적 분해: 입력에 따라 하위 작업을 정함 → [[오케스트레이터-워커]], 에이전트.
- 공식 글: 각 고려 사항을 별도 LLM 호출이 맡으면 더 잘 처리한다. 쉬운 작업으로 바꿔 정확도를 얻는다.
- 서브에이전트에게 맡길 때는 목표·출력 형식·도구·경계를 명시한다(멀티 에이전트 리서치 글).
- 〔해석〕 분해의 대가: 호출 수만큼 지연·비용이 늘고, 단계 사이에서 정보가 빠질 수 있다.
