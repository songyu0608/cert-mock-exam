# 검색 전략과 하이브리드 검색

> [!summary] 한 줄 정의
> 질의 패턴과 데이터 모양에 맞춰 의미 검색(임베딩)·정확 일치 검색(BM25)·구조화 질의·재랭킹을 조합한다.

**日本語** 検索戦略　·　**English** Retrieval strategies and hybrid search

## 시험 트리거
- "오류 코드 TS-999를 정확히 찾아야 한다"
- "뜻은 같지만 표현이 다른 질문"
- "표 형태 데이터에서 집계해야 한다"

## 핵심
- 임베딩: 의미가 비슷한 내용을 찾는다. 정확한 식별자에는 약하다.
- BM25: 정확한 단어·식별자 일치에 강하다. 공식 글 예: "Error code TS-999"는 임베딩이 일반적인 오류 코드 내용만 찾고 정확 일치를 놓칠 수 있다.
- 하이브리드: 두 결과를 합치고(중복 제거·순위 결합) 재랭킹으로 상위 청크만 모델에 보낸다.
- 〔해석〕 데이터 모양이 표·DB면 임베딩 검색보다 SQL·API 도구로 정확히 조회하는 편이 맞다. 질의가 탐색형이면 에이전트가 반복 검색(just-in-time)하게 한다.
- 〔해석〕 지식 베이스가 작으면 검색 대신 전체 투입 + 캐싱 → [[RAG vs 전체 컨텍스트 투입]].
