# 모델 선택 트레이드오프

> [!summary] 한 줄 정의
> 능력·속도·비용·effort를 함께 보고, 자기 사용 사례의 평가셋으로 모델을 고른다.

**日本語** トレードオフに基づくモデルの選択　·　**English** Selecting Claude models based on trade-offs

## 시험 트리거
- "실시간 응답이 필요하고 비용이 민감하다"
- "정확도가 비용보다 중요하다"
- "어떤 모델이 맞는지 판단할 근거"

## 핵심
- 공식 문서의 선택 기준: 능력(capabilities), 속도(speed), 비용(cost), effort.
- effort 파라미터는 한 모델 안에서 지능과 지연·비용을 맞바꾼다. 공식 문서: effort 조정이 모델 교체보다 나은 레버인 경우가 많다.
- 두 가지 시작 방식: 효율 우선(빠르고 저렴한 모델로 시작) / 능력 우선(가장 강한 모델로 시작 후 effort를 낮추거나 모델을 내려 최적화).
- 사용 사례 전용 벤치마크(평가셋)를 만드는 것이 선택 과정에서 가장 중요한 단계다.
- 멀티 모델 전략: 저비용 모델과 상위 모델을 짝지어 대부분의 토큰을 낮은 단가로 처리한다(실행자→조언자 에스컬레이션, 오케스트레이터→저비용 워커).
- 모델 이름·기본 effort 값은 자주 바뀐다. 2026-11 기준 문서는 Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5를 안내한다(변동 정보).
