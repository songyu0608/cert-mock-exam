# 증강 LLM

> [!summary] 한 줄 정의
> 검색(retrieval)·도구(tools)·메모리(memory)로 기능을 늘린 LLM. 워크플로와 에이전트를 만드는 기본 구성 요소다.

**日本語** 拡張LLM　·　**English** Augmented LLM

## 시험 트리거
- "LLM이 외부 정보를 찾고 도구를 쓰고 기억을 유지해야 한다"
- "에이전트 시스템의 기본 블록"

## 핵심
- 공식 글은 에이전트 시스템의 기본 블록을 검색·도구·메모리로 증강된 LLM으로 설명한다.
- 모델이 스스로 검색 쿼리를 만들고, 적절한 도구를 고르고, 무엇을 기억할지 정할 수 있다.
- 구현 포인트: 사용 사례에 맞게 기능을 고르고, LLM이 쓰기 쉬운 잘 문서화된 인터페이스를 제공한다.
- MCP(모델 컨텍스트 프로토콜)는 이런 증강을 표준 방식으로 연결하는 한 가지 방법이다 → [[MCP(모델 컨텍스트 프로토콜)]].

## 오답 함정
> [!warning] "증강 LLM = 에이전트" → 증강 LLM 한 번 호출로 끝나는 구조도 많다. 에이전트는 LLM이 스스로 절차를 정하는 경우
