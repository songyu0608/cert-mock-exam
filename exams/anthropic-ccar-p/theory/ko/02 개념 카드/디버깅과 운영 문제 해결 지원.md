# 디버깅과 운영 문제 해결 지원

> [!summary] 한 줄 정의
> 로그·트레이스·모니터링 도구를 Claude에 연결해 원인 분석을 돕게 하고, 운영 환경에 대한 변경은 권한과 확인으로 통제한다.

**日本語** デバッグと運用上の問題解決　·　**English** Supporting debugging and operational issue resolution

## 시험 트리거
- "장애 로그를 빠르게 분석"
- "Sentry·Grafana 같은 도구를 Claude가 조회"
- "운영 서버에서 명령을 실행해야 한다"

## 핵심
- MCP로 관측 도구(예: GitHub, Slack, Sentry, Grafana, Splunk)를 연결할 수 있다. 다만 이 다섯 서버만으로 도구 정의가 약 55k 토큰 → 도구 검색 고려 → [[도구 검색 도구]].
- 에이전트 디버깅은 비결정성 때문에 어렵고, 전체 트레이싱이 원인 진단을 가능하게 했다(멀티 에이전트 글).
- 되돌리기 어려운 운영 작업(삭제, 강제 푸시 등)은 실행 전 확인을 받게 한다(프롬프트 모범 사례).
- 〔해석〕 운영 환경 접근은 읽기 전용부터 주고, 변경 권한은 훅·권한 규칙으로 제한한다 → [[Claude Code 훅]].
