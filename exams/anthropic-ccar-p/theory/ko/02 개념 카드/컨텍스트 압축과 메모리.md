# 컨텍스트 압축과 메모리

> [!summary] 한 줄 정의
> 긴 작업에서 컨텍스트가 차면 요약(컴팩션)하거나 오래된 도구 결과를 지우고, 중요한 정보는 컨텍스트 밖 노트에 남긴다.

**日本語** コンテキストの圧縮とメモリ　·　**English** Compaction, context editing and memory

## 시험 트리거
- "장시간 에이전트가 컨텍스트 한도에 닿는다"
- "수십 번의 도구 호출 뒤 초기 결정을 잊는다"
- "세션을 넘어 진행 상황을 유지"

## 핵심
- 컴팩션: 대화가 한도에 가까워지면 내용을 요약해 새 컨텍스트로 이어간다. 무엇을 남길지(결정, 미해결 문제)가 핵심이다.
- 가장 가벼운 형태는 오래된 도구 결과 지우기(tool result clearing)다.
- 구조화된 노트: 에이전트가 컨텍스트 밖에 노트를 남겨 나중에 다시 가져온다(예: 할 일 목록, NOTES 파일).
- 서브에이전트: 깨끗한 컨텍스트로 세부 작업을 하고 압축된 요약만 돌려준다.
- 공식 문서: 장시간 대화·에이전트에는 서버 측 컴팩션이 기본 전략이다.
