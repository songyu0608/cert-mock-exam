# 가드레일 계층

> [!summary] 한 줄 정의
> 입력 검사 → 프롬프트 정책 → 도구 권한 → 출력 검사 → 모니터링을 겹쳐 쌓는 다층 방어. 한 층에만 의존하지 않는다.

**日本語** ガードレールと安全管理策　·　**English** Guardrails and safety controls

## 시험 트리거
- "유해 요청을 메인 대화 전에 걸러내고 싶다"
- "시스템 프롬프트 지시만으로 충분한가"
- "같은 사용자가 반복해서 우회를 시도한다"

## 핵심
- 입력 검사: 가벼운 모델(예: Haiku)로 사용자 입력을 사전 분류(구조화된 출력으로 단순 분류).
- 프롬프트: 윤리·법적 고려를 담은 시스템 프롬프트, 거절 방식 안내. 도구 결과는 신뢰할 수 없는 데이터라는 정책을 명시.
- 도구·권한: 최소 권한, 샌드박스, 되돌릴 수 없는 작업 전 확인 → [[기능 비대화와 최소 권한]].
- 출력·운영: 출력 검사, 반복 위반 사용자 대응(조치·제한), 지속 모니터링. 여러 보호 장치를 연결(chain safeguards)한다.
- 병렬화 패턴: 응답 생성과 별도 인스턴스가 검사하는 편이 한 호출에서 둘 다 하는 것보다 낫다(Building effective agents).
