# 병렬화(섹셔닝·투표)

> [!summary] 한 줄 정의
> 여러 LLM 호출을 동시에 실행하고 결과를 프로그램으로 합치는 워크플로. 독립 하위 작업으로 나누는 섹셔닝과, 같은 작업을 여러 번 돌리는 투표가 있다.

**日本語** 並列化　·　**English** Parallelization (sectioning, voting)

## 시험 트리거
- "응답 생성과 부적절 콘텐츠 검사를 동시에"
- "여러 관점으로 코드 취약점을 검토"
- "속도를 높이거나 신뢰도를 높이고 싶다"

## 핵심
- 섹셔닝: 독립 하위 작업을 병렬 실행해 속도를 얻는다.
- 공식 글 예: 한 인스턴스가 질의를 처리하고, 다른 인스턴스가 부적절한 내용을 걸러낼 때, 한 호출이 둘 다 하는 것보다 성능이 좋다 → 가드레일 구현에 쓰인다.
- 투표: 같은 작업을 여러 번 실행해 다양한 결과를 얻고 신뢰도를 높인다(예: 취약점 검토, 부적절 콘텐츠 판정 임계값).
- 각 고려 사항을 별도 호출이 맡을 때 LLM이 더 잘 처리한다.
