# ライフサイクルの各フェーズ

> [!summary] 一行定義
> ディスカバリー → 設計 → 引き継ぎ → モニタリング → 反復（ガイドの5フェーズ）。リリースは終わりではなく反復的な改善の始まりである。

**English** Lifecycle phases (discovery, design, handoff, monitoring, iteration)

## 試験のトリガー
- 「リリース後に誰が品質に責任を持つのか」
- 「PoCから本番運用に移る段階」
- 「モデルが変わったら再評価」

## 要点
- ガイドの目標6.5のフェーズ：ディスカバリー、設計、引き継ぎ、モニタリング、反復。
- 〔解釈〕ディスカバリー：要件・成功基準 → [[体系的なディスカバリー]]。設計：パターン・モデル・統合 → [[ワークフローとエージェント型]]。
- 〔解釈〕引き継ぎ：文書・評価セット・運用手順 → [[アーキテクチャの文書化と引き継ぎ]]。モニタリング：トレーシング・指標 → [[オブザーバビリティとモニタリング]]。
- 〔解釈〕反復：評価に基づくA/Bテストでプロンプト・モデル・検索を改善する → [[A-Bテストと反復的な改善]]。
- ガイド自体も、技術の変化が速いため認定の有効期間を12か月としていると説明している。
