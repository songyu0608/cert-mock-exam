# 検索戦略とハイブリッド検索

> [!summary] 一行定義
> クエリパターンとデータの形状に合わせて、意味検索（埋め込み）・完全一致検索（BM25）・構造化クエリ・リランキングを組み合わせる。

**English** Retrieval strategies and hybrid search

## 試験のトリガー
- 「エラーコードTS-999を正確に見つける必要がある」
- 「意味は同じだが表現が違う質問」
- 「表形式のデータで集計する必要がある」

## 要点
- 埋め込み：意味の近い内容を見つける。正確な識別子には弱い。
- BM25：正確な単語・識別子の一致に強い。公式記事の例：「Error code TS-999」では、埋め込みはエラーコード一般の内容だけを見つけ、完全一致を逃すことがある。
- ハイブリッド：両方の結果を統合し（重複除去・順位の結合）、リランキングで上位チャンクだけをモデルに渡す。
- 〔解釈〕データの形状が表やDBなら、埋め込み検索よりSQLやAPIのツールで正確に照会する方が適切。クエリが探索型ならエージェントに反復検索（just-in-time）させる。
- 〔解釈〕ナレッジベースが小さければ検索の代わりに全文投入＋キャッシング → [[RAGと全文投入の比較]]。
