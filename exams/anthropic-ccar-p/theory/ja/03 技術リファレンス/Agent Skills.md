# Agent Skills

> [!summary] 一行定義
> 指示・メタデータ・スクリプト・リソースをフォルダにまとめ、Claudeが必要なときだけ読み込んで使うモジュール型の機能。段階的な開示でコンテキストを節約する。

**English** Agent Skills

## 試験のトリガー
- 「チームの手順を再利用できる部品にしたい」
- 「すべての指示をシステムプロンプトに入れると長すぎる」
- 「外部から入手したスキルをインストールする」

## 要点
- レベル1 メタデータ（name・description）：常に読み込まれ、スキルあたり約100トークン。
- レベル2 SKILL.mdの本文：リクエストがdescriptionに合致したときに読み込まれ、5kトークン未満。
- レベル3 リソース・コード：必要なときだけ。スクリプトはbashで実行され、出力だけがコンテキストに入る。
- descriptionには、何をするのかといつ使うべきかの両方を書く必要がある（トリガーの基準）。
- 信頼できる提供元（自作またはAnthropic提供）のスキルだけを使い、外部のスキルは監査する。悪意のあるスキルは意図しないツールの使用やデータ流出を引き起こしうる。
