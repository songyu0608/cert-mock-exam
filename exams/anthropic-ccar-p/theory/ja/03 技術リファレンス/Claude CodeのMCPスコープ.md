# Claude CodeのMCPスコープ

> [!summary] 一行定義
> Claude CodeのMCPサーバーはローカル・プロジェクト・ユーザーの3つのスコープに設定し、チーム共有はプロジェクトスコープ（.mcp.json）で行う。

**English** Claude Code MCP installation scopes

## 試験のトリガー
- 「チーム全員が同じMCPサーバーを使う必要がある」
- 「個人用のMCPサーバーをすべてのプロジェクトで」

## 要点
- ローカル：現在のプロジェクトのみ、共有しない、~/.claude.json（デフォルト）。
- プロジェクト：現在のプロジェクト、バージョン管理でチーム共有、プロジェクトルートの.mcp.json。
- ユーザー：すべてのプロジェクト、共有しない、~/.claude.json。
- 同じ名前が複数のスコープにある場合、ローカル > プロジェクト > ユーザー > プラグイン > claude.aiコネクタの順で1つだけを使い、フィールドは結合されない。
- 管理者は管理対象のMCP構成で、すべてのユーザーにサーバーを配布・制限できる。

## 誤答の落とし穴
> [!warning] チーム共有用のMCPサーバーをユーザースコープに置く選択肢 → 共有されない。プロジェクトスコープ（.mcp.json）
