# コード実行とMCP

> [!summary] 一行定義
> MCPツールをコードAPI（ファイル）として公開し、エージェントがファイルシステムを探索して必要なツール定義だけを読み、コードで呼び出す方式。

**English** Code execution with MCP

## 試験のトリガー
- 「接続したMCPツールが多すぎる」
- 「機密データがモデルを経由しないようにしたい」

## 要点
- エージェントが./servers/ディレクトリを探索し、必要なツールファイルだけを読む。公式記事の例：150,000→2,000トークン（98.7%削減）。
- プライバシー保護：MCPクライアントがPIIをトークン化し、実際の値がモデルを経由せずにシステム間を移動するようにできる。
- 保存した関数にSKILL.mdを付ければ、再利用可能なスキルになる。
- 代償：エージェントが生成したコードを実行するには、サンドボックス・リソース制限・モニタリングが必要で、運用負担とセキュリティ上の考慮事項が増える。
