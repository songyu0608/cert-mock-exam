## 概念の確認
公式サンプル1で最小権限に合う変更は？::役割に不要な返金・削除ツールをエージェントの構成から完全に削除
ツール選択の精度が落ち始めるツール数（ツール検索のドキュメント）は？::30〜50個超
list_users・list_events・create_eventの代わりに公式記事が勧めるツール設計は？::schedule_eventのようなワークフロー単位のツール一つ
Claude Codeのツール応答のデフォルト上限は？::25,000トークン
認証と認可の違いは？::認証は本人確認、認可は許可された行動の範囲の決定
MCPコネクタが認証サーバーへの接続でサポートする方式は？::OAuth Bearerトークン
レイテンシを下げる公式の方法5つは？::ベースラインの測定、適切なモデル、プロンプト・出力の簡潔化、max_tokensの制限、ストリーミング
精度を損なわずにTTFTとコストを同時に下げるレバーは？::静的な内容を前に置く＋プロンプトキャッシング
マルチエージェントの記事がエージェントの失敗原因を診断した方法は？::本番環境のフルトレーシング
実行中のエージェントを壊さないデプロイ方式は？::レインボーデプロイ（旧・新バージョンを同時稼働し、トラフィックを段階的に切り替え）
RAGなしでナレッジベース全体を入れてよい基準（公式記事）は？::約200,000トークン（約500ページ）未満
サンプル3で最初に調査すべき箇所は？::検索／インデックス作成のステップが関連のない、または古いチャンクを返していないか
チャンクが元の文脈を失う問題を公式記事はどう解決するか？::チャンクごとに50〜100トークンの文脈説明を付けて埋め込み・BM25インデックスを作る（コンテキスト検索）
コンテキスト埋め込み＋コンテキストBM25の失敗率の削減幅は？::49%（5.7%→2.9%）
リランキングまで組み合わせた場合は？::67%（5.7%→1.9%）
正確な識別子（例：TS-999）の検索に強い方式は？::BM25（語彙・キーワードの一致）
ハイブリッド検索の結果を絞り込む最後のステップは？::リランキング
Messages APIのMCPコネクタの2つの制限は？::MCPの機能のうちツール呼び出しのみ、公開HTTPサーバーのみ接続（ローカルSTDIO不可）
Claude Codeのハイブリッド戦略は？::CLAUDE.mdは最初から入れ、ファイルはglob・grepで必要なときに探索
コード実行＋MCPの段階的な開示で減ったトークン（公式記事の例）は？::150,000 → 2,000トークン（98.7%削減）
ツール検索が削減するツール定義のトークンの割合は？::通常85%以上（必要な3〜5個だけを読み込む）
最初に読み込まないツールを指定する属性は？::defer_loading: true
プログラムによるツール呼び出しのトークン削減（公式発表）は？::37%（43,588→27,297）
コード実行＋MCPの公式記事の例のトークン削減は？::150,000→2,000トークン（98.7%）
この方式の代償は？::サンドボックス・リソース制限・モニタリングなどの運用・セキュリティ負担
MCPの一行定義（公式記事）は？::AIエージェントを外部システムに接続するオープン標準
MCPコネクタがサポートするMCPの機能は？::ツール呼び出しのみ
MCPコネクタはZDRの対象か？::対象ではない（標準の保持ポリシー）

## 状況 → 判断
状況：役割に不要な危険ツールが付いている → 正解の方向は？::構成から削除（最小権限）
状況：ツールが30〜50個を超えて選択を誤る → 正解の方向は？::ツール検索・ツールの整理
状況：APIエンドポイントごとのツールが多い → 正解の方向は？::ワークフロー単位のツールに統合
状況：エージェントがサービスアカウントの権限で全データにアクセス → 正解の方向は？::認可をツール・データの層で強制
状況：精度を上げるためにステップ・推論を追加 → 正解の方向は？::レイテンシの増加を測定してSLAと比較
状況：エージェントの失敗の原因が分からない → 正解の方向は？::本番環境のフルトレーシング
状況：実行中のエージェントを壊さずにデプロイ → 正解の方向は？::レインボーデプロイ
状況：ナレッジベースが200,000トークン未満 → 正解の方向は？::RAGなしで全文投入＋キャッシング
状況：チャンクが元の文脈を失う → 正解の方向は？::コンテキスト検索（50〜100トークンの説明）
状況：正確なエラーコード・IDの検索 → 正解の方向は？::BM25を組み合わせる（ハイブリッド）
状況：複数のアプリが同じ社内システムを使う → 正解の方向は？::MCP
状況：ローカルのSTDIOサーバーをAPIに接続 → 正解の方向は？::MCPコネクタでは不可（リモートHTTPのみ）
状況：ツール定義が数万トークン → 正解の方向は？::段階的ディスカバリー（ツール検索・コード実行）
