# 誤答選択肢パターン

サンプル問題の解説と公式ドキュメントから抜き出した、もっともらしいが誤りやすい選択肢の類型。サンプルの表記がない行は、公式ドキュメントを根拠とした整理（解釈）である。

| 誤答になりやすい選択肢 | 正しい方 | ノート |
|---|---|---|
| 不正使用を後から監査できるようにロギングを追加 | 不要なツールを削除（サンプル1） | [[機能の肥大化と最小権限]] |
| すべてのツールを残して確認プロンプトだけを追加 | 不要な権限の削除が先（サンプル1） | [[発見的統制と予防的統制]] |
| より大きなモデルに替えてセキュリティを解決 | モデルのサイズは認可の範囲と無関係（サンプル1） | [[機能の肥大化と最小権限]] |
| ポリシー文書を先頭部分だけ残して切り詰める | 静的な内容を先頭に＋キャッシング（サンプル2） | [[プロンプトキャッシング]] |
| タスクへの適合性にかかわらず最小のモデル | 評価で適合性を確認してから縮小（サンプル2） | [[モデル選択のトレードオフ]] |
| ポリシーをfew-shotの例示ブロックに移動 | キャッシュ可能な接頭辞にならない（サンプル2） | [[few-shotプロンプティング]] |
| モデルの重み・temperature・コンテキストウィンドウのせいにする | まず検索・インデックス作成（サンプル3） | [[システムの問題の診断]] |
| 常に自律エージェントの方が良い | 最も単純な解決策から | [[ワークフローとエージェント型]] |
| エージェントを増やせば品質が上がる | トークン約15倍、依存関係の大きいタスクには不適 | [[マルチエージェントの導入判断]] |
| コンテキストウィンドウが大きいので全部入れる | context rot — シグナルの高い情報だけ | [[コンテキストウィンドウとトークン管理]] |
| システムプロンプトの先頭に現在時刻 | 先頭の動的な値はキャッシュを壊す | [[プロンプトキャッシング]] |
| 外部ドキュメントをシステムプロンプトに貼り付ける | tool_resultに分離 | [[プロンプトインジェクション]] |
| ハルシネーションを完全になくす | 減らすことしかできない | [[ハルシネーションの低減]] |
| リアルタイムの応答にBatches API | 非同期処理 — 大量で遅延を許容できるタスク向け | [[Message Batches API]] |
| バッチの24時間をSLAとして約束 | 24時間は期限切れの期限 | [[期待値の調整とSLA管理]] |
| LLM採点器を検証せずに大規模に使用 | 信頼性をテストしてから拡大 | [[採点方法（コード・LLM・人間）]] |
| 大規模な評価セットができるまで評価を先送り | 少数のケースですぐに始める | [[評価データセットの設計]] |
| 複数の要素を同時に変えてA/B | 一度に1つの変数 | [[A-Bテストと反復的な改善]] |
| 正確なコード検索に埋め込みだけ | BM25を組み合わせる | [[検索戦略とハイブリッド検索]] |
| ローカルのSTDIOサーバーをMCPコネクタに接続 | リモートHTTPサーバーのみ | [[MCPコネクタ]] |
| スキルの本文は常に読み込まれる | 常に読み込まれるのはメタデータだけ | [[Agent Skills]] |
| CLAUDE.mdでコマンドを強制的に禁止 | 管理対象設定のpermissions.deny・フック | [[CLAUDE.mdのスコープ]] |
| ユーザー設定が管理対象設定を上書きする | 管理対象が最上位 | [[Claude Codeの設定の優先順位]] |
| Claude CodeもHIPAA対応の範囲 | 含まれない | [[データ保持（ZDR・HIPAA対応）]] |
| 引用＋構造化出力を同時に使用 | 互換性がない | [[引用（Citations）]] |
