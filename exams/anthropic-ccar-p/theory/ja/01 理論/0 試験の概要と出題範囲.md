# 0 試験の概要と出題範囲

Claude Certified Architect – Professional（CCAR-P）は、AnthropicのClaudeプラットフォームを使用して、本番環境レベルのAIソリューションを設計、構築、提供できることを証明する認定資格である。適切なモデル、アーキテクチャ、APIパターンを選択し、プロンプトエンジニアリングとコンテキストエンジニアリングを適用し、Claudeをエンタープライズシステムに統合し、評価、セキュリティ、コンプライアンス、ガバナンスを設計に組み込むアーキテクトの役割が対象である（ガイド1章）。

## 試験の情報（試験ガイド v1.0、2026年7月発効）
| 項目 | 内容 |
|---|---|
| 試験コード | CCAR-P |
| 問題数 | 63 |
| 出題形式 | 択一式および複数選択式。各問題に選択する解答の数が明記される |
| 制限時間 | 120分 |
| 合格点 | 100–1,000のスケールでスケールスコア720 |
| 受験料 | $175 USD。支払い画面の受験料にはパートナーティアの割引が反映される |
| 有効期間 | 資格が授与された日から12か月 |
| 結果の通知 | 合格／不合格とスケールスコア、分野別の正答率（合否の判定には使用されない） |
| 採点 | 基準準拠型：他の受験者との比較ではなく、固定された到達基準に照らして測定 |
| 実施方法 | Pearson VUEによる監督付き（オンライン監督付きまたはテストセンター） |
| キャンセル・予約変更 | 予約時刻の24時間前まで。24時間以内の変更では受験料は返金されない |
| 再受験 | 不合格後14日 / 30日 / 90日の待機。同じ試験は連続する12か月に4回まで。受験料は毎回必要 |
| 無断欠席・遅刻 | 受験料は返金されず、あらためて申し込みが必要 |
| 更新 | 期限内に変更点を確認し、Partner Academyで無料の監督なしのアセスメントを完了。失効後は正規の受験料で試験全体を再受験 |
| 異議申し立て | 通知を受けた日、または試験日から14日以内（Pearson VUEのサポート経由） |
| 前提条件 | なし。推奨される経験：システムアーキテクチャ3年以上、本番環境のClaude（または同等のLLM）6か月以上 |
| 試験言語 | ガイドに記載なし。外部記事は英語・日本語と伝えている（未確認） |
| シナリオ・出題範囲外の一覧 | ガイドに記載なし |

## 学習のポイント
- ガイドは分野別の目標の文言だけを示し、知識の一覧・対象サービス・出題範囲外のトピックは示していない。目標番号（1.1など）はこのVaultが付けた。
- サンプル3問の解説が判断基準を示している：**不要な権限は削除**（ロギング・確認は発見的・補完的統制）、**静的な内容を先頭に＋キャッシング**、**文書更新後の誤答はまず検索・インデックス作成**。
- ガイド7章はClaude API、モデル、プロンプトエンジニアリング、MCP、Skillsの公式ドキュメントを参照するよう勧めている。カードの補足内容はこれらの公式ドキュメントから取り、各カードに根拠のリンクを付けた。
- モデル名・価格・デフォルト値などの製品情報は変わりやすい。カードには「変動情報」と記した。
