# 오답 선택지 패턴

공식 자료와 반대되어 오답이 되기 쉬운 진술을 모았다(이 볼트의 정리).

| 오답이 되기 쉬운 진술 | 맞는 쪽 | 노트 |
|---|---|---|
| GITHUB_TOKEN 푸시가 push 워크플로를 트리거한다 | 새 실행 없음(dispatch 2종 예외) | [[GITHUB_TOKEN]] |
| branches와 paths 중 하나만 맞으면 실행 | 둘 다 만족해야 실행 | [[워크플로 트리거와 이벤트]] |
| schedule은 1분 간격 가능 | 최소 5분, 기본 브랜치 최신 커밋 | [[예약 실행(schedule)]] |
| workflow_call 입력에 choice가 있다 | boolean·number·string뿐 | [[수동 실행(workflow_dispatch)]] |
| 재사용 워크플로를 단계에서 uses로 호출 | 작업(job) 수준에서만 | [[재사용 워크플로]] |
| 호출자 env가 재사용 워크플로로 전달 | 전달 안 됨 | [[재사용 워크플로]] |
| 작업 if에서 secrets 참조 | 불가 → env 경유 | [[조건 실행(if)]] |
| concurrency 기본이 진행 중 실행 취소 | cancel-in-progress: true 필요 | [[동시성 제어(concurrency)]] |
| GITHUB_ENV 값이 같은 단계에 즉시 적용 | 다음 단계부터 | [[환경 변수와 환경 파일]] |
| 서비스 컨테이너가 Windows에서 동작 | Linux 러너만 | [[서비스 컨테이너]] |
| fail-fast 기본 false | 기본 true | [[매트릭스 전략]] |
| github.ref는 짧은 브랜치 이름 | refs/heads/… 전체, 짧은 이름은 ref_name | [[컨텍스트]] |
| 캐시로 작업 간 빌드 결과 전달 | 결과물은 아티팩트 | [[캐시 vs 아티팩트]] |
| 아티팩트 영구 보관 | 기본 90일 | [[워크플로 아티팩트]] |
| 재실행은 최신 커밋으로 | 원래 GITHUB_SHA·GITHUB_REF | [[워크플로와 작업 재실행]] |
| 템플릿 수정이 기존 워크플로에 반영 | 복사본이라 반영 안 됨 | [[워크플로 템플릿]] |
| 워크플로 비활성화 시 진행 중 실행 취소 | 취소되지 않음 | [[워크플로 비활성화와 삭제]] |
| Docker 액션이 macOS에서 동작 | Linux 러너만 | [[사용자 지정 액션 유형]] |
| 복합 액션 run에 shell 생략 가능 | run이면 shell 필수 | [[복합 액션]] |
| required: true면 입력 누락 시 자동 실패 | 자동 오류 아님 | [[액션 메타데이터(action.yml)]] |
| 비공개 리포 액션을 Marketplace에 게시 | 공개 리포만 | [[Marketplace 게시]] |
| 검증된 작성자 배지 = 보안 감사 통과 | 작성자 신원 확인일 뿐 | [[신뢰할 수 있는 Marketplace 액션]] |
| 리포 설정으로 조직이 막은 액션 허용 | 상위 정책 우선 | [[조직 Actions 정책]] |
| 호스팅 러너 작업 최대 5일 | 6시간(5일은 자체 호스팅) | [[GitHub 호스팅 러너]] |
| 자체 호스팅 러너에 인바운드 포트 개방 필요 | 아웃바운드 HTTPS 443 | [[자체 호스팅 러너]] |
| GET /meta IP를 사내 허용 목록에 쓰라 | 권장 안 함 → 정적 IP 더 큰 러너 | [[러너 네트워크와 IP 허용 목록]] |
| 러너가 여러 그룹에 동시 소속 | 한 그룹만 | [[러너 그룹]] |
| 조직 비밀이 리포 비밀보다 우선 | 환경 > 리포 > 조직 | [[비밀(secrets)]] |
| REST API로 비밀 값을 읽는다 | 값은 반환되지 않음 | [[비밀·변수 REST API]] |
| ${{ github.event.issue.title }}를 따옴표로 감싸면 run에 안전 | 환경 변수로 넘긴다 | [[스크립트 인젝션]] |
| permissions 일부 지정 시 나머지는 기본값 | 나머지는 none | [[GITHUB_TOKEN]] |
| id-token: write가 리포 쓰기 권한도 준다 | OIDC 토큰 발급만 | [[OIDC]] |
| 축약 SHA로 고정해도 충분 | 전체 길이 SHA | [[액션 SHA 고정]] |
| pull_request_target에서 PR 코드 빌드는 안전 | 비밀·쓰기 권한으로 신뢰할 수 없는 코드 실행 | [[포크 PR 워크플로 보안]] |
| 아티팩트 증명이 있으면 안전한 아티팩트 | 출처·무결성 증명일 뿐 | [[아티팩트 증명]] |
| Base64 인코딩 비밀은 자동 마스킹 | ::add-mask::로 등록 | [[비밀 유출 방지]] |
| 필수 검토자 전원 승인 필요 | 1명 승인 | [[환경과 배포 보호 규칙]] |
