# 플래시카드 도메인 2　워크플로 사용과 문제 해결

#flashcards/gh-200/d2

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
로그 검색이 대상으로 하는 단계는?::펼친 단계만
자체 호스팅 러너용 작업이 대기하다 실패하는 시간은?::24시간
단계 디버그 로그를 켜는 이름은?::ACTIONS_STEP_DEBUG
러너 진단 로그를 켜는 이름은?::ACTIONS_RUNNER_DEBUG
재실행 가능 기간은?::최초 실행 후 30일
실행당 재실행 최대 횟수는?::50회
재실행 시 사용하는 커밋은?::원래 이벤트의 GITHUB_SHA
아티팩트 다운로드 REST의 응답 코드는?::302 리디렉션(만료 시 410)
실행 로그를 삭제하는 데 필요한 권한은?::리포지토리 write
캐시 키로 삭제하는 엔드포인트는?::DELETE /repos/{owner}/{repo}/actions/caches?key=
GITHUB_TOKEN의 REST API 시간당 한도는?::리포지토리당 1,000(Enterprise Cloud 15,000)
조직 워크플로 템플릿을 두는 위치는?::.github 리포지토리의 workflow-templates/
기본 브랜치 이름으로 바뀌는 자리 표시자는?::$default-branch
internal .github의 템플릿을 쓸 수 있는 리포지토리는?::internal과 private
private .github 템플릿 사용자에게 필요한 권한은?::.github 리포지토리 Read
워크플로를 끄는 GitHub CLI 명령은?::gh workflow disable
비활성 워크플로의 기존 실행을 재실행할 수 있나?::아니요. 다시 활성화해야 한다

## 상황 → 판단
상황: 로그만으로 원인 불명 → 정답은?::ACTIONS_STEP_DEBUG / 재실행 Enable debug logging
상황: 러너 내부 동작 진단 → 정답은?::ACTIONS_RUNNER_DEBUG
상황: 매트릭스 한 조합만 일시 실패 → 정답은?::그 작업만 재실행
상황: 오래된 아티팩트 자동 정리 → 정답은?::REST DELETE /actions/artifacts/{id}
상황: 조직 표준 CI 출발점 제공 → 정답은?::조직 워크플로 템플릿(.github/workflow-templates)
상황: 템플릿을 조직 밖에 공개하지 않기 → 정답은?::internal·private .github 리포
상황: 장애 동안 워크플로 잠시 중지 → 정답은?::워크플로 비활성화(gh workflow disable)
