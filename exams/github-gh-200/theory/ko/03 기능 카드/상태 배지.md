# 상태 배지

> [!summary] 한 줄 정의
> 워크플로 상태 배지는 README 등에 워크플로 실행 성공·실패 상태를 이미지로 보여 준다.

**English** Adding a workflow status badge

## 시험 트리거
- "README에 CI 상태 표시"
- "develop 브랜치 상태를 배지로"

## 핵심
- URL: `https://github.com/OWNER/REPO/actions/workflows/FILE.yml/badge.svg`(워크플로 파일 이름).
- 기본은 기본 브랜치 상태. 기본 브랜치에 실행이 없으면 모든 브랜치의 최근 실행.
- `?branch=이름`, `?event=push` 쿼리로 브랜치·이벤트 지정.
- UI: Actions 탭 → 워크플로 → 메뉴 → Create status badge → Copy status badge Markdown.

## 오답 함정
> [!warning] 배지 URL에 워크플로 name: 값을 쓴다는 선택지 → 워크플로 파일 이름
