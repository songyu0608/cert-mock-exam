# 매트릭스 전략

> [!summary] 한 줄 정의
> `strategy.matrix`에 변수와 값 목록을 주면 모든 조합마다 작업이 하나씩 만들어진다(OS × 언어 버전 등).

**English** Using a matrix for your jobs

## 시험 트리거
- "Node 18·20·22를 3개 OS에서 테스트"
- "특정 조합만 빼기"
- "한 조합이 실패해도 나머지는 계속"
- "동시에 2개씩만"

## 핵심
- 워크플로 실행당 매트릭스 작업 최대 256개.
- `include`: 기존 조합에 값 추가. 어느 조합과도 맞지 않으면 새 조합으로 추가. `exclude`: 조합 제거(include보다 먼저 처리)〔해석: 처리 순서는 문서 예시 기준〕.
- `fail-fast`(기본 true): 한 작업이 실패하면 진행 중·대기 중인 매트릭스 작업 취소. `max-parallel`: 동시 실행 수 제한.
- `continue-on-error: ${{ matrix.experimental }}`처럼 특정 조합의 실패를 허용.
- `fromJSON()`으로 앞 작업 출력에서 동적 매트릭스 생성.
- 작업 이름에 매트릭스 값이 붙어(예: test (ubuntu-latest, 20)) 어느 축에서 실패했는지 식별 → 실패한 조합만 다시 실행 가능.
- 비용: 조합 수 = 작업 수. 꼭 필요한 조합만 두고 exclude·include로 줄인다.

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| include vs exclude | include = 추가·확장, exclude = 제거 |

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - fail-fast 기본값이 false라는 선택지 → 기본 true
> - 매트릭스 작업 수 제한이 없다는 선택지 → 실행당 256개
