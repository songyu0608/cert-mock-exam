# 더 큰 러너

> [!summary] 한 줄 정의
> GitHub가 관리하는 호스팅 러너 중 RAM·CPU·디스크가 더 큰 머신이다. Team·Enterprise Cloud에서 쓰며 정적 IP, Azure 사설 네트워크, GPU 같은 고급 기능을 준다.

**English** Larger runners

## 시험 트리거
- "사내 방화벽에 고정 IP로 허용해야 한다"
- "빌드에 코어가 더 필요"
- "GPU 작업"

## 핵심
- 요금제: GitHub Team, GitHub Enterprise Cloud 조직·엔터프라이즈.
- 정적 IP 범위 할당(Linux·Windows) → 방화벽 허용 목록에 사용. 조직·엔터프라이즈당 정적 IP 10개(한도, 변동 정보).
- Azure 사설 네트워크 연결(Linux·Windows). 러너 그룹으로 접근 제어. 자동 확장.
- 공개 리포 사용도 분당 과금. 쓰지 않을 때는 비용 없음.
- 사용자 지정 이미지는 더 큰 러너에서만 쓸 수 있다.

## 오답 함정
> [!warning] 더 큰 러너가 공개 리포지토리에서 무료라는 선택지 → 공개 리포도 분당 과금
