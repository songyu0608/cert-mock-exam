# 액션 허용·차단 목록

> [!summary] 한 줄 정의
> 엔터프라이즈·조직·리포지토리 Actions 설정에서 어떤 액션과 재사용 워크플로를 쓸 수 있는지 허용·차단 목록으로 제한한다.

**English** Enforcing action usage policies

## 시험 트리거
- "우리 조직과 GitHub 제작 액션만 허용"
- "특정 버전의 위험한 액션을 차단"
- "검증되지 않은 액션 사용을 통제"

## 핵심
- 정책 옵션: 모든 액션 / 조직(OWNER) 액션만 / OWNER와 선택한 외부 액션.
- 선택 옵션: Allow actions created by GitHub, Allow Marketplace actions by verified creators, Allow or block specified actions and reusable workflows.
- 목록 문법: `octo-org/act@v2`, `octo-org/*`, `*` 와일드카드, 쉼표 구분, `!`로 시작하면 차단. 최대 1,000개.
- 로컬 액션과 같은 리포 재사용 워크플로는 제한 정책에서도 허용.
- 전체 SHA 고정 강제 옵션.
- 학습 가이드의 "확인되지 않은 액션에 대한 필수 검토자": GitHub 문서에서 같은 이름의 설정을 확인하지 못했다. 〔해석〕 CODEOWNERS로 .github/workflows 변경에 지정 검토자 승인을 요구하고, 허용 목록 밖 액션은 정책으로 막는 조합으로 이해한다.

## 오답 함정
> [!warning] 조직 액션만 허용하면 같은 리포의 로컬 액션도 막힌다는 선택지 → 로컬 액션은 허용
