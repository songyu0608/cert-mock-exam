# 러너 그룹

> [!summary] 한 줄 정의
> 러너 그룹은 러너를 묶어 어느 조직·리포지토리(·워크플로)가 쓸 수 있는지 제한하는 보안 경계다.

**English** Managing runner groups

## 시험 트리거
- "민감한 배포용 러너는 특정 리포만"
- "새 러너가 어느 그룹에 들어가나"

## 핵심
- 조직·엔터프라이즈 수준. GitHub Team 플랜 조직도 사용 가능.
- 새 러너는 따로 지정하지 않으면 기본(Default) 그룹에 들어간다.
- 러너는 한 번에 한 그룹에만 속한다. 그룹 간 이동 가능.
- 그룹에 리포지토리 접근 정책을 둔다(엔터프라이즈 그룹은 조직 단위). 동시성 한도로 비용·용량 제어.
- 워크플로에서 `runs-on: { group: 그룹이름, labels: [...] }`으로 지정〔해석: 문법은 workflow syntax 문서 기준〕.
- 표준 호스팅 러너를 비활성화하고 러너 그룹만 쓰게 강제할 수 있다. 그룹당 러너 최대 10,000.

## 오답 함정
> [!warning] 러너 하나가 여러 그룹에 동시에 속한다는 선택지 → 한 그룹만
