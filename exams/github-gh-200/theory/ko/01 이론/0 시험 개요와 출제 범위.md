# 0 시험 개요와 출제 범위

GitHub Actions(GH-200)는 GitHub Actions로 워크플로를 작성·운영하고, 액션을 만들어 배포하며, 엔터프라이즈 규모에서 러너·비밀·정책을 관리하고 자동화를 안전하게 최적화하는 능력을 검증하는 중급(Intermediate) 자격증이다. 응시자는 CI/CD, 리포지토리, GitHub Packages, 타사 통합에 익숙해야 한다(자격증 페이지).

| 시험 코드 | GH-200 |
| 수준 | Intermediate(중급) |
| 시간 | 100분 |

| 시험 언어 | 영어, 스페인어, 포르투갈어(브라질), 한국어, 일본어 |
| 출제 범위 | 대부분 정식 출시(GA) 기능. 널리 쓰이는 미리 보기 기능도 나올 수 있음. 목표 아래 항목은 예시이며 관련 주제도 나올 수 있음 |
| 형식 | Pearson VUE 감독 시험. 시험 환경 체험(sandbox) 제공. 개인 Microsoft 계정 사용 권장 |

## 공부 포인트
- 목표 번호(1.1 등)는 이 볼트가 붙였다. 안내서는 글머리 목록만 제시한다.
- 안내서에는 샘플 문제가 없다. 카드의 셀프 체크와 비교 노트의 질문은 이 볼트가 만든 것이다.
- **한국어 공식 안내서 주의**: 기계 번역으로 보이며 action과 job을 모두 "작업"으로 옮겼다(예: "작업 작성 및 유지 관리" = Author and maintain actions, "작업 간의 종속성" = dependencies between jobs). runner는 "실행기"와 "러너"가 섞여 있고, matrix는 "매트릭스"와 "행렬", fail-fast는 "장애를 신속하게 처리"로 옮겼다. 한국어로 응시한다면 [[용어 대조표]]를 꼭 본다. 실제 시험의 한국어 표기는 확인하지 못했다.
- 이 볼트 본문은 GitHub 화면·문서 용어(액션, 작업, 러너)를 쓰고, 안내서 표기는 별칭과 용어 대조표에 실었다.
- 카드 내용은 GitHub 공식 문서(docs.github.com)와 GitHub 변경 로그에서 보충했고, 카드마다 근거 링크를 달았다.
- 변동 정보: 러너 이미지(-latest 이전), 불변 액션(로드맵에서 제외), YAML 병합 키(<<) 지원 여부, 요금·한도, 2026 보안 로드맵 기능(의존성 잠금 등)은 바뀔 수 있다.
