# 출처와 주의 사항

## 사용한 자료 (2026-11-08 확인)
- **Study guide for Exam GH-200: GitHub Actions** (Microsoft Learn, 영어). 기술 목록 2026년 1월 기준, 페이지 갱신 2026-02-05.
- 같은 학습 가이드의 **한국어 페이지**(learn.microsoft.com/ko-kr). 이론 노트의 "한국어 공식 안내서" 인용은 이 페이지 문구를 웹 가져오기 도구로 옮긴 것이라 문장부호·띄어쓰기가 원문과 조금 다를 수 있다.
- **GitHub Actions 자격증 페이지**(Microsoft Learn): 수준, 시간, 언어, 유효 기간, 재응시, 대상 역할, 사전 지식.
- 보충 근거: GitHub 공식 문서(docs.github.com) 약 50개 페이지, GitHub 변경 로그 3건(Ubuntu 20 퇴역, windows-latest 이전, YAML 앵커·비공개 템플릿), GitHub 공개 로드맵(불변 액션), GitHub 블로그(2026 보안 로드맵), VS Code 확장 리포지토리. 카드마다 링크를 달았다.

## 안내서·자격증 페이지에서 확인한 사실
- 도메인별 비중과 목표 문구(53개), 합격 700점, 시험 100분, 시험 언어 5개, 중급, 2년 유효, 24시간 뒤 재응시, 2026년 1월 큰 개정.
- 목표 문구의 한국어는 영어 원문을 이 볼트가 번역한 것이다.

## 한국어 공식 안내서 표기 문제
- action과 job을 모두 "작업"으로 옮겼다. 도메인 3 "작업 작성 및 유지 관리"는 Author and maintain actions, 목표 "작업 간의 종속성 구현"은 dependencies between jobs다.
- runner는 "실행기"(대부분)와 "러너"(그룹 제목), matrix는 "매트릭스"와 "행렬"(컨텍스트 목록), needs 컨텍스트는 "요구 사항", fail-fast는 "장애를 신속하게 처리", max-parallel은 "병렬 최대화"로 옮겼다.
- 비중 표기 "20~25개%" 같은 오탈자가 있다. 이 볼트는 영어판 비중(20–25% 등)을 따랐다.

## 안내서에 없음 · 확인하지 못함
- 문항 수, 한국 응시료, 샘플 문제(이 볼트의 질문은 모두 자작), 목표 번호.
- 실제 한국어 시험이 공식 안내서와 같은 용어를 쓰는지.
- **YAML 병합 키(<<)**: 안내서는 언급하지만 GitHub 문서·변경 로그(2025-09-18)에서 지원 여부를 확인하지 못했다. 2025-09 제3자 글은 미지원이라고 했다.
- **불변 액션**: 안내서는 "호스팅 러너에서의 도입·적용"을 출제 범위에 넣었지만, GitHub 공개 로드맵 #592는 최신 코멘트에서 "로드맵에서 일단 제거"했다고 밝혔다. 카드에서는 불변 릴리스·SHA 고정과 함께 정리했다.
- **확인되지 않은 액션에 대한 필수 검토자**(목표 5.7): 같은 이름의 GitHub 설정을 문서에서 찾지 못했다. 카드에 〔해석〕으로 정리했다.
- 자체 호스팅 러너 기본 라벨 목록, 오프라인 러너 자동 제거 기간, 변수 REST API 세부, GitHub CLI 명령 일부는 이 볼트에서 원문을 확인하지 못해 싣지 않거나 〔해석〕으로 표시했다.

## 해석과 변동 정보
- 러너 이미지 라벨과 사양, 요금제별 동시 작업·저장 포함량, 과금, 한도 수치는 **변동 정보**다(2026-11 문서 기준).
- 2026 보안 로드맵(워크플로 의존성 잠금, 정책 기반 실행, 범위 지정 비밀, 이그레스 방화벽 등)은 2026-03-26 게시 시점에 정식 출시 전이었다. 문서 일부(secure use, find actions)는 이미 lockfile을 언급한다.
- 카드의 "시험 트리거", "오답 함정", 비교표, 판단 패턴은 공식 자료를 바탕으로 **정리한 해석**이다.
