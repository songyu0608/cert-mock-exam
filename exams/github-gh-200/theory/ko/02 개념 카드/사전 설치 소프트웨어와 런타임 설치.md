# 사전 설치 소프트웨어와 런타임 설치

> [!summary] 한 줄 정의
> 호스팅 러너 이미지에는 많은 도구가 미리 설치돼 있다. 정확한 목록은 실행 로그와 이미지 릴리스 정보에서 확인하고, 필요한 버전은 setup-* 액션 등으로 실행 중에 설치한다.

**English** Preinstalled software and installing software at runtime

## 시험 트리거
- "러너에 설치된 Python 버전 확인"
- "이미지 업데이트 후 도구 버전이 바뀌었다"
- "자체 호스팅 러너에 매번 같은 도구 설치"

## 핵심
- 확인: 작업 로그 "Set up job" → "Runner Image" → "Included Software" 링크. 목록 원본은 actions/runner-images. 매주 업데이트.
- 도구 캐시: `RUNNER_TOOL_CACHE` = 호스팅 러너의 미리 설치된 도구 디렉터리. setup-* 액션이 이 캐시에 있으면 빠르게 사용〔해석: 캐시 활용 방식은 일반 동작〕.
- 런타임 설치: setup-node·setup-python 등 setup-* 액션(버전 지정·내장 캐시), apt·brew·choco 같은 패키지 관리자(Linux·macOS는 sudo), 의존성 캐싱, 작업 컨테이너(container:) 이미지.
- 문서 권장: 설치 소프트웨어와 상호작용할 때 액션을 써서 버전을 고정 → 이미지 업데이트에도 안정.
- 자체 호스팅·더 큰 러너는 사용자 지정 이미지로 미리 굽는다(호스팅 사용자 지정 이미지는 더 큰 러너만).
- 도구 추가 요청은 actions/runner-images 이슈.

## 오답 함정
> [!warning] -latest 이미지의 도구 버전이 고정돼 있다는 선택지 → 매주 업데이트, 필요한 버전은 setup-*로 지정
