# 작업 간 데이터 전달

> [!summary] 한 줄 정의
> 단계 간에는 GITHUB_OUTPUT·GITHUB_ENV, 작업 간에는 작업 출력(outputs)과 아티팩트, 재사용 워크플로와는 workflow_call 출력으로 데이터를 넘긴다.

**English** Passing information between jobs and steps

## 시험 트리거
- "빌드 단계가 만든 버전 번호를 배포 작업에서 사용"
- "큰 파일을 다음 작업으로"

## 핵심
- 단계 출력: `echo "ver=1.2" >> "$GITHUB_OUTPUT"` → 같은 작업에서 `steps.<id>.outputs.ver`(단계에 id 필요).
- 작업 출력: `jobs.<id>.outputs.ver: ${{ steps.s1.outputs.ver }}` → 다음 작업은 needs 후 `needs.<id>.outputs.ver`.
- 작업 출력 한도: 작업당 1 MB, 실행당 50 MB. 비밀이 포함된 출력은 가려져 전달되지 않는다.
- 파일·큰 데이터는 아티팩트. 다음 실행에서 재사용할 의존성은 캐시.
- 재사용 워크플로: on.workflow_call.outputs → 호출자 needs.<job>.outputs.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 다른 작업에서 steps.<id>.outputs를 직접 읽는다는 선택지 → 작업 outputs로 올리고 needs로 읽는다
> - 단계 출력에 id 없이도 접근된다는 선택지 → 단계 id가 필요
