# 불변 액션과 불변 릴리스

> [!summary] 한 줄 정의
> 불변 액션은 액션을 변경 불가능한 패키지 버전으로 게시·사용하려던 기능이다. 불변 릴리스는 게시 후 태그와 자산을 바꿀 수 없게 하는 GitHub 릴리스 기능이다.

**English** Immutable actions and immutable releases

## 시험 트리거
- "태그가 다른 커밋으로 옮겨져 공급망 공격을 당했다"
- "릴리스 자산이 몰래 바뀌지 않게"

## 핵심
- 학습 가이드는 "호스팅 러너에서의 불변 액션 도입·적용"과 버전 고정을 출제 범위에 넣었다.
- GitHub 공개 로드맵 #592(Immutable Actions)는 액션을 GitHub Packages에 의미 있는 버전의 불변 패키지로 게시하는 방식을 설명했으나, 최신 코멘트는 "로드맵에서 일단 제거"하고 불변 릴리스에 집중한다고 밝혔다(변동 정보).
- 불변 릴리스: 게시 후 연결된 Git 태그가 커밋에 고정되고 자산을 수정·삭제할 수 없다. 릴리스를 지워도 그 태그 이름은 재사용 불가. 릴리스 증명(release attestation)이 자동 생성된다.
- 불변 릴리스 권장 절차: 초안 작성 → 자산 첨부 → 게시.
- 사용자 쪽 대응은 같다: 전체 커밋 SHA 고정, 태그는 신뢰하는 작성자만, 이동하는 @main 피하기 → [[액션 SHA 고정]].
- 2026 보안 로드맵(2026-03-26)은 워크플로 의존성 잠금(lockfile)과 게시용 불변 릴리스를 예고했다(게시 시점 미출시, 변동 정보).

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 불변 릴리스에서도 태그를 다른 커밋으로 옮길 수 있다는 선택지 → 고정된다
> - 불변 릴리스에서 릴리스 노트도 수정할 수 없다는 선택지 → 제목·노트는 수정 가능, 태그·자산만 잠김
