# 사용 한도와 과금

> [!summary] 한 줄 정의
> GitHub Actions에는 실행 시간·대기열·매트릭스·API 같은 사용 한도가 있고, 비공개 리포의 호스팅 러너 사용과 저장은 요금제의 포함량을 넘으면 과금된다.

**English** Actions usage limits and billing

## 시험 트리거
- "작업이 6시간에 취소"
- "매트릭스 300개 조합"
- "공개 리포 Actions 비용"

## 핵심
- 무료: 공개 리포의 표준 호스팅 러너, 자체 호스팅 러너.
- 비공개 리포: 계정별 저장·월간 포함 사용량, 초과분 과금. 재사용 워크플로 과금은 호출자 기준(변동 정보).
- 한도: 호스팅 작업 6시간, 자체 호스팅 작업 5일·대기 24시간, 워크플로 실행 35일(대기·승인 포함), 매트릭스 256, 재실행 50회, 워크플로 파일 500 KB, 대기열 500 실행/10초. 한도에 걸리면 취소.
- 동시 작업(표준 러너): Free 20, Pro 40, Team 60, Enterprise 500(macOS 5/5/5/50).
- 캐시 리포당 10 GB(모든 요금제). 아티팩트 저장 포함량 Free 500 MB, Pro 1 GB, Team 2 GB, Enterprise Cloud 50 GB.

## 오답 함정
> [!warning] 공개 리포의 표준 호스팅 러너가 유료라는 선택지 → 무료(더 큰 러너는 과금)
