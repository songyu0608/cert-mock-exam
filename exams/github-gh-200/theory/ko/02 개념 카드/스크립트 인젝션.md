# 스크립트 인젝션

> [!summary] 한 줄 정의
> 이슈 제목, PR 제목, 브랜치 이름처럼 공격자가 정할 수 있는 값을 `run:` 안의 `${{ }}`에 넣으면, 값이 셸 스크립트의 일부가 되어 임의 명령이 실행될 수 있다.

**English** Mitigating script injection

## 시험 트리거
- "PR 제목을 run 스크립트에서 echo"
- "브랜치 이름으로 명령을 만든다"
- "인라인 스크립트의 입력 처리"

## 핵심
- 위험 입력 예: github.event.issue.title, github.event.pull_request.title·body, github.head_ref 등 이벤트 필드.
- 원인: run의 ${{ }}는 스크립트가 만들어지기 전에 텍스트로 치환된다.
- 완화 1(선호): 값을 액션의 입력(with:)으로 넘긴다 → 스크립트 생성에 쓰이지 않는다.
- 완화 2: 중간 환경 변수 → `env: TITLE: ${{ github.event.issue.title }}` 후 `run: echo "$TITLE"`(큰따옴표로 감싸기).
- 추가: GITHUB_TOKEN 최소 권한, 입력 검증·정제, 검증된 액션 선호, CodeQL·OpenSSF Scorecards로 탐지.

## 오답 함정
> [!warning] ${{ github.event.issue.title }}를 따옴표로 감싸면 run에 직접 넣어도 안전하다는 선택지 → 치환 후 따옴표를 깰 수 있다. 환경 변수로 넘긴다
