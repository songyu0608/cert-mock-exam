# 러너 이미지 변경

> [!summary] 한 줄 정의
> GitHub 호스팅 러너의 `-latest` 라벨이 가리키는 OS 이미지는 바뀐다. 오래된 이미지는 퇴역한다. 버전을 고정하거나 미리 대응해야 한다.

**English** Runner image changes

## 시험 트리거
- "windows-latest에서 갑자기 도구가 없다"
- "ubuntu-20.04 라벨 작업이 대기하다 실패"

## 핵심
- Ubuntu 20.04 이미지: 2025-04-15까지 완전 퇴역. 대체는 ubuntu-22.04 또는 ubuntu-24.04(변경 로그 2025-01-15).
- windows-latest: Windows Server 2022 → 2025로 2025-09-02부터 2025-09-30까지 이전(변경 로그 2025-07-31). 설치 도구가 달라질 수 있다.
- `-latest`는 GitHub가 제공하는 최신 안정 이미지이며 OS 공급사의 최신 버전이 아닐 수 있다.
- 안정성이 중요하면 `ubuntu-24.04`처럼 버전 라벨을 고정하고, 이미지 릴리스 정보(actions/runner-images)를 확인한다.
- (변동 정보) 2026-11 문서 라벨 표에는 ubuntu-26.04, windows-2025-vs2026, macos-26 등도 있다.

## 오답 함정
> [!warning] -latest가 항상 OS 공급사의 최신 버전이라는 선택지 → GitHub의 최신 안정 이미지
