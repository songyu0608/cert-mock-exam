# 액션 배포 모델

> [!summary] 한 줄 정의
> 액션은 같은 리포지토리 안(로컬), 조직 내 비공개·내부 리포지토리 공유, 공개 리포지토리, GitHub Marketplace로 배포할 수 있다.

**English** Action distribution models

## 시험 트리거
- "이 리포에서만 쓰는 액션"
- "조직 안에서만 공유"
- "전 세계에 공개하고 검색되게"

## 핵심
- 로컬: 워크플로가 있는 리포의 디렉터리(예: .github/actions/x). checkout 후 `uses: ./.github/actions/x`.
- 비공개·내부 리포 공유: 리포 Settings → Actions → General → Access에서 조직(또는 엔터프라이즈) 리포에 허용 → [[조직 내 액션·워크플로 공유]].
- 공개 리포: 누구나 `owner/repo@ref`로 사용.
- Marketplace: 공개 리포 + 루트 단일 action.yml + 릴리스에서 게시 → 검색·카테고리 노출.
- 어느 모델이든 소비자는 버전(태그·SHA)으로 참조한다.

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| 공개 리포 vs Marketplace | Marketplace는 공개 리포 액션 중 요건을 갖춰 등재한 것. 등재하지 않아도 공개 액션은 사용 가능 |

## 오답 함정
> [!warning] 비공개 리포지토리 액션을 Marketplace에 게시할 수 있다는 선택지 → 공개 리포지토리만
