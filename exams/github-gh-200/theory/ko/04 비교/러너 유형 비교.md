# 러너 유형 비교

| | [[GitHub 호스팅 러너]] | [[더 큰 러너]] | [[자체 호스팅 러너]] |
|---|---|---|---|
| 관리 | GitHub | GitHub | 사용자 |
| 환경 | 작업마다 새 VM | 작업마다 새 VM〔해석〕 | 깨끗한 환경 보장 없음(임시 러너 선택) |
| 비용 | 공개 리포 무료, 비공개 포함량 후 과금 | 공개 리포도 분당 과금 | 러너 무료, 머신 비용 본인 |
| 고정 IP | 없음(GET /meta 범위, 허용 목록 비권장) | 정적 IP 할당 가능 | 본인 네트워크 |
| 작업 최대 | 6시간 | 6시간〔해석〕 | 5일 |
| 요금제 | 모두 | Team·Enterprise Cloud | 모두 |
| 확장 | 자동 | 자동 확장 | ARC 등 직접 |

> [!question]- 사내망 데이터베이스에 접근하는 통합 테스트를 돌려야 한다.
> 자체 호스팅 러너(또는 Azure 사설 네트워킹 더 큰 러너).

> [!question]- 공개 오픈 소스 리포에서 외부 기여자 PR을 빌드한다. 어떤 러너?
> GitHub 호스팅 러너. 공개 리포에 자체 호스팅 러너는 쓰지 않는다.
