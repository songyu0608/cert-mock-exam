# 비밀 vs 변수 vs 환경 변수

| | [[비밀(secrets)]] | [[구성 변수(vars)]] | [[환경 변수와 환경 파일\|env·환경 변수]] |
|---|---|---|---|
| 저장 위치 | 조직·리포·환경 설정(암호화) | 조직·리포·환경 설정 | 워크플로 파일 env:, GITHUB_ENV, 기본 변수 |
| 읽기 | `${{ secrets.X }}` | `${{ vars.X }}` | `$X`(셸), `${{ env.X }}` |
| 로그 | 자동 마스킹 | 마스킹 안 됨〔해석〕 | 마스킹 안 됨 |
| 우선순위 | 환경 > 리포 > 조직 | 환경 > 리포 > 조직 | 단계 > 작업 > 워크플로 |
| 한도 | 48 KB/개, 조직 1,000·리포 100·환경 100 | 48 KB/개, 조직 1,000·리포 500·환경 100, 실행당 256 KB | 기본 변수 GITHUB_*·RUNNER_* 덮어쓰기 불가 |
| 포크 PR | 전달 안 됨(GITHUB_TOKEN 제외) | 〔확인 안 함〕 | 워크플로 정의대로 |

> [!question]- 여러 리포가 같은 배포 대상 URL(민감하지 않음)을 조직 설정에서 관리하고 싶다.
> 조직 구성 변수(vars).

> [!question]- 클라우드 API 키를 production 환경 승인 후에만 쓰게 하고 싶다.
> 환경 비밀(또는 더 나은 방법으로 OIDC).
