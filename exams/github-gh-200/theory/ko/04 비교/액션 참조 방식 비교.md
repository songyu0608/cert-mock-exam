# 액션 참조 방식 비교

| 참조 | 예 | 장점 | 단점 |
|---|---|---|---|
| 전체 커밋 SHA | `@8f4b7f8...`(40자) | 불변, 가장 안전 | 자동 업데이트 없음, Dependabot 취약점 알림 없음 |
| 태그 | `@v4`, `@v4.1.0` | 읽기 쉬움, major 태그로 수정 반영 | 유지 관리자가 옮기거나 삭제 가능 |
| 브랜치 | `@main` | 항상 최신 | 깨지는 변경·악성 변경 위험 |
| 로컬 경로 | `./.github/actions/x` | 같은 리포·같은 커밋 | 먼저 checkout 필요 |
| Docker Hub | `docker://alpine:3.20` | 이미지 직접 실행 | 이미지 무결성 확인 필요 |
