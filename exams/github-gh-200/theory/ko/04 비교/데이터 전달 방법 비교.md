# 데이터 전달 방법 비교

| 방법 | 범위 | 쓰기 | 읽기 |
|---|---|---|---|
| GITHUB_ENV | 같은 작업의 다음 단계 | `echo "X=1" >> "$GITHUB_ENV"` | `$X`, `env.X` |
| GITHUB_OUTPUT | 같은 작업(단계 id 필요) | `echo "x=1" >> "$GITHUB_OUTPUT"` | `steps.<id>.outputs.x` |
| 작업 outputs | 다른 작업(needs) | `jobs.<id>.outputs` | `needs.<id>.outputs.x` |
| 재사용 워크플로 출력 | 호출자 | `on.workflow_call.outputs` | `needs.<job>.outputs.x` |
| 아티팩트 | 같은 실행의 다른 작업, 실행 후 다운로드 | upload-artifact | download-artifact |
| 캐시 | 다음 실행들 | actions/cache | actions/cache |
| GITHUB_STATE | 같은 액션의 pre·main·post | `echo "k=v" >> "$GITHUB_STATE"` | `STATE_k` 환경 변수 |

관련: [[작업 간 데이터 전달]] · [[환경 변수와 환경 파일]]

> [!question]- 버전 문자열 하나를 빌드 작업에서 배포 작업으로 넘긴다.
> 단계 GITHUB_OUTPUT → 작업 outputs → needs.<job>.outputs.
