# 토큰과 인증 방식 비교

| | [[GITHUB_TOKEN]] | PAT(개인 액세스 토큰) | GitHub App 설치 토큰 | [[OIDC]] |
|---|---|---|---|---|
| 대상 | 이 리포의 GitHub API | GitHub API(사용자 권한) | GitHub API(앱 권한) | 클라우드 공급자 |
| 생성 | 작업마다 자동 | 사용자가 발급·저장(비밀) | 앱 키로 실행 중 발급 | 실행 중 요청(id-token: write) |
| 수명 | 작업 종료(최대 수명 제한) | 길다(만료 설정) | 짧다〔해석〕 | 작업 하나 |
| 범위 | 워크플로가 있는 리포 | 사용자가 접근 가능한 리포 | 앱 설치 범위 | 클라우드 신뢰 조건(sub 등) |
| 새 워크플로 트리거 | 안 함(dispatch 예외) | 함 | 함 | — |

**판별**: 같은 리포 작업 → GITHUB_TOKEN(permissions 최소화). 다른 리포·생성 PR이 CI를 돌려야 함 → GitHub App 토큰(권장) 또는 PAT. 클라우드 배포 → OIDC.

> [!question]- 워크플로가 만든 PR에서도 CI가 승인 없이 돌아야 한다.
> GitHub App 설치 토큰 또는 PAT로 PR 생성.
