# GH-200 대시보드

> [!info] 이 보관함
> GitHub Actions(GH-200) 학습용. Microsoft Learn 학습 가이드(2026년 1월 기준 기술 목록)를 한국어로 옮기고, 한국어 공식 안내서 표기를 함께 실었다. 안내서는 목표 문구만 제시하므로 카드 내용은 GitHub 공식 문서와 변경 로그에서 보충하고 카드마다 근거를 달았다. 〔해석〕 표시는 공식 자료에 직접 근거가 없는 정리다.

## 추천 학습 순서
1. [[0 시험 개요와 출제 범위]]로 구조와 시험 정책, 한국어 안내서의 "작업" 표기 문제 파악
2. 도메인 1(20–25%, 목표 16개)부터 이론 노트를 읽고, 링크된 카드의 **시험 트리거·오답 함정**까지 본다
3. 도메인 4(20–25%) → 2·3(각 15–20%) → 5(10–15%) 순서로 진행
4. [[비교 노트 목록|비교 노트]]와 [[오답 선택지 패턴]]으로 헷갈리는 선택지 정리
5. [[판단 패턴 역색인]]으로 상황 → 기능 연결 연습
6. [[분류·목록 암기표]], [[수치 암기표]] 암기
7. 한국어로 응시한다면 [[용어 대조표]]로 공식 안내서 표기 확인
8. 실습 리포지토리에서 매트릭스, 재사용 워크플로, 복합 액션, 환경 승인, OIDC, 캐시·아티팩트를 한 번씩 돌려 본다
9. 매일 플래시카드 복습, 마지막에 [[공식 목표 53개 체크리스트]]로 빈 곳 점검, Microsoft Learn 연습 평가로 마무리
