# 공식 목표 53개 체크리스트

학습 가이드의 도메인별 목표 53개(16/11/7/9/10). 가이드는 번호를 붙이지 않았고 번호는 이 볼트가 붙였다. 각 목표에 이 볼트 번역, 영어 원문, 한국어 공식 안내서 문구를 차례로 실었다. 관련 카드를 설명할 수 있으면 체크한다.
