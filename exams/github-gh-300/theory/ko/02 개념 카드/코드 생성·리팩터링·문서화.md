# 코드 생성·리팩터링·문서화

> [!summary] 한 줄 정의
> Copilot으로 기능 설명에서 코드를 만들고, 기존 코드를 더 나은 패턴으로 바꾸고(언어 변환 포함), 주석·README 같은 문서를 생성한다.

**English** Code generation, refactoring, and documentation

## 시험 트리거
- "REST API 기본 구조를 빨리 만들고 싶다"
- "복잡한 함수를 읽기 쉽게 고쳐 줘"
- "이 모듈에 주석과 README"

## 핵심
- 코드 생성: 높은 수준의 기능 설명을 코드 구조로, 오류 처리·로깅·엣지 케이스를 포함한 구현(Learn).
- 보일러플레이트: REST API 설정, 클래스 구조 같은 반복 코드(Learn).
- 리팩터링: 더 나은 패턴·효율적 구현 제안, 프로그래밍 언어 변환, 기능을 유지한 복잡한 변환(Learn).
- 문서화: 복잡한 부분의 인라인 주석, 코드베이스 기반 README 구조·내용 제안(Learn).
- 채팅 명령 /explain(설명), /fix(수정)과 자연어 요청을 함께 쓴다 → [[채팅 명령, 참가자, 변수]].
- 모든 결과는 검토·테스트 후 사용 → [[AI 출력 검증]].
