# 컨텍스트 결정 방식

> [!summary] 한 줄 정의
> Copilot은 커서 주변 코드, 열린 탭, 파일 이름·유형, 프로젝트 구조, 사용자가 명시한 #·@ 참조, 지침 파일 등으로 컨텍스트를 정한다.

**English** How Copilot determines context

## 시험 트리거
- "관련 없는 파일 내용이 답에 섞인다"
- "Copilot이 우리 유틸 함수를 모른다"
- "특정 파일만 근거로 답하게"

## 핵심
- 자동 수집(Learn): 커서 앞뒤 코드, 파일 이름·유형, 인접한 열린 탭, 프로젝트 구조·경로, 언어·프레임워크.
- 명시 지정(채팅): #file, #selection, #codebase 같은 변수, @ 참가자, 파일·이미지 첨부 → [[채팅 명령, 참가자, 변수]].
- 상시 컨텍스트: 사용자 지정 지침 파일, Spaces, MCP 서버.
- 관련 파일은 열고 관련 없는 파일은 닫으며, 참고할 코드를 강조(선택)한다(docs).
- 채팅 기록도 다음 응답의 컨텍스트가 된다 → [[채팅 기록과 체인 프롬프팅]].
- 콘텐츠 제외된 파일은 컨텍스트에서 빠진다(단, IDE가 간접 제공하는 타입 정보 등은 쓰일 수 있음) → [[콘텐츠 제외]].
