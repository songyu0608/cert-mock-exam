# 데이터 사용·보존

> [!summary] 한 줄 정의
> Copilot은 제안을 만들 때 코드와 컨텍스트를 프롬프트로 보내고, 보존·학습 사용 여부는 기능과 요금제에 따라 다르다.

**English** Copilot data usage, flow, retention, and sharing

## 시험 트리거
- "우리 코드가 모델 학습에 쓰이나"
- "IDE 채팅 프롬프트는 저장되나"
- "GitHub.com 채팅 기록은 얼마나 남나"

## 핵심
- IDE 코드 제안: 제안 생성용 프롬프트(코드·컨텍스트)를 기반 모델 학습용으로 보존하지 않고, 제안을 돌려준 뒤 폐기한다(Learn).
- Business·Enterprise 기본값(Learn): IDE의 Copilot Chat과 Copilot CLI는 프롬프트·제안을 기본으로 보존하지 않고, GitHub.com과 GitHub Mobile의 Copilot은 최대 28일 보존.
- 개인 요금제(Free·Pro·Pro+·Max): 2026-04-24부터 GitHub가 상호 작용을 AI 모델 학습에 쓸 수 있고, 설정 "Allow GitHub to use my data for AI model training"을 꺼서 거부한다. Business·Enterprise 계정에는 이 설정이 없다 → [[개인 Copilot 설정]].
- 콘텐츠 제외 정책을 받기 위해 클라이언트가 현재 리포지토리 URL을 보내며, 이 URL은 로그에 남기지 않는다.
- 세부 보존·처리 정책은 GitHub Copilot Trust Center에서 확인한다(학습 가이드 공부 자료).
- 데이터 정책은 바뀐다(변동 정보). Learn 모듈과 docs의 표현이 시점마다 다를 수 있다.

> [!warning] 오답이 되기 쉬운 선택지
> - Business의 IDE 코드 제안 프롬프트가 모델 학습에 쓰인다는 선택지 → 보존·학습에 쓰지 않음
> - GitHub.com 채팅 기록이 무기한 보존된다는 선택지 → Business·Enterprise 기본 최대 28일
