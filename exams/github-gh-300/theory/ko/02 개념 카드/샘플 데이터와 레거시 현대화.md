# 샘플 데이터와 레거시 현대화

> [!summary] 한 줄 정의
> Copilot으로 테스트용 현실적 샘플 데이터를 만들고, 오래된 코드를 이해·설명받아 최신 패턴이나 다른 언어로 옮긴다.

**English** Generating sample data and modernizing legacy code

## 시험 트리거
- "테스트용 가짜 고객 데이터 100건"
- "COBOL·오래된 Java 코드를 최신 방식으로"
- "아무도 모르는 레거시 함수 이해"

## 핵심
- 샘플 데이터: 테스트 시 현실적인 샘플 데이터를 생성해 수작업을 줄인다(Learn).
- 레거시 현대화: 코드 설명(/explain)으로 이해 → 테스트로 현재 동작 고정 → 리팩터링·언어 변환 → 테스트로 동작 확인〔해석: Learn의 리팩터링·언어 변환·맥락 보존 내용을 합친 절차〕.
- 실제 개인 데이터 대신 생성 데이터를 쓰면 개인정보 노출 위험이 줄어든다〔해석〕.
- 오래된 관행이 학습 데이터에 섞여 있을 수 있으므로 결과가 "최신"인지 검토한다(Learn 한계).
