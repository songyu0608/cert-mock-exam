# 프록시 필터와 후처리

> [!summary] 한 줄 정의
> 프록시는 입력 단계에서 프롬프트 조작·해킹 시도를 막고, 생성 후에는 유해성·코드 품질·공개 코드 일치 검사로 응답을 걸러 낸다.

**English** Proxy filtering and post-processing

## 시험 트리거
- "시스템 프롬프트를 알아내려는 요청"
- "생성 코드에 SQL 인젝션 패턴"
- "공개 코드와 같은 긴 코드 블록"

## 핵심
- 입력 쪽 프록시 필터: 프롬프트 해킹, 생성 방식 노출 유도 차단.
- 입력 쪽 유해성 필터: 혐오 표현, 부적절한 내용, 개인 데이터.
- 출력 쪽 후처리: 유해 내용 제거, 코드 품질(XSS, SQL 인젝션 등) 검사, 공개 코드 일치(약 150자 이상, 설정 시) 차단.
- 검사에 걸리면 응답을 자르거나 폐기한다.
- docs: 콘텐츠 필터가 유해·공격적 콘텐츠와 불안전한 코드를 감지·차단하고, 공개 코드 일치는 설정에 따라 차단하거나 출처·라이선스 참조를 붙인다.
