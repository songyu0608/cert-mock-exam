# 제로샷·원샷·퓨샷 프롬프팅

> [!summary] 한 줄 정의
> 예시 없이 요청하면 제로샷, 예시 하나를 주면 원샷, 여러 예시를 주면 퓨샷이다. 예시가 많을수록 원하는 패턴·규칙을 따르기 쉽다.

**English** Zero-shot, one-shot, and few-shot prompting

## 시험 트리거
- "우리 팀 코드 스타일대로 비슷한 함수를 하나 더"
- "예시 없이 섭씨→화씨 변환 함수"
- "여러 경우를 다루는 복잡한 구현"

## 핵심
- 제로샷: 예시 없이 기본 학습만으로 생성(예: 주석으로 섭씨→화씨 변환 함수 요청).
- 원샷: 예시 하나로 패턴·관례를 따르게 함(예: 온도 변환 함수 하나를 보여 주고 비슷한 함수 요청).
- 퓨샷: 여러 예시로 제로샷의 예측 불가능성과 파인튜닝의 정밀함 사이 균형. 여러 시나리오·엣지 케이스 처리에 강하다.
- docs: 예시(입력·출력 샘플, 구현, 단위 테스트)를 주면 원하는 바를 더 잘 이해한다.

> [!warning] 퓨샷 프롬프팅이 모델을 다시 학습시킨다는 선택지 → 프롬프트에 예시를 넣을 뿐, 모델은 바뀌지 않는다
