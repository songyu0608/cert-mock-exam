# 보안·성능 개선 제안

> [!summary] 한 줄 정의
> Copilot에게 코드의 보안 취약점과 성능 병목을 찾고 개선안을 제안하게 할 수 있다. 제안은 보안 도구와 사람의 검토로 확인한다.

**English** Suggesting security improvements and performance optimizations

## 시험 트리거
- "이 로그인 코드의 취약점을 찾아 줘"
- "큰 데이터에서 느린 정렬을 개선"
- "OWASP 기준으로 점검"

## 핵심
- 역할 프롬프팅 예: "사이버보안 전문가로서 OWASP 지침을 따르는 비밀번호 검증 함수를 만들어", "성능 최적화 전문가로서 대용량 데이터용으로 정렬 알고리즘을 리팩터링해"(Learn).
- /fix, 채팅으로 문제 코드 선택 후 개선 요청.
- PR 전에 Copilot으로 잠재 문제·개선점·품질 기준을 점검(Learn).
- 생성 코드는 보안 모범 사례를 항상 따르지 않으므로 검토가 필요하다(Learn 한계).
- Copilot 후처리는 XSS·SQL 인젝션 같은 흔한 취약 패턴을 검사하지만 완전하지 않다 → [[프록시 필터와 후처리]].
- 〔해석〕 코드 스캐닝의 Copilot Autofix(GitHub Advanced Security)는 경고에 대한 수정 제안 기능으로, 이 목표와 관련 있지만 학습 가이드에는 명시되지 않았다.

## 오답 함정
> [!warning] Copilot이 보안 검토를 대신하므로 보안 도구가 필요 없다는 선택지 → 제안은 보조, 보안 검토·도구는 계속 필요
