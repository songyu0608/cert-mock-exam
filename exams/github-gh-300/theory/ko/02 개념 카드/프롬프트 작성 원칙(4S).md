# 프롬프트 작성 원칙(4S)

> [!summary] 한 줄 정의
> 좋은 프롬프트는 한 가지 작업에 집중하고(Single), 구체적이며(Specific), 간결하고(Short), 주변 컨텍스트를 갖춘다(Surround). Microsoft Learn 모듈의 원칙이다.

**English** Prompt structure and the 4 Ss

## 시험 트리거
- "함수 하나를 정확히 받고 싶다"
- "Copilot이 엉뚱한 파일 맥락으로 답한다"
- "요청이 길고 여러 개가 섞였다"

## 핵심
- Single: 한 프롬프트는 잘 정의된 한 작업·질문에 집중.
- Specific: 지시를 명시적이고 자세하게.
- Short: 구체적이되 간결하게.
- Surround: 설명적인 파일 이름을 쓰고 관련 파일을 열어 둔다.
- 프롬프트 구성 요소〔해석〕: 목표(무엇을), 맥락(어디서·무엇과), 제약·요구사항(언어·라이브러리·형식), 예시.
- 주석으로 의도를 설명하면 인라인 제안에도 맥락이 된다.
