# 학습 가속과 컨텍스트 전환 감소

> [!summary] 한 줄 정의
> Copilot은 편집기 안에서 설명·제안을 줘 새 언어·API를 빨리 익히게 하고, 검색·문서를 오가는 컨텍스트 전환을 줄인다.

**English** Accelerating learning and reducing context switching

## 시험 트리거
- "처음 쓰는 프레임워크를 빨리 익혀야 한다"
- "API 문서를 계속 찾아보느라 흐름이 끊긴다"
- "인수인계받은 코드를 이해"

## 핵심
- 학습 가속: 새 개념을 빨리 이해·적용. API 사용·함수 매개변수를 인라인으로 제안해 외부 문서 참조를 줄인다(Learn).
- 컨텍스트 전환 감소: IDE 안 지원으로 온라인 검색 필요를 줄이고, 반복 패턴 자동 완성으로 생각의 흐름을 유지(Learn).
- 맥락 보존: 남의 코드를 이해하고 같은 스타일로 이어서 개발(Learn).
- /explain, 채팅 질문으로 낯선 코드를 설명받는다.
- 측정: 사용량 지표 API(제안, 수락, 활성 사용자, 편집기·언어별)와 설문(짧은 설문 2주마다, 긴 설문 4주에 1회 이하, 익명)(Learn).

## 오답 함정
> [!warning] Copilot을 쓰면 새 기술은 공부할 필요가 없다는 선택지 → 새롭거나 드문 기술은 정확도가 낮을 수 있어 검증과 학습이 필요
