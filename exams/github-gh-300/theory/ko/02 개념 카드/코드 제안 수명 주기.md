# 코드 제안 수명 주기

> [!summary] 한 줄 정의
> 코드 제안은 사용자의 입력·컨텍스트 → 프롬프트 → 모델 생성 → 필터 → 편집기 표시 → 수락·거절 → 다음 입력으로 반복되는 순환이다.

**English** Code suggestion lifecycle

## 시험 트리거
- "제안이 화면에 뜨기까지 어떤 일이 일어나나"
- "수락하지 않은 제안은 어떻게 되나"

## 핵심
- ① 입력: 사용자가 코드·주석을 쓰거나 채팅으로 요청.
- ② 컨텍스트 수집·전처리: 커서 주변 코드, 열린 탭 등.
- ③ 프롬프트로 LLM에 전송, 모델이 완성·편집 제안 생성.
- ④ 필터: 유해·불안전 코드, 공개 코드 일치 차단 또는 참조 표시.
- ⑤ 표시: 주변과 구분되는 제안(고스트 텍스트)으로 표시.
- ⑥ 사용자가 명시적으로 수락할 때만 적용. 거절·수정도 다음 상호 작용의 입력이 된다(Learn의 피드백 루프).
- IDE 코드 제안의 프롬프트는 제안 반환 후 폐기된다(Learn).
- 〔해석〕 학습 가이드는 "수명 주기를 시각화"라고만 쓴다. 위 단계는 docs의 책임 있는 사용 문서와 Learn 흐름을 합친 정리다.
