# 출력의 소유권과 책임

> [!summary] 한 줄 정의
> GitHub는 사용자의 입력과 출력(제안)에 소유권을 주장하지 않으며, 출력의 검토·라이선스 판단·법 준수 책임은 사용자에게 있다.

**English** Ownership and limitations of outputs

## 시험 트리거
- "Copilot이 만든 코드의 저작권은 누구에게"
- "생성 코드가 오픈 소스 코드와 비슷하다"
- "라이선스 문제가 걱정된다"

## 핵심
- GitHub 이용 약관(J.2): "GitHub does not claim ownership of your Input or Output." 출력이 학습 데이터의 코드와 비슷할 수 있다.
- 사용자 책임: 출력 사용에 제3자 라이선스가 필요한지 판단(J.2), 사용 전 검토·테스트·검증(J.4), 법 준수(J.5).
- 책임 있는 사용 문서: 사용자는 생성 코드의 보안 취약점·버그·IP 침해 위험을 진다.
- 공개 코드와 일치하는 제안은 차단하거나 출처·라이선스 참조를 보고 판단한다 → [[공개 코드 일치 필터와 코드 참조]].
- 한계: 부정확, 편향, 보안 위험, 공개 코드 일치 → [[생성형 AI의 위험과 한계]].
- 〔해석〕 법적 지식재산권 보장(indemnity) 조건은 계약·요금제별로 다를 수 있어 이 볼트에서 확인하지 않았다.

> [!warning] 오답이 되기 쉬운 선택지
> - GitHub가 Copilot 출력의 소유권을 가진다는 선택지 → 소유권을 주장하지 않는다
> - 출력의 라이선스 확인은 GitHub 책임이라는 선택지 → 사용자 책임
