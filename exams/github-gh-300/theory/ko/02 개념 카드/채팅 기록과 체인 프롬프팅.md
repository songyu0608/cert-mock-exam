# 채팅 기록과 체인 프롬프팅

> [!summary] 한 줄 정의
> Copilot Chat은 대화 기록을 컨텍스트로 쓴다. 단계적으로 요청을 이어 가면(체인 프롬프팅) 정밀해지지만 기록이 길어지면 비용과 혼선이 커진다.

**English** Chat history and chain prompting

## 시험 트리거
- "앞서 만든 함수에 오류 처리를 추가해 줘"
- "대화가 길어지니 엉뚱한 답이 나온다"
- "새 기능 작업을 시작"

## 핵심
- 채팅은 대화 기록을 유지해 이어지는 상호 작용에서 맥락을 이해한다(Learn).
- 체인 프롬프팅 예: 인증 함수 만들기 → 오류 처리 추가 → 단위 테스트 → 문서 주석 → 성능 최적화(Learn).
- 기록이 길어지면 요청당 소모가 커진다(Learn은 긴 기록이 요청당 더 많은 사용량을 쓴다고 설명, 변동 정보). 대응: 맥락 요약, 대화 초기화 후 집중된 맥락 제공, 이전 작업은 짧게 참조.
- docs: 새 작업은 새 스레드, 관련 없거나 실패한 요청은 삭제해 기록을 관련 있게 유지.
- CLI에서는 /compact로 컨텍스트를 압축하고 /context로 사용량을 본다.
