# 0 시험 개요와 출제 범위

GitHub Copilot(GH-300)은 GitHub Copilot으로 개발 생산성·품질·보안을 높이는 능력을 검증하는 중급(Intermediate) 자격증이다. 책임 있는 AI 사용, 프롬프트 엔지니어링, 요금제별 Copilot 기능, 개인정보 보호 장치를 다룬다. 응시자는 GitHub 기본기와 하나 이상의 프로그래밍 언어 경험이 있어야 한다(학습 가이드).

## 시험 정보 (Microsoft Learn, 2026-11-07 확인)
| 항목 | 내용 |
|---|---|
| 시험 코드 | GH-300 |
| 수준 | Intermediate(중급) |
| 시간 | 100분 |
| 합격 점수 | 700점 이상 |
| 문항 수 | 학습 가이드·자격증 페이지에 없음 |
| 응시료 | 시험을 감독하는 국가·지역에 따라 다름. 한국 가격은 이 볼트에서 확인하지 않음 |
| 시험 언어 | 영어, 스페인어, 포르투갈어(브라질), 한국어, 일본어 |
| 현지화 반영 | 영어판 변경은 약 8주 뒤 현지화 버전에 반영. 원하는 언어가 없으면 30분 추가 요청 가능 |
| 출제 범위 | 대부분 정식 출시(GA) 기능. 널리 쓰이는 미리 보기 기능도 나올 수 있음. 목표 아래 항목은 예시이며 관련 주제도 나올 수 있음 |
| 형식 | Pearson VUE 감독 시험. 대화형 문항 포함 가능. 시험 환경 체험(sandbox) 제공 |
| 재응시 | 첫 응시 후 24시간 뒤부터. 이후는 재응시 정책에 따름 |
| 유효 기간·갱신 | GitHub 자격증은 2년 유효. Microsoft 재인증 절차로 전환 중이며, 새 절차 전에 만료되는 자격증은 6개월 연장 |
| 연습 | 무료 연습 평가(Practice Assessment) 제공 |
| 대상 역할 | App Maker, Developer, DevOps Engineer, Technology Manager |
| 개정 | 2026년 8월 7일 기준. 이전 판 대비 IDE 사용, 기능과 역량, 보호 장치 영역이 소폭 변경(Minor) |

## 공부 포인트
- 학습 가이드의 "Skills at a glance"에는 "GitHub Copilot features (25–30%)"라는 줄이 하나 더 있지만 세부 목표가 없다. 이 볼트는 이를 중복 표기로 보고 세부 목표가 있는 6개 도메인으로 정리했다(해석).
- 목표 번호(2.1 등)는 이 볼트가 붙였다. 안내서는 글머리 목록만 제시한다.
- 안내서에는 샘플 문제가 없다. 카드의 셀프 체크와 비교 노트의 질문은 이 볼트가 만든 것이다.
- 한국어 공식 안내서는 기계 번역으로 보인다(예: Copilot → "부조종사", few-shot → "몇 샷", edge cases → "극한 사례"). 한국어로 응시한다면 [[용어 대조표]]를 본다. 실제 시험의 한국어 표기는 확인하지 못했다.
- 카드 내용은 GitHub 공식 문서(docs.github.com)와 학습 가이드가 공부 자료로 지정한 Microsoft Learn 모듈에서 보충했고, 카드마다 근거 링크를 달았다.
- Copilot은 빠르게 바뀐다. 요금제·모델·보존 기간·미리 보기 상태는 "변동 정보"로 표시했다. 예: GitHub Spark는 2026년 8월 지원 종료가 공지되었지만 학습 가이드에는 남아 있다.
