# 도메인 6　개인정보 보호, 콘텐츠 제외, 보호 장치 구성

**English** Domain 6: Configure privacy, content exclusions, and safeguards  
**한국어 공식 안내서** 개인 정보 보호, 콘텐츠 제외 및 보호 구성

도메인 6 (10–15%) · 목표 4개

콘텐츠 제외와 편집기 설정, 출력 소유권, 공개 코드 일치 필터, 제안·제외 문제 해결을 다룬다.

## 목표 6.1

**콘텐츠 제외와 편집기 설정을 구성한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Configure content exclusions and editor settings
>
> 콘텐츠 제외 및 편집기 설정 구성

관리자는 콘텐츠 제외로 파일·리포지토리를 빼고, 개인은 편집기 설정과 Copilot settings로 언어·기능·학습 사용·웹 검색을 조정한다.

관련 카드: [[IDE에서 Copilot 활성화와 편집기 설정]] · [[콘텐츠 제외]] · [[개인 Copilot 설정]]

## 목표 6.2

**출력의 소유권과 한계를 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe ownership and limitations of outputs
>
> 출력의 소유권 및 제한 사항 설명

GitHub는 입력·출력의 소유권을 주장하지 않는다. 출력의 라이선스 판단·검증·법 준수는 사용자 책임이다.

관련 카드: [[출력의 소유권과 책임]] · [[공개 코드 일치 필터와 코드 참조]]

> [!abstract] 보호 장치 적용과 문제 해결
> Apply safeguards and troubleshoot · 세이프가드 적용 및 문제 해결

## 목표 6.3

**공개 코드와 일치하는 제안 필터링을 활성화한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Enable suggestions matching public code filtering
>
> 공개 코드 필터링과 일치하는 제안 활성화

"Suggestions matching public code"를 Block으로 두면 일치 제안을 막고, Allow면 출처·라이선스 참조를 보여 준다. 조직 좌석은 조직 정책을 따른다.

관련 카드: [[공개 코드 일치 필터와 코드 참조]] · [[개인 Copilot 설정]]

## 목표 6.4

**제안과 콘텐츠 제외 관련 문제를 해결한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Resolve issues with suggestions and content exclusions
>
> 제안 및 콘텐츠 제외 관련 문제 해결

서비스 상태·확장 버전·로그인·정책을 확인하고, 제외 문제는 반영 시간(최대 30분), 다시 불러오기, 미지원 모드(Edit·Agent)를 확인한다.

관련 카드: [[콘텐츠 제외]] · [[Copilot 문제 해결]]

## 요약
- 콘텐츠 제외 = 입력 제외, 공개 코드 필터 = 출력 차단.
- 콘텐츠 제외는 보안 경계가 아니다.
- 반영 최대 30분 → Reload Window.

## 이 도메인의 카드
- [[콘텐츠 제외]] — 리포지토리 관리자, 조직 소유자, 엔터프라이즈 소유자가 특정 파일·경로·리포지토리를 Copilot이 쓰지 않도록 제외하는 설정(Business·Enterprise).
- [[출력의 소유권과 책임]] — GitHub는 사용자의 입력과 출력(제안)에 소유권을 주장하지 않으며, 출력의 검토·라이선스 판단·법 준수 책임은 사용자에게 있다.
- [[공개 코드 일치 필터와 코드 참조]] — 공개 코드와 일치하는 제안을 차단(Block)하거나, 허용(Allow)하고 출처 리포지토리·라이선스 참조를 함께 보여 주는 설정.
- [[개인 Copilot 설정]] — 개인 구독자가 프로필 사진 → Copilot settings에서 공개 코드 일치, 데이터의 AI 모델 학습 사용, Bing 웹 검색 등을 정하는 설정.
- [[Copilot 문제 해결]] — 제안이 안 나오거나 이상할 때는 서비스 상태, 확장 버전, 로그인, 정책, 콘텐츠 제외를 순서대로 확인한다.
