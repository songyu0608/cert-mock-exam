# 공개 코드 일치 필터와 코드 참조

> [!summary] 한 줄 정의
> 공개 코드와 일치하는 제안을 차단(Block)하거나, 허용(Allow)하고 출처 리포지토리·라이선스 참조를 함께 보여 주는 설정.

**English** Public code filter and code referencing

## 시험 트리거
- "오픈 소스 라이선스 위험을 피하고 싶다"
- "일치하는 공개 코드의 출처와 라이선스를 보고 싶다"
- "개인 Pro 사용자가 필터를 켜는 방법"

## 핵심
- 비교: 제안과 주변 코드 약 150자를 GitHub.com의 모든 공개 리포지토리 색인과 비교(비공개·GitHub 외부 코드는 대상 아님). 색인은 몇 달마다 갱신.
- 차단(Block): 일치 제안을 버린다. 허용(Allow): 제안을 보여 주고 코드 참조(출처 URL, 라이선스)를 제공.
- 참조 표시: IDE에서는 수락한 일치 제안을 로그에 남긴다(VS Code·Visual Studio·JetBrains). Chat은 응답 끝에 표시. 클라우드 에이전트는 세션 로그.
- 빈도: 일반적으로 제안의 1% 미만.
- 개인 설정(Free·Pro·Pro+·Max): 프로필 사진 → Copilot settings → "Suggestions matching public code" Allow/Block. 조직에서 좌석을 받으면 조직 정책을 상속해 개인이 바꿀 수 없다.
- 조직은 Copilot 정책에서 설정하며, REST API로 좌석을 부여하려면 이 정책이 먼저 구성되어 있어야 한다.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 공개 코드 필터가 비공개 리포지토리 코드와도 비교한다는 선택지 → GitHub.com 공개 리포지토리 색인만
> - 조직 좌석 사용자가 개인 설정에서 필터를 바꾼다는 선택지 → 조직 정책 상속
> - 코드 참조가 모든 일치를 실시간으로 잡는다는 선택지 → 색인은 몇 달마다 갱신되어 최근 코드는 빠질 수 있다
