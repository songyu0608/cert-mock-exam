# 채팅 명령, 참가자, 변수

> [!summary] 한 줄 정의
> 채팅에서 / 명령으로 작업 종류를, @ 참가자로 영역을, # 변수로 컨텍스트를 지정한다.

**English** Copilot Chat slash commands, participants, and variables

## 시험 트리거
- "선택한 코드의 단위 테스트를 만들어 줘"
- "터미널 명령을 물어보고 싶다"
- "현재 파일만 참고해서 답해 줘"

## 핵심
- 슬래시 명령(VS Code): /clear(새 세션), /explain(설명), /fix(문제 수정 제안), /fixTestFailure(실패 테스트 수정), /help, /new(새 프로젝트), /tests(단위 테스트 생성).
- 채팅 참가자: @github(GitHub 관련 기능), @terminal(터미널 명령), @vscode(VS Code 명령·기능), @azure(공개 미리 보기).
- 채팅 변수: #file, #selection, #function, #class, #block, #line, #comment, #path, #project, #sym. Learn 모듈은 #codebase(작업 영역 검색), #editor도 소개한다.
- 사용 가능한 명령은 환경(IDE·버전)마다 다르다.

## 오답 함정
> [!warning] @ 기호로 파일을 컨텍스트에 넣는다는 선택지 → 채팅에서 파일은 #(예: #file), @는 참가자
