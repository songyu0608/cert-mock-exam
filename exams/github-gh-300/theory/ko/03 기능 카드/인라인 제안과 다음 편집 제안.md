# 인라인 제안과 다음 편집 제안

> [!summary] 한 줄 정의
> 편집기에서 입력하는 동안 회색 글자(고스트 텍스트)로 보이는 자동 완성 제안. 다음 편집 제안은 다음에 고칠 위치까지 예측해 제안한다.

**English** Inline suggestions and next edit suggestions

## 시험 트리거
- "함수 이름과 주석만 쓰면 본문을 제안받고 싶다"
- "여러 대안 제안을 보고 고르고 싶다"
- "변수 이름을 바꾸면 관련 위치 수정까지 제안"

## 핵심
- 제안은 커서 주변 코드와 열린 탭 등 컨텍스트로 만들어지고, 수락해야만 적용된다.
- 다음 편집 제안(next edit suggestions): 다음 편집 위치를 예측해 완성을 제안. VS Code, Xcode, Eclipse.
- VS Code 단축키(Windows/Linux): 수락 Tab, 닫기 Esc, 다음 제안 Alt+], 이전 제안 Alt+[, 수동 트리거 Alt+\, 여러 제안 패널 Ctrl+Enter.
- 주석으로 의도를 설명하면 제안이 좋아진다 → [[프롬프트 작성 원칙(4S)]].
- Copilot Free는 월 완성 횟수 제한이 있다(2026-11 문서 2,000회, 변동 정보).
