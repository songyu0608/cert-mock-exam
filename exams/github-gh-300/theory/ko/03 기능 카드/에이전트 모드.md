# 에이전트 모드

> [!summary] 한 줄 정의
> IDE에서 Copilot이 자율적으로 작업하는 모드. 필요한 파일을 고르고 편집과 터미널 명령을 제안해 승인받으며, 결과를 보고 반복한다.

**English** Agent mode in the IDE

## 시험 트리거
- "여러 파일에 걸친 기능 구현을 AI가 진행"
- "테스트를 돌리고 실패하면 고치기까지"
- "AI가 낸 변경을 되돌리고 싶다"

## 핵심
- Copilot이 변경과 터미널 명령을 제안하고 사용자가 승인한다.
- 변경 검토: 바뀐 파일의 diff를 보고 Keep(수락) 또는 Undo(되돌리기).
- 체크포인트: 파일과 채팅 기록을 이전 시점으로 되돌린다. 외부 서비스 변경은 되돌리지 않는다. 요청을 멈춰도 이미 끝난 편집·명령은 남는다.
- MCP 서버를 붙여 외부 도구·데이터를 쓴다 → [[MCP]].
- 하위 에이전트에 작업을 위임해 컨텍스트를 아낀다 → [[하위 에이전트와 에이전트 세션]].
- 에이전트 모드 프롬프트는 AI 크레딧을 쓴다. 관리자가 IDE 에이전트 모드를 끌 수 있다.
- 콘텐츠 제외는 에이전트 모드(Edit·Agent 모드)에서 지원되지 않는다 → [[콘텐츠 제외]].

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 에이전트 모드에서도 콘텐츠 제외가 적용된다는 선택지 → Edit·Agent 모드에서는 지원되지 않는다
> - 요청을 중지하면 이미 실행된 편집이 자동으로 되돌려진다는 선택지 → 체크포인트로 복원해야 한다
