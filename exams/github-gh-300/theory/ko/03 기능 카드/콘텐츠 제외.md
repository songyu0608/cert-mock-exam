# 콘텐츠 제외

> [!summary] 한 줄 정의
> 리포지토리 관리자, 조직 소유자, 엔터프라이즈 소유자가 특정 파일·경로·리포지토리를 Copilot이 쓰지 않도록 제외하는 설정(Business·Enterprise).

**English** Content exclusion

## 시험 트리거
- "비밀 설정 파일(.env)을 Copilot이 읽지 않게"
- "특정 리포지토리 전체를 Copilot에서 제외"
- "제외했는데 아직 제안이 나온다"

## 핵심
- 설정 위치: 리포지토리 Settings → Copilot → Content exclusion("Paths to exclude in this repository"), 조직 Settings → Copilot → Content exclusion("Repositories and paths to exclude"), 엔터프라이즈 AI controls → Copilot → Content exclusion.
- 범위: 엔터프라이즈 규칙은 엔터프라이즈 전체 Copilot 사용자, 조직 규칙은 그 조직에서 좌석을 받은 사용자.
- 문법: 한 줄에 경로 하나(`- "/scripts/**"`, `- "*.cfg"`, `- "secrets.json"`), fnmatch, 대소문자 무시. 조직은 리포지토리 참조를 키로(`"*":`는 Git 밖을 포함한 모든 위치, `octo-repo:`, git URL).
- 효과: 제외 파일에서 인라인 제안 없음, 다른 파일의 제안·채팅 응답에 쓰이지 않음, Copilot 코드 리뷰에서 리뷰하지 않음.
- 한계: Copilot Chat의 Edit·Agent 모드는 지원 안 함. 심볼릭 링크·원격 파일 시스템에는 적용 안 됨. IDE가 간접 제공하는 타입 정보·호버 정의 등은 쓰일 수 있다. 파일 시스템 보안 경계가 아니다. 서드파티 MCP는 준수를 보장하지 않는다.
- 반영: 이미 설정을 불러온 IDE에서는 최대 30분. VS Code는 "Developer: Reload Window", JetBrains·Visual Studio는 재시작.
- GitHub 웹사이트와 GitHub Mobile에서는 공개 미리 보기(변동 정보).

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 콘텐츠 제외를 설정하면 즉시 모든 IDE에 반영된다는 선택지 → 최대 30분, 다시 불러오기로 앞당김
> - 콘텐츠 제외가 에이전트 모드에도 적용된다는 선택지 → Edit·Agent 모드는 지원 안 함
> - 콘텐츠 제외를 비밀 보호 보안 경계로 쓴다는 선택지 → 파일 시스템 보안 경계가 아니다
