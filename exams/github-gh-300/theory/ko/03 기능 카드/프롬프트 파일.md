# 프롬프트 파일

> [!summary] 한 줄 정의
> 자주 쓰는 프롬프트 지시를 `*.prompt.md` Markdown 파일로 작업 영역에 저장해 채팅에서 재사용하는 기능. 팀이 일관된 응답을 얻는다.

**English** Prompt files

## 시험 트리거
- "팀원 모두 같은 형식으로 코드 리뷰 프롬프트를 쓰게"
- "반복되는 컴포넌트 생성 요청을 표준화"

## 핵심
- 확장자 `*.prompt.md`, 작업 영역(리포지토리)에 저장.
- VS Code, Visual Studio, JetBrains IDE에서 사용. VS Code·JetBrains에서는 공개 미리 보기로 표시(변동 정보).
- 사용자 지정 지침은 항상 붙고, 프롬프트 파일은 필요할 때 실행한다.
- 프롬프트 파일 frontmatter의 tools에 agent 도구 세트를 넣어 하위 에이전트 위임 워크플로를 만들 수도 있다(VS Code 문서).

## 오답 함정
> [!warning] 프롬프트 파일이 모든 채팅에 자동 적용된다는 선택지 → 자동 적용은 사용자 지정 지침, 프롬프트 파일은 골라 실행
