# 플래시카드 도메인 6　개인정보 보호, 콘텐츠 제외, 보호 장치 구성

#flashcards/gh-300/d6

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
콘텐츠 제외를 설정할 수 있는 세 역할은?::리포지토리 관리자, 조직 소유자, 엔터프라이즈 소유자
콘텐츠 제외 변경이 IDE에 반영되기까지 최대 시간은?::30분
콘텐츠 제외가 지원되지 않는 채팅 모드는?::Edit 모드, Agent 모드
GitHub는 Copilot 출력의 소유권을 주장하나?::아니다(입력·출력 모두 주장하지 않음)
출력 사용에 제3자 라이선스가 필요한지 판단할 책임은?::사용자
공개 코드 비교에 쓰는 대략적 길이는?::약 150자
공개 코드 일치 설정의 두 값은?::Allow(참조 표시), Block(차단)
개인 Copilot 설정에 들어가는 경로는?::프로필 사진 → Copilot settings
Copilot Chat의 Bing 웹 검색 기본값은?::꺼짐
특정 파일에서만 제안이 안 나오면 먼저 의심할 것은?::콘텐츠 제외(상태 표시줄 아이콘의 대각선)
Copilot이 전체적으로 안 될 때 먼저 볼 곳은?::githubstatus.com과 확장 버전

## 상황 → 판단
상황: .env 파일을 Copilot에서 빼기 → 정답은?::콘텐츠 제외
상황: 제외 변경이 IDE에 반영 안 됨 → 정답은?::최대 30분, Reload Window
상황: 특정 파일에서만 제안 없음 → 정답은?::콘텐츠 제외(상태 표시줄 대각선)
상황: 라이선스 코드가 그대로 제안됨 → 정답은?::공개 코드 일치 Block
상황: 일치 코드의 출처·라이선스 확인 → 정답은?::Allow + 코드 참조
상황: 생성 코드 소유권 → 정답은?::GitHub는 주장하지 않음, 책임은 사용자
상황: 개인 데이터의 모델 학습 거부 → 정답은?::Copilot settings에서 학습 사용 Disabled
