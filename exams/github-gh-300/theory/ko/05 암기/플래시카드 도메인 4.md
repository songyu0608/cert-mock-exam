# 플래시카드 도메인 4　프롬프트 엔지니어링과 컨텍스트 구성

#flashcards/gh-300/d4

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
4S는?::Single, Specific, Short, Surround
관련 파일을 열어 두라는 원칙은?::Surround
관련 없는 내용이 섞일 때 docs의 권장은?::관련 파일만 열고 관련 없는 파일은 닫기, 참고할 코드 선택
예시 없이 요청하는 방식은?::제로샷
기존 함수 하나를 보여 주고 비슷한 함수를 요청하는 방식은?::원샷
docs가 제시하는 프롬프트 전략의 첫 단계는?::넓게 시작해 구체화(Start general, then get specific)
결과가 틀렸을 때 권장 행동은?::프롬프트를 고쳐 반복(실험과 반복)
새 작업을 시작할 때 docs의 권장은?::새 채팅 스레드 시작
Copilot CLI에서 컨텍스트를 수동으로 압축하는 명령은?::/compact

## 상황 → 판단
상황: 요청이 여러 개 섞임 → 정답은?::Single: 한 작업씩
상황: 관련 없는 파일 맥락이 섞임 → 정답은?::관련 파일만 열기(Surround), #file 지정
상황: 팀 스타일대로 비슷한 함수 → 정답은?::원샷·퓨샷(예시 제공)
상황: 첫 결과가 틀림 → 정답은?::프롬프트를 고쳐 반복
상황: 큰 기능을 한 번에 요청해 실패 → 정답은?::작은 작업으로 분할
상황: 새 작업 시작 → 정답은?::새 채팅 스레드
