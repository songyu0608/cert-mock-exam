# 플래시카드 도메인 2　GitHub Copilot 기능 사용

#flashcards/gh-300/d2

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
VS Code에서 언어별로 Copilot을 켜고 끄는 설정 키는?::github.copilot.enable
Business 사용자가 다음 편집 제안을 쓰려면 조직이 허용해야 하는 설정은?::Editor preview features
VS Code에서 인라인 제안 수락·다음 제안 단축키는?::Tab, Alt+]
여러 제안을 패널로 여는 단축키는?::Ctrl+Enter
VS Code 채팅 모드 3가지는?::Agent, Plan, Ask
Copilot Chat 응답에 피드백을 주는 방법은?::엄지 위·아래 아이콘
선택한 코드의 단위 테스트를 만드는 슬래시 명령은?::/tests
VS Code 터미널 명령을 돕는 채팅 참가자는?::@terminal
현재 선택 영역을 컨텍스트로 넣는 변수는?::#selection
에이전트 모드 변경을 파일·채팅까지 이전 시점으로 되돌리는 기능은?::체크포인트
에이전트 모드에서 콘텐츠 제외는 적용되나?::지원되지 않는다
콘텐츠 제외가 지원되지 않는 Copilot Chat 모드 2가지는?::Edit 모드와 Agent 모드
하위 에이전트에 위임하는 주된 이유는?::중간 작업을 메인 대화에서 분리해 메인 컨텍스트를 아끼기 위해
하위 에이전트가 다른 하위 에이전트를 만들 수 있나?::없다
조직 정책 "MCP servers in Copilot"의 기본값은?::꺼짐(Disabled)
Copilot CLI에 기본 내장된 MCP 서버는?::GitHub MCP 서버
npm으로 Copilot CLI를 설치하는 명령은?::npm install -g @github/copilot (Node.js 22+)
조직에서 받은 Copilot으로 CLI를 쓰기 위한 조건은?::조직 설정에서 Copilot CLI 정책이 켜져 있어야 함
Copilot CLI에서 한 번만 실행하고 종료하는 옵션은?::-p 또는 --prompt
특정 도구를 확실히 막는 옵션과 우선순위는?::--deny-tool, 다른 허용 옵션보다 우선
대화형 세션에서 계획 모드로 전환하는 키는?::Shift+Tab
클라우드 에이전트의 결과를 검토하는 방법은?::브랜치의 diff와 풀 리퀘스트 리뷰
Copilot 코드 리뷰의 기본 리뷰 유형은?::Comment(필수 승인에 포함 안 됨)
리포지토리 전체 리뷰 기준 파일은?::.github/copilot-instructions.md
리포지토리 전체 지침 파일 경로는?::.github/copilot-instructions.md
지침 우선순위는?::개인 > 리포지토리(경로별 > 전체 > 에이전트) > 조직
경로별 지침 파일의 대상 경로를 정하는 키는?::applyTo
프롬프트 파일의 확장자는?::.prompt.md
Spaces에 추가한 GitHub 파일이 바뀌면?::자동으로 갱신된다
GitHub Spark의 목적은?::아이디어를 빠르게 동작하는 앱으로 만드는 것
PR 요약을 만드는 위치는?::PR 설명·코멘트 입력란 헤더의 Copilot 아이콘 → Summary
조직 Copilot 정책 위치는?::조직 Settings → Copilot → Policies / Models
엔터프라이즈와 조직 정책이 다르면?::엔터프라이즈 정책이 우선
Copilot 관련 감사 로그 이벤트를 모두 찾는 검색어는?::action:copilot
감사 로그 보존 기간은?::최근 180일
사용자에게 Copilot 좌석을 부여하는 엔드포인트는?::POST /orgs/{org}/copilot/billing/selected_users
Copilot 좌석 관리에 필요한 클래식 토큰 범위는?::manage_billing:copilot
콘텐츠 제외·감사 로그 같은 관리 기능이 있는 요금제는?::Copilot Business, Copilot Enterprise

## 상황 → 판단
상황: 특정 언어에서만 Copilot 끄기 → 정답은?::github.copilot.enable 언어별 설정
상황: 여러 제안 중 고르기 → 정답은?::Alt+] / Alt+[ 또는 Ctrl+Enter 패널
상황: 파일을 바꾸지 않고 질문만 → 정답은?::Ask 모드
상황: 여러 파일 수정·명령 실행까지 IDE에서 → 정답은?::에이전트 모드
상황: 에이전트 변경을 이전 시점으로 → 정답은?::체크포인트 복원
상황: 긴 조사로 메인 컨텍스트가 넘침 → 정답은?::하위 에이전트에 위임
상황: 에이전트가 외부 이슈 트래커·DB 사용 → 정답은?::MCP 서버
상황: 조직에서 MCP 사용 허용 → 정답은?::정책 "MCP servers in Copilot"(기본 꺼짐)
상황: 터미널에서 Copilot 사용 → 정답은?::Copilot CLI(`copilot`)
상황: 스크립트에서 1회 요청 → 정답은?::`copilot -p "…"`
상황: CLI에서 rm 명령만 금지 → 정답은?::--deny-tool='shell(rm)'
상황: 조직 좌석인데 CLI가 안 됨 → 정답은?::조직 Copilot CLI 정책 확인
상황: 이슈를 맡겨 PR 받기 → 정답은?::클라우드 에이전트(이슈를 Copilot에 할당)
상황: 모든 PR에 AI 리뷰 → 정답은?::Copilot 코드 리뷰 자동 리뷰
상황: 리뷰가 팀 규칙을 따르게 → 정답은?::.github/copilot-instructions.md
상황: tests 폴더에만 규칙 적용 → 정답은?::.github/instructions/*.instructions.md + applyTo
상황: 반복 작업 프롬프트 표준화 → 정답은?::프롬프트 파일(*.prompt.md)
상황: 프로젝트 문서·코드 근거로 답하게 → 정답은?::Copilot Spaces
상황: PR 설명 자동 작성 → 정답은?::PR 요약(Copilot 아이콘 → Summary)
상황: 선택 코드 단위 테스트 → 정답은?::/tests
상황: 터미널 명령 도움 → 정답은?::@terminal
상황: 조직에서 기능·모델 제한 → 정답은?::Settings → Copilot → Policies·Models
상황: 누가 정책을 바꿨나 → 정답은?::감사 로그 action:copilot
상황: 좌석 부여 자동화 → 정답은?::REST API selected_users
