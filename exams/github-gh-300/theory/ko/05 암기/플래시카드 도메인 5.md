# 플래시카드 도메인 5　GitHub Copilot으로 개발 생산성 향상

#flashcards/gh-300/d5

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
Copilot이 문서화를 돕는 두 가지 예는?::인라인 주석, README 생성
Copilot이 컨텍스트 전환을 줄이는 방법은?::IDE 안에서 제안·설명을 줘 외부 검색·문서 이동을 줄임
Copilot이 테스트를 돕는 데이터 관련 기능은?::현실적인 샘플 데이터 생성
테스트 프레임워크가 없을 때 쓰는 명령은?::/setupTests (Agent 모드)
팀의 어설션 관례를 Copilot에 알리는 방법은?::사용자 지정 지침(예: tests/**에 applyTo한 .instructions.md)
보안 개선을 요청할 때 쓸 수 있는 프롬프트 기법은?::역할 프롬프팅(예: 사이버보안 전문가로서)

## 상황 → 판단
상황: REST API 뼈대 빨리 → 정답은?::보일러플레이트 생성
상황: 테스트용 가짜 데이터 → 정답은?::샘플 데이터 생성
상황: 테스트 프레임워크가 없음 → 정답은?::/setupTests
상황: 엣지 케이스 누락 → 정답은?::명시적으로 요청, Ask로 시나리오 목록
상황: 보안 관점 검토 요청 → 정답은?::역할 프롬프팅(보안 전문가)
