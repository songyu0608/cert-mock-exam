# 판단 패턴 역색인

문제 속 상황에서 정답 기능을 거꾸로 찾는 표. 가운데 열을 가리고 말해 본다. 표의 상황은 이 볼트가 공식 자료를 바탕으로 만든 예다.

| 문제 속 상황 | 정답 방향 | 노트 |
|---|---|---|
| AI 코드가 유효해 보이지만 요구사항과 다름 | 부정확한 코드 한계 → 검토·테스트 | [[생성형 AI의 위험과 한계]] |
| AI 결과가 특정 집단에 불리 | 공정성 원칙 | [[책임 있는 AI 원칙 6가지]] |
| AI가 왜 그렇게 판단했는지 설명 불가 | 투명성 원칙 | [[책임 있는 AI 원칙 6가지]] |
| AI 결과에 누가 책임지나 | 책임성: 사람이 책임 | [[책임 있는 AI 원칙 6가지]] |

| 제안을 그대로 배포하려 함 | 검토·테스트·검증 후 사용 | [[AI 출력 검증]] |

## 도메인 2　GitHub Copilot 기능 사용

| 문제 속 상황 | 정답 방향 | 노트 |
|---|---|---|
| 특정 언어에서만 Copilot 끄기 | github.copilot.enable 언어별 설정 | [[IDE에서 Copilot 활성화와 편집기 설정]] |
| 여러 제안 중 고르기 | Alt+] / Alt+[ 또는 Ctrl+Enter 패널 | [[인라인 제안과 다음 편집 제안]] |
| 파일을 바꾸지 않고 질문만 | Ask 모드 | [[Copilot Chat]] |
| 여러 파일 수정·명령 실행까지 IDE에서 | 에이전트 모드 | [[에이전트 모드]] |
| 에이전트 변경을 이전 시점으로 | 체크포인트 복원 | [[에이전트 모드]] |
| 긴 조사로 메인 컨텍스트가 넘침 | 하위 에이전트에 위임 | [[하위 에이전트와 에이전트 세션]] |
| 에이전트가 외부 이슈 트래커·DB 사용 | MCP 서버 | [[MCP]] |
| 조직에서 MCP 사용 허용 | 정책 "MCP servers in Copilot"(기본 꺼짐) | [[MCP]] |
| 터미널에서 Copilot 사용 | Copilot CLI(`copilot`) | [[Copilot CLI]] |
| 스크립트에서 1회 요청 | `copilot -p "…"` | [[Copilot CLI 명령과 세션]] |
| CLI에서 rm 명령만 금지 | --deny-tool='shell(rm)' | [[Copilot CLI 명령과 세션]] |
| 조직 좌석인데 CLI가 안 됨 | 조직 Copilot CLI 정책 확인 | [[Copilot CLI]] |
| 이슈를 맡겨 PR 받기 | 클라우드 에이전트(이슈를 Copilot에 할당) | [[Copilot 클라우드 에이전트]] |
| 모든 PR에 AI 리뷰 | Copilot 코드 리뷰 자동 리뷰 | [[Copilot 코드 리뷰]] |
| 리뷰가 팀 규칙을 따르게 | .github/copilot-instructions.md | [[Copilot 코드 리뷰]] |
| tests 폴더에만 규칙 적용 | .github/instructions/*.instructions.md + applyTo | [[사용자 지정 지침]] |
| 반복 작업 프롬프트 표준화 | 프롬프트 파일(*.prompt.md) | [[프롬프트 파일]] |
| 프로젝트 문서·코드 근거로 답하게 | Copilot Spaces | [[Copilot Spaces]] |
| PR 설명 자동 작성 | PR 요약(Copilot 아이콘 → Summary) | [[PR 요약]] |
| 선택 코드 단위 테스트 | /tests | [[채팅 명령, 참가자, 변수]] |
| 터미널 명령 도움 | @terminal | [[채팅 명령, 참가자, 변수]] |
| 조직에서 기능·모델 제한 | Settings → Copilot → Policies·Models | [[조직 Copilot 정책]] |
| 누가 정책을 바꿨나 | 감사 로그 action:copilot | [[Copilot 감사 로그]] |
| 좌석 부여 자동화 | REST API selected_users | [[Copilot 사용자 관리 REST API]] |
