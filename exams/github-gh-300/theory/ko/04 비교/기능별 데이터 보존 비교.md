# 기능별 데이터 보존 비교

| 기능 | 기본 보존(Business·Enterprise, Learn 모듈 기준) |
|---|---|
| IDE 코드 제안 | 제안 반환 후 프롬프트 폐기, 학습용 보존 없음 |
| IDE의 Copilot Chat | 기본 보존하지 않음 |
| Copilot CLI | 기본 보존하지 않음 |
| GitHub.com·GitHub Mobile의 Copilot | 최대 28일 |
| 감사 로그(설정·라이선스 이벤트) | 180일, 프롬프트는 없음 |

- 개인 요금제의 학습 사용은 설정 "Allow GitHub to use my data for AI model training"으로 정한다 → [[개인 Copilot 설정]].
- 정책은 바뀐다. 최신 값은 GitHub Copilot Trust Center에서 확인(변동 정보).
