# 콘텐츠 제외 vs 공개 코드 필터

| | [[콘텐츠 제외]] | [[공개 코드 일치 필터와 코드 참조\|공개 코드 일치 필터]] |
|---|---|---|
| 막는 방향 | 입력: 내 파일을 Copilot이 쓰지 않게 | 출력: 공개 코드와 같은 제안이 나오지 않게(또는 참조 표시) |
| 설정자 | 리포지토리 관리자, 조직·엔터프라이즈 소유자 | 개인(Free·Pro·Pro+·Max) 또는 조직 정책 |
| 요금제 | Business·Enterprise | 개인 설정 또는 조직 정책 |
| 단위 | 파일·경로·리포지토리(fnmatch) | 제안 단위(약 150자 비교) |
| 한계 | Edit·Agent 모드 미지원, 반영 최대 30분, 보안 경계 아님 | 공개 리포지토리 색인만, 몇 달마다 갱신 |

> [!question]- 비밀 키가 든 설정 파일을 Copilot 컨텍스트에서 빼고 싶다.
> 콘텐츠 제외. 다만 보안 경계가 아니므로 비밀은 원래 리포지토리에 두지 않는 편이 맞다〔해석〕.

> [!question]- 오픈 소스 라이선스 코드가 그대로 제안되는 것을 막고 싶다.
> 공개 코드 일치 필터를 Block으로.
