# 채팅 모드 비교(Ask·Plan·Agent·Edits)

| | Ask | Plan | Agent | [[Copilot Edits]](편집 모드) |
|---|---|---|---|---|
| 하는 일 | 질문 답변, 코드 제안 | 구현 계획 작성 | 자율 작업(파일 선택·편집·명령) | 지정 파일에 걸친 편집 제안 |
| 파일 변경 | 하지 않음 | 계획 중심 | 함 | 함(검토 후 수락) |
| 도구·터미널 | 쓰지 않음 | — | 씀(승인) | 〔해석〕 제한적 |
| 콘텐츠 제외 | 지원 | 문서에 없음 | **지원 안 함** | **지원 안 함** |

- 2026-11 VS Code 문서의 채팅 모드는 Agent·Plan·Ask다. 학습 가이드는 Copilot Edits를 여전히 언급한다.
- 테스트 전략을 묻기만 하려면 Ask, 테스트 파일을 실제로 만들고 돌리려면 Agent(Learn 테스트 모듈).

> [!question]- 파일을 바꾸지 않고 어떤 엣지 케이스를 테스트해야 하는지 목록만 받고 싶다.
> Ask 모드.
