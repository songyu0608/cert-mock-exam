# Obsidian 사용법

1. zip을 풀고 Obsidian에서 **Open folder as vault**로 `GH-300` 폴더를 연다.
2. 시작은 [[GH-300 대시보드]].
3. 접힌 칸(`> [!question]-`, `> [!quote]-`)은 클릭하면 펼쳐진다.
4. 플래시카드는 커뮤니티 플러그인 **Spaced Repetition**을 설치하면 `질문::답` 줄이 카드로 인식된다. 태그는 `#flashcards/gh-300/d1` ~ `d6`, `#flashcards/gh-300/terms`.
5. 그래프 뷰에서 태그 `#gh-300`으로 필터하면 전체 연결이 보인다.
6. 다른 플러그인은 필요 없다(표는 일반 Markdown).
