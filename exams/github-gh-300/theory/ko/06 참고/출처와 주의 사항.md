# 출처와 주의 사항

## 사용한 자료 (2026-11-07 확인)
- **Study guide for Exam GH-300: GitHub Copilot** (Microsoft Learn, 영어). 기술 목록 2026년 8월 7일 기준, 페이지 갱신 2026-07-09.
- 같은 학습 가이드의 **한국어 페이지**(learn.microsoft.com/ko-kr). 이론 노트의 "한국어 공식 안내서" 인용은 이 페이지 문구다.
- **GitHub Copilot 자격증 페이지**(Microsoft Learn): 수준, 시간, 언어, 유효 기간, 재응시, 대상 역할.
- 보충 근거: GitHub 공식 문서(docs.github.com) 약 25개 페이지, VS Code 문서 2개, GitHub 변경 로그(Spark), 학습 가이드가 공부 자료로 지정한 Microsoft Learn 교육 모듈(책임 있는 AI, 프롬프트 엔지니어링, 데이터, LLM, 개발자 사용 사례, 단위 테스트). 카드마다 링크를 달았다.

## 안내서·자격증 페이지에서 확인한 사실
- 도메인별 비중과 목표 문구(41개), 합격 700점, 시험 100분, 시험 언어 5개, 중급, 2년 유효, 24시간 뒤 재응시.
- 목표 문구의 한국어는 영어 원문을 이 볼트가 번역한 것이다.

## 안내서 표기 문제
- "Skills at a glance"에 "Use GitHub Copilot features (25–30%)"와 "GitHub Copilot features (25–30%)" 두 줄이 있다. 두 번째 줄은 세부 목표가 없고, 영어·한국어 페이지 모두 같다. 이 볼트는 중복 표기로 보고 6개 도메인으로 정리했다(해석). 비중 범위를 더하면 6개 도메인 기준 하한 80%, 상한 110%다.

## 안내서에 없음 · 확인하지 못함
- 문항 수, 한국 응시료.
- 샘플 문제: 안내서에 없다. 이 볼트의 질문은 모두 자작이다.
- 목표 번호(1.1 등).
- 실제 한국어 시험이 공식 안내서와 같은 용어(부조종사, 몇 샷, 극한 사례 등)를 쓰는지.
- Copilot Edits: 학습 가이드에는 있지만 2026-11 GitHub 기능 문서와 VS Code 채팅 모드(Agent·Plan·Ask) 안내에는 별도 항목이 없다. 카드에 〔해석〕으로 정리했다.
- 출력 관련 지식재산권 보장(indemnity) 조건은 확인하지 않았다.

## 해석과 변동 정보
- Microsoft Learn 교육 모듈의 일부 서술(예: 프롬프트 처리 흐름의 필터 단계, Chat 컨텍스트 창 크기)은 docs 문서보다 오래되었을 수 있다. 수치가 다른 경우 docs를 우선했고, 컨텍스트 창 수치는 싣지 않았다.
- 데이터 보존(28일 등)은 Learn 모듈이 밝힌 Business·Enterprise 기본값이다. 최신 값은 GitHub Copilot Trust Center에서 확인한다.
- 요금제 가격, AI 크레딧, 모델, 미리 보기 상태, GitHub Spark 지원 종료(2026-08), 개인 요금제의 학습 데이터 사용(2026-04-24부터)은 **변동 정보**다.
- 카드의 "시험 트리거", "오답 함정", 비교표, 판단 패턴은 공식 자료를 바탕으로 **정리한 해석**이다.
