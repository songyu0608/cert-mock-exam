# 출처와 주의 사항

## 사용한 자료 (2026-11-07 확인)
- **Study guide for Exam GH-900: GitHub Foundations** (Microsoft Learn, 영어). 기술 목록은 2026년 1월 기준, 페이지 갱신 2026-02-19.
- 같은 학습 가이드의 **한국어 페이지**(learn.microsoft.com/ko-kr). 이론 노트의 "한국어 공식 안내서" 인용은 이 페이지 문구다.
- **GitHub Foundations 자격증 페이지**(Microsoft Learn): 수준, 시간, 언어, 갱신, 재응시.
- 보충 내용의 근거: GitHub 공식 문서(docs.github.com) 약 60개 페이지와 GitHub 글 "What is innersource?". 카드마다 링크를 달았다.

## 안내서·자격증 페이지에서 확인한 사실
- 도메인 7개와 비중, 도메인별 목표 문구(36개), 합격 700점, 시험 100분, 시험 언어 5개, 갱신 없음, 24시간 뒤 재응시.
- 목표 문구의 한국어는 영어 원문을 이 볼트가 번역한 것이다. 이론 노트에 영어 원문과 한국어 공식 안내서 문구를 접어 두었다.

## 안내서에 없음 · 확인하지 못함
- 문항 수: 안내서·자격증 페이지에 없다.
- 응시료: "국가별로 다름"만 있다. 한국 가격은 확인하지 않았다.
- 샘플 문제: 안내서에 없다. 이 볼트의 질문은 모두 자작이다.
- 목표 번호(1.1 등): 안내서는 글머리 목록만 제시한다.
- 목표 2.4의 "리포지토리 지표 대시보드(repository metrics dashboards)": 이 이름의 GitHub 기능 문서를 찾지 못했다. 리포지토리 인사이트 카드에 〔해석〕으로 정리했다.
- 실제 한국어 시험 문항이 한국어 공식 안내서와 같은 용어(문제, 끌어오기 요청, 분기 등)를 쓰는지는 확인하지 못했다.

## 해석과 변동 정보
- 한국어 공식 안내서는 기계 번역으로 보인다. passkeys가 "암호"로, milestones가 "중요 시점"으로 옮겨진 것이 예다. 본문은 GitHub 화면에서 쓰는 용어(이슈, 풀 리퀘스트, 브랜치)를 쓰고, 공식 안내서 표기는 별칭과 [[용어 대조표]]에 넣었다.
- 카드의 "시험 트리거", "오답 함정", 비교표, 판단 패턴은 공식 문서를 바탕으로 **정리한 해석**이다. 시험이 이 세부까지 묻는다는 보장은 없다.
- Copilot 요금제 가격·포함 기능, Actions 포함 사용량, 미리 보기 기능 상태는 **변동 정보**다(2026-11 문서 기준). Actions 포함 사용량은 요금제 페이지(분 단위)와 청구 페이지(금액 단위)의 표기가 달라 카드에 숫자를 싣지 않았다.
- 학습 가이드는 영어판 변경이 현지화 버전에 약 8주 늦게 반영된다고 밝힌다. 응시 전 최신판을 확인한다.
