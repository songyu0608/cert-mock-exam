# 디스커션

> [!summary] 한 줄 정의
> 프로젝트 방향, 질문, 아이디어처럼 바로 실행할 작업이 아닌 열린 대화를 나누는 커뮤니티 공간.

**English** GitHub Discussions

## 시험 트리거
- "사용법 질문이 이슈 트래커를 어지럽힌다"
- "커뮤니티 의견을 투표로 묻고 싶다"
- "공지를 올릴 곳"

## 핵심
- 카테고리별로 대화. 공지(Announcements), Q&A(답변 채택), 설문(Polls), 일반 열린 대화.
- 열린 성격의 이슈를 디스커션으로 변환할 수 있다.
- 리포지토리 디스커션(그 리포지토리 주제)과 조직 디스커션(여러 리포지토리에 걸친 주제).
- 관리자가 켜야 하고, 켜면 접근 권한이 있는 누구나 참여. 고정(pin)으로 눈에 띄게 한다.
- 팀 디스커션은 종료되었고 조직 디스커션으로 대신한다 → [[팀]]. 한국어 공식 안내서는 "토론"으로 표기.
