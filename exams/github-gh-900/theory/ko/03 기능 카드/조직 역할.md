# 조직 역할

> [!summary] 한 줄 정의
> 조직 단위 역할: 소유자, 구성원, 중재자, 결제 관리자, 보안 관리자, GitHub App 관리자, 외부 협업자.

**English** Roles in an organization

## 시험 트리거
- "외부 컨설턴트에게 리포지토리 하나만 접근 허용"
- "결제 정보만 관리하는 담당자"
- "전체 리포지토리의 보안 알림을 보는 팀"

## 핵심
- 소유자(Owners): 조직 전체 관리 권한. 최소한으로 두되 2명 이상 권장.
- 구성원(Members): 기본 비관리 역할(리포지토리·프로젝트 생성 등).
- 중재자(Moderators): 비구성원 차단·해제, 상호작용 제한, 공개 리포지토리 코멘트 숨기기.
- 결제 관리자(Billing managers): 결제 설정. 보안 관리자(Security managers): 보안 알림 보기, 보안 설정 관리, 모든 리포지토리 읽기.
- GitHub App 관리자: 조직 소유 앱 등록 설정 관리(설치·제거는 불가).
- 외부 협업자(Outside collaborators): 구성원이 아니지만 일부 리포지토리에 접근(예: 컨설턴트).
- 조직 설정과 보안 기능은 소유자와 보안 관리자만 관리. 사용자 지정 조직 역할은 Enterprise Cloud.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 컨설턴트를 조직 구성원으로 초대해야만 리포지토리를 줄 수 있다는 선택지 → 외부 협업자
> - 조직 소유자를 한 명만 두는 것이 권장된다는 선택지 → 2명 이상

## 셀프 체크
> [!question]- 구성원이 아닌데 일부 리포지토리에 접근하는 사람의 역할은?
> 외부 협업자(outside collaborator)

> [!question]- 권장 최소 조직 소유자 수는?
> 2명

> [!question]- 모든 리포지토리의 보안 알림을 보고 보안 설정을 관리하는 역할은?
> 보안 관리자(security manager)
