# 리포지토리 공개 범위

> [!summary] 한 줄 정의
> 공개(누구나), 비공개(권한 받은 사람), 내부(엔터프라이즈 구성원 전체 읽기) 세 가지. 바꾸면 포크·스타·기능에 영향이 있다.

**English** Repository visibility (public, private, internal)

## 시험 트리거
- "사내 모든 직원이 코드를 볼 수 있게(외부엔 비공개)"
- "공개 리포지토리를 비공개로 바꾸려 한다"
- "비공개를 공개로 전환"

## 핵심
- 공개: GitHub.com을 방문하는 누구나 본다. 이용 약관에 따라 포크 가능.
- 내부(internal): 엔터프라이즈 구성원 모두에게 읽기 권한. Enterprise 요금제 기능 → [[InnerSource]].
- 비공개 전환 시: 공개 포크는 분리되어 공개로 남는다. Free는 일부 기능을 잃고 Pages가 내려간다. 스타·워처가 지워진다.
- 공개 전환 시: 누구나 포크 가능, Actions 기록·로그가 공개, 비공개 포크는 분리, 스타·워처가 지워진다.
- 변경: Settings > Danger Zone > Change visibility. 조직 소유자가 변경 권한을 소유자로 제한할 수 있다.
- 한국어 공식 안내서는 "개인 정보 옵션, 표시 유형 설정"으로 표기.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 공개 리포지토리를 비공개로 바꾸면 기존 공개 포크도 비공개가 된다는 선택지 → 분리되어 공개로 남는다
> - 사내 전체 공개에 public을 쓴다는 선택지 → internal
