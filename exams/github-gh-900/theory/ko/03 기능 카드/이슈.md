# 이슈

> [!summary] 한 줄 정의
> 버그, 기능 아이디어, 작업을 계획·논의·추적하는 단위. 레이블·마일스톤·담당자·프로젝트와 연결된다.

**English** GitHub Issues

## 시험 트리거
- "버그를 보고하고 해결까지 추적"
- "큰 작업을 작은 단위로 나누고 싶다"
- "이 작업이 다른 작업에 막혀 있다"

## 핵심
- 만드는 곳: 리포지토리, 이슈·PR 코멘트를 변환, 코드 특정 줄, URL 쿼리, Desktop·CLI·API·Mobile.
- 하위 이슈(sub-issues)로 여러 단계 중첩 분해. 이슈 종속성으로 막힘(blocked by)·막는 관계 표시.
- 정리: 이슈 유형, 레이블, 마일스톤, 담당자 → [[레이블과 마일스톤]] · [[담당자]].
- 다른 이슈·PR에서 #번호로 언급하면 참조가 생긴다. PR 본문의 닫기 키워드로 자동 종료 → [[PR과 이슈 연결]].
- 논의 성격이면 디스커션으로 변환할 수 있다 → [[디스커션]]. 한국어 공식 안내서는 이슈를 "문제"로 표기.
