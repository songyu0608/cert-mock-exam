# GitHub Desktop

> [!summary] 한 줄 정의
> 명령줄 대신 그래픽 화면으로 Git 작업(클론, 브랜치, 커밋, 푸시)을 하는 무료 오픈 소스 데스크톱 앱. Windows·macOS용.

**English** GitHub Desktop

## 시험 트리거
- "Git 명령어에 익숙하지 않은 팀원"
- "변경 줄을 골라 커밋하고 싶다"
- "PR을 로컬에서 체크아웃해 확인"

## 핵심
- 무료·오픈 소스, Windows와 macOS용.
- 리포지토리 내려받기, 브랜치 만들기, 커밋, 푸시. 커밋할 줄을 골라 담고 공동 작성자를 추가할 수 있다.
- 별도 자격 증명 관리자 없이 GitHub·GitHub Enterprise에 인증.
- PR을 체크아웃해 브라우저를 열지 않고 확인할 수 있다.
- 공식 문서: Git·GitHub 초보자에게 맞고(변경을 시각화), 문법을 외우지 않고 덜 쓰는 명령을 쓰려는 숙련자에게도 맞다.
