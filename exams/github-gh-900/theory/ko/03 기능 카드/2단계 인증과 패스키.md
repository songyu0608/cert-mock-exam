# 2단계 인증과 패스키

> [!summary] 한 줄 정의
> 비밀번호 외에 두 번째 인증 수단(TOTP 앱, SMS, 보안 키, GitHub Mobile)을 요구하는 2FA와, 비밀번호와 2FA를 한 번에 만족하는 패스키로 계정을 보호한다.

**English** Two-factor authentication (2FA) and passkeys

## 시험 트리거
- "비밀번호가 유출돼도 계정을 지키고 싶다"
- "비밀번호 없이 한 번에 안전하게 로그인"
- "조직 구성원 전원에게 2FA를 강제"

## 핵심
- 2FA 수단: 인증 앱(TOTP), 문자(SMS), 보안 키(WebAuthn: 하드웨어 키, Touch ID, Windows Hello), GitHub Mobile. 보안 키와 GitHub Mobile은 TOTP나 SMS를 먼저 설정한 뒤 추가.
- 패스키: 비밀번호와 2FA 요구를 둘 다 만족해 한 단계로 로그인. 잠김에 대비해 TOTP·SMS 같은 대체 수단을 유지하라고 권장.
- 복구 코드: 설정 때 내려받아 보관. 2FA 수단과 복구 수단을 모두 잃으면 GitHub 지원도 계정을 복구해 주지 못한다.
- 2023년 3월부터 GitHub.com에 코드를 기여하는 사용자에게 2FA 필수(대상자 45일 등록 기간).
- 조직 소유자는 구성원, 결제 관리자, 외부 협업자에게 2FA를 요구할 수 있다.
- 한국어 공식 안내서는 passkeys를 "암호"로 옮겼다(오역으로 보임). 패스키를 뜻한다.

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 2FA를 잃어도 GitHub 지원이 본인 확인 후 복구해 준다는 선택지 → 복구 코드·복구 수단이 없으면 복구 불가
> - 패스키를 쓰면 2FA가 따로 필요하다는 선택지 → 패스키가 비밀번호와 2FA를 둘 다 만족
