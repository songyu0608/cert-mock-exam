# 위키

> [!summary] 한 줄 정의
> 리포지토리마다 하나씩 있는 긴 프로젝트 문서 공간. README보다 긴 사용 설명·설계 문서를 둔다.

**English** Wikis

## 시험 트리거
- "README가 너무 길어졌다"
- "검색 엔진에 문서가 노출되어야 한다"
- "외부인도 문서를 편집하게"

## 핵심
- 리포지토리마다 위키 하나. Markdown 등 GitHub이 지원하는 형식으로 작성.
- 요금제: Free는 공개 리포지토리, Pro·Team·Enterprise는 비공개 리포지토리에서도.
- 편집: 기본은 쓰기 권한이 있는 사람. 공개 리포지토리는 모든 GitHub 사용자에게 편집을 열 수 있다.
- 검색 엔진은 스타 500개 이상이고 공개 편집을 막은 위키만 색인한다. 검색 노출이 필요하면 GitHub Pages 권장.
- 파일 5,000개 소프트 한도. 더 크면 Pages 권장.
