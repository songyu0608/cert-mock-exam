# 템플릿 리포지토리

> [!summary] 한 줄 정의
> 디렉터리 구조와 파일을 복사해 새 리포지토리를 시작하게 하는 리포지토리. 포크와 달리 원본과 이력이 이어지지 않는다.

**English** Template repositories

## 시험 트리거
- "팀마다 같은 초기 구조로 새 프로젝트를 시작"
- "원본에 변경을 돌려보낼 필요는 없다"
- "보일러플레이트를 배포"

## 핵심
- 관리자 권한이 있는 사람이 Settings에서 Template repository를 켠다.
- 복사되는 것: 기본 브랜치의 디렉터리 구조와 파일(선택하면 다른 브랜치도).
- 복사되지 않는 것: Git LFS 파일. 새 리포지토리는 원본과 관련 없는 이력이라 원본으로 PR·병합할 수 없다.
- 〔해석〕 포크는 원본에 기여(PR)하려는 용도, 템플릿은 같은 구조로 새 독립 프로젝트를 시작하는 용도.

## 헷갈리는 개념
| 개념 | 차이 |
|---|---|
| [[포크]] | 원본과 이어진 사본(기여용) vs 독립된 새 리포지토리(시작점) |

## 오답 함정
> [!warning] 템플릿으로 만든 리포지토리에서 원본으로 PR을 보낼 수 있다는 선택지 → 이력이 관련 없어 불가
