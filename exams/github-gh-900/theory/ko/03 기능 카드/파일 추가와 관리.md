# 파일 추가와 관리

> [!summary] 한 줄 정의
> 브라우저(Add file > Upload files·새 파일)나 명령줄(git add·commit·push)로 파일을 추가하고, 커밋으로 변경을 기록한다.

**English** Adding and managing files

## 시험 트리거
- "브라우저로 큰 파일을 올리려 한다"
- "100MiB가 넘는 파일"
- "기본 브랜치에 바로 커밋해도 되나"

## 핵심
- 브라우저 업로드: 파일당 25MiB, 한 번에 100개까지. 커밋 메시지와 브랜치를 고르고 Propose changes.
- 기본 브랜치에서 작업 중이면 새 브랜치에 커밋하고 PR을 여는 것을 권장 → [[GitHub 플로]].
- 명령줄: 파일당 100MiB까지(git add → git commit → git push). 100MiB 초과는 Git LFS.
- 보호된 브랜치는 웹에서 편집·업로드할 수 없다. 푸시 보호는 토큰 같은 비밀이 든 파일을 막는다.
- 이름 변경·이동·삭제도 커밋으로 기록된다(이력 보존).
