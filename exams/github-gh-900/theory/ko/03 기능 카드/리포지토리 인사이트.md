# 리포지토리 인사이트

> [!summary] 한 줄 정의
> Insights 탭의 Pulse, Contributors, Traffic, Commits, Code frequency, Network 그래프로 리포지토리 활동과 건강도를 본다.

**English** Repository insights and graphs

## 시험 트리거
- "최근 일주일 동안 무슨 일이 있었는지 요약"
- "누가 가장 많이 기여했나"
- "방문자·클론 수"

## 핵심
- Pulse: 기간별 활동 요약(병합된 PR, 열린·닫힌 이슈 등). 프로젝트가 활발히 유지되는지 볼 때도 쓴다.
- Contributors(기여자), Traffic(방문·클론), Commits, Code frequency(추가·삭제량), Network(브랜치·포크 네트워크).
- 요금제: Free는 이 그래프들을 공개 리포지토리에서만, Pro·Team·Enterprise Cloud는 비공개 리포지토리에서도.
- 일부 그래프는 커밋 10,000개 미만 리포지토리에서만 제공.
- 〔해석〕 가이드의 "리포지토리 지표 대시보드(repository metrics dashboards)"가 가리키는 정확한 기능은 공식 문서에서 특정하지 못했다. Insights 그래프로 대비한다.
