# 프로젝트 자동화

> [!summary] 한 줄 정의
> Projects의 내장 워크플로로 항목이 추가·닫힘·병합될 때 상태를 바꾸고, 조건에 맞는 항목을 자동 추가·보관한다.

**English** Project built-in automations (workflows)

## 시험 트리거
- "이슈를 닫으면 상태가 Done으로 바뀌게"
- "특정 레이블 이슈를 프로젝트에 자동으로 넣기"
- "오래된 완료 항목을 정리"

## 핵심
- 항목 추가 → 상태 Todo, 이슈·PR 닫힘 → Done, PR 병합 → Done, 상태 변경 → 이슈 닫기.
- 자동 추가: 리포지토리에서 필터에 맞는 항목을 추가. 자동 보관: 조건에 맞는 항목을 보관.
- 프로젝트를 만들면 "닫힘 → Done"과 "PR 병합 → Done" 두 개가 기본으로 켜져 있다.
- 더 복잡한 자동화는 GraphQL API와 GitHub Actions.

## 오답 함정
> [!warning] 프로젝트를 만들면 모든 내장 워크플로가 꺼져 있다는 선택지 → 닫힘·병합 → Done 두 개는 기본으로 켜짐
