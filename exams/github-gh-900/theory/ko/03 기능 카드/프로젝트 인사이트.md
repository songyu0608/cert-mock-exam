# 프로젝트 인사이트

> [!summary] 한 줄 정의
> Projects 항목 데이터로 현재 상태 차트와 시간에 따른 변화(과거) 차트를 만들어 진행과 생산성을 추적하는 기능.

**English** Insights for Projects

## 시험 트리거
- "담당자별 작업량을 차트로"
- "남은 작업과 완료 작업의 추이"
- "반복(스프린트)별 이슈 수"

## 핵심
- 현재 차트: 지금 상태(예: 담당자별 항목 수, 반복별 이슈 수).
- 과거 차트: X축을 시간(Time)으로 두어 변화 추이를 본다. 기본 차트는 번업(Burn up): 완료한 작업 대 남은 작업.
- 필터와 차트 유형을 바꿔 사용자 지정. 만든 차트는 프로젝트를 볼 수 있는 누구나 본다.
- 보관·삭제된 항목은 추적하지 않는다.
