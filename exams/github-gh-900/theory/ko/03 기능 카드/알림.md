# 알림

> [!summary] 한 줄 정의
> 구독한 대화와 활동 소식을 웹 알림함, 이메일, GitHub Mobile로 받고, Done·Save·구독 해제로 정리하는 기능.

**English** Notifications

## 시험 트리거
- "리뷰 요청만 골라 보고 싶다"
- "알림이 너무 많다"
- "나중에 다시 볼 알림을 보관"

## 핵심
- 자동 구독: 할당됨, 이슈·PR을 엶, 코멘트, @멘션(또는 내 팀 멘션), Watch·Subscribe 클릭, 상태 변경(닫기·병합).
- 푸시 권한이 있는 리포지토리는 자동 워치(포크 제외). 내가 만든 리포지토리는 기본 워치.
- 전달: github.com/notifications 알림함, 이메일, GitHub Mobile(푸시 예약 가능) 조합.
- 정리: Done(is:done), Save(is:saved), 읽음 표시, 구독 해제(이후 멘션되면 다시 받음). reason:review-requested 같은 이유 필터, 사용자 지정 필터.
- 보관: 저장하지 않은 알림은 3개월, 저장한 알림은 무기한.

> [!warning] 구독을 해제하면 이후 멘션돼도 알림이 오지 않는다는 선택지 → 다시 멘션되면 알림이 온다
