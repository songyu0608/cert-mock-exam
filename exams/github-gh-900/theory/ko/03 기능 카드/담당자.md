# 담당자

> [!summary] 한 줄 정의
> 이슈·PR의 책임자를 지정해 누가 일하는지 분명히 하는 기능. 최대 10명, Copilot에 할당할 수도 있다.

**English** Assignees

## 시험 트리거
- "이 이슈를 누가 처리하는지 모호하다"
- "Copilot이 이슈를 맡아 PR을 만들게"

## 핵심
- 이슈·PR당 최대 10명.
- 할당 가능 대상: 자신, 해당 이슈·PR에 코멘트한 사람, 쓰기 권한자, 읽기 권한이 있는 조직 구성원.
- 쓰기 권한이 있으면 할당할 수 있다.
- Copilot에 이슈를 할당하면 자율적으로 작업해 PR을 만들고 리뷰를 요청한다(권한·요금제에 따라) → [[GitHub Copilot 기능]].
- 할당되면 자동으로 알림이 구독된다 → [[알림]].

> [!warning] 이슈 하나에 담당자를 무제한 지정한다는 선택지 → 최대 10명
