# 기능 미리 보기

> [!summary] 한 줄 정의
> 공개 미리 보기 상태의 기능을 개인 계정에서 켜고 끄는 메뉴(프로필 사진 > Feature preview).

**English** Feature preview

## 시험 트리거
- "새 기능을 먼저 써 보고 싶다"
- "미리 보기 기능에 SLA가 있나"

## 핵심
- 위치: 오른쪽 위 프로필 사진 > Feature preview. 기능별 Enable/Disable, 피드백 링크.
- 단계: 비공개 미리 보기(개발 중, SLA·지원 없음) → 공개 미리 보기(문서화, SLA·지원 없음) → GA(일반 공급, SLA·지원).
- 시험 범위: 대부분 GA 기능이고, 널리 쓰이는 미리 보기 기능도 나올 수 있다(학습 가이드).

## 오답 함정
> [!warning] 공개 미리 보기 기능도 SLA와 기술 지원이 있다는 선택지 → GA부터
