# GitHub Mobile

> [!summary] 한 줄 정의
> iOS·Android 앱으로 알림을 분류하고, 이슈·PR을 읽고 리뷰하며, 2FA·로그인 확인에 쓰는 이동용 도구.

**English** GitHub Mobile

## 시험 트리거
- "이동 중에 알림을 정리하고 PR을 리뷰"
- "멘션되면 푸시 알림을 받고 싶다"
- "휴대폰으로 로그인 승인"

## 핵심
- 알림 관리·분류·정리, 이슈·PR 읽기·리뷰·협업(PR 안 파일 편집 포함), 사용자·리포지토리·조직 검색, 리포지토리 안 코드 검색.
- 멘션되면 푸시 알림. Copilot Chat으로 질문하고 이슈를 Copilot에 할당할 수 있다.
- 2FA 구성, 새 기기 로그인 시도 확인, 앱으로 GitHub 인증 → [[2단계 인증과 패스키]].
- 언어: 영어, 스페인어, 일본어, 브라질 포르투갈어, 중국어 간체, 한국어, 독일어.
- 제약: VPN이 필요한 엔터프라이즈에서는 동작하지 않을 수 있다.
