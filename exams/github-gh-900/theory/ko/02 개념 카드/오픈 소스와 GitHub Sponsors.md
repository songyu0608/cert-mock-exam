# 오픈 소스와 GitHub Sponsors

> [!summary] 한 줄 정의
> 오픈 소스는 누구나 코드를 보고 쓰고 고치고 기여할 수 있게 공개하는 방식이고, GitHub Sponsors는 그런 개발자·조직을 금전적으로 후원하는 기능이다.

**English** Open source and GitHub Sponsors

## 시험 트리거
- "내가 쓰는 오픈 소스 메인테이너를 금전적으로 돕고 싶다"
- "후원 등급(티어)별 금액"
- "일회성 또는 매월 후원"

## 핵심
- 오픈 소스의 이점: 코드 재사용, 여러 사람의 리뷰로 품질 향상, 투명성, 커뮤니티 학습과 기여. 〔해석〕 안내서는 "이점"만 언급하고 목록은 제시하지 않는다. 이 목록은 InnerSource 글이 설명하는 오픈 소스 관행 이점을 바탕으로 정리했다.
- 재사용 권리는 라이선스가 정한다. 라이선스가 없으면 기본 저작권이 적용되어 재사용 권리가 없다 → [[LICENSE]].
- Sponsors: 후원 프로필(sponsored profile)이 있는 개발자·조직을 후원. 받는 쪽은 지원 지역(약 100개국)에 있어야 한다.
- 후원 방식: 등급(tier)을 골라 일회성 또는 매월.
- 수수료: 개인 계정의 후원은 수수료 없음. 조직 계정의 후원은 최대 6%(카드 3% + 서비스 3%), 청구서(invoice) 결제는 카드 수수료가 없다. (변동 정보)
- 리포지토리에 FUNDING.yml을 두면 후원 버튼을 표시할 수 있다 → [[커뮤니티 상태 파일]].

## 오답 함정
> [!warning] 오답이 되기 쉬운 선택지
> - 개인 계정의 후원에도 GitHub가 수수료를 뗀다는 선택지 → 개인 후원은 수수료 없음(조직 후원만 최대 6%)
> - 후원은 매월 정기 결제만 가능하다는 선택지 → 일회성도 가능
