# Git과 GitHub의 차이

> [!summary] 한 줄 정의
> Git은 버전 관리 도구 자체이고, GitHub는 Git 리포지토리를 호스팅하면서 이슈·풀 리퀘스트·코드 리뷰 같은 협업 기능을 더한 플랫폼이다.

**English** Git vs GitHub

## 시험 트리거
- "Git을 설치하지 않고 GitHub만 쓸 수 있나"
- "풀 리퀘스트는 Git 기능인가"
- "로컬에서 커밋한다"

## 핵심
- Git: 로컬에서 동작하는 분산 버전 관리 도구. 커밋·브랜치·병합은 Git의 기능이다.
- GitHub: Git 리포지토리 호스팅 + 이슈, 풀 리퀘스트, 코드 리뷰, 앱·통합 마켓플레이스 같은 협업 기능.
- 〔해석〕 시험 구분법: 이력·스냅샷·브랜치 같은 버전 관리 동작은 Git, 사람 사이의 협업·관리 기능(이슈, PR, Actions, Projects)은 GitHub.
