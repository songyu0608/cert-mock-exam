# 오픈 소스 지원 기능

> [!summary] 한 줄 정의
> GitHub가 공개 리포지토리에 무료로 주는 자동화·보안·커뮤니티 기능으로 오픈 소스 프로젝트를 지원하는 방식.

**English** How GitHub supports open-source projects

## 시험 트리거
- "공개 리포지토리에서 CI를 무료로"
- "오픈 소스 프로젝트의 보안 점검"
- "커뮤니티 질문과 공지를 한곳에"

## 핵심
- Actions: 공개 리포지토리에서 표준 GitHub 호스트 러너는 무료 → [[GitHub Actions]]. (변동 정보)
- 보안: 공개 리포지토리는 코드 스캐닝·비밀 스캐닝이 무료이고 기본으로 켜져 있다. 종속성 그래프와 Dependabot 경고는 모든 요금제 → [[GitHub Advanced Security]].
- 커뮤니티: [[디스커션]], 이슈·PR 템플릿, 커뮤니티 상태 파일, good first issue 레이블.
- 공유·홍보: [[GitHub Pages]](무료 요금제는 공개 리포지토리만), 토픽·Explore·Trending으로 발견되기 쉬움 → [[오픈 소스 프로젝트 탐색]].
- 자금: [[오픈 소스와 GitHub Sponsors]].
- 〔해석〕 "지원 방식"을 한 페이지로 정리한 공식 문서는 찾지 못했다. 각 기능 문서의 공개 리포지토리 조건을 모은 것이다.
