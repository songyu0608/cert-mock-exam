# 이슈·풀 리퀘스트·디스커션 비교

| | [[이슈]] | [[풀 리퀘스트]] | [[디스커션]] |
|---|---|---|---|
| 목적 | 해야 할 일 추적(버그, 기능, 작업) | 코드 변경 제안·리뷰·병합 | 열린 대화(질문, 아이디어, 공지) |
| 코드 변경 | 없음 | 있음(브랜치 간 비교) | 없음 |
| 상태 | 열림·닫힘(완료·계획 안 함·중복) | 초안·열림·병합·닫힘 | 답변 표시(Q&A), 고정 |
| 계획 도구 연결 | 담당자, 레이블, 마일스톤, Projects, 하위 이슈 | 리뷰어, 상태 확인, 연결된 이슈 | 카테고리, 투표(poll) |
| 연결·변환 | 이슈를 디스커션으로 변환 가능 | 이슈와 연결(Closes #번호) | 이슈에서 변환되어 올 수 있음 |

**판별**: 끝나야 할 일인가? → 이슈. 코드를 바꾸나? → 풀 리퀘스트. 결론이 정해지지 않은 대화·질문인가? → 디스커션.

> [!question]- 사용자들이 "이 기능을 어떻게 쓰나요?" 질문을 이슈로 올려 이슈 목록이 혼잡하다.
> 디스커션(Q&A 카테고리)을 켜고 질문 이슈는 디스커션으로 변환한다.
