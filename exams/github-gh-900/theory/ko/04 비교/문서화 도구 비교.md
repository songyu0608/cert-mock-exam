# 문서화 도구 비교

| | [[README]] | [[위키]] | [[GitHub Pages]] | [[Gist]] |
|---|---|---|---|---|
| 무엇 | 리포지토리 첫 화면 소개 | 리포지토리에 딸린 긴 문서 공간 | 리포지토리에서 정적 웹사이트 호스팅 | 코드 조각·짧은 글을 담는 작은 Git 리포지토리 |
| 단위 | 리포지토리(폴더별 README 가능) | 리포지토리당 하나 | 사용자·조직 사이트 계정당 1개, 프로젝트 사이트 리포지토리당 1개 | 개인 계정 |
| 공개 | 리포지토리 공개 범위를 따름 | Free는 공개 리포지토리만, Pro 이상은 비공개도 | Free는 공개 리포지토리만, Pro 이상은 비공개도 | 공개(Discover·검색됨) 또는 비밀(목록에 없지만 URL로 접근 가능) |
| 검색 엔진 | 리포지토리 페이지로 노출 | 스타 500개 이상 + 공개 편집 해제일 때만 색인 | 웹사이트로 색인 | 공개 gist는 검색 가능 |
| 맞는 상황 | 프로젝트가 무엇이고 어떻게 쓰나 | 사용 가이드·설계 문서 | 문서 사이트·포트폴리오·프로젝트 홈페이지 | 스니펫·설정 예·짧은 메모 공유 |

**판별**: 첫 화면 안내 → README. 길고 여러 페이지인 문서 → 위키. 외부에 웹사이트로 공개·검색 노출 → Pages. 리포지토리 없이 조각만 공유 → Gist.

> [!warning] 비밀(secret) gist는 비공개가 아니다. URL을 아는 누구나 볼 수 있다.

> [!question]- 위키 내용이 검색 엔진에 잘 노출되지 않는다. 대안은?
> GitHub Pages. 위키는 스타 500개 이상이고 공개 편집이 꺼진 경우에만 색인된다.
