# Copilot 요금제 비교

| | 개인용(Free·Pro·Pro+ 등) | Business | Enterprise |
|---|---|---|---|
| 구매 주체 | 개인 | 조직·엔터프라이즈(좌석 단위) | GitHub Enterprise Cloud 엔터프라이즈(좌석 단위) |
| 가격(2026-11 문서) | Free 무료, Pro $10/월, Pro+ $39/월 | $19/좌석/월 | $39/좌석/월 |
| 중앙 관리·정책 | 없음 | 있음 | 있음(엔터프라이즈 정책이 조직 정책보다 우선) |
| 관리 기능 | 해당 없음 | 정책·접근 관리, 사용 데이터, 감사 로그, 파일 제외 | Business와 같은 관리 기능 + 엔터프라이즈 단위 |
| 클라우드 에이전트 | Free 제외 유료 개인 요금제 | 관리자가 정책으로 켬 | 관리자가 정책으로 켬 |

**판별**: "회사가 직원 Copilot을 중앙에서 관리" → Business 이상. "GHEC 엔터프라이즈 전체" → Enterprise. "개인 개발자 혼자" → 개인용.

> [!warning] 가격·요금제 이름·포함 사용량은 자주 바뀐다(변동 정보). 시험은 "누가 사고 누가 관리하나"의 구분을 묻는다고 보는 편이 안전하다〔해석〕.

> [!question]- 조직 소유자가 공개 코드와 일치하는 제안을 막는 정책을 걸고 싶다. 필요한 요금제는?
> Copilot Business 또는 Enterprise. 정책 관리는 이 두 요금제의 조직·엔터프라이즈 소유자 기능이다.
