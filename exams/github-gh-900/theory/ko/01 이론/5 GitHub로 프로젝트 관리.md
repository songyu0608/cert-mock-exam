# 도메인 5　GitHub로 프로젝트 관리

**English** Domain 5: Manage projects with GitHub  
**한국어 공식 안내서** GitHub를 사용하여 프로젝트 관리

도메인 5 (5–10%) · 목표 4개

GitHub Projects의 레이아웃과 필드, 레이블·마일스톤, 내장 워크플로, 저장된 답글·담당자, 프로젝트 인사이트를 다룬다.

> [!abstract] 프로젝트 추적과 정리
> Project tracking and organization · 프로젝트 추적 및 조직

## 목표 5.1

**GitHub Projects와 레이아웃 옵션을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe GitHub Projects and layout options
>
> GitHub 프로젝트 및 레이아웃 옵션 설명

Projects는 이슈·PR과 양방향으로 동기화되는 계획 도구로 테이블·보드·로드맵 레이아웃과 사용자 지정 필드(텍스트, 숫자, 날짜, 단일 선택, 반복)를 쓴다.

관련 카드: [[GitHub Projects]]

## 목표 5.2

**프로젝트, 레이블, 마일스톤, 워크플로를 구성하는 방법을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Explain how to configure projects, labels, milestones, and workflows
>
> 프로젝트, 레이블, 중요 시점 및 워크플로를 구성하는 방법 설명

레이블(분류), 마일스톤(마감일·완료율), 내장 워크플로(닫힘·병합 → Done, 자동 추가·보관)를 설정한다.

관련 카드: [[GitHub Projects]] · [[프로젝트 자동화]] · [[레이블과 마일스톤]]

## 목표 5.3

**저장된 답글과 담당자로 소통을 간소화하는 방법을 식별한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Identify how to use saved replies and assignees to streamline communication
>
> 저장된 회신 및 담당자를 사용하여 통신을 간소화하는 방법 식별

저장된 답글(개인 계정, 최대 100개)로 반복 답변을 줄이고, 담당자(최대 10명, Copilot 포함)로 책임을 분명히 한다.

관련 카드: [[저장된 답글]] · [[담당자]]

## 목표 5.4

**프로젝트 인사이트로 진행 상황과 생산성을 추적하는 방법을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe how project insights can be used to track progress and productivity
>
> 프로젝트 인사이트를 사용하여 진행률 및 생산성을 추적하는 방법 설명

프로젝트 인사이트로 현재 상태 차트와 시간 축의 과거 차트(기본 번업)를 만들어 진행과 생산성을 추적한다.

관련 카드: [[프로젝트 인사이트]]

## 요약
- 레이아웃 3종: 테이블 · 보드 · 로드맵.
- 기본 켜진 워크플로: 닫힘 → Done, PR 병합 → Done.
- 레이블 생성 = 쓰기 권한, 적용 = Triage 이상.
- 기본 과거 차트 = 번업.

## 이 도메인의 카드
- [[GitHub Projects]] — 이슈와 PR을 바탕으로 테이블·보드·로드맵 레이아웃과 사용자 지정 필드로 작업을 계획·추적하는 도구. 이슈와 양방향으로 동기화된다.
- [[프로젝트 자동화]] — Projects의 내장 워크플로로 항목이 추가·닫힘·병합될 때 상태를 바꾸고, 조건에 맞는 항목을 자동 추가·보관한다.
- [[레이블과 마일스톤]] — 레이블은 이슈·PR·디스커션을 분류하는 태그, 마일스톤은 이슈·PR 묶음의 마감일과 완료율로 진행을 추적하는 목표 단위.
- [[저장된 답글]] — 자주 쓰는 답글을 개인 계정에 저장해 이슈·PR·디스커션에서 재사용하는 기능.
- [[담당자]] — 이슈·PR의 책임자를 지정해 누가 일하는지 분명히 하는 기능. 최대 10명, Copilot에 할당할 수도 있다.
- [[프로젝트 인사이트]] — Projects 항목 데이터로 현재 상태 차트와 시간에 따른 변화(과거) 차트를 만들어 진행과 생산성을 추적하는 기능.
