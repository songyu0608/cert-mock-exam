# 도메인 4　최신 개발 방식 적용

**English** Domain 4: Apply modern development practices  
**한국어 공식 안내서** 최신 개발 방법 적용

도메인 4 (10–15%) · 목표 5개

GitHub Actions의 자동화, Copilot의 AI 지원과 요금제, Codespaces·개발 컨테이너, github.dev를 다룬다. 2026년 1월 개정에서 Copilot 에이전트·에이전트 모드·다중 모델이 명시되었다.

> [!abstract] 자동화와 AI 도구
> Automation and AI tools · 자동화 및 AI 도구

## 목표 4.1

**GitHub Actions의 목적과 기능을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe the purpose and capabilities of GitHub Actions
>
> GitHub Actions의 목적 및 기능 설명

Actions는 이벤트(push, pull_request, schedule, 수동 등)로 시작되는 YAML 워크플로(.github/workflows)로 CI/CD와 이슈 분류 같은 자동화를 한다. 작업(job)은 러너에서 실행되고 기본적으로 병렬이다.

관련 카드: [[GitHub Actions]] · [[GitHub Marketplace]]

## 목표 4.2

**GitHub Copilot이 Copilot 에이전트, 에이전트 모드, 다중 모델 지원을 포함해 AI 코드 제안을 어떻게 돕는지 식별한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Identify how GitHub Copilot assists with AI-powered code suggestions, including Copilot agents, Agent Mode, and multi‑model support
>
> GitHub Copilot가 코필로트 에이전트, 에이전트 모드 및 다중 모델 지원을 비롯한 AI 기반 코드 제안을 지원하는 방법 식별

Copilot은 코드 완성·다음 편집 제안, Chat, IDE의 에이전트 모드(파일 선택·편집·명령 제안 반복), 클라우드 에이전트(이슈를 맡아 브랜치에서 작업하고 PR 생성), 코드 리뷰를 제공한다. 요금제·정책에 따라 여러 모델을 고를 수 있다.

관련 카드: [[GitHub Copilot 기능]]

## 목표 4.3

**개인용, Business, Enterprise용 GitHub Copilot의 차이를 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Explain the differences between GitHub Copilot for Individuals, Business, and Enterprise
>
> 개인, 비즈니스 및 엔터프라이즈용 GitHub Copilot의 차이점 설명

개인용(Free·Pro·Pro+ 등)은 개인이 구독하고, Business는 조직이 좌석 단위로 사서 중앙 관리·정책을 쓰며, Enterprise는 GitHub Enterprise Cloud 엔터프라이즈 대상이다. 가격은 변동 정보.

관련 카드: [[GitHub Copilot 요금제]] · [[Copilot 정책 관리]]

## 목표 4.4

**GitHub Codespaces와 개발 컨테이너의 설정, 사용자 지정, 사용 방법을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe GitHub Codespaces and how to set up, customize, and use dev containers
>
> GitHub Codespaces 및 개발 컨테이너 설정, 사용자 지정 및 사용 방법 설명

Codespaces는 GitHub 호스팅 VM의 컨테이너에서 도는 클라우드 개발 환경이다. devcontainer.json으로 이미지·기능·확장을 지정해 모두에게 같은 환경을 준다. 기본 30분 비활동 정지, 30일 보존.

관련 카드: [[GitHub Codespaces]]

## 목표 4.5

**github.dev 편집기를 언제 쓰는지, Codespaces와 어떻게 다른지 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Explain when to use the github.dev editor and how it differs from Codespaces
>
> github.dev 편집기를 사용하는 시기와 Codespaces와 어떻게 다른지 설명합니다.

github.dev는 . 키로 여는 무료 브라우저 편집기로 컴퓨팅이 없다. 실행·터미널·디버그가 필요하면 Codespaces를 쓴다.

관련 카드: [[GitHub Codespaces]] · [[github.dev]]

## 요약
- Actions: 이벤트 → 워크플로(YAML) → 작업(job) → 단계(step), 러너에서 실행.
- Copilot 에이전트 모드 = IDE 안, 클라우드 에이전트 = GitHub에서 PR 생성.
- Copilot 중앙 정책 관리 = Business·Enterprise.
- github.dev = 편집만·무료, Codespaces = 실행 가능·사용량 과금.

## 이 도메인의 카드
- [[GitHub Actions]] — 리포지토리 이벤트(푸시, PR, 이슈 생성 등)나 일정·수동 실행으로 YAML 워크플로를 돌려 빌드·테스트·배포와 각종 자동화를 하는 CI/CD 플랫폼.
- [[GitHub Copilot 기능]] — AI 코드 제안(완성·다음 편집 제안), Chat, IDE의 에이전트 모드, GitHub 위의 클라우드 에이전트, 코드 리뷰, 여러 모델 선택을 제공하는 AI 개발 도구.
- [[GitHub Copilot 요금제]] — 개인용(Free·Pro 등)은 개인이 구독하고, Business는 조직·엔터프라이즈가 사용자별로 구매해 중앙 관리·정책을 쓰며, Enterprise는 GitHub Enterprise Cloud용 상위 요금제다.
- [[GitHub Codespaces]] — GitHub가 호스팅하는 VM 위 Docker 컨테이너에서 도는 클라우드 개발 환경. devcontainer.json으로 모두에게 같은 환경을 준다.
- [[github.dev]] — 리포지토리에서 . 키를 누르면 열리는 브라우저 전용 경량 편집기. 무료지만 컴퓨팅이 없어 실행·터미널을 쓸 수 없다.
