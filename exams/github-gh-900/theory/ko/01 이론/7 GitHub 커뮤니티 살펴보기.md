# 도메인 7　GitHub 커뮤니티 살펴보기

**English** Domain 7: Explore the GitHub community  
**한국어 공식 안내서** GitHub 커뮤니티 살펴보기

도메인 7 (5–10%) · 목표 6개

오픈 소스와 GitHub Sponsors, GitHub의 오픈 소스 지원, 팔로우, Marketplace, InnerSource, 포크·템플릿·검색 가능한 리포지토리를 다룬다.

> [!abstract] 오픈 소스 참여
> Open-source engagement · 오픈 소스 참여

## 목표 7.1

**오픈 소스와 GitHub Sponsors의 이점을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe the benefits of open source and GitHub Sponsors
>
> 오픈 소스 및 GitHub 스폰서의 이점 설명

오픈 소스는 재사용·리뷰·투명성으로 품질과 학습을 높이고, Sponsors로 메인테이너를 일회성·매월 후원한다(개인 후원 수수료 없음).

관련 카드: [[LICENSE]] · [[오픈 소스와 GitHub Sponsors]]

## 목표 7.2

**GitHub가 오픈 소스 프로젝트를 지원하고 발전시키는 방식을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Explain how GitHub supports and advances open-source projects.
>
> GitHub가 오픈 소스 프로젝트를 지원하고 발전시키는 방법을 설명합니다.

공개 리포지토리에 무료 Actions(표준 러너), 코드·비밀 스캐닝, 디스커션, Pages, 토픽·Explore 같은 발견 기능을 제공해 오픈 소스를 지원한다.

관련 카드: [[디스커션]] · [[레이블과 마일스톤]] · [[GitHub Advanced Security]] · [[오픈 소스 지원 기능]] · [[오픈 소스 프로젝트 탐색]]

## 목표 7.3

**사용자와 조직을 팔로우해 활동 소식을 받는 방법을 식별한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Identify how to follow users and organizations to stay informed about activity.
>
> 사용자 및 조직을 따라 활동에 대한 정보를 유지하는 방법을 식별합니다.

사람·조직을 팔로우하면 공개 활동이 개인 대시보드에 보인다. 리포지토리 활동 알림은 워치로 받는다.

관련 카드: [[스타]] · [[팔로우와 워치]]

## 목표 7.4

**GitHub Marketplace와 그 용도를 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Describe the GitHub Marketplace and its purpose.
>
> GitHub Marketplace 및 해당 용도에 대해 설명합니다.

Marketplace는 Actions와 Apps를 찾고 설치·구매하는 디렉터리다. 판매는 조직 소유 앱만 가능하다.

관련 카드: [[GitHub Marketplace]]

## 목표 7.5

**InnerSource가 조직 안에서 오픈 소스 원칙을 적용하는 방식을 설명한다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Explain how InnerSource applies open-source principles within organizations.
>
> InnerSource가 조직 내에서 오픈 소스 원칙을 적용하는 방법을 설명합니다.

InnerSource는 조직 내부 소프트웨어에 오픈 소스 관행을 적용해 재사용을 늘리고 사일로를 줄인다. 코드를 외부에 공개하지 않는다(internal 공개 범위).

관련 카드: [[InnerSource]]

## 목표 7.6

**협업을 촉진하려면 포크, 템플릿, 검색 가능한 리포지토리를 언제 쓰는지 안다**

> [!quote]- 공식 원문 (English / 한국어 공식 안내서)
> Recognize when to use forks, templates, and discoverable repositories to promote collaboration.
>
> 포크, 템플릿 및 검색 가능한 리포지토리를 사용하여 협업을 촉진하는 시기를 인식합니다.

쓰기 권한 없이 기여하려면 포크, 같은 구조로 새로 시작하려면 템플릿, 기여자를 모으려면 검색 가능하게(토픽·README·good first issue) 정리한다.

관련 카드: [[템플릿 리포지토리]] · [[포크]] · [[오픈 소스 프로젝트 탐색]]

## 요약
- Sponsors: 개인 후원 수수료 0, 조직 후원 최대 6%.
- 팔로우 = 대시보드, 워치 = 알림, 스타 = 북마크.
- InnerSource = 방화벽 안의 오픈 소스.
- 포크 = PR 가능, 템플릿 = 새 이력.

## 이 도메인의 카드
- [[오픈 소스와 GitHub Sponsors]] — 오픈 소스는 누구나 코드를 보고 쓰고 고치고 기여할 수 있게 공개하는 방식이고, GitHub Sponsors는 그런 개발자·조직을 금전적으로 후원하는 기능이다.
- [[오픈 소스 지원 기능]] — GitHub가 공개 리포지토리에 무료로 주는 자동화·보안·커뮤니티 기능으로 오픈 소스 프로젝트를 지원하는 방식.
- [[팔로우와 워치]] — 팔로우는 사람·조직의 공개 활동을 개인 대시보드에서 보는 것이고, 워치는 리포지토리 활동을 알림으로 받는 것이다.
- [[GitHub Marketplace]] — GitHub 워크플로를 확장하는 GitHub Actions와 앱(Apps)을 찾고 설치·구매하는 디렉터리.
- [[InnerSource]] — 조직 내부의 독점 소프트웨어를 오픈 소스 방식(공개적 협업, 리뷰, 문서화)으로 개발하는 관행. "방화벽 안의 오픈 소스".
- [[포크]] — 다른 리포지토리를 내 계정·조직으로 복사한 GitHub 상의 리포지토리. 쓰기 권한이 없는 프로젝트에 변경을 제안하거나 내 아이디어의 출발점으로 쓴다.
- [[오픈 소스 프로젝트 탐색]] — 토픽·Explore·Trending·레이블로 기여할 프로젝트를 찾고, 내 리포지토리는 같은 장치로 발견되기 쉽게 만드는 방법.
