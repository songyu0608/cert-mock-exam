# 0 시험 개요와 출제 범위

GitHub Foundations(GH-900)는 Git과 GitHub의 기본 개념, 리포지토리, 협업, 최신 개발 방식(Actions·Copilot·Codespaces), 프로젝트 관리, 보안·관리, 커뮤니티에 대한 기초 지식을 검증하는 입문(Beginner) 자격증이다. Microsoft Learn이 운영한다.

## 시험 정보 (Microsoft Learn, 2026-11-07 확인)
| 항목 | 내용 |
|---|---|
| 시험 코드 | GH-900 |
| 수준 | Beginner(입문) |
| 시간 | 100분 |
| 합격 점수 | 700점 |
| 문항 수 | 안내서·자격증 페이지에 없음 |

| 시험 언어 | 영어, 스페인어, 포르투갈어(브라질), 한국어, 일본어 |
| 현지화 반영 | 영어판 변경은 약 8주 뒤 현지화 버전에 반영. 원하는 언어가 없으면 30분 추가 요청 가능 |

| 재응시 | 첫 응시 후 24시간 뒤부터 |

## 공부 포인트
- 안내서는 도메인별 목표 문구만 제시한다. 목표 번호(1.1 등)는 이 볼트가 붙였다.
- 안내서에는 샘플 문제가 없다. 이 볼트는 공식 문제를 싣지 않았고, 카드의 셀프 체크와 비교 노트의 질문은 이 볼트가 만든 것이다.
- 한국어 공식 안내서는 기계 번역으로 보인다(예: issues → 문제, pull request → 끌어오기 요청, passkeys → 암호). 한국어로 응시하면 문제에 이런 표기가 나올 수 있으니 [[용어 대조표]]를 본다. 실제 시험의 한국어 표기는 확인하지 못했다.
- 카드 내용은 GitHub 공식 문서(docs.github.com)에서 보충했고 카드마다 근거 링크를 달았다.
- 요금제 가격, Copilot 기능·모델, Actions 포함 사용량은 자주 바뀐다. "변동 정보"로 표시했다.
