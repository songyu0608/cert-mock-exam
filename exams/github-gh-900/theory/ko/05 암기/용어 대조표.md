# 용어 대조표

이 볼트의 표기와 한국어 공식 안내서(Microsoft Learn 한국어 페이지) 표기, 영어 원문을 짝지었다. 한국어 공식 안내서는 기계 번역으로 보여 GitHub 화면의 용어와 다른 경우가 많다.

> [!info] 공식 표시
> ◎ = 한국어 공식 안내서와 영어 안내서 양쪽에 그 표기가 그대로 있음, ○ = 한쪽에만 있음, · = 안내서에 없음. 자동 대조이며 공백·괄호·대소문자는 무시했다.
