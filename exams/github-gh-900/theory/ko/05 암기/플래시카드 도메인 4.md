# 플래시카드 도메인 4　최신 개발 방식 적용

#flashcards/gh-900/d4

형식: `질문::답` (Spaced Repetition 플러그인). 플러그인이 없어도 한 줄씩 읽으면 된다.

## 개념 확인
워크플로 파일 위치는?::.github/workflows 폴더의 YAML 파일
잡의 기본 실행 방식은?::병렬(의존성을 설정하면 순차)
공개 리포지토리에서 표준 GitHub 호스팅 러너 비용은?::무료
IDE에서 파일 선택·편집·터미널 명령 제안을 반복하며 작업을 끝내는 모드는?::에이전트 모드(Agent Mode)
이슈를 할당받아 브랜치에서 작업하고 PR을 만드는 Copilot 기능은?::클라우드 에이전트(이전 이름 코딩 에이전트)
조직 구성원 Copilot을 중앙 관리·정책 제어하는 최소 요금제는?::Copilot Business
Copilot Enterprise의 대상은?::GitHub Enterprise Cloud를 쓰는 엔터프라이즈
개발 컨테이너 설정 파일 위치는?::.devcontainer/devcontainer.json 또는 루트의 .devcontainer.json
codespace의 기본 비활동 정지 시간은?::30분
정지된 codespace의 기본 보존 기간은?::30일
github.dev를 여는 단축키는?::. 키(같은 탭), > 키(새 탭)
github.dev에서 할 수 없는 것은?::빌드·실행·디버그, 통합 터미널

## 상황 → 판단
상황: PR마다 자동 테스트 → 정답은?::GitHub Actions(pull_request 이벤트)
상황: 새 이슈에 자동으로 레이블 → 정답은?::GitHub Actions(issues 이벤트)
상황: IDE에서 여러 파일 수정·터미널 명령까지 AI가 진행 → 정답은?::Copilot 에이전트 모드
상황: 이슈를 AI에 맡겨 PR을 받고 싶다 → 정답은?::Copilot 클라우드 에이전트(이슈를 Copilot에 할당)
상황: 조직이 직원 Copilot을 중앙 관리 → 정답은?::Copilot Business 이상
상황: 새 팀원이 곧바로 같은 개발 환경 → 정답은?::Codespaces + devcontainer.json
상황: 브라우저에서 오타만 빠르게 수정 → 정답은?::github.dev(. 키)
상황: 브라우저에서 코드 실행·디버그 → 정답은?::Codespaces
