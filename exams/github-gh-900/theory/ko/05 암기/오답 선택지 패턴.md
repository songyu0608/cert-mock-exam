# 오답 선택지 패턴

공식 문서와 반대되어 오답이 되기 쉬운 진술을 모았다(이 볼트의 정리).

| 오답이 되기 쉬운 진술 | 맞는 쪽 | 노트 |
|---|---|---|
| Git과 GitHub는 같은 것 | Git은 도구, GitHub는 호스팅·협업 플랫폼 | [[Git과 GitHub의 차이]] |
| 조직 계정으로 직접 로그인한다 | 조직에는 로그인하지 않는다. 개인 계정으로 소속 | [[GitHub 계정 유형]] |
| 브랜치를 지우면 PR 이력도 사라진다 | PR·커밋 이력은 남고 브랜치는 복원 가능 | [[GitHub 플로]] |
| 라이선스가 없으면 자유롭게 써도 된다 | 기본 저작권 적용, 재사용 권리 없음 | [[LICENSE]] |
| 템플릿에서 만든 리포지토리에서 원본으로 PR | 이력이 무관해 불가. PR이 목적이면 포크 | [[템플릿 리포지토리]] |
| 웹 업로드로 100 MiB 파일 | 웹은 파일당 25 MiB, 명령줄 100 MiB, 초과는 LFS | [[파일 추가와 관리]] |
| 보관된 리포지토리에 이슈를 계속 단다 | 보관은 모두에게 읽기 전용 | [[리포지토리 보관]] |
| 기능 브랜치로 가는 PR에 Closes #1을 써도 이슈가 닫힌다 | 기본 브랜치 대상일 때만 | [[PR과 이슈 연결]] |
| 비밀 gist는 비공개다 | URL을 알면 누구나 볼 수 있다 | [[Gist]] |
| 위키는 항상 검색 엔진에 색인된다 | 스타 500개 이상 + 공개 편집 해제일 때만 | [[위키]] |
| Unwatch하면 알림이 전혀 오지 않는다 | @멘션·참여 알림은 온다 | [[팔로우와 워치]] |
| 스타를 주면 알림을 받는다 | 알림은 워치 | [[스타]] |
| github.dev에서 테스트 실행 | 컴퓨팅이 없어 불가. Codespaces | [[github.dev]] |
| Codespaces 탭을 닫으면 바로 정지 | 비활동 시간 초과(기본 30분)나 직접 정지 | [[GitHub Codespaces]] |
| Copilot 에이전트 모드가 사람 승인 없이 병합 | 편집·명령을 제안해 승인받고, 클라우드 에이전트도 PR로 리뷰받음 | [[GitHub Copilot 기능]] |
| 개인 Pro 구독으로 조직 Copilot 정책 관리 | 정책 관리는 Business·Enterprise | [[GitHub Copilot 요금제]] |
| Copilot 요금제와 GitHub 요금제는 같다 | 별개 구독 | [[GitHub Copilot 요금제]] |
| 프로젝트에서 바꾼 담당자가 이슈엔 반영 안 됨 | 양방향 동기화 | [[GitHub Projects]] |
| Triage 권한으로 레이블 생성 | 생성은 Write, Triage는 적용·해제 | [[레이블과 마일스톤]] |
| 저장된 답글은 팀과 공유된다 | 개인 계정에 속함 | [[저장된 답글]] |
| 담당자를 무제한 지정 | 최대 10명 | [[담당자]] |
| 2FA를 잃으면 GitHub Support가 복구해 준다 | 복구 코드 등 복구 수단 필요, Support는 복구 불가 | [[2단계 인증과 패스키]] |
| Maintain 역할로 브랜치 보호 규칙 설정 | 보호 규칙·공개 범위 변경은 Admin | [[리포지토리 역할]] |
| 조직 소유자는 한 명이면 충분 | 2명 이상 권장 | [[조직 역할]] |
| EMU 사용자가 공개 리포지토리를 만든다 | 공개 콘텐츠 생성·외부 협업 불가 | [[EMU(Enterprise Managed Users)]] |
| 공개 → 비공개 전환 시 공개 포크도 비공개가 된다 | 포크는 분리되어 공개로 남는다 | [[리포지토리 공개 범위]] |
| 한 브랜치에 보호 규칙 여러 개 | 하나만. 겹치려면 룰셋 | [[브랜치 보호 규칙과 룰셋]] |
| 비밀 팀을 중첩할 수 있다 | 비밀 팀은 중첩 불가 | [[팀]] |
| 개인 계정 후원에도 수수료가 붙는다 | 개인 후원은 수수료 없음, 조직 후원 최대 6% | [[오픈 소스와 GitHub Sponsors]] |
| Marketplace에서 개인 소유 앱 판매 | 판매는 조직 소유 앱만 | [[GitHub Marketplace]] |
| InnerSource는 코드를 public으로 공개 | 조직 안에서만 공개(internal) | [[InnerSource]] |
| 기여는 코드 PR만 인정 | 문서·이슈 분류 등도 기여 | [[오픈 소스 프로젝트 탐색]] |
